# Windows update quality

# Summary

Survey data showed low satisfaction, and the October 2018 update's file deletion and driver issues reinforced advice to defer feature updates and keep images.

September 2026's 974-fix update broke RDS, domain trust (Machine Identity Isolation), Excel copy/paste, USB audio and some boots (#1097).
