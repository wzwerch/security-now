# JavaScript ransomware

# Summary

Pure-JavaScript crypto ransomware uses public crypto libraries and needs no downloaded executable, evading border scanning. Hiding extensions and the Windows Script Host association help it succeed; Steve advised unhiding extensions and opening .js files in Notepad.
