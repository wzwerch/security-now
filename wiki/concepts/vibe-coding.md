# AI-assisted (vibe) coding

# Summary

Leo's Claude Code demos, listener testimonials, Andrew Ng's free course and skeptical views (Uncle Bob Martin, defect-rate statistics) frame the debate; Steve says not yet for his own code.

Studies cited by FLAWED: AI-assisted developers introduce security flaws at 10 times the rate; nearly half of AI-generated code contains known vulnerabilities without security guidance (#1094).
