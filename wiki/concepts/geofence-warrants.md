# Geofence warrants

# Summary

Police use staged requests to Google's Sensorvault, starting with anonymous device IDs and ending with identities, which has misidentified innocents.

Google's Sensorvault location archive returned about 1,500 device IDs for arson cases in Milwaukee; critics call the sweeps overbroad and note false arrests.
