# Z-Wave

# Summary

Z-Wave is controlled by Sigma Designs with an SDK under NDA. Researchers using software-defined radio and firmware reverse engineering found a protocol mistake that allowed unlocking an AES-protected door lock without keys. Steve argued closed designs hinder security review.
