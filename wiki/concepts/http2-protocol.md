# HTTP/2

# Summary

One connection per server, binary frames with stream IDs, multiplexing, priorities, header compression and server push; browsers and servers were adopting it in early 2015, with encryption optional in the spec but universal in practice, and SPDY to be dropped from Chrome in 2016.
