# Default credentials

# Summary

Steve argues devices should generate a random password at setup; Unitronics PLCs with password 1111 were hacked.

Japan's NICT scan, Ubiquiti devices and botnet servers all show it.

Ubiquiti modems and InnGate routers exposed management with weak defaults.

Wifatch spread through default Telnet passwords, DNS Changer malware targeted routers with defaults, and Steve advises changing router logins.
