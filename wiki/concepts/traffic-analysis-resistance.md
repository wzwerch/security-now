# Traffic-analysis-resistant anonymity

# Summary

Tor's weakness is a state observer correlating entry and exit traffic. Riffle shuffles equal traffic from every user to resist analysis but would be extremely slow.

VPN servers and Tor; bursty web traffic aids correlation.
