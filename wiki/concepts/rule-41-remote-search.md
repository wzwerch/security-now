# Rule 41 remote search warrants

# Summary

The change lets a single warrant authorise remote access to many computers whose location is hidden, notably botnet victims, and took effect through a rules process without legislation. Steve sees the need but dislikes the lack of oversight, suggesting ISP egress filtering and service termination instead.
