# Web PKI and certificate authority trust

# Summary

The Entrust case showed root programs can only trust or distrust, and that repeated rule violations and non-revocation can end a CA's browser business.

Episodes cover Google's Symantec distrust plan, Let's Encrypt PayPal certificates, Chrome dropping the common name fallback and revocation weakness.

Loren Kohnfelder's 1978 MIT thesis introduced certificates and certificate revocation lists (#1093).
