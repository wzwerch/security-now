# Typosquatting

# Summary

The PyPI package 'Fabrice' imitated Fabric and was downloaded about 37,100 times over three years, stealing AWS keys. Public repositories like PyPI and NPM struggle to keep malicious packages out.

Chrome tested suggesting the correct domain for typos.

Cited as the model for HalluSquatting, recalling the 2016 study with 214 booby-trapped packages (#1087).
