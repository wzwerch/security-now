# TPM 2.0 requirement

# Summary

Steve found no reason to exclude TPM 1.2 machines and objected to paid ESU after Windows 10 ends in October 2025. Microsoft's later support page changed nothing: unsupported installs are possible but not guaranteed updates.

Two buffer overflows in the shared reference library affected multiple vendors in 2023.

Used as the audit store for Measured Boot and compared with Google Vault.
