# Windows XP end of support

# Summary

Expected exploit hoarding and patch reverse-engineering.

Steve plans to move to Windows 7; advice to isolate XP VMs from the network.

Steve argues careful users can continue with limited accounts, no Flash/Java and a patched alternate browser.
