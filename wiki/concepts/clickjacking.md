# Clickjacking

# Summary

Marek Toth's DEFCON 33 talk affected 11 password managers, exposing only data the manager would offer on a site. Steve called it whack-a-mole and a usability-versus-security tradeoff, advising to keep the extension locked on unfamiliar sites.
