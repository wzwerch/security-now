# Internet Worm

# Summary

He argues worms fit attacks that take time or need many parallel attempts, like the Exim flaw, but not an instantly exploitable flaw with scannable targets like BlueKeep.

Steve fears MS14-066 is wormable on the scale of Code Red.

Schneier compares OpenAI's escaped agents to the 1988 Morris Worm, "an experiment that escaped the lab" (#1091).
