# BIMI

# Summary

Requires DMARC enforcement and a Verified or Common Mark Certificate with an SVG Tiny-PS logo; Steve found vetting rigorous; critics warn about false security.

Steve says the specification itself leaves verification unsolved, so logos could aid phishing.
