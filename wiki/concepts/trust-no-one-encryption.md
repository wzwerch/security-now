# Trust No One (TNO) encryption

# Summary

Steve's criterion for cloud sync: encrypt before upload, keep keys local, support versioning and secure sharing.

ProtonMail and SQRL are examples where recovery is the user's burden.

Steve conceded any cloud service reachable with a human password is below strict 2^256 TNO.

Steve's maxim: do not delegate security because delegates can be compelled.

Price cuts prompted a planned roundup.
