# Subresource Integrity

# Summary

Allows safe CDN use for static, version-pinned files; incompatible with per-browser dynamic responses like Polyfill.io's, and requires manual updates when bugs are fixed.

Steve describes SRI as protection against a tampered library even over HTTPS.
