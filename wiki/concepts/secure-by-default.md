# Secure by default

# Summary

Cisco Resilient Infrastructure pledge; exposed MongoDB shows costs of insecure defaults.

AWS will enable S3 Block Public Access by default, VMware disabled OpenSLP by default after ESXiArgs, and Android 14 blocks apps targeting old API levels.
