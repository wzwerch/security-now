# OpenAI Preparedness Framework

# Summary

Defines a Critical cyber level for models that autonomously find and exploit zero-days in hardened systems; Astra may reach it, prompting paused work and stricter controls (#1091).

GPT-6 Astra became the first model OpenAI treats as Critical for cyber (#1095).
