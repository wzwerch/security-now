# ZigBee

# Summary

ZigBee Home Automation 1.2 uses a well-known default link key to hand out network keys at join time and supports insecure rejoin for sleepy devices, making spoofed joining and key retrieval feasible. ZigBee 3.0 moves to per-device install codes delivered out of band.
