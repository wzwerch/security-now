# Browser extension security

# Summary

Palant's critique of the Chrome Web Store and the Cyberhaven compromise (at least 35 extensions, over a million users) lead to Steve's advice: keep extensions to a minimum, favour well-known ones, decide per extension.

Episode 938 reports plaintext passwords exposed to extensions on major sites and a proof-of-concept extension that passed Chrome Web Store review.

The Hover Zoom+ author logged over 165 purchase offers; the Under New Management extension flags developer changes, and loading unpacked extensions freezes a vetted version.

Mozilla banned obfuscated add-on code after Chrome and Firefox private windows disabled extensions by default.
