# Attack surface

# Summary

Antivirus, font renderers, media parsers and ad scripts illustrate how security software and convenience features enlarge attack surface; Steve cites Tavis Ormandy's antivirus findings.

Used to explain StageFright, HOLA VPN peers, exposed PA and vendor services and local web servers.
