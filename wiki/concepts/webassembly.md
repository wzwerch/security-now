# WebAssembly

# Summary

Now in all major browsers; it enables fast code such as in-browser miners.

Precompiled stack-machine code that starts quickly and approaches but does not equal native speed; unsuited for efficient mining.

Its speed conflicts with Spectre timer mitigations, so SharedArrayBuffer support was withheld.

Google, Apple, Microsoft and Mozilla announced joint work.
