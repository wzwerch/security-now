# Biometric authentication

# Summary

Match-on-chip sensors can still be spoofed when the host link is unprotected.

A 3D-printed print unlocked a Galaxy S10; Steve calls biometrics convenient soft signals.

MasterPrints, listener fingerprint tests and Samsung's easily fooled face unlock show fuzzy-match weaknesses.

Steve warns fingerprints cannot be changed and are convenience, not secrets.

Touch ID is a username-like convenience control; fingers can be compelled.
