# Warrant canary

# Summary

Conceived by Steve Schear in 2002, canaries avoid illegal gag-order disclosure by dropping a positive assurance. CanaryTail proposes a signed JSON file with flags for warrants, gag orders, duress and a seppuku pledge, bound to a Bitcoin block hash.
