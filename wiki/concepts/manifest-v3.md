# Manifest V3

# Summary

Manifest V3 bans remotely hosted code but removes the API the full uBlock Origin needs; Mozilla reaffirmed support for both V2 and V3.

Removes capabilities content blockers rely on; Chrome policy ExtensionManifestV2Availability delays MV2 to June 2025; Firefox keeps MV2.
