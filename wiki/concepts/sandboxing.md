# Sandboxing

# Summary

Windows Sandbox is container-like, so host compromise carries into it.

Sandboxie, browser sandboxes, VM-based browsing and Qubes OS compared; Sandboxie by default allows reads, so file theft is possible.

Adobe's PDF sandbox ended PDF exploit waves; Java sandbox bypasses continue.
