# Model Context Protocol

# Summary

GTG-1002 drove open-source pentest tools via MCP servers; Leo and Vint Cerf cite protocols as emerging standards.

1Password and Bitwarden both offer MCP servers for governed credential access by agents (#1088).

Unit 42 advises inventorying every MCP gateway and AI integration after an agentic intrusion (#1101).

Binary Ninja's MCP server let an AI agent find a USB encryption tool's fixed key in seven minutes (#1103).
