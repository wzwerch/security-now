# Formal verification

# Summary

Steve argues flawless software is possible if hardware is correct, though practical systems must handle messy I/O.

Purdue researchers' formal model of Bluetooth Low Energy found BLESA, illustrating Steve's argument that complex protocols need verification.

Galois argues proofs, now scalable with computer help, can eliminate bug classes in embedded vehicle software.
