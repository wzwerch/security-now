# Hypervisor-Protected Code Integrity

# Summary

Enabled by default on qualifying Windows 11 PCs from October 2026; blocks kernel shellcode, driver-signature bypasses and kernel patching, with little overhead on CPUs with MBEC/GMET (#1095).
