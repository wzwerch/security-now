# Steganography

# Summary

GhostPoster extensions hid JavaScript loaders after marker bytes in PNG icons to evade store reviews; the Zombie ZIP trick is a similar scanner-evasion idea using a false compression flag.

Steve explains hiding encrypted data in least significant bits of uncompressed images; limited bandwidth and defeated by compression.
