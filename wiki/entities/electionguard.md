# ElectionGuard

# Summary

ElectionGuard gives voters a tracking code to confirm their ballot was counted unaltered while keeping votes private, with third-party verifier apps. Microsoft planned a GitHub release and partnerships with voting machine makers.

Offers end-to-end verifiable elections via homomorphic encryption; a bug bounty of up to $15,000 started in October 2019.

ElectionGuard was piloted in Fulton, Wisconsin on VotingWorks machines in February 2020, giving voters tracking codes and allowing third-party verification of encrypted tallies.
