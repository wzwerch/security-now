# Google

# Summary

Topics include Gmail spam misfires, Drive ransomware detection, Android developer registration, Play Store compliance with Texas SB2420, Chrome bounties and a free ACME certificate service.

Google features through Chrome features and zero-days, Android Key Verifier, the Masked Domain List, threat researchers targeted by Scattered LapSus Hunters, the DDR5 Rowhammer study, the search antitrust remedies ruling, and a planned cyber disruption unit.

Google features through Project Zero disclosures, Passkeys, the .zip TLD launch, Privacy Sandbox, bug bounty programs, Assured OSS, a cryptomining protection offer for Google Cloud and the joint tracker standard with Apple.

Discussed in episodes 932-942 for the Web Environment Integrity proposal, the Topics API in Chrome and Android, Chrome's HTTPS-First plans, its Web Store review gaps and the TAG team's spyware forensics with Citizen Lab.

Discussed for Chrome's Incognito settlement, the Privacy Sandbox and its repeated delay of third-party cookie removal, Android 15 app quarantine, Project Zero's 90-day disclosure policy and the zero-day count it reported for 2023.

Topics include Chrome restrictions, Project Zero analyses, Android package-visibility limits, funding Linux security maintainers and FLoC.

Items: Open Source Maintenance Crew and security pledges, Play Store malware, retpoline mitigation, Privacy Sandbox delays, a Russian fine of about $358M, and Half-Double Rowhammer research.

2019 coverage includes Trusted Types, Adiantum, Android security, Sensorvault and auto-delete location controls.

Runs Project Zero, Chrome, Android and the Privacy Sandbox proposals; expanded bug bounty programs and shipped a fast Chrome zero-day fix.

Google appeared for FuzzBench, Chrome release changes and notification-abuse rules, the Android update gap, Messages gaining encrypted RCS and its Project Zero finding in Samsung phones.

Google features through Chrome policy changes (HTTP warnings, cookie caps, HPKP removal, extension installs), Certificate Transparency, RCS chat, Firebase and Project Zero research.

Topics include location history disclosures, Project Dragonfly, Titan keys, the Google+ API bug and shutdown, Chrome policies, and its quick disclosure of the Fortnite installer flaw.

Episodes cover Google's CNNIC decision, search-history download, SHA-1 certificates on its own mail servers, Project Vault, Project Soli and a false malware flag on GRC.

2048-bit certificate migration, Street View fine, Play app abuse and QUIC.

Reports of Drive encryption; ZVE critique; Wi-Fi password sync; Project Shield.

Engineers reacted angrily to the NSA tap of its data-centre links; moved to 2048-bit keys and forward secrecy; proxies images in Gmail; U2F tokens with Yubico.

Made Gmail HTTPS-only, cut cloud storage prices, discovered Heartbleed, and downplayed revocation checking in Chrome.

Drove SHA-1 deprecation in Chrome, Certificate Transparency, FIDO U2F security keys and Simply Secure, and removed the Zedo malvertiser.
