# Akira

# Summary

Akira and Fog were found exploiting the SonicWall CVE-2024-40766 flaw (a Japanese researcher found 46 percent of their victims run SonicWall). In one case Akira encrypted servers via an unmonitored Linux webcam after EDR blocked its Windows payload.
