# Big Sleep

# Summary

Found an exploitable SQLite stack buffer underflow in a development branch before release, billed as the first public AI-found real-world memory-safety bug.

Part of the lineage (with Naptime and a Gemini harness) behind Chrome's AI-driven vulnerability pipeline (#1091).
