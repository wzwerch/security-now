# Oracle

# Summary

Oracle denied a legacy Oracle Cloud breach claimed by actor rose87168, later confirming only verbally; CISA issued guidance before Oracle did (SN 1021, 1022).

Fixed 42 then 40 Java flaws, added signed-applet prompts, changed Java version numbering, and fought Google over API copyright.

Forgeable Java warning dialogs and unpatched Java 6.

Java installers changed plugin defaults; Oracle won the appeals ruling on Java API copyright.

Moved from quarterly to monthly patches because of AI bug discovery (#1089).
