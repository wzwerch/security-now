# Zoom

# Summary

Zoom grew from about 10 million to 200 million daily users in spring 2020. Episodes covered Zoom bombing, a Windows UNC link credential leak, ECB-mode encryption and key routing through China, path traversal flaws in chat, and the company's rapid response: security consultants, Keybase acquisition and a four-phase end-to-end encryption plan, followed by confusing statements about which users would get it.

In mid 2020 Zoom drew scrutiny for its end-to-end encryption plans, a Windows 7 remote code flaw micropatched by 0patch, vanity-URL spoofing, six-digit meeting PINs without rate limiting, and then added two-factor authentication.

A Security found a screen-sharing annotation flaw allowing silent takeover of call participants' devices with fewer than 20 AI prompts; fixed (#1092).
