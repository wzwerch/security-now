# Comodo

# Summary

Comodo issued a certificate to a researcher whose domain published a CAA record naming Let's Encrypt, a day after CAA checking became mandatory for CAs.

Its security suite installed a Chromium-based browser with same-origin policy disabled and a support tool with a default-on remote desktop server. Ormandy found Comodo fixed only the specific proof of concept.
