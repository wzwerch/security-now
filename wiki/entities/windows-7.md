# Windows 7

# Summary

The episodes follow Windows 7's SHA-2 update requirement, paid Extended Security Updates for enterprises, Azure Windows Virtual Desktop support through 2023 and the end-of-support notification dialog that began appearing in April 2019.

Windows 7 was still on roughly one in four desktops when Microsoft ended regular updates on January 14, 2020. The show followed the final updates, broken last patches, paid Extended Security Updates, the BypassESU hack, continuing Security Essentials signatures and third-party 0patch micropatches.

Microsoft's January 2018 Meltdown patch for 64-bit Windows 7 mistakenly made kernel memory accessible to user programs until KB4100480 in late March. Steve also urges Microsoft to backport efficient mitigations to Windows 7.
