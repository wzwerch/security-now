# SandboxEscaper

# Summary

SandboxEscaper posted proof-of-concept local privilege escalation exploits for Windows 10 without notifying Microsoft, citing frustration with the industry and the FBI. Steve notes the exploits were limited in reach but useful when chained, and that Microsoft quickly removed the code from GitHub.

Known for frequent Windows kernel and privilege escalation disclosures, SandboxEscaper announced a goal of working at Microsoft and was reported hired in April 2020, which Steve welcomed.

Posted a task-scheduler privilege escalation on GitHub without notifying Microsoft; ESET saw PowerPool use it within two days and GandCrab 5 later adopted it.
