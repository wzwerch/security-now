# VUSec (Vrije Universiteit Amsterdam)

# Summary

Steve calls the group's attacks sublime hacks. The ANC attack of SN 600 used cache timing to learn memory layout from JavaScript.

Disclosed Branch Target Reuse, a Spectre-v2 attack on JIT engines in Linux cBPF, GraalVM and SpiderMonkey (#1099).
