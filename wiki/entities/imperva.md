# Imperva

# Summary

Imperva observed attacks on Drupal sites, hundreds of exposed Docker hosts running cryptominers, and a DDoS built on the HTML ping attribute against gaming sites.

Imperva documented the Kitty campaign against Drupal, UPnP port translation to evade DDoS filters, and SSH key planting on exposed Redis servers.
