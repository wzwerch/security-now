# npm

# Summary

Episodes cover malicious package waves, a GlueStack RAT compromise, wiper packages posing as WhatsApp libraries, the Nx compromise that weaponized AI CLI tools, and the 8 September 2025 phishing-driven compromise of 18 packages with over two billion weekly downloads. Steve calls the model a castle of cards.

Several 2021 compromises (UAParser.js, coa, rc) used hijacked maintainer accounts and install scripts.
