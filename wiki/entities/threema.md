# Threema

# Summary

Threema added end-to-end encrypted video calls in 2020 (fixing WebRTC metadata leaks), then announced plans to open-source its apps with reproducible builds and add multi-device support.

Threema passed an independent audit in 2015, and Steve used it as an example of secure but less convenient messaging that would survive weakened mainstream apps.

Three-dot in-person key verification praised.

Steve's pick in 427: about two dollars, server cannot read messages, three-level key verification by QR scan.

Praised as a correctly designed trust-no-one messenger using Curve25519 keys, 14-day relay storage and colour-coded verification dots.

Recommended for end-to-end trust via QR verification; an iOS PIN-retry bug allowed unlimited guesses.

Praised for putting identity verification up front, though closed source.
