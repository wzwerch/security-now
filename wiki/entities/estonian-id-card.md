# Estonian ID card

# Summary

Estonia issued about 760,000 Infineon-based ID cards used for authentication and legally binding signatures. After ROCA, the police and border guard suspended them and the country migrated to elliptic-curve keys via remote updates; timestamped signatures kept older documents trustworthy.
