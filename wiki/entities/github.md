# GitHub

# Summary

PHP made GitHub canonical with mandatory two-factor in 2021, and GitHub removed an early ProxyLogon proof of concept under its active-exploit policy.

GitHub had its own plaintext password logging incident and was among the first to disable TLS 1.0/1.1.

GitHub hosted projects helping users bypass Chinese censorship and came under a large JavaScript-based DDoS; China had earlier blocked it briefly before developers' outcry.
