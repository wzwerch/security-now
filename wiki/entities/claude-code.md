# Claude Code

# Summary

Leo built a Rust RSS reader with it live on air and listeners reported dramatic productivity gains. Steve says he will not use AI for his own production code yet; Uncle Bob Martin warns of regressions, and attackers use fake download pages as malware lures.

One of six coding assistants vulnerable to Wiz's GhostApproval symlink attack (#1087).

Used with Opus 4.8 in the FLAWED patching study and to build its test harness (#1094).
