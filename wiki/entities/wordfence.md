# Wordfence

# Summary

It blocked 29,300+ exploit attempts and credited the plugin's unsanitised eval() use.

Wordfence observed active exploitation of the Fancy Product Designer plugin zero-day starting January 2021 and withheld details until sites patched.

Reported the Epsilon Framework attack wave, the Login/Signup Popup family and WP HTML Mail issues covered across several episodes.

Along with Patchstack, Wordfence is part of a sub-industry selling virtual patches for WordPress plugin flaws.
