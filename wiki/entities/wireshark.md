# Wireshark

# Summary

Wireshark 3.0 replaced the WinPcap driver with Npcap, added localhost loopback capture and Wi-Fi capture without special hardware, and can decrypt TLS given a server key. Steve used it while building ShieldsUP! and his DNS spoofability test.
