# Tesla

# Summary

In 2019 Pwn2Own added a Tesla Model 3 category, and the infotainment browser fell to a JIT bug. Tencent Keen Security Lab also showed steering control via the Autopilot ECU and ways to trick camera-based wipers and lane recognition. Steve stressed that headlines claiming cars could be steered into oncoming traffic were exaggerated.

A Russian national offered a Tesla employee up to one million dollars to install malware; the employee informed Tesla and helped the FBI build a case.

Tesla patched the Model X key fob update flaw over the air after Lennert Wouters reported it.

RedLock found Tesla's unprotected Kubernetes console exposing cloud credentials and hosting a stealthy miner.

Tesla published safe-harbor terms for registered researchers in September 2018. The same week KU Leuven showed that Model S key fobs using a 40-bit cipher could be cloned in seconds, leading to fob upgrades and an optional PIN-to-drive.
