# Windows 11

# Summary

Topics included the TPM 2.0 requirement (unchanged despite headlines), Admin Protection replacing the UAC token split, the return of Recall, the removal of the bypassnro script, and the end of Windows 10 support in October 2025.

Episode 942 notes passkey support via Windows Hello and new Custom App Control and firewall features.

The show tracked the TPM 2.0 and CPU rules, the registry bypass, early bugs and Microsoft's mixed messages about updates for unsupported hardware.

Items in this batch: accidental offering of 22H2 to unsupported PCs, a default account-lockout policy against RDP brute force, VAES encryption bugs that damaged data, and an SMB server remote code execution bug only in Windows 11.
