# Wiz Research

# Summary

Discovered the Azure SAS token exposure of 38 TB in Microsoft's AI GitHub repository (ep. 941).

Published GhostApproval, a symlink trust-boundary gap in six AI coding assistants (#1087).

Wiz launched red, blue and green security agents for attack simulation, investigation and remediation (#1088).

Reported active wp2shell exploitation with web shells, including a 150 KB fake CMSmap plugin (#1089).

Independently discovered and reported the PHP2Shell vulnerabilities (#1102).
