# Thunderbird / Thunderbird Pro

# Summary

SN 1021 covers Thunderbird Pro: Thundermail email with bring-your-own-domain, Send (encrypted file sharing), Appointment scheduling and Assist AI, offered first under paid tiers.

Mozilla announced Microsoft Exchange email support for summer 2024, with new mail code written in Rust for memory safety.

Steve urged updating to 52.5.2 to fix a critical buffer overflow.
