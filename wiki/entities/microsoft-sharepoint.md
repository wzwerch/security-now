# Microsoft SharePoint

# Summary

On-premises SharePoint Server 2016 and 2019 was hit in July 2025 by the ToolShell zero-day chain after Microsoft's first Patch Tuesday fix for the Pwn2Own Berlin bugs was bypassable. More than 400 organizations, including US federal agencies, were compromised and machine keys had to be rotated.

ProPublica reported SharePoint on-premises code is maintained by a China-based Microsoft team supervised by a US digital escort; Microsoft says the work is moving. Steve questions whether the incomplete first patch could have been deliberate. A listener explained why enterprises need weeks to patch on-prem SharePoint. Microsoft ends on-prem support in July 2026.
