# GitHub Actions

# Summary

After the Trivy, Cisco and LiteLLM incidents GitHub said it would accelerate planned Actions security features.

Basis of GitHub Agentic Workflows, which Noma Security's GitLost attack abused via prompt injection in issues (#1087).
