# Binarly

# Summary

Binarly's Transparency Platform unpacks UEFI images and found the untrusted AMI test Secure Boot Platform Key across nearly 850 device models.

Binarly's research showed shared firmware code from Insyde exposes many PC vendors to Secure Boot bypass and persistence.
