# Discord

# Summary

In September 2025 attackers reached Discord's Zendesk support instance through a compromised outsourced agent account, claiming 5.5 million users and 1.6 TB; Discord acknowledged about 70,000 government-ID photos collected for age appeals. Steve uses it as the main example of why retained ID scans are dangerous.
