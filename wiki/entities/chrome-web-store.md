# Chrome Web Store

# Summary

Wladimir Palant documented fake reviews, meaningless Featured badges, spam clusters and cloned or malicious extensions among roughly 135,000 listings. The Cyberhaven extension compromise showed the supply-chain risk of OAuth-phished developer accounts.

Announced bans on obfuscated code, restrictions on inline installation, more user host controls and mandatory two-step verification for developers in 2019.
