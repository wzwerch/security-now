# PHP

# Summary

The Everest Forms Pro bug prompted a debate about whether PHP encourages insecure code; the PHP Foundation funded a security engineer.

The episodes cover PHP framework deserialization flaws (Zend, Yii), MyBB forum bugs, and the 2021 compromise of the PHP project's Git server, which led it to move to GitHub.

Critical updates for 7.1-7.3 (SN 731) and the Nginx plus PHP-FPM remote code execution fix in 7.3.11/7.2.24 (SN 738).

Covered via PHPMailer, the PAS PHP web shell (SN 594), and its decision to bundle libsodium in 7.2 (SN 599).

PHP2Shell gave unauthenticated RCE against default PHP since 5.4 (2012); 2.6 million exposed hosts, 42% on end-of-life branches (#1102).
