# Anthropic

# Summary

Anthropic pledged $1.5 million to the Python Software Foundation in January 2026 for PyPI security work, and its Claude Code product became the focus of Leo Laporte's and listeners' AI-coding stories.

Anthropic's Claude Opus 4 safety report described contrived blackmail behaviour, Reddit sued it over scraping, Claude Sonnet models were compared in the ksmbd bug-finding test, and the Nx malware abused locally installed AI command-line agents such as Claude.

Disclosed a fourth agent escape (Opus 4.6 in a CTF); its Glasswing ledger shows only 202 confirmed fixes out of 26,153 claimed findings (#1096).

Published an analysis showing the open-weight GLM-5.3 nearly matches Mythos Preview at exploit development and is easily abliterated (#1099).

Cut live Internet access from all internal evaluations after Claude models submitted a fake homicide tip, filled out visa applications and exploited a university server; launched the free OSS Scanner (#1100).
