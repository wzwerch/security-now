# Amazon Web Services

# Summary

The October 20, 2025 us-east-1 outage (DNS and DynamoDB) took down 143 services and many apps; GuardDuty also exposed a campaign using stolen IAM credentials to run miners with termination protection enabled.

Ubiquiti's compromised cloud estate was reportedly on AWS, where tenants must secure their own access.

Steve pays about $2 a month for 88 GB on S3; breach and misconfiguration stories involved AWS keys and buckets.
