# Gibson Research Corporation

# Summary

GRC runs its own servers (Windows with IIS, assembly-language apps, PHP forums on an isolated host). Steve plans to release all source code into the public domain eventually (SN 1023).

GRC news in these episodes includes a rebuilt e-commerce system, strict DMARC alignment against spoofed mail, code signing and the mailing list.

Hosts the show's free tools such as InControl, which pins a Windows version to avoid forced upgrades, and ShieldsUP! port scanning.

Publishes SpinRite, DNS Benchmark and ValiDrive; plans email lists to replace Twitter.

GRC publishes the freeware and commercial tools discussed on the show and hosts the shortcut redirector grc.sc used for show links.

GRC added a Linux/Mac-friendly SpinRite boot image, rebuilt site search, announced an email list system to replace Twitter feedback, and tracked download rates for its freeware (ValiDrive, DNS Benchmark and others).

In June and July 2024 Steve launched GRC's own email system (about 4,300 subscribers growing to 7,500) built on nuevoMailer, with no open or click tracking after listener objections.

GRC runs ShieldsUP, the DNS Benchmark, Cookie Forensics, the revoked.grc.com test, shortcut service (grc.sc), and since 2024 a custom email system for the Security Now mailing list.

GRC hosts show shortcuts, ShieldsUP! and SpinRite 6.1 development.

Offers ShieldsUP! port tests, shortcut links such as grc.sc/854 for each episode, and the DNS Benchmark.

GRC released InControl for pinning Windows versions and pre-announced Never11; its fixed-IP firewall setup is Steve's example of IP-based service restriction.

Mid-2022 notes: SpinRite 6.1 re-architecture, grc.sc short links run on YOURLS, and ShieldsUP! lacking IPv6.

GRC makes SpinRite and free tools including ShieldsUP!, DNS Benchmark and Never10, and in 2019 relaunched its blog and prepared SQRL.

These episodes cover SQRL's release, the grc.sc link shortener, a calendar of OWASP talks and SpinRite plans.

GRC tools mentioned include ShieldsUP (including a UPnP exposure test), Cookie Forensics, the DNS Spoofability Test, the HTTPS fingerprinting page and revoked.grc.com for testing revocation.

GRC hosts ShieldsUP!, SpinRite, DNS Benchmark and SQRL; Steve describes keeping no web logs and preparing GDPR-conformant privacy text.

GRC hosts Steve's free tools, the show's transcripts and audio, a TrueCrypt archive, a port probe and the SQRL work. Steve discusses site matters such as redirects for old podcast links and a false malware flag on an old test file.

GRC hosts Security Now! show notes and transcripts, the Linkfarm, ShieldsUP! port tests and the SQRL work. Episodes mention its ecommerce system with strict attempt limits, a Cox warning triggered by DNS Benchmark use, and the SQRL presentation slides.

GRC moved to HTTPS-only with HSTS, added a certificate fingerprint service showing EV status, a SpinRite S.M.A.R.T. page and ShieldsUP UPnP exposure counts.

GRC went off the air when Level 3 retired the slave nameservers serving GRC.com; fixed by switching to new nameservers (#1089).
