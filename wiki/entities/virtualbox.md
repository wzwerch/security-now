# VirtualBox

# Summary

Steve praised VirtualBox and its VBoxManage tool for mounting physical USB drives as virtual disks and building DOS images. A listener warned the closed-source Extension Pack is only free for personal use and that Oracle audits can lead to costly settlements.

Suggested to isolate email from CryptoLocker, and used to run SpinRite with a modern virtual BIOS that gave one listener a seven-fold speed-up and runs on Macs.
