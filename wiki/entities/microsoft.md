# Microsoft

# Summary

Covered here: the botched SharePoint patch, Windows 10 ESU, Smart App Control, IE Mode removal, Azure Trusted Signing with three-day certificates, hardware-accelerated BitLocker and the Security Store.

Microsoft features through Windows 10 end of support and ESU terms, the SharePoint patch mess and China-based engineers, MAPP early notification, the Exchange hybrid emergency directive, the Entra ID actor token flaw, Outlook attachment blocking, Quick Machine Recovery, and passwordless accounts. Steve is critical of the Windows 11 hardware cutoff.

Topics include Teams Wi-Fi location, native Sysmon, BitLocker recovery keys given to the FBI, hardware-program account suspensions, MDASH and dropping SMS MFA.

Microsoft is covered for Patch Tuesday volumes, the plan to throttle and block mail from legacy Exchange servers, mandatory SMB signing in Windows 11, the Windows Platform Binary Table mechanism, and its role in taking down cracked Cobalt Strike servers.

Episodes 931-941 cover unpatched Office flaw CVE-2023-36884, Azure vulnerability handling, the stolen Storm-0558 signing key, Secure Time Seeding clock jumps and the 38 TB SAS token exposure.

Episodes cover Microsoft's Digital Defense Report, VBScript and NTLM phase-outs, unpatched Exchange flaws, Windows 11 adoption and its SDCP fingerprint protocol.

Microsoft's handling of the Russian Midnight Blizzard intrusion, including Friday-evening disclosures and a legacy test tenant without MFA, drew criticism from Steve and Alex Stamos. It also dropped special treatment for EV code-signing certificates, moved audit logs to the standard tier after the Storm-0558 episode, and the new Outlook app revealed 772 data-sharing third parties.

Microsoft appears throughout these episodes: the Storm-0558 breach and Secure Future Initiative, the Recall controversy, the Windows Wi-Fi flaw CVE-2024-30078, the dangling code.microsoft.com subdomain and honeypot, the Azure cloud and its kernel-access arrangements with security vendors. Steve is sceptical of its ability to secure Recall.

Appears for its CrowdStrike-driven endpoint summit, Recall redesign, log loss, honeypot phishing decoys, Windows 10 ESU pricing, patch statistics, and rejection of a CLFS bug report.

Coverage includes Patch Tuesday releases, Solorigate analyses, the slow Exchange response and Defender's automatic mitigation.

Recurring theme in mid-2022 episodes: dismissing reports as non-issues (Follina, DogWalk), breaking updates (domain controllers, USB printers, VAES), regulating macros, and launching Defender External Attack Surface Management.

In this batch: ECB-mode Office message encryption left unfixed, a vulnerable-driver blocklist not updated for years, a narrow CVE definition, ProxyNotShell Exchange zero-days, a Mark-of-the-Web bypass Microsoft could not reproduce, and a November 2022 Kerberos regression. Steve also praised features such as Windows admin lockout and SMB rate limiting.

2019 stories cover Patch Tuesday volume, SHA-2 update signing, Windows 7 end of support, Edge on Chromium and 10 update problems.

Coverage includes BlueKeep fixes for unsupported Windows, Patch Tuesday volumes, a Windows 7 telemetry update, Edge on Chromium, ElectionGuard, expanded Azure bug bounties and reporting on Russian IoT intrusions.

Appears for Patch Tuesday cycles, Windows 7 end of support and paid ESU, Windows TLS enforcement breakage, Defender features and the ElectionGuard SDK.

Microsoft shipped record patch volumes in March to May 2020, mishandled the SMBGhost disclosure, offered Teams free for six months, previewed DoH for Windows 10 and began replacing legacy Edge with Chromium Edge.

Episodes 600 to 613 cover cancelled February 2017 patches, March's catch-up update, CPU-based update blocking for Windows 7 and 8.1, Authenticator password-free sign-in, Docs.com exposure, the Edge same-origin bug, Defender engine flaws, Windows 10 S restrictions and Brad Smith's response to WannaCry.

In early 2018 Microsoft gated updates on antivirus compatibility, pushed repeated January patches, issued an out-of-band update to disable the Spectre variant 2 mitigation, and then began shipping Intel microcode in Windows 10 updates. It also ran a side-channel bounty and absorbed the fix for a Windows 7 x64 page-table permission mistake.

Episodes cover its Spectre microcode distribution, Azure Sphere and TCPS, the Cybersecurity Tech Accord, a missed zero-day deadline, security servicing criteria, the GitHub acquisition and Windows 10 1803 problems.

These episodes track its monthly patches, Windows 7 extended support, the 1809 update debacle, the Jet flaw, takedown of APT28 domains, Skype Signal chats and Windows 10 installer warnings for other browsers.

Microsoft relaxed the Windows 10 Secure Boot off-switch requirement, patched an IIS range bug, dropped Do Not Track as default, and pushed a Windows 10 upgrade reservation.

Root store updates, Windows Update, WiFi Sense, Windows 10 privacy settings, telemetry back-ported to Windows 7 and 8, and monthly Patch Tuesday fixes.

Episodes cover its Windows 10 upgrade pressure, certificate trust list update for Dell's roots, SHA-1 deprecation timing, and uploading device-encryption recovery keys.

Patch Tuesdays, Skype scanning, IE8 zero-day and EV flaws, and the Guardian documents on NSA cooperation.

Monthly Patch Tuesday releases, the Office TIFF zero-day, plans to encrypt traffic after NSA revelations, joined the FIDO Alliance, XP end of support.

Ended XP support in April 2014 but issued an out-of-cycle IE fix for XP; RTF and VML zero-days.

Appears for the XP embedded hack, CASL email scare, No-IP seizure and its password portfolio paper.

Announced the 2017 SHA-1 sunset, issued the Sandworm OLE patch and the critical MS14-066 Schannel patch (then a corrected version), and is previewing Windows 10.
