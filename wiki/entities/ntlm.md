# NTLM

# Summary

CVE-2024-43451 let a .URL file leak NTLM hashes on right-click, used against Ukrainian organisations. Microsoft has stopped investing in NTLM fixes. NTLMv1 and NTLMv2 flaws appeared in later Patch Tuesdays.
