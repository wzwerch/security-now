# Tinfoil Security

# Summary

Steve compared three scanners and judged Tinfoil Security best: it verifies domain control by a DNS TXT record, explains each of its findings and found 64 items on GRC, including missing subresource integrity, cookie flags and unescaped echoed input. It offers a 90-day trial.
