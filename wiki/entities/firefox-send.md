# Firefox Send

# Summary

Firefox Send encrypts files in the browser and offers expiring links, with 1 GB for anonymous users and 2.5 GB with an account; Steve recommended it over services with daily limits.

Encrypts files in the browser, uploads them, and places the key in the URL fragment so the server never sees it; links expire after a day or one download. Steve endorsed it.
