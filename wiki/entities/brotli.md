# Brotli

# Summary

Gives roughly 17 to 25 percent better compression than gzip for web assets; browsers support it only over HTTPS.

OpenAI researchers used GPT-6 Cyber to show a critical Brotli flaw enables remote code execution in downstream apps (#1104).
