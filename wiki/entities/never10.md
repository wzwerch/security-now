# Never10

# Summary

An 81 KB no-install tool released in March 2016: it updates the Windows Update client if needed, sets the two policy values and locks them read-only; v1.3 added detection and removal of the 6.5 GB pre-download and command-line switches. It passed 150,000 downloads quickly.

A tiny freeware program from GRC that sets the registry policies Microsoft itself sanctions for enterprises, hiding the Get Windows 10 prompt and optionally removing already-downloaded install files. It became GRC's fastest-growing download, passing 1.5 million copies by July 2016.
