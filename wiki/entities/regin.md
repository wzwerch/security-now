# Regin

# Summary

Discovered by Symantec: staged, encrypted, rootkit-hidden framework active since 2008, targeted outside the US and UK.

Discussed as a Symantec-named Norse-myth malware with a four-stage encrypted loader that antivirus firms allegedly knew of for years; first guessed Russian, then tied by Kaspersky code comparison to the NSA QWERTY tool and so to the Five Eyes.
