# SolarWinds

# Summary

SolarWinds' Orion monitoring platform was backdoored in 2020 in a state-linked campaign. Across these episodes Steve follows its testimony about a weak password, repeated new Orion and Serv-U vulnerabilities, shareholder suits and the question of whether to keep using the product.

SolarWinds makes the Orion network and application monitoring platform. Attackers inserted the Sunburst backdoor into signed Orion updates from spring 2020, and about 18,000 customers installed them. A separate Supernova web shell was also found in Orion. Steve corrected himself that Orion is Windows software, not an appliance.
