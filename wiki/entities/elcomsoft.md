# ElcomSoft

# Summary

Published benchmarks for cracking 1Password, KeePass, LastPass and Dashlane master passwords, then corrected a 1Password figure that used stale data.

Argued iOS 11 weakened security by allowing the backup password to be reset with only the passcode.

ElcomSoft found that attaching any Lightning accessory resets the hourly timer.
