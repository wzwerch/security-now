# GhostPoster

# Summary

Koi Security found 17 Firefox extensions (about 50,000 installs) and LayerX later found 17 more across Edge, Chrome and Firefox with over 840,000 installs since February 2020. They hijack affiliate links, strip security headers and inject iframes.
