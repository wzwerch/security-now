# Chrome zero-day streak, fall 2020

# Overview

A run of in-the-wild Chrome zero-days and the chained Windows and iOS flaws.

# Timeline

* **#786 (2020-09-29)** — Chrome 85 fixed ten flaws, none known to be exploited. ([source](../sources/sn-0786.md))
* **#790 (2020-10-27)** — A FreeType heap overflow was exploited in the wild; Chrome fixed it within a day. ([source](../sources/sn-0790.md))
* **#791 (2020-11-03)** — Project Zero revealed it was chained with a Windows cng.sys privilege escalation zero-day. ([source](../sources/sn-0791.md))
* **#792 (2020-11-10)** — More zero-days in V8 and Android Chrome, plus iOS 14.2 fixes, were linked by Google TAG to one campaign. ([source](../sources/sn-0792.md))
* **#793 (2020-11-17)** — Two more zero-days brought the tally to five in three weeks. ([source](../sources/sn-0793.md))
