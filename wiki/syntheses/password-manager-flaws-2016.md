# Password manager flaws in 2016

# Overview

LastPass add-on bug and teased Dashlane and 1Password findings.

* **#571 (2016-08-02)** — Tavis Ormandy finds a message-hijacking bug in the LastPass 4.x Firefox add-on, fixed immediately; an older URL-parsing report is also recycled. ([source](../sources/sn-0571.md))
