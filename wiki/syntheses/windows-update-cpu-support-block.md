# Windows 7/8.1 update block on new CPUs

# Overview

Microsoft refusing updates to newer processors on older Windows.

# Timeline

* **#604 (2017-03-21)** — Microsoft's support page confirmed updates stop on Kaby Lake, Ryzen and Qualcomm 8996 PCs running Windows 7 or 8.1. ([source](../sources/sn-0604.md))
* **#609 (2017-04-25)** — A one-byte patch to IsCPUSupported showed the block was policy, not technical. ([source](../sources/sn-0609.md))
