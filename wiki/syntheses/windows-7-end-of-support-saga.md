# Windows 7 end of support – Timeline

# Overview

From free upgrades to final patches, ESU hacks and broken last updates.

# Timeline

* **#743 (2019-12-03)** — Steve notes the free Windows 10 upgrade still works via the Media Creation Tool, advising an image backup first. ([source](../sources/sn-0743.md))
* **#744 (2019-12-10)** — The BypassESU tool appears to trick Windows 7 into taking Extended Security Updates, and Microsoft begins forcing Windows 10 1809 feature updates. ([source](../sources/sn-0744.md))
* **#745 (2019-12-17)** — A full-screen Windows 7 end-of-support notice is shown; Security Essentials updates are expected to end. ([source](../sources/sn-0745.md))
* **#746 (2019-12-23)** — Microsoft says MSE signatures continue after January 14 while its ESU FAQ contradicts it. ([source](../sources/sn-0746.md))
* **#749 (2020-01-14)** — Final Patch Tuesday for Windows 7 arrives alongside the Crypt32 flaw; about a quarter of desktops still run it. ([source](../sources/sn-0749.md))
* **#750 (2020-01-21)** — An unpatched IE JScript zero-day exposes Windows 7 users with no vendor patch coming. ([source](../sources/sn-0750.md))
* **#752 (2020-02-04)** — The last January update breaks wallpaper stretching; Microsoft promises a fix for all users and an FSF petition asks to open-source Windows 7. ([source](../sources/sn-0752.md))
* **#753 (2020-02-11)** — The wallpaper fix bricks Server 2008 R2 systems missing prerequisite updates; MSE definitions confirmed to continue. ([source](../sources/sn-0753.md))
