# Record Windows patch volumes in spring 2020

# Overview

March to May 2020 Patch Tuesdays and related zero-days.

# Timeline

* **#758 (2020-03-17)** — March Patch Tuesday fixed about 117 flaws, 25 critical, including a .LNK remote code execution bug. ([source](../sources/sn-0758.md))
* **#759 (2020-03-24)** — An unpatched Adobe Type Manager zero-day affected all Windows versions; 0patch offered a GDI micropatch for Windows 7. ([source](../sources/sn-0759.md))
* **#763 (2020-04-21)** — April brought 113 fixes and three exploited zero-days that Windows 7 users without support would not receive. ([source](../sources/sn-0763.md))
* **#767 (2020-05-19)** — May's 111 fixes made the three months the largest in Microsoft history, with no zero-days but all genuine vulnerabilities. ([source](../sources/sn-0767.md))
