# Windows 10 update problems of 2018

# Overview

Dissatisfaction, 1809 file deletion and related October regressions.

# Timeline

* **#675 (2018-08-07)** — Susan Bradley's survey shows broad dissatisfaction with Windows 10 updates; Microsoft's reply is boilerplate. ([source](../sources/sn-0675.md))
* **#680 (2018-09-11)** — Windows 7 extended security updates will be sold through January 2023. ([source](../sources/sn-0680.md))
* **#684 (2018-10-09)** — The October 2018 feature update deletes some users' documents; Microsoft pauses it and Leo describes the Known Folder Redirection cause. ([source](../sources/sn-0684.md))
* **#685 (2018-10-16)** — More October problems (HP driver, Intel audio, IPv6 for Edge) and an incompletely fixed Jet flaw add to the debacle. ([source](../sources/sn-0685.md))
