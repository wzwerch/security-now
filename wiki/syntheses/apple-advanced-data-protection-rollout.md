# Apple Advanced Data Protection rollout

# Overview

From announcement to global availability.

# Timeline

* **#901 (2022-12-13)** — Apple announces ADP raising end-to-end encrypted iCloud categories from 14 to 23, plus Security Keys and Contact Key Verification. ([source](../sources/sn-0901.md))
* **#902 (2022-12-20)** — Listener feedback clarifies that keys are moved to the user's Keychain blob and deleted from Apple's HSMs. ([source](../sources/sn-0902.md))
* **#907 (2023-01-24)** — iOS 16.3 makes ADP globally available but requires all devices to run capable OS versions. ([source](../sources/sn-0907.md))
* **#908 (2023-01-31)** — iOS 16.3 also supports FIDO security keys for Apple ID; Leo warns against rushing to enable ADP. ([source](../sources/sn-0908.md))
