# Windows 10 upgrade pressure

# Overview

Microsoft's push, telemetry and key upload around Windows 10.

# Timeline

* **#533 (2015-11-10)** — Spybot Anti-Beacon recommended to disable telemetry; Patch Tuesday discussed. ([source](../sources/sn-0533.md))
* **#535 (2015-11-24)** — The November update silently removed some third-party apps. ([source](../sources/sn-0535.md))
* **#537 (2015-12-08)** — Microsoft moving the upgrade into optional then recommended updates; GWX Control Panel recommended. ([source](../sources/sn-0537.md))
* **#539 (2015-12-22)** — The upgrade dialog dropped the decline option. ([source](../sources/sn-0539.md))
* **#541 (2016-01-05)** — Listeners reported the setting re-enabling itself; Windows 10 uploads disk recovery keys by default. ([source](../sources/sn-0541.md))
