# SQRL release and ecosystem

# Overview

Steve Gibson's SQRL authentication system reaches 1.0 and builds an implementer community.

# Timeline

* **#714 (2019-05-14)** — Steve added Controlled Folder Access support to the SQRL Windows client and began the final documentation. ([source](../sources/sn-0714.md))
* **#717 (2019-06-04)** — SQRL had 1,275 forum members and merchandise appeared; Steve contrasted it with Sign in with Apple tracking. ([source](../sources/sn-0717.md))
* **#718 (2019-06-11)** — SQRL Explained and client version 1.0 were released. ([source](../sources/sn-0718.md))
* **#719 (2019-06-18)** — The explainer grew to 21 pages and the Ask feature was documented; forum passed 2,000 members. ([source](../sources/sn-0719.md))
* **#722 (2019-07-09)** — A WordPress SQRL plugin appeared and the HTTPS requirement was explained. ([source](../sources/sn-0722.md))
* **#724 (2019-07-23)** — Server and client implementations in Go, C, PAM, Symfony and Drupal were announced alongside OWASP talks in Dublin and Gothenburg. ([source](../sources/sn-0724.md))
* **#727 (2019-08-13)** — A calendar of SQRL presentations was published and a pre-recorded file-sync episode planned during Steve's travel. ([source](../sources/sn-0727.md))
