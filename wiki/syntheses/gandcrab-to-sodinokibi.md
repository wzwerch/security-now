# GandCrab to Sodinokibi succession

# Overview

How the GandCrab shutdown led to Sodinokibi/REvil with similar code and affiliates.

# Timeline

* **#730 (2019-09-03)** — Sodinokibi emerges as the fourth most common family with a 60-70% affiliate split and a CIS-exclusion rule; link to GandCrab suspected. ([source](../sources/sn-0730.md))
* **#731 (2019-09-10)** — Texas's $2.5 million Sodinokibi demand is declined. ([source](../sources/sn-0731.md))
* **#735 (2019-10-08)** — McAfee shows near-identical affiliate-ID design, code blocks and C2 URL generation between GandCrab and Sodinokibi. ([source](../sources/sn-0735.md))
