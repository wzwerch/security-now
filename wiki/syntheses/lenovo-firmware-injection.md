# Lenovo firmware injection and telemetry (2015)

# Overview

Lenovo BIOS tricks and ThinkPad data collection.

# Timeline

* **#521 (2015-08-18)** — Lenovo BIOS replaces a Windows boot file to reinstall software, similar to CompuTrace. ([source](../sources/sn-0521.md))
* **#522 (2015-08-25)** — Lenovo retracts the feature and issues firmware updates. ([source](../sources/sn-0522.md))
* **#524 (2015-09-08)** — A listener argues ThinkPads were unaffected; encrypted boot partitions would stop the file trick. ([source](../sources/sn-0524.md))
* **#527 (2015-09-29)** — Columnist shows ThinkPads also send inventory and usage data to a third party. ([source](../sources/sn-0527.md))
