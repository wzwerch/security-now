# Windows 10 2004 and 2020 patch problems

# Overview

Record Patch Tuesdays and recurring breakage from updates.

# Timeline

* **#771 (2020-06-16)** — June 2020 Patch Tuesday has 129 fixes and breaks printing; 2004 has defrag, TRIM and printer-port bugs. ([source](../sources/sn-0771.md))
* **#772 (2020-06-23)** — Optional out-of-band fixes for the printing issue; Edge pushed to Windows 7. ([source](../sources/sn-0772.md))
* **#774 (2020-07-07)** — Out-of-cycle Windows codec fixes arrive through the Microsoft Store. ([source](../sources/sn-0774.md))
* **#776 (2020-07-21)** — July Patch Tuesday has 123 fixes; Steve laments Windows complexity. ([source](../sources/sn-0776.md))
* **#780 (2020-08-18)** — August has 120 fixes and two exploited zero-days that Microsoft had delayed fixing. ([source](../sources/sn-0780.md))
* **#784 (2020-09-15)** — September ties the record at 129 with critical Exchange and SharePoint flaws. ([source](../sources/sn-0784.md))
