# LastPass extension vulnerabilities 2017

# Overview

Tavis Ormandy's series of browser extension bugs and LastPass's fast fixes.

# Timeline

* **#604 (2017-03-21)** — A trusted subdomain could create privileged windows to call extension functions; LastPass killed the DNS name within hours. ([source](../sources/sn-0604.md))
* **#605 (2017-03-28)** — A second sophisticated code-execution report was acknowledged; Steve defended continued use and mentioned KeePass. ([source](../sources/sn-0605.md))
* **#606 (2017-04-04)** — Details: LastPass relied on undefined JavaScript variables as switches, which DOM content could define; over 3,000 instances were fixed. Leo removed the browser extension. ([source](../sources/sn-0606.md))
* **#607 (2017-04-11)** — A joke tweet about Tavis traveling to Miami was the Picture of the Week. ([source](../sources/sn-0607.md))
