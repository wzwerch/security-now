# WordPress plugin and theme vulnerabilities

# Overview

A steady stream of takeover bugs in third-party WordPress add-ons.

# Timeline

* **#783 (2020-09-08)** — File Manager's accidentally renamed connector file exposes hundreds of thousands of sites. ([source](../sources/sn-0783.md))
* **#784 (2020-09-15)** — Probes reach 2.6 million sites; attackers install backdoors and steal credentials. ([source](../sources/sn-0784.md))
* **#849 (2021-12-14)** — Epsilon Framework themes and four plugins attacked from 16,000 IPs by enabling open registration with administrator default role. ([source](../sources/sn-0849.md))
* **#853 (2022-01-11)** — WordPress 5.8.3 fixed four core bugs including two SQL injections. ([source](../sources/sn-0853.md))
* **#854 (2022-01-18)** — Three WooCommerce-related plugins from one author exposed 84,000 sites to option-update abuse. ([source](../sources/sn-0854.md))
* **#855 (2022-01-25)** — WP HTML Mail lacked REST authentication; AccessPress's website was breached to backdoor 93 extensions; Leo stresses the plugin model rather than core is at fault. ([source](../sources/sn-0855.md))
* **#856 (2022-02-01)** — Zerodium's standing 300,000 dollar WordPress pre-auth bounty remaining unclaimed suggests core is hard to break. ([source](../sources/sn-0856.md))
