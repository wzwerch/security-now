# Hyperlink ping tracking becomes permanent

# Overview

From Chrome removing the disable option to Mozilla's planned default.

# Timeline

* **#709 (2019-04-09)** — Steve explained ping tracking and Chrome 74's removal of the switch. ([source](../sources/sn-0709.md))
* **#710 (2019-04-16)** — Imperva reported a ping-based DDoS and uBlock Origin was noted as a blocker. ([source](../sources/sn-0710.md))
* **#711 (2019-04-23)** — Mozilla told BleepingComputer it would enable ping by default and offer no off switch; Brave kept blocking it. ([source](../sources/sn-0711.md))
