# Microsoft security failures and responses

# Overview

Recurring complaints about how Microsoft fixes, reports and describes vulnerabilities.

# Timeline

* **#889 (2022-09-20)** — September Patch Tuesday with an exploited CLFS flaw and group policy side effects. ([source](../sources/sn-0889.md))
* **#891 (2022-10-04)** — Teams plaintext tokens deemed not urgent; ProxyNotShell mitigation bypassed. ([source](../sources/sn-0891.md))
* **#892 (2022-10-11)** — Mitigation script edited daily; Exchange zero-days seen in under 10 organizations. ([source](../sources/sn-0892.md))
* **#893 (2022-10-18)** — OME's ECB encryption left unfixed and the vulnerable-driver blocklist found stale for years. ([source](../sources/sn-0893.md))
* **#894 (2022-10-25)** — Microsoft could not reproduce a Mark-of-the-Web bypass used by Magniber. ([source](../sources/sn-0894.md))
* **#895 (2022-11-01)** — Blocklist finally refreshed; Microsoft declined a CVE for a patched SharePoint SSRF. ([source](../sources/sn-0895.md))
* **#897 (2022-11-15)** — November Patch Tuesday brought a Kerberos regression and four exploited zero-days. ([source](../sources/sn-0897.md))
* **#931 (2023-07-18)** — Unpatched Office flaw CVE-2023-36884 mitigated rather than fixed. ([source](../sources/sn-0931.md))
* **#934 (2023-08-08)** — Tenable CEO criticizes Azure vulnerability handling; Schneier on the stolen signing key. ([source](../sources/sn-0934.md))
* **#936 (2023-08-22)** — Secure Time Seeding clock jumps ignored for seven years. ([source](../sources/sn-0936.md))
* **#939 (2023-09-12)** — Microsoft's five-bug explanation of the leaked signing key. ([source](../sources/sn-0939.md))
* **#941 (2023-09-26)** — An over-permissive SAS token exposed 38 TB of internal data. ([source](../sources/sn-0941.md))
