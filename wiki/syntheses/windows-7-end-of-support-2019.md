# Windows 7 approaching end of support

# Overview

SHA-2 update signing, paid updates and end-of-life notices.

# Timeline

* **#701 (2019-02-12)** — Windows 7 ESU pricing for enterprises was announced. ([source](../sources/sn-0701.md))
* **#702 (2019-02-19)** — SHA-2 only update signing will start August 2019. ([source](../sources/sn-0702.md))
* **#706 (2019-03-19)** — The SHA-2 support update KB4474419 arrived with March patches. ([source](../sources/sn-0706.md))
* **#707 (2019-03-26)** — The end-of-support dialog was described, along with Azure Windows Virtual Desktop support to 2023. ([source](../sources/sn-0707.md))
* **#711 (2019-04-23)** — The dialogs began appearing and linked to PC sales. ([source](../sources/sn-0711.md))
