# DNS over HTTPS adoption

# Overview

How DoH moved from browsers to OS support and Firefox defaults.

# Timeline

* **#742 (2019-11-26)** — Microsoft pre-announces native DoH for Windows and Steve explains why HTTP-based DoH could push DNS answers via HTTP/2. ([source](../sources/sn-0742.md))
* **#746 (2019-12-23)** — Mozilla adds NextDNS as a second Trusted Recursive Resolver partner beside Cloudflare. ([source](../sources/sn-0746.md))
* **#755 (2020-02-25)** — Firefox starts enabling DoH by default for new US installs and rolls it to all US users, excluding the UK. ([source](../sources/sn-0755.md))
