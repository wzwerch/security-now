# Windows 10 upgrade end and Windows Update rollups

# Overview

Free upgrade quirks, GWX removal, Anniversary Update issues and the shift to monolithic updates.

# Timeline

* **#571 (2016-08-02)** — The free Windows 10 offer ends but an assistive-technologies page still offers the upgrade; the GWX installer update is reported withdrawn. ([source](../sources/sn-0571.md))
* **#572 (2016-08-09)** — Anniversary Update problems: freezes, McAfee incompatibility, dual-boot damage and removed Pro Group Policies; Windows 7/8 keys still upgraded. ([source](../sources/sn-0572.md))
* **#573 (2016-08-16)** — Microsoft announces monthly rollups for Windows 7 and 8.1 and extends Skylake support to the normal end of life. ([source](../sources/sn-0573.md))
* **#579 (2016-09-27)** — KB 3184143 removes the Get Windows 10 app; guest co-host leaves Windows 10 after forced updates ignored active hours. ([source](../sources/sn-0579.md))
* **#580 (2016-10-04)** — The removal update is optional; Steve explains the loss of update granularity coming with rollups. ([source](../sources/sn-0580.md))
* **#581 (2016-10-11)** — First rollup Patch Tuesday for Windows 7/8.1 fixes five zero-days. ([source](../sources/sn-0581.md))
* **#582 (2016-10-18)** — A listener reports stopping the update service and installing KB 3102810 fixes stuck Windows 7 updates. ([source](../sources/sn-0582.md))
