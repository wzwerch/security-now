# ProxyLogon and Hafnium Exchange attacks

# Overview

The March 2021 Exchange Server zero-day crisis and its slow cleanup.

# Timeline

* **#808 (2021-03-02)** — Leo reports Microsoft's emergency patches for seven Exchange remote code execution flaws used by a Chinese state-linked group. ([source](../sources/sn-0808.md))
* **#809 (2021-03-09)** — Mass web-shell planting follows disclosure; at least 60,000 victims; timeline shows Microsoft knew from January; MSERT and run-as-admin warning. ([source](../sources/sn-0809.md))
* **#810 (2021-03-16)** — Attack attempts rise tenfold, ten-plus groups, DearCry ransomware, GitHub removes a PoC; about 82,000 servers unpatched. ([source](../sources/sn-0810.md))
* **#811 (2021-03-23)** — Defender gains automatic URL Rewrite mitigation; Black Kingdom ransomware appears. ([source](../sources/sn-0811.md))
