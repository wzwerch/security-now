# uBlock Origin and Manifest V3

# Overview

Chrome's extension API changes and research showing exploitable extensions.

* **#699 (2019-01-29)** — Proposed limits on webRequest blocking and remote code would break uBlock Origin, uMatrix and Tampermonkey, while the EmPoWeb study found 197 exploitable extensions. ([source](../sources/sn-0699.md))
* **#986 (2024-08-06)** — Leo and Steve flag Manifest V3 as a reason to prefer Firefox. ([source](../sources/sn-0986.md))
* **#995 (2024-10-08)** — Registry policy delays MV2 until June 2025; uBlock Origin Lite leaves Firefox. ([source](../sources/sn-0995.md))
* **#996 (2024-10-15)** — Annoyance filter lists enabled; Brave and Arc plan built-in blockers. ([source](../sources/sn-0996.md))
* **#999 (2024-11-05)** — Hijacked extension case reinforces using fewer extensions. ([source](../sources/sn-0999.md))
