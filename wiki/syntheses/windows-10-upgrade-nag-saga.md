# Windows 10 upgrade nagging and Never10

# Overview

Microsoft's increasingly aggressive Get Windows 10 prompts and GRC's Never10 response during 2016.

# Timeline

* **#556 (2016-04-19)** — Steve fixes a Never10 parsing bug (1.3.1) and notes users reclaiming gigabytes of hidden download files. ([source](../sources/sn-0556.md))
* **#559 (2016-05-10)** — The Get Windows 10 update reappears; a Windows 7 Secure Boot removal update breaks boots on ASUS boards; Never10 users report no problems. ([source](../sources/sn-0559.md))
* **#560 (2016-05-17)** — The prompt is refreshed with no clear way to decline; Steve explains he likes Windows but objects to Microsoft's motives. ([source](../sources/sn-0560.md))
* **#561 (2016-05-24)** — Closing the dialog with X now accepts the upgrade; Never10 reaches 535,000 downloads at 25,000 per day; Never10 cannot block the nag update itself, only set policy. ([source](../sources/sn-0561.md))
* **#562 (2016-05-31)** — Never10 passes 783,000 downloads; third-party download sites bundle it with junk. ([source](../sources/sn-0562.md))
* **#563 (2016-06-07)** — Over one million downloads; some users disable all updates to avoid the upgrade. ([source](../sources/sn-0563.md))
* **#566 (2016-06-28)** — Microsoft pays a $10,000 judgment to a user whose business was hurt by a forced upgrade and drops its appeal; the prompt gains a Decline button; downloads reach 1.365 million. ([source](../sources/sn-0566.md))
* **#567 (2016-07-05)** — Never10 nears 1.5 million downloads as the July 29 free-upgrade deadline approaches. ([source](../sources/sn-0567.md))
