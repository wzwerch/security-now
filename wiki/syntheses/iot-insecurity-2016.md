# IoT and home-automation insecurity in 2016

# Overview

A run of episodes dissecting insecure consumer IoT: ZigBee, Z-Wave, SmartThings, baby monitors, cameras and smart plugs.

# Timeline

* **#559 (2016-05-10)** — SmartThings and ZigBee analysis: over-privileged SmartApps, a well-known default link key and insecure rejoin. ([source](../sources/sn-0559.md))
* **#560 (2016-05-17)** — Z-Wave proves closed and proprietary, with a researcher-found flaw letting a door lock be opened without keys; Ring doorbell video mix-up traced to merged databases. ([source](../sources/sn-0560.md))
* **#561 (2016-05-24)** — Hosts warn against Internet baby monitors; the Ring Doorbell Pro is introduced. ([source](../sources/sn-0561.md))
* **#562 (2016-05-31)** — IoT Infancy part one: Bitdefender finds weak WeMo, LIFX, GE and MUZO setups; CVE assignment is overloaded by IoT volume. ([source](../sources/sn-0562.md))
* **#563 (2016-06-07)** — Rapid7's baby-monitor study: enumerable cloud IDs, default Telnet logins, unauthenticated registration; advice to segment IoT devices. ([source](../sources/sn-0563.md))
* **#565 (2016-06-21)** — Netgear Arlo cameras can show a new owner's feed to the previous account holder. ([source](../sources/sn-0565.md))
* **#567 (2016-07-05)** — A returned multicamera system alerts the old owner, and an Amazon review exposes an ESP8266 smart plug controlled via a Chinese server. ([source](../sources/sn-0567.md))
* **#569 (2016-07-19)** — Steve recommends the $50 EdgeRouter X for isolating IoT networks. ([source](../sources/sn-0569.md))
