# Chrome pushes HTTPS

# Overview

Chrome's 2018 policies against HTTP and its shift from key pinning to Certificate Transparency.

# Timeline

* **#659 (2018-04-17)** — Chrome 70 will cap cookie lifetimes from HTTP sites to a year. ([source](../sources/sn-0659.md))
* **#664 (2018-05-22)** — Chrome 68 will label HTTP sites Not Secure, with red warnings on form entry later. ([source](../sources/sn-0664.md))
* **#666 (2018-06-05)** — Chrome 67 removes HPKP and Steve introduces Certificate Transparency. ([source](../sources/sn-0666.md))
