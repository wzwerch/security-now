# Windows 10 update breakage 2020

# Overview

Series of broken February updates for Windows 10.

# Timeline

* **#752 (2020-02-04)** — Steve complains that Windows 10 is a moving target across feature releases. ([source](../sources/sn-0752.md))
* **#753 (2020-02-11)** — A Windows 10 update prompts 'no permission to shut down' errors for some users. ([source](../sources/sn-0753.md))
* **#754 (2020-02-18)** — Adobe Creative Cloud services are identified as the shutdown bug source; One Button Reset and a profile-hiding rollup also fail. ([source](../sources/sn-0754.md))
* **#755 (2020-02-25)** — Reports of permanent profile data loss emerge, and Microsoft plans optional driver updates in 2004. ([source](../sources/sn-0755.md))
