# State HTTPS interception and root distrust

# Overview

DarkMatter and Kazakhstan show governments seeking trusted roots.

# Timeline

* **#723 (2019-07-16)** — Mozilla decided to distrust DarkMatter's intermediates and reject its CA application. ([source](../sources/sn-0723.md))
* **#724 (2019-07-23)** — Kazakhstan began requiring a state root certificate for HTTPS interception and a fake Facebook certificate was observed; browser vendors weighed blacklisting. ([source](../sources/sn-0724.md))
