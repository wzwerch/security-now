# Ransomware evolution 2015-2016

# Overview

Server ransomware, buggy decryptors and JavaScript kits.

# Timeline


* **#484 (2014-12-02)** — RDP-exposed company PC encrypted while backups had silently stopped. ([source](../sources/sn-0484.md))
* **#489 (2015-01-06)** — CryptoWall 2.0 spreads; backups advised. ([source](../sources/sn-0489.md))
* **#490 (2015-01-13)** — Non-admin victims can restore from shadow copies. ([source](../sources/sn-0490.md))
