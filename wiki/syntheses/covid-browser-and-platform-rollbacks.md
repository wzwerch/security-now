# COVID-19 rollbacks of browser and platform changes

# Overview

Planned deprecations delayed to keep essential services reachable.

# Timeline

* **#759 (2020-03-24)** — Mozilla reversed TLS 1.0/1.1 removal and Chrome paused version 81. ([source](../sources/sn-0759.md))
* **#760 (2020-03-31)** — Chrome 82 was skipped and Windows 10 optional updates were paused from May. ([source](../sources/sn-0760.md))
* **#761 (2020-04-07)** — Chrome rolled back SameSite enforcement. ([source](../sources/sn-0761.md))
* **#763 (2020-04-21)** — Chrome undeprecated FTP; Microsoft and Google postponed Basic Authentication shutdowns. ([source](../sources/sn-0763.md))
