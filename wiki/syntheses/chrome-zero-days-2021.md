# Chrome zero-days of 2021

# Overview

A run of actively exploited Chrome vulnerabilities and rapid patching.

# Timeline

* **#815 (2021-04-20)** — Chrome 89 fixed two exploited flaws, one reported to patched in under a week. ([source](../sources/sn-0815.md))
* **#821 (2021-06-01)** — Chrome 91 shipped 32 security fixes and blocked port 10080. ([source](../sources/sn-0821.md))
* **#823 (2021-06-15)** — Kaspersky's timeline showed attackers chaining Chrome and Windows zero-days and exploiting the gap between a public commit and patch. ([source](../sources/sn-0823.md))
* **#824 (2021-06-22)** — CVE-2021-30554 was the seventh exploited Chrome zero-day of the year. ([source](../sources/sn-0824.md))
