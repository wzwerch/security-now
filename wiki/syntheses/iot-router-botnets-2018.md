# IoT and router botnets and the auto-update argument

# Overview

Flash botnets, Mirai variants, Torii and the case for self-updating devices.

# Timeline

* **#673 (2018-07-24)** — Anarchy enlists 18,000 Huawei routers in a day; Steve argues Internet-facing appliances need default auto-update. ([source](../sources/sn-0673.md))
* **#674 (2018-07-31)** — Death botnet targets AVTECH devices through a shell-command password flaw. ([source](../sources/sn-0674.md))
* **#678 (2018-08-28)** — Sora Mirai uses a cross-compiling toolchain, reaching Android and Debian. ([source](../sources/sn-0678.md))
* **#681 (2018-09-18)** — Mirai has 16 exploits and Nexusguard reports average DDoS size up more than fivefold; California's IoT bill bans shared default passwords. ([source](../sources/sn-0681.md))
* **#683 (2018-10-02)** — Torii, written in Go, has six persistence mechanisms and many architectures; VPNFilter's final report shows router pivoting. ([source](../sources/sn-0683.md))
* **#685 (2018-10-16)** — ACI found 83 percent of sampled routers had known flaws; Steve proposes asking at setup and defaulting to auto-update. ([source](../sources/sn-0685.md))
