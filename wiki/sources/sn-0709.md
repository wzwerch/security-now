# Summary

With Jason Howell filling in for Leo, Steve devotes the main segment to the HTML5 "ping" attribute on links, which lets a page order the browser to send a background POST to any servers when a link is clicked; Chrome 74 and later will no longer allow disabling it, Edge (now Chromium-based) inherits it, and only Firefox and Brave keep it off. Google already serves different search-result markup to Chrome (direct links plus ping) and to browsers without ping (tracking redirects). Steve regards it as another lost battle against tracking, though it is arguably faster than redirect chains. Earlier items cover Microsoft's official Chromium Edge preview with Chrome extension support, the UK government's Online Harms White Paper, Windows 10's new feature-update controls, a 3D-printed fingerprint that unlocks a Galaxy S10, an industry study showing poor security in Android financial apps, the full source release of NSA's Ghidra (with an early debug-port bug), and Facebook briefly asking users for their email passwords. Steve also explains the Windows 10 1809 change to Quick Removal for external drives.

# Key points

- Link "ping" attribute: formalised in HTML5; the browser POSTs (with Ping-From and Ping-To headers, content type text/ping) to one or more arbitrary URLs asynchronously, with no same-origin restriction; Chrome 73 allowed disabling it, Chrome 74 and 75 do not; Safari and Opera have it; Firefox and Brave disable it by default. In Firefox, Google result links point back through a /url redirect, whereas in Chrome they point directly at the target with a ping attribute.
- Steve's view: ping has no purpose other than tracking, but blocking it is futile because redirect chains do the same job and cannot be blocked without breakage, and ping is parallel so pages load faster.
- Microsoft Edge Insider (Chromium) builds are public in Beta, Dev and Canary channels, will come to Windows 7, 8.1 and macOS, and can install Chrome extensions; Google services were stripped out. The SQRL browser extension already runs on it.
- UK Online Harms White Paper (102 pages, consultation to July 1, 2019): proposes a statutory duty of care for platforms, an independent regulator with enforcement powers, and coverage of both illegal and legal-but-harmful content.
- Windows 10 May 2019 Update: users will initiate feature updates from a prominent "download and install now" option, can pause updates up to 35 days, and the release preview phase will be longer after the 1809 problems.
- Biometrics: a Reddit user unlocked a Samsung Galaxy S10's ultrasonic in-display fingerprint reader with a resin 3D print made from a photographed wineglass fingerprint; Steve argues all biometrics are spoofable "soft signals" traded for convenience, and lists countermeasures such as impedance and pulse sensing; Jason finds the S10 reader unreliable.
- Arxan/Aite Group study of 30 Android financial apps: 97% lacked binary protection, 90% leaked data to other apps, 83% stored data insecurely, 80% had weak encryption, 70% used insecure random numbers; apps could be cracked open in about 8.5 minutes on average, exposing keys, SQL queries and API endpoints.
- Ghidra source published on GitHub (Java, many processor families); Matthew Hickey found its debug port 18001 listened on all interfaces, which was fixed.
- Facebook briefly showed an interstitial asking some users for their external email password to verify the address (screenshot with a gmx.net account); after press coverage Facebook said it did not store the passwords and would stop offering the option.
- Windows 10 1809 defaults external drives to Quick Removal (write caching off) because users pulled drives without ejecting; Steve explains that Better Performance with write-cache flushing reduces wear and describes where to change the policy in Disk Management.

# Other segments

- Windows tip: hold Shift while right-clicking a file to get "Copy as path"; Brad Silverberg's point about copy-and-paste of files in Explorer.
- Banter on cookie banners after GDPR, 35-day update pause, and Steve's use of vertical tabs in Firefox; Steve suggests listeners explore older tutorial episodes.
