# Summary

StartCom announced it is ceasing operations after browsers distrusted it, ending a saga that began with undisclosed WoSign ownership and misissuance. Steve explains the macOS High Sierra root flaw: a password-check routine returned "I completed the comparison" and the caller treated that as a match, while the first attempt silently enabled the disabled root account, and Apple's patches fumbled by regressing after upgrades. Apps can now read Face ID camera depth data, and Facebook is testing selfie-based CAPTCHAs and a controversial nude-photo hashing pilot. Attackers quickly exploited an Office DDE flaw patched the previous month. Malwarebytes found sites that keep mining after Chrome closes via a hidden pop-under window; Mailsploit abuses Unicode encoding in email headers to spoof senders; Google tightens Android and Chrome enforcement (unwanted software policy, and a phased ban on third-party code injection). A Mirai variant took about 100,000 ZyXEL routers, a dongle-authentication directory is shared, and listener feedback covers SpinRite stories, Quad9's secondary address and the HP printer hack.

# Key points

- StartCom/StartSSL: Firefox removed it in October 2016, Chrome in March 2017; after secret acquisition by WoSign and Qihoo 360 and misissuance, owners announced no new certificates from 1 January 2018, revocation services for two years and revocation of the rest by 2020. Steve sees no malice, but says CAs must behave or be removed, as Symantec's sale to DigiCert shows.
- macOS root bug (Patrick Wardle's analysis): the check function returned success for completing the comparison, not for matching hashes; first attempt enabled the root account with a blank password; the 10.13.1 patch broke file sharing for some and upgrading from 10.13 could regress without a reboot notice.
- Face ID mesh access: apps using the camera API can read the 3D face mesh; Leo says no enclave data is exposed. Steve suggests Apple may add clearer consent later.
- Facebook CAPTCHA-style selfie check requires a never-seen photo and promises deletion; Jeff Jarvis proposed client-side hashing for the anti-revenge-porn pilot so no one sees the photos.
- Office exploit: DDE, a 17-year-old data exchange mechanism, was abused through malicious RTF documents to run PowerShell and Cobalt Strike (November Patch Tuesday fixed 53 issues); opening the document is enough. Update promptly and be wary of email attachments.
- Hidden miner: pages open a small Chrome pop-under tucked beneath the Windows taskbar that keeps mining at 50-60% CPU after the main browser closes; look for chrome.exe in Task Manager.
- Mailsploit (Sabri Haddouche): non-ASCII encoded-word handling in email headers (RFC 1342) lets attackers spoof the sender display while passing SPF/DKIM/DMARC; 33 clients vulnerable at disclosure, eight fixed, Mozilla and Opera declined to fix; Apple clients affected.
- Google expands its unwanted software policy: warnings via Play Protect and browsers within 60 days, apps must disclose and get consent for unrelated personal-data collection.
- dongleauth.info lists sites supporting hardware second-factor keys (OTP and U2F), sorted by category; Steve still prefers time-based codes but says Yubico will support SQRL.
- Mirai variant infected nearly 100,000 ZyXEL devices (mostly in Argentina) through a fixed superuser password, first posted 31 October; the control domains were sinkholed but devices remain vulnerable.
- Chrome and code injection: telemetry showed over 15% of Chrome users with injecting third-party software crash; Chrome 66 (April 2018) will warn, Chrome 68 (July 2018) blocks with fallback, and Chrome 72 (January 2019) blocks completely, pushing vendors to extensions or native messaging.
- Quad9 has a filtered secondary address, 149.112.112.112, and a points-of-presence map at pch.net; clients differ in how they use secondary DNS.
