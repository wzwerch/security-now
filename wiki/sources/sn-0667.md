# Summary

Steve starts with VPNFilter: Cisco Talos now lists at least 71 affected router models (adding ASUS, D-Link, Huawei, Ubiquiti, UPVEL and ZTE) and found device-specific modules, including one that sniffs a TP-Link VPN router and one that downgrades HTTPS to HTTP, so absence from the list gives no assurance. Guardicore describes Operation Prowli, a 40,000-machine cryptomining and traffic-redirection network. A scan suggests about 115,000 Drupal 7 sites were still behind the Drupalgeddon2 fix. A wormable cryptominer spreads through Android devices that ship with the Android Debug Bridge open on port 5555. Cisco keeps discovering hardcoded backdoors in its own software. The show closes with Zip Slip, a directory-traversal flaw in archive extraction libraries across many languages, plus a RAR decompressor state bug in F-Secure's antivirus.

# Key points

- VPNFilter update: more than half a million devices still; many device-specific stage-three modules; an HTTPS-stripping man-in-the-middle plugin; Steve calls it Russian state cyberwar with new indicators that command infrastructure had many more fallback locations than first thought.
- Operation Prowli: over 40,000 compromised hosts across more than 9,000 companies (CMS flaws, HP backup server weak passwords, DSL modems, IoT) tied together by shared command-and-control IPs; used for mining, traffic redirection and tech support scams.
- Drupalgeddon2 status (CVE-2018-7600): passive scan of about 500,000 Drupal 7 sites found 115,000 outdated, 134,000 patched, 225,000 undeterminable; Drupal developers contested the method; Leo notes major Drupal upgrades are painful.
- "Root Bridge" (Kevin Beaumont): vendors ship Android devices (TVs, DVRs, even tanker systems) with unauthenticated ADB listening on port 5555; scanning for that port spiked in February; a cryptomining worm propagates; Shodan shows over 82,000 such hosts in China. GRC ShieldsUP! can probe port 5555 on demand.
- Cisco backdoors: researchers found another hardcoded SNMP-related backdoor in Cisco Wide Area Application Services, the fourth such find that year; Steve wonders about NSA implants or insiders but concedes it is unknowable.
- Stealthy miners: a new cryptominer runs via Task Scheduler every minute from midnight and exits when it sees Task Manager-like tools or certain games; Steve says smarter miners would run at idle priority and back off on load.
- Fancy Bear (APT28) shifted from tightly targeted phishing to broader spraying using harvested email addresses (Palo Alto Unit 42).
- MyHeritage: 92 million account email/password-hash records leaked (snapshot October 2017); DNA and payment data lived in separate databases; per-user salted hashes; disclosed immediately; GDPR's 72-hour rule noted.
- Adobe Flash zero-day (exploited via Office documents with embedded Flash) prompted an emergency update; Steve urges Adobe to kill Flash remotely instead of waiting until 2020.
- Marcus Hutchins (MalwareTech): the government filed a superseding indictment with added counts; commentators argue the case is weak.
- Zip Slip (Snyk): archive libraries for zip, tar, jar, war, cpio, apk, RAR and 7z in many languages accepted entries with ../ paths that write outside the extraction folder; thousands of projects affected; Java suffered because handwritten snippets spread via Stack Overflow. Interpreters (decompressors) are a recurring theme.
- Antivirus RAR bug: a first RAR entry claiming to continue a solid-mode stream left decompressor state uninitialized, enabling code execution in F-Secure's scanner (fixed); Avast and Bitdefender had related issues.
