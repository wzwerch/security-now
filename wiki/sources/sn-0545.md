# Summary

A light news week. Oracle announced that the Java browser plugin will be deprecated in JDK 9 and later removed, pushing developers toward plugin-free Java Web Start. Google's February Nexus security bulletin fixed two critical Broadcom WiFi driver flaws (exploitable only from the same WiFi network) and further critical bugs in the Android mediaserver component, which Steve described as a normal OS patch cycle. Windows 10 moved from optional to recommended in Windows Update, and two listeners challenged Steve's earlier compromise on warrant-accessible encryption: every other vendor would also need a key vault, and other governments would demand access. A long segment covered the Zeo EEG sleep monitor, which Steve found on the surplus market for about 40 dollars. The main topic corrected his earlier advice on IoT isolation. Two chained routers fail either way: IoT devices on the inner router can discover the middle network by tracing routes and then probe it, while IoT devices on the middle network share Ethernet with the main router and can use ARP spoofing to become a man in the middle. The robust answer is a root router with separate NAT routers hanging off it like a Y, each network behind its own router.

# Key points

- Oracle: browser plugin support is disappearing from browsers, so the Java plugin will be deprecated in JDK 9; Java Web Start is the suggested alternative.
- Android February bulletin: two critical Broadcom WiFi driver flaws (same-network attacker, kernel memory corruption) and two critical remotely reachable mediaserver issues (malformed media via browsing, mail or MMS); Nexus owners should update.
- Windows 10 upgrade becomes a recommended update; the official block feature and the GWX Control Panel remain the ways to avoid it.
- Listener rebuttals on escrowed phone keys: all vendors, not only Apple, would need secure key safes, and a key accessible to U.S. courts could be demanded by other governments. Steve calls the idea a useful thought experiment with real holes.
- Sysinternals TCPView is a Windows GUI alternative to netstat for viewing connections.
- Why two routers are not enough: with IoT on the inside router, a malicious device can reveal the middle network's addressing via a short-TTL trace and probe it with ordinary IP packets; with IoT on the middle network, it sits on the same Ethernet as the secure router's uplink.
- Ethernet uses 48-bit MAC addresses and is non-routable; ARP maps IP to MAC by broadcast with no authentication, so a malicious device can answer first for the gateway and relay traffic (ARP spoofing), invisible to the victims.
- Dumb NAT routers block Ethernet broadcasts and ARP, so putting each network behind its own router that feeds a shared root router isolates them with no configuration. VLANs can emulate this but need tag-aware switches.
- Trade-off: you cannot reach an isolated IoT device from the secure side except by joining its WiFi, so name that network clearly and forget it after use.
- Threat model: devices will be exposed via UPnP port mappings and found with Shodan once a vulnerability appears, creating beachheads into home networks.
- Zeo Sleep Manager Pro: a headband with forehead electrodes reads real EEG (including REM via eye-muscle signal), unlike activity-based wristbands; the app requires Android; headbands wear out and the internal lithium cell will age.
