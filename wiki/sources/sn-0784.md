# Summary

Steve starts with a Firefox error page for a site that only supports TLS older than 1.2, then explains Chrome's planned intervention against heavy ads, built on EasyList-style ad tagging and unloading ads that use extreme CPU or network resources, with intervention reports sent back through the Reporting API. Malwarebytes reports a malvertising campaign using old IE and Flash exploits on adult sites, Edge gains download controls, and September Patch Tuesday fixed 129 flaws with notable critical bugs in Exchange and SharePoint. The WordPress File Manager campaign grew to millions of probed sites, Zoom added two-factor authentication, and the Raccoon timing attack on TLS-DHE up to TLS 1.2 is judged impractical. The SpinRite forums are nearly ready. The main segment covers BlindSide, which uses Spectre-style speculation to probe kernel addresses without crashing and so defeats KASLR in a blind ROP attack, and BLURtooth, where cross-transport key derivation in dual-mode Bluetooth 4.0 to 5.0 lets a low-security pairing overwrite stronger keys.

# Key points

- Firefox shows SSL_ERROR_UNSUPPORTED_VERSION for servers limited to TLS 1.0/1.1 and says those versions will be permanently disabled; GRC still supports older versions on some servers.
- Chrome heavy-ad intervention: ads are tagged via filter lists and their descendants; an unclicked ad is unloaded if it uses over 60 seconds of main-thread time, over 15 seconds in any 30-second window, or over 4 MB of network data; thresholds sit near the 99.9th percentile and saved about 12.8% of ad network usage and 16.1% of ad CPU; flags exist in Chrome 84+; unloaded frames get an intervention report.
- Malsmoke malvertising reached large adult video sites and tried exploit kits against unpatched IE and old Flash; Microsoft is moving users to Chromium-based Edge, which gains copy and delete options when asked about each download.
- September Patch Tuesday: 129 fixes (23 critical), tying the record. Highlights were an unauthenticated Exchange remote code execution via email, seven SharePoint RCEs (one scoring 9.9), GDI and HEVC codec bugs; none known exploited yet, but patched flaws attract fast reverse-engineering. The excessive defragmentation bug is fixed, TRIM errors on hard drives remain.
- WordPress File Manager: probes rose to 2.6 million sites; two groups, including one stealing credentials for sale, closed the hole behind them and planted disguised backdoors; compromised sites should be rebuilt without restoring files.
- Zoom added two-factor authentication options (TOTP, SMS, phone call) configurable per account, role or group.
- Raccoon attack: a timing side channel against TLS-DHE (TLS 1.2 and earlier) that needs unusual server settings and proximity; vendors including Microsoft, Mozilla, OpenSSL and F5 patched.
- BlindSide (ETH Zurich, Stevens, Amsterdam; Herbert Bos): combines speculative execution with blind ROP, probing unknown kernel layouts without crashes, bypassing KASLR and demonstrating a root shell in minutes; requires code execution on the machine, so relevant to VMs and local attackers; source on GitHub.
- BLURtooth: Bluetooth 4.0 to 5.0 dual-mode devices (BLE plus BR/EDR) use Cross-Transport Key Derivation; an attacker pairing via "Just Works" on one transport can overwrite keys protecting the other, enabling man-in-the-middle; Bluetooth 5.1 tightened this, but unmaintained devices will remain vulnerable.
- SpinRite: few remaining edge cases in the benchmark; GRC's XenForo forums are nearly ready, with SQRL login extended to multiple subdomains.
