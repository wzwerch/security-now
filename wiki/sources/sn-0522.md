# Summary

After Black Hat and DefCon the news slows, so Steve and Leo finally run a Q&A. Steve starts with follow-ups: Lenovo retracted its BIOS-level Lenovo Service Engine, saying it did not follow Microsoft's guidelines, and published a firmware update and model list. He then notes an open-source ransomware sample on GitHub and why crypto itself is now trivial but running a criminal operation is not, then Mozilla's plan to require signed extensions (enforcement on by default in Firefox 41, no override in 42) and to adopt a Chrome-compatible WebExtensions API. Steve reflects on how the Ashley Madison breach and a study on search-engine manipulation of voter preferences show the Internet intersecting with real lives, uses the controversy over a politician's email server stored in a bathroom closet to stress physical security, and praises Google's OnHub router for automatic updates, coining the principle that anything on the Internet must be updatable by its maker. He gives a plain explanation of what SpinRite does. The Q&A covers wiping drives, Google Contributor, Sandboxie read restrictions, limited user accounts and DropMyRights, a company's VM-based browsing design, Qubes OS, advice to use Mac, Chrome and uBlock Origin, per-site ad-block toggles, and Steve's recent audio dropouts caused by losing his dedicated T1 lines.

# Key points

- **Lenovo:** retracted the BIOS file-injection service and issued firmware updates to disable or remove it; not auto-pushed; Steve notes laptop subsidy economics (pre-installed paid software).
- **Hidden Tear:** a small open-source ransomware proof of concept using AES and a key-upload design with extension lists; harmless without delivery and payment infrastructure, but illustrates how simple the cryptography is. Steve ties this to arguments against crypto bans.
- **Firefox extension signing:** warnings in 40, preference defaults to enforcing in 41, no bypass in 42; signing is free via Mozilla review. Mozilla also moves toward WebExtensions compatible with Chrome and Opera, and Firefox is splitting its rendering process.
- **Ashley Madison / SEME paper:** breach shows real-life harm from poor security; research claims search rankings can shift undecided voters by 20 percent or more.
- **Physical security:** servers kept in a bathroom closet undermine any email security; Steve describes layered access control at his own colocation.
- **Google OnHub router:** automatic updates without interrupting Wi-Fi; Steve's rule: if it is connected to the Internet, the entity responsible must be able to update it.
- **Secure wipe:** Darik's Boot And Nuke wipes whole drives; Windows `cipher /w` wipes free space; multi-pass overwriting beyond a few passes is unnecessary; drilling through platters is more reliable than degaussing.
- **Google Contributor:** listeners and Steve report positive experience replacing ads with thank-you images and itemized payments.
- **Sandboxie read blocking:** vendor says closed file path and key path settings can block reads as well as writes.
- **Standard user accounts:** Windows 7 and later pair admin and standard tokens with UAC prompts; DropMyRights helps XP users.
- **VM browsing patterns (listener):** host-only network with the VM as the file server, regex-based URL router that dispatches links to different VMs, one-way clipboard sharing.
- **Qubes OS:** per-app VM isolation by Joanna Rutkowska's team; powerful but requires abandoning the existing OS.
- **uBlock Origin preview:** Steve describes it as an HTML firewall, lightweight, cross-browser, with per-site switches; to be covered next week. A tech-support listener recommends Mac plus Chrome plus uBlock Origin and suggests setting up Windows 10 offline to get a local account.
- **Audio quality:** dropouts stem from packet loss on Steve's cable connection after losing the T1s.

# Other segments

- "The Expert" comedy video recommended; "Mr. Robot" and "Humans" praised.
- SpinRite background: began as an interleave optimizer, evolved into the strongest data recovery tool; works on SSDs; wiping tool "Beyond Recall" planned after SpinRite 6.1.
- A quip about Matthew Green noting the slow news after the conferences.
