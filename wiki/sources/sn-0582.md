# Summary

A Q&A show built around two stories. First, a Forbes-reported warrant that sought to compel everyone found at a California house to press their fingers on phones, which legal experts called overbroad; Leo suggests powering the phone off, which forces the passcode, and shares an iOS accessibility fix for the iOS 10 double-press unlock. Second, the Open Source Technology Improvement Fund's audit of VeraCrypt by Quarkslab, which found no showstoppers but a set of inherited TrueCrypt problems and a few new ones, most of which have been fixed in the current release. Steve follows up on browsers constantly rewriting session data and wearing out SSDs, tells listeners about Elon Musk's one-in-a-billion remark on base reality, summarises a battery-safety blog on lithium crystals and thin safety margins, notes his updated Healthy Sleep Formula dosage protocol, and answers eleven listener items on IPv6 and IPsec, dynamic DNS, key versus password rotation, Windows 7 update repair, the Flip Feng Shui detail, Intel True Key, SQRL rekeying, LastPass breach alerts and more.

# Key points

- Fingerprint warrant (Central District of California, May 2016): authorised forcing any person on the premises believed to be a device user to use fingerprints on phones; EFF's Jennifer Lynch says warrants must be particular; courts treat passcodes as testimonial but biometrics less so; Steve guesses it was driven by an IP address trace; powering off or a 48-hour lapse requires the passcode again.
- iOS 10 Home button: Settings, General, Accessibility, Home Button, "Rest Finger to Open" restores one-press unlocking.
- VeraCrypt audit (Quarkslab, 32 person-days, funded via OSTIF with donations from DuckDuckGo and a VPN company) tested version 1.18; Steve recommends 1.19 or later.
- Fixed items: key derivation iteration counts raised from 1,000/2,000 to roughly 200,000 and 655,000; a Personal Iterations Multiplier overflow that lowered rounds; compiler-eliminated memset wipes replaced by a secure zeroing function; old compression libraries replaced; GOST89 cipher removed (64-bit block with null IV in a kludged mode); kernel driver and boot loader issues.
- Remaining or structural concerns: key material may be paged out unless the system partition is encrypted; the kernel driver leaked file-existence information; AES software implementations are timing-attack prone without AES-NI; CRC-32 is used to mix keyfiles and authenticate headers, allowing crafted keyfiles; BIOS keyboard ring-buffer head/tail pointers reveal password length modulo 16 and UEFI may have similar buffers; command-line password and PIN options are discouraged.
- Steve concludes the audit shows a healthy project and suggests moving from TrueCrypt to VeraCrypt; he himself is fine with BitLocker.
- Browser SSD fatigue: browsers rewrite the whole session store frequently (Firefox sessionstore interval; Chrome similar); fix by lengthening the interval, moving profiles via profiles.ini to a non-SSD drive, or using a RAM disk; Process Explorer shows per-process disk I/O.
- Elon Musk's simulation argument is about reality emerging from a rule-based container like Conway's Game of Life rather than a Matrix-style avatar world; Steve mentions quantised space-time and a Star Trek holodeck episode.
- Qnovo battery blog: internal lithium crystal growth bridging an undersized safety margin between anode and cathode causes shorts and fires, worsened by fast charging and high voltage; Samsung was only first to be hit.
- Healthy Sleep Formula page now has a dosage-determination protocol; Leo orders oleamide.
- Q&A: IPv6 mandates IPsec but that does not solve authentication, so it does not replace HTTPS; spoofing blocks at ISPs would not stop valid-looking IoT floods; DuckDNS is another free dynamic DNS service with Raspberry Pi VPN guides; password rotation is generally bad, whereas a rare DNSSEC root key change was also a size upgrade; for Windows 7 updating, stop the update service, install KB 3102810, then reboot (admin batch file approach reported 100 percent success).
- Flip Feng Shui clarification: the attacker's bit flip changes the shared page, hence the victim's copy of the public key; the attacker factors the modified value and immediately authenticates against it.
- Intel True Key is limited in free tier and offers little beyond biometrics already on phones; SQRL deliberately keeps no list of visited sites to avoid giving thieves a map; LastPass now warns about Yahoo passwords, and LastPass remains acceptable after LogMeIn's purchase.
- Leo's iCloud two-factor setup delayed 30 days after resetting security questions; Yahoo plans to recycle unused addresses, so keep old accounts active.
