# Summary

Steve flags an emerging malware trend: dropping a self-signed root certificate into the victim's trust store to man-in-the-middle HTTPS, seen in a Fortnite cheat add-on downloaded about 78,000 times that injected ads (caught by the Rainway streaming service), and in a Rakhni ransomware/miner variant that installs fake Microsoft and Adobe certificates. Other items: Polar's activity map exposed identifiable military and intelligence personnel, a Blob-saving browser freeze trick fuels fake tech-support scams, Coinhive's proof-of-work link shortener is being abused, D-Link lost control of a code-signing certificate used to sign BlackTech malware, and iOS 11.4.1 adds a USB Restricted Mode with a one-hour timer. A UK study found two thirds of second-hand memory cards held recoverable data. The main topic is the EFF's STARTTLS Everywhere initiative to make opportunistic email encryption validated and downgrade-resistant.

# Key points

- Fortnite cheat malware: Rainway's whitelist logs showed hundreds of thousands of blocked ad connections; the culprit was a cheat (aimbot, in-game currency) that installed a root certificate and injected ad content; hosting provider removed it and ad platforms pulled the ads. Steve wants operating systems to restrict root-store changes to the OS vendor's update mechanism.
- Polar Flow's public Explore map revealed names, routes and heart-rate data for opt-in users, letting journalists (De Correspondent, Bellingcat) identify military and intelligence personnel; Polar suspended the feature. Leo notes sequential user IDs in an API also contributed.
- Browser-lock scam: abuse of an asynchronous save-blob call in a tight loop pegs the CPU and freezes Chrome and other non-Microsoft browsers, pushing victims to call a fake support number; fix is to kill the browser via Task Manager or Force Quit.
- Audit third-party app permissions on Google accounts (a Wall Street Journal piece about email-scanning apps; Leo calls it link bait).
- Rakhni variant (Kaspersky): checks for virtual machines, then chooses ransomware if a bitcoin folder exists, a MinerGate miner if the machine has enough processors, otherwise acts as a worm; uses rogue certificates to look like Microsoft/Adobe.
- Coinhive launched a mining-based link shortener (cnhv.co) that attackers plant on compromised sites in hidden iframes; only a minority of AV engines flagged it at first.
- D-Link (and Changing Information Technology) code-signing certificates were used to sign BlackTech's Plead backdoor and a password stealer; revocation after the fact does not protect against already time-stamped signatures and most AV does not check revocation.
- iOS 11.4.1 USB Restricted Mode disables data over Lightning an hour after lock; ElcomSoft found that plugging any Lightning accessory resets the timer; pressing the side button five times engages it immediately; brute-force speeds are limited to one guess per 10 minutes.
- University of Hertfordshire bought used memory cards: 36 not wiped, 29 formatted but recoverable, 25 properly wiped. Steve plans a separate secure-wipe product ("Beyond Recall") built on his new low-level SpinRite 6.1 drivers.
- USB fans handed out at the North Korea-US summit were examined and contained only power wiring; Steve still advises USB data blockers.
- STARTTLS: email has implicit-TLS ports (995 POP, 993 IMAP, 465 SMTP) and plaintext ports where STARTTLS upgrades the session; about 89% of servers advertise STARTTLS (up from 39% five years earlier), but most do not validate certificates, using self-signed ones; an active attacker can strip the STARTTLS advertisement. DANE would fix this but depends on DNSSEC (10-15% deployment). EFF's three goals: Certbot plugins (Postfix first, then Dovecot and Sendmail) for valid certificates; a preload list of mail servers' security policies to detect downgrades; lowering the barrier to running a mail server. Steve would rather move to implicit TLS ports.
- Email is store-and-forward, so intermediate servers see plaintext unless users apply PGP or S/MIME.

# Other segments

- Picture of the Week: Chinese-made USB fans from the summit.
- Reader question on running SpinRite on a Linux software RAID 6: Steve suggests overnight runs on one disk at a time, which does not break the array because SpinRite does not alter data; SpinRite 6.1 target speed is about half a terabyte per hour.
- Leo shows the itty.bitty.site trick of encoding a page entirely in a URL; Steve uses hMailServer with a blacklisting rule against guessed accounts.
