# Summary

New Intel disclosures about cache-sampling leaks (vector register and L1D eviction sampling) open the show as another microarchitectural class. Steve and Leo then dissect a Reuters report that Apple dropped plans for end-to-end encrypted iCloud backups after FBI objections, noting Apple's wording about what is and is not end-to-end encrypted is confusing and that locally encrypted iTunes backups remain the only clearly trust-no-one option. Other items include a Microsoft support-case database exposed for weeks, New York bills to bar paying ransoms with public funds, the Muhstik botnet attacking Tomato routers with default credentials, Google freezing updates to paid Chrome extensions amid fraud, and Mozilla banning nearly 200 add-ons. NIST published a Privacy Framework, a booter operator leaked over 500,000 telnet logins, and 0patch released a micropatch for the IE JScript zero-day. The main story is "SHA-1 is a Shambles", the first practical chosen-prefix collision on SHA-1, demonstrated against PGP key certifications.

# Key points

- Intel/Digital Ocean notice: new data-leakage flaws in CPU caches, affecting multi-tenant clouds; Steve calls caching itself a footprint-leaving design and notes no real-world exploits.
- Reuters: Apple abandoned a plan to offer end-to-end encrypted iCloud backups; sources cite FBI pushback. Steve and Leo stress iCloud Messages keys are stored with iCloud Backup, so backups are not trust-no-one; encrypted local backups are. Apple disclosed iCloud content for 1,568 US cases (about 6,000 accounts) in the first half of 2019.
- Microsoft misconfigured a database of about 250 million support records for roughly three weeks; found by Bob Diachenko, fixed on December 31.
- New York bills S7246 and S7289 would bar public agencies from paying ransomware ransoms; context is the Albany airport attack; Leo argues funding for defence is also needed.
- Muhstik botnet variant targets Tomato router firmware via admin web interface on port 8080 with default admin or root credentials; Steve says default credentials on WAN admin are malpractice.
- Chrome Web Store halted publishing or updating paid extensions due to fraud at scale; Mozilla banned 197 add-ons (129 from one developer fetching remote code) for remote code, data theft or obfuscation.
- NIST Privacy Framework (43 pages): voluntary risk-management checklist for privacy-by-design; Steve recommends using it for discussion with IT.
- A booter-service operator leaked IP, username and password for more than 515,000 telnet-exposed IoT devices; ShieldsUP! can reveal UPnP-opened ports; modern OSes like FreeBSD 12.1 no longer allow telnet remote logins.
- 0patch released an 18-byte micropatch for CVE-2020-0674 (IE JScript) without the side effects of Microsoft's file-permission workaround, and promises three years of Windows 7 micropatches; free for personal use, paid for organisations.
- SHAmbles (Leurent and Peyrin): first practical chosen-prefix collision against SHA-1, cost about 75,000 dollars of GPU time (900 GTX 1060s over two months), enabling forged PGP key certifications (CVE-2019-14855); chosen-prefix collisions threaten signatures and TLS/SSH handshakes; migrate to SHA-2 or SHA-3.
