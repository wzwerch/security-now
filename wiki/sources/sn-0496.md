# Summary

Most of the show is about Lenovo's preinstalled Superfish adware. It used the Komodia SDK, a commercial HTTPS-interception toolkit, which installs a root certificate and signs forged certificates on the fly; Komodia reused one private key, protected by a trivial password, across its whole customer base, so anyone who got the key (Robert Graham extracted it in about three hours) could impersonate any website to affected machines. The toolkit also accepts ancient, broken ciphers to the real servers. Steve explains why antivirus products and corporate gateways also intercept TLS, argues it can be done safely only with great care, and points to GRC's HTTPS fingerprint page and a Badfish test site; Comodo's PrivDog is named as another problem. The Intercept reported that GCHQ with NSA help had hacked SIM card maker Gemalto and obtained the keys for billions of SIMs, so 3G, 4G and LTE encryption could be bypassed, which pushes people toward end-to-end tools. Other items: the TrueCrypt phase 2 audit has been contracted to NCC Group; Internet Explorer is the last major browser adding HSTS and the Chromium HSTS preload list closes the first-visit gap; and a correction that HTTP/2 does not use zlib header compression because of the CRIME attack. Q&A topics include unsubscribe links in spam, whether firmware malware defeats disk encryption, low-level formatting, HTTP/2 server push and ad blocking, CryptoWall recovery, SQRL on shared computers, egress filtering and FaceTime versus Skype. Next week the researchers behind the 60 Minutes car hack will join the show.

# Key points

- Komodia and Superfish: Lenovo shipped laptops with Superfish visual-search adware that decrypts HTTPS using a shared root certificate. Because the signing private key was identical on every machine and its password trivial, any attacker on the same network could create certificates that those machines trust. The proxy also negotiates weak ciphers (40-bit RC4, single DES, MD5) to remote sites and is likely buggy. Users are advised to test and remove the root certificate (Windows certmgr.msc, Mac Keychain Access); Komodia also sells rootkit-like tools.
- Why this happens: encryption makes the Internet "go dark" for antivirus, corporate gateways and law enforcement; many antivirus products install their own root certificate for TLS inspection. Steve and Leo agree that if you do not need it you should avoid anything that decrypts your traffic, and that ISP caching proposals that require customers to trust an ISP certificate would be harmful.
- Gemalto: GCHQ and NSA infiltrated the SIM manufacturer (about two billion SIMs a year, supplying major carriers) and stole the per-SIM keys, enabling passive decryption of 3G/4G/LTE calls without warrants; 2G encryption was already trivially broken; SIM cards were created for billing-fraud control, not privacy. Steve urges layering end-to-end encryption such as Threema, since iMessage keys are managed by Apple.
- TrueCrypt: the second audit phase of version 7.1a is being done by NCC Group Cryptography Services; Steve says attorneys consider forks of the TrueCrypt source illegal under its license.
- HSTS: Internet Explorer in Windows 10 is the last major browser to support it; sites can be added to the Chromium preload list at hstspreload.appspot.com to protect first visits; chrome://net-internals/#hsts lets you inspect it.
- Correction on HTTP/2: shared-context zlib compression was abandoned after the CRIME attack; HTTP/2 uses a purpose-built header compression with pre-assigned tokens and deltas.
- The documentary "Citizenfour" won an Oscar and airs on HBO; Steve says it taught him to respect others' privacy concerns.
- Unsubscribe links in spam can lead to malware, and are a vector for social engineering.
- Hard drive firmware malware (from the Equation Group report): researchers found only the dropper, not infected firmware, because firmware cannot be read back; whether disk encryption defeats it is unknown, though the implant's knowledge of specific file systems suggests it may help.
- Low-level formatting is no longer possible on modern drives; commands now just write zeros. SpinRite 1 was originally a low-level formatter.
- HTTP/2 push: the client and server exchange settings, server push obeys the same-origin policy and is announced via a push-promise frame the browser can refuse, so bandwidth and ad blocking concerns are limited.
- CryptoWall: a non-admin victim could still be infected locally; Steve points to BleepingComputer forums for CryptoWall 3 help and notes the old FAT undelete method.
- SQRL for shared computers: multiple identities can be created and a setting can ask which identity to use at each authentication; one company expects it to cut password-related support calls.
- Egress filtering: ISPs should drop outbound packets whose source address is not in their network, which would stop spoofed SYN floods and reflection attacks; the only reason it is not done is inertia.
- SpinRite roadmap: SQRL first, then SpinRite 6.1 (free, about a terabyte per hour), then SpinRite 7 with parallel multi-drive operation.
- Skype versus FaceTime: Microsoft has changed Skype to allow lawful interception while Apple still claims to refuse; neither is trust-no-one, and open-source tools such as RedPhone or Silent Circle are better.
