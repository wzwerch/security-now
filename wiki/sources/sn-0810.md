# Summary

Chrome 89.0.4389.90 fixed five flaws including the third in-the-wild zero-day of 2021, a use-after-free in the Blink engine, within three days of Google learning of it, a contrast Steve draws with Microsoft's two-month delay on Exchange. Chrome 89 also cuts memory use through the PartitionAlloc allocator. Google published a working JavaScript Spectre proof of concept and urged web developers to adopt opt-in isolation headers (CORP, COOP, COEP, Fetch Metadata), which Steve expects to see slow uptake because the web is open by default. Israeli, US and Australian researchers built a cache side channel using only HTML and CSS, which Steve finds clever but overhyped. March Patch Tuesday fixed 89 flaws, including an Internet Explorer zero-day used by North Korean actors, and two critical Windows DNS server bugs; some printing updates caused blue screens. The Linux Foundation, Google, Red Hat and Purdue announced Sigstore, free code signing for open source. The main topic is a further week of the ProxyLogon crisis: attacks multiplied tenfold, at least ten state-linked groups and ransomware crews joined in, tens of thousands of servers stayed unpatched, and GitHub removed a published exploit.

# Key points

- Chrome 89.0.4389.90: Blink use-after-free zero-day (anonymously reported), WebRTC use-after-free ($500 reward), tab-group heap overflow; Chrome 89 saves memory via PartitionAlloc (as little as 78 percent of previous RAM use) and trims background tab use.
- Google's Spectre proof of concept in JavaScript leaks browser memory across platforms; mitigations such as Site Isolation and Cross-Origin Read Blocking do not stop Spectre but keep secrets out of reach. Developers can opt in with Cross-Origin Resource Policy, Cross-Origin Opener Policy and Cross-Origin Embedder Policy (both COOP and COEP are needed for guaranteed process isolation).
- Steve explains cross-site request forgery as an example of the web being open by default, and compares the needed shift to firewalls moving from allow-all to deny-all.
- "Prime+Probe 1, JavaScript 0" (USENIX Security 2021): a cache-contention fingerprinting attack built entirely from CSS and HTML, using a huge class name and attribute selectors with DNS-request timing; works on Intel, AMD, Exynos and Apple M1 and survived Tor Browser, DeterFox and Chrome Zero.
- March Patch Tuesday: 89 fixes (14 critical), an actively exploited Internet Explorer zero-day also used by North Korean actors, two Windows DNS server dynamic-update RCEs at CVSS 9.8, a Hyper-V RCE at 9.9, and five flaws under active attack including the four ProxyLogon bugs. Printing-related updates caused blue screens until optional fixes shipped.
- Sigstore ("Let's Encrypt for code signing"): short-lived certificates from OpenID Connect identities, a dedicated code-signing root CA and transparency logs; Steve sees it as the real answer to dependency confusion and open source supply chain attacks.
- John McAfee's DOJ indictment over alleged crypto pump-and-dump promotion is mentioned briefly.
- ProxyLogon scale: Check Point saw attempts rise tenfold between March 11 and 15 (US 17 percent of attempts, government and military the top sector); Threatpost counted at least 10 nation-state groups; ESET named LuckyMouse, Tick and Calypso; Huntress found over 200 distinct web shells; RiskIQ saw about 400,000 vulnerable servers on March 1, about 100,000 by March 9 and 82,000 by March 12 (Palo Alto estimated 125,000).
- DearCry ransomware (public key embedded, AES-256 bulk encryption) hit Exchange servers through Hafnium's leftover web shells; Kryptos Logic found 6,970 exposed web shells. Patching without removing web shells leaves servers open.
- GitHub removed a published Exchange proof-of-concept exploit under its policy on active exploits, sparking criticism; Marcus Hutchins and Steve backed the removal because tens of thousands of servers were unpatched. Microsoft was also reportedly probing whether a partner in its early-access MAPP program leaked details.
