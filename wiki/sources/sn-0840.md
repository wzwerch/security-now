# Summary

A new "Windows 11 Watch" segment begins with a documented registry value, AllowUpgradesWithUnsupportedTPMOrCPU, that lets machines with TPM 1.2 or unsupported CPUs upgrade, and early Windows 11 problems: an AMD L3-cache latency issue costing up to 15% in some games, profile and Start menu glitches, the File Explorer memory leak (fixed in an Insider build), and VirtualBox and Killer network optimiser conflicts. Microsoft will disable legacy Excel 4.0 XLM macros by default only for Microsoft 365 subscribers. Google warned about 14,000 Gmail users targeted by the Russian APT28 group, and announced automatic two-step verification enrolment for 150 million accounts. A US Senate committee advanced bills requiring critical-infrastructure incident reports within 72 hours and ransom payment reports within 24 hours. Twitch suffered a 125 GB source and payout-data leak, Apache 2.4.49 introduced an exploited path traversal flaw fixed in 2.4.50, and the Facebook outage sent tens of millions of users to Telegram and Signal. The closing essay notes Apple's iOS 15.0.2 fix for CVE-2021-30883 and argues that zero-day counts (Apple 17, Chrome 14 so far in 2021) are mostly a threat to high-value targets, while sharing code between iOS and macOS lowers iOS security.

# Key points

- Registry value HKLM\SYSTEM\Setup\MoSetup AllowUpgradesWithUnsupportedTPMOrCPU = 1 permits Windows 11 setup on unsupported CPUs with TPM 1.2; Steve doubts Microsoft would withhold security updates from such PCs and notes the contrast with his Never10 tool.
- AMD KB: some Windows 11 workloads see a roughly threefold L3 latency increase (3-5% typical, up to 15% in eSports titles) and preferred-core scheduling errors, with fixes promised in October.
- Other Windows 11 issues: upgraded installs keeping the old taskbar or missing the Store, spurious "does not meet requirements" messages despite a passing PC Health Check, Hyper-V versus VirtualBox incompatibility, and UDP drops with Killer and SmartByte network optimisers.
- Excel XLM macros (since 1992, abused by TrickBot, Qbot, Dridex and Zloader) will be off by default only for Microsoft 365 customers; admins can use group policy and users can set Trust Center macro options; AMSI scanning for XLM was added in March.
- Google sent warnings to roughly 14,000 Gmail users about an APT28 (Fancy Bear, GRU-linked) phishing campaign, all attempts blocked; Google TAG's Shane Huntley said such warnings indicate targeting, not compromise.
- Google auto-enrols 150 million accounts into 2SV (two-step verification) where backup methods exist, with an Android prompt for new sign-ins; Steve expects the broader rollout to be hard.
- Cyber Incident Reporting Act (Senate Homeland Security Committee): critical-infrastructure hacks reported within 72 hours and ransom payments within 24 hours; exemptions for religious groups and small businesses as defined by the Small Business Act.
- Twitch: about 125 GB leaked on 4chan including source code, an unreleased Steam competitor, internal security tooling and creator payouts since 2019; Twitch blamed a server configuration change and said no passwords or card numbers were exposed; the source seemed to be an old internal Git server.
- Apache HTTP Server 2.4.49 added a path traversal and file disclosure flaw (exploited; may lead to RCE with mod_cgi and missing "require all denied"); about 112,755 servers ran it; 2.4.50 followed on 4 October.
- During the Facebook outage Telegram reported over 70 million new users in a day and Signal also struggled with sign-ups.
- Apple's iOS 15.0.2 fixed CVE-2021-30883, an exploited IOMobileFramebuffer kernel flaw; a public bindiff write-up followed. Apple's 2021 count is 17 (10 in WebKit, 10 shared with macOS).
- Steve's "0-day angst" view: modern software is secure enough for nearly everyone; exploited zero-days are mostly used against high-value targets, are self-limiting, and Apple weakened iOS by sharing code with macOS, trading obscurity for development economies. Leo adds that exploit brokers such as NSO outbid Zerodium.

# Other segments

- Picture of the Week: a fake O'Reilly cover "Web Development With Assembly"; Steve says all GRC web services are written in assembler.
- Listener feedback: whether to buy a Mac instead of a Windows 11-incapable PC (Steve says no new hardware for Windows 11), a Windows version "good/bad" pattern, fans of Paint Shop Pro 6; errata that Apple's "Invasion" starts October 22.
- SpinRite 6.1: new benchmark with dynamic scaling is nearly done; the new I/O abstraction layer is complete and will get wider testing.
- A student's Rickroll of a school district's networked displays (whitehoodhacker.net), mentioned by Leo.
