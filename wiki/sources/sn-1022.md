# Summary

Steve first explains how to enable Firefox 137 tab groups through about:config (browser.tabs.groups.enabled). Microsoft's Recall returned in a Windows 11 preview build as an off-by-default, opt-in feature. The Mitre-run CVE and CWE programs nearly lost U.S. funding; CISA extended the contract for 11 months and a new CVE Foundation was announced to remove the single-government dependency. The Wall Street Journal reported that Chinese officials acknowledged in a December meeting that Beijing was behind infrastructure intrusions (Volt Typhoon), tying them to U.S. support for Taiwan. CISA issued generic credential-risk guidance about the legacy Oracle Cloud compromise that Oracle still has not admitted in writing. Rapid7 reported rising credential spraying aimed at accounts lacking MFA, and a Dutch study found insured ransomware victims pay 2.8 times more. BentoML reintroduced an insecure-deserialization remote code execution bug (CVE-2025-27520). The CA/Browser Forum unanimously passed ballot SC-081v3 stepping maximum TLS certificate lifetimes down to 47 days by 2029, which Steve strongly questions. The main topic is Windows Sandbox, a disposable, hypervisor-isolated clean copy of Windows built into Pro, Enterprise and Education editions that reuses the host's files and memory.

# Key points

- Firefox tab groups are shipped but disabled; enable via about:config keys under browser.tabs.groups.
- Recall reappears in the Windows 11 Release Preview channel (build 26100.3909) and will be opt-in.
- CVE program: Mitre warned on 15 April 2025 that the contract would lapse; CISA exercised an option for 11 months; the CVE Foundation (non-profit) formed to take over; ENISA launched the EUVD database. Steve and Leo stress the value of a single naming authority and worry about CISA's current state and politics around Chris Krebs.
- China acknowledged the infrastructure hacking in a secret December meeting (ports, water utilities, airports) and linked it to Taiwan policy.
- CISA alert on the legacy Oracle Cloud compromise: reset affected passwords, hunt for hardcoded credentials, monitor logs, use phishing-resistant MFA. Steve says Oracle's refusal to be open destroys trust.
- Rapid7: over a million brute-force login attempts using the Go FastHTTP library, about 70% from Brazil; remote access without MFA was the top initial-access vector in prior reports. Steve advises MFA everywhere, auditing and removing stale accounts, disabling legacy authentication, using IP-based filtering (accepting its brittleness), and keeping MFA on a separate device; passkeys give servers no secrets to lose.
- BentoML 1.3.8 through 1.4.2 are vulnerable to unauthenticated remote code execution through unsafe pickle deserialization; the fix for the earlier CVE-2024-2912 had been removed in a later version; fixed in 1.4.3.
- Google decided to keep its current third-party cookie approach in Chrome, ending the planned phase-out and Privacy Sandbox prompt.
- Certificate lifetimes: 398 days until 15 March 2026, then 200 days, 100 days from March 2027, and 47 days from March 2029. All four browser vendors and 25 of 30 CAs voted yes with none against. Steve notes the browser-side CRLite Bloom filter revocation already works, that DDoS or outages could cause certificates to expire, that ACME already secures about 70% of web servers, and that private trust roots may become attractive for appliances.
- Crosswalk buttons in Silicon Valley were hacked to play AI-generated voices of tech billionaires, reportedly due to default PINs (speculation by Xeno Kovah); the maker Polara did not comment.
- Google Play services 25.14 mentions enabling a future optional feature that restarts a phone locked for three days.
- EFF opposes Florida SB 868/HB 743, which would force social media platforms to provide a mechanism to decrypt end-to-end encrypted messages of minors; Steve agrees backdoors cannot be limited to the good guys.
- Ransomware research (Dutch): insured victims pay 2.8x more; attackers search for insurance documents; good backups reduce payment 27-fold; in 95% of paying cases no recovery alternative existed because backups were destroyed.
- Windows Sandbox: enable via "Turn Windows features on or off"; requires virtualization support in firmware; uses Windows container technology, a dynamic base image of about 100 MB linked to host files, direct-mapped host memory pages, an integrated scheduler, snapshot and clone for fast start, virtual GPU and battery pass-through; one instance at a time; everything is discarded on close; defaults include networking, clipboard sharing and microphone, all changeable via .wsb XML configuration files.
