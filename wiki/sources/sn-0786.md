# Summary

The episode opens with a counterfeit Seagate drive photo and a look at Chrome 85, which fixed ten flaws including serious remote code execution bugs; the top bounties were 15,000 and 10,000 dollars, and Steve praises finders who report rather than sell to exploit brokers such as Zerodium. Next is a report that the FortiGate SSL VPN client by default does not check the gateway certificate's name, making man-in-the-middle interception easy, with roughly 200,000 exposed businesses; Fortinet reportedly declined to change it. Steve then summarizes BleepingComputer's one-week ransomware timeline and covers the REvil/Sodinokibi affiliate drive, followed by the Ryuk attack on Universal Health Services, where hospitals lost systems and four deaths were attributed to the outage. He comments on Amazon Ring's Always Home Cam drone. After a Vitamin D aside, GRC news (InitDisk success story, new XenForo forums with non-public registration), the main topic returns to Zerologon, which went from three public exploits to dozens, was confirmed by Microsoft as exploited, and also affects Samba; 0patch offered a micropatch for the unsupported Windows Server 2008 R2.

# Key points

- Chrome 85 (desktop build 85.0.4183.121) fixed 10 security issues, none known to be exploited; details are withheld until most users update. Steve advises forcing an update via the About page.
- FortiGate SSL VPN: the client with default settings accepts any validly signed certificate and does not check the name, so an attacker who intercepts the connection (for example a compromised IoT device) can relay credentials to the real gateway. SAM Seamless Network found about 230,000 devices on Shodan, roughly 88% on defaults; Fortinet said the user can replace the certificate. Steve's takeaway: the VPN gateway you choose matters.
- Ransomware week roundup: Egregor, ThunderX (free decryptor exists), assorted Matrix and STOP variants, a Mount Locker campaign that steals files first, AgeLocker hitting QNAP NAS devices, and a Go-based fake REvil with no contact information that may be a wiper. Luxottica and Tyler Technologies were also hit.
- A cyber insurer that scans clients before underwriting reported a 65% drop in later ransomware claims.
- Nathan Wyatt (Dark Overlord) was sentenced to five years for extortion.
- REvil (Sodinokibi) reopened affiliate recruitment and showed about 99 bitcoin on a hacker forum; the ransomware-as-a-service split is typically 20-30% to developers and 70-80% to affiliates.
- Universal Health Services (about 400 facilities) was hit by Ryuk; systems went offline, ambulances were diverted, and four deaths were ascribed to delays. Reporting pointed to an Emotet and TrickBot phishing chain; Steve doubts a sprawling network can be fully secured.
- Antivirus coverage of Zerologon tooling was only around 43-45 of 71 scanners, which Steve says shows signature-based limits.
- Ring Always Home Cam: a 250 dollar flying camera docking to a base; Steve notes the humming noise, privacy and hijack concerns and pets.
- Zerologon update: many public exploit and scanner scripts, a Metasploit module, Microsoft observed real attacks within a day of CISA's directive; the flaw resets the domain controller's machine password to an empty value.
- Samba implements the Netlogon protocol and is vulnerable unless it enforces secure channel (the default since 4.8); the advice is to set server schannel to yes.
- 0patch released a 29-byte micropatch for Windows Server 2008 R2 (out of support) and plans ports to supported servers.

# Other segments

- Photo of the Week: a counterfeit Seagate BarraCuda with misspelled label text; Steve advises checking gear bought online.
- Health aside: Dr. Fauci's reported 6,000 IU daily Vitamin D dose, a discussion of RDA limits and Vitamin C.
- GRC: InitDisk revived a failed USB stick for a Reddit poster; GRC's new XenForo forums at forums.grc.com are open for early ID registration; Steve removed his WordPress blog and moved it into a forum; SPF, DKIM and DMARC records were set up; ReadSpeed benchmark still in finalization.
- Housekeeping: an ITProTV panel on IT after COVID with Amy Webb.
