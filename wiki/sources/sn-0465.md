# Summary

The main topic is a HOPE X talk by forensic expert Jonathan Zdziarski, which the press turned into "iOS backdoor" headlines. Steve read the underlying paper and argues the key point is device pairing: undocumented services such as a packet capture facility and file-relay are only reachable by a computer holding a trusted pairing record, created over a physical USB connection, and since iOS 7 the device must be unlocked and the user must accept. He agrees the pairing record is effectively a long-lived skeleton key (kept until a restore or erase), that users should be able to audit, expire or revoke pairings, that debug services should be limited to developer mode, and that Apple should explain itself, but he does not see deliberate surveillance. Leo adds that a screen lock is only a UI lock and that powering off flushes decrypted keys; the Apple Configurator offers stricter control. In the news, Chrome removed its "check for certificate revocation" checkbox, Level 3 rebutted Verizon's Netflix diagram by showing the L.A. interconnect is only four 10 Gbit/s ports that could be expanded quickly, Microsoft Research's paper on password portfolios was misreported as telling users to stop using strong passwords, Oracle shipped Java 7 Update 65, and canvas fingerprinting (mostly via AddThis, about 5.7 bits of entropy) was debunked as less sinister than headlines claimed. Steve also recommends the EFF's Privacy Badger, notes Dell accepting bitcoin, and promotes the film "Particle Fever" and his DNS Benchmark.

# Key points

- Chrome removed its revocation-check option: desktop Chrome already benefits from the OS revocation stack, mobile platforms provide nothing, and Steve expects Chrome to build its own, helped by the BoringSSL fork.
- Firefox 31 released with only incremental changes.
- Level 3 versus Verizon: the congested point is one L.A. interconnect with four 10 Gbit/s ports (40 Gbit/s total); Level 3 says adding ports takes minutes; Leo sees monopoly leverage, Steve stresses that one provider generating so much traffic breaks diffusion assumptions.
- Microsoft Research "Password portfolios and the finite effort user" argues different sites merit different password strength; Steve says password managers or SQRL already solve the burden.
- Oracle's Java 7 Update 65 fixed about 20 remotely exploitable flaws ("patch it or pitch it" per Krebs).
- Canvas fingerprinting (renders text and shapes to a canvas and hashes the bitmap) was found on 5.5 percent of the top 100,000 sites, 95 percent via AddThis, but only gives under 6 bits of entropy.
- EFF Privacy Badger is a tracker blocker that learns algorithmically and needs little configuration; Steve notes Ghostery itself tracks.
- Dell began accepting bitcoin through Coinbase.
- Zdziarski's findings: pairing leads to iTunes-like control; before iOS 7 pairing was silent; pairing works over WiFi afterwards (lockdownd on TCP port 62078); backup-encryption bypass and "undocumented" services; recommendation that law enforcement seize desktops for pairing records.
- Steve's reading: no iOS 7 jailbreak existed, the attack requires physical USB pairing and an unlocked device, so words like "spilling all data" are overblown; still, persistent pairing and always-running services deserve user control.
- Plugging into untrusted chargers should never prompt for trust; users should decline.
- Advice: use a strong passcode, power the device off to flush working keys, consider Apple Configurator supervision.

# Other segments

- DNS Benchmark has been downloaded about 1.5 million times; SpinRite questions about repairing a MacBook drive on a Windows PC; Steve says SpinRite only fixes drives.
- ABetterQueue (Rotten Tomatoes filter for Netflix), "Particle Fever" film recommendation.
