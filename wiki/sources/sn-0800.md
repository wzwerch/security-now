# Summary

The first show of 2021 takes a longer look at fewer stories. Steve opens with the old PayPal/VeriSign one-time-password "football" token and explains time-based versus event-based one-time codes. He then discusses a false McAfee detection of a ReadSpeed DOS splash program and how unsigned or newly signed code is treated with suspicion. Chrome received a retry-loop workaround because antivirus products briefly lock newly created files; Steve calls it a kludge and says AV tools should block the calling thread instead. Zyxel enterprise firewalls and gateways (over 100,000 devices) were found to carry a hardcoded admin account, a repeat of a 2016 incident, and Steve doubts the vendor's explanation. The FBI warned about swatting attacks run through hijacked smart cameras on accounts that reuse email passwords. Two PHP deserialization flaws (Zend, CVE-2021-3007, and Yii) are covered. Steve explains how SSD trimming interacts with SpinRite Level 3 passes and ReadSpeed results, and announces work on SpinRite 6.1 has begun. The show closes with SolarWinds Orion follow-ups: an authentication bypass in the Orion API used for Supernova, and Microsoft's statement that source-code viewing is not a risk because of its inner-source model.

# Key points

- Authenticator history: the PayPal token (made by VeriSign) used event-style codes; TOTP uses a clock plus secret, YubiKey OTP uses a counter checked by a central server.
- McAfee flagged a harmless ReadSpeed DOS splash file as a trojan (2 of 60 engines on VirusTotal); new certificates and unsigned binaries trigger false positives; Steve plans to sign future SpinRite releases.
- SolarWinds showed that even code signed by a long-trusted certificate can be malicious.
- Chromium added a retry loop around ReplaceFile (bug 1099284) because AV scanners lock new files, breaking saves of bookmarks; Steve argues AV hooks should suspend the requesting thread rather than return errors.
- Zyxel ATP, USG, USG Flex, VPN and NXC devices contained a hardcoded admin credential (account "zyfwp") reachable over the web admin port and SSH, found by Dutch researchers at Eye Control; patches issued, NXC patch due January 8; the vendor's "firmware update over FTP" explanation does not fit the exposed ports. Mitigation: patch and disable external admin access.
- The 2016 Zyxel backdoor (CVE-2016-10401) is still in botnet password lists; the new one is worse because it needs no prior access and hits enterprise gear.
- FBI public service announcement: attackers use credential-stuffed smart camera accounts to livestream and speak through devices during swatting calls; use unique passwords and 2FA. Ring had added extra protections and was preparing end-to-end video encryption.
- PHP runs about 80% of sites with a known language; untrusted deserialization flaw in the Zend framework (CVE-2021-3007, also affecting successor Laminas) could allow remote code execution; Yii has a similar disclosed flaw; deserialization is on the OWASP Top 10.
- SSD behaviour: unwritten regions read back as zeros at interface speed, so ReadSpeed shows impossible maximum numbers; a SpinRite Level 3 pass writes everywhere and leaves the SSD "untrimmed", which can slow later writes; fix is an OS re-trim (PowerShell Optimize-Volume with -ReTrim) afterward. A Level 2 scan alone often restores front-of-drive speed.
- SpinRite 6.1: ReadSpeed's new drivers proved robust; SpinRite's 31 assembly files were assembled and driver integration began on January 3, 2021.
- SolarWinds Orion API authentication bypass (CVE-2020-10148) tied to the Supernova malware; Microsoft reported one internal account was used to view (not change) source code and noted its inner-source approach assumes attackers know the source.
