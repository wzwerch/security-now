# Summary

Jason Howell fills in for Leo. The lead story is Kazakhstan's government requiring citizens to install a state root certificate so ISPs can intercept HTTPS; a cloned Facebook certificate signed by that root was observed in the wild, and Mozilla, Google and Microsoft are weighing a response (blacklisting versus persistent warning). Firefox 70 will flag all HTTP pages as not secure, Firefox 68 exposes about:compat for site-specific compatibility fixes, Chrome 76 closes the file-system API leak that let paywalled sites detect incognito mode, and Mozilla is exploring a Tor-mode add-on. A fast Rust TLS library (Rustls) beats OpenSSL in the author's benchmarks, and Microsoft announced the open-source ElectionGuard voting SDK using homomorphic encryption. More than a million ProFTPD servers are exposed to a mod_copy flaw allowing unauthenticated file copying. Steve shares SQRL ecosystem progress and announces OWASP talks in Dublin and Gothenburg. The final segment covers Sophos honeypots: ten RDP servers received 4.3 million password guesses in a month, the first within about 84 seconds, which supports hiding RDP behind a VPN.

# Key points

- Kazakhstan: July 17, 2019 start of HTTPS interception via an ISP-pushed government root; fake *.facebook.com certificate with issuer "Security Certificate" seen; official later claimed installation was voluntary; Mozilla, Google, Microsoft consulted; Kazakh citizens asked for blacklisting; a similar 2015 attempt had collapsed after lawsuits and Mozilla refusal.
- Firefox 70 will mark all HTTP pages "not secure" (HTTPS exceeds 80 percent of sites); relevant about:config flags under security.insecure_connection exist; grc.sc serves an HTTP page for testing.
- about:compat lists Firefox's per-site webcompat interventions, including spoofed user-agent behavior.
- Incognito detection: paywall sites used Chrome's file-system API difference; Chrome 76 (July 30) fixes it and Google pledged to fix other detection methods.
- Firefox "Tor mode" proposal (add-on with Tor compiled to WebAssembly, dedicated profile window, HTTPS required) discussed at a Tor meeting in Stockholm.
- Rustls: benchmarks by its author show faster handshakes, resumption, bulk transfer and half the memory of OpenSSL; Steve urges caution with new TLS stacks; notes Microsoft's finding that about 70 percent of their security bugs are memory-safety issues and growing Rust adoption.
- ElectionGuard: tracking codes let voters verify counts; homomorphic encryption lets votes be tallied encrypted; third-party verifier apps; open-sourced on GitHub; partners include Smartmatic and Clear Ballot.
- ProFTPD mod_copy (SITE CPFR/CPTO) lets anonymous clients copy files on the server; over a million Internet-visible servers; remedy is disabling mod_copy.
- SQRL: sqrl-ssp in Go, a C service provider, PAM module, Symfony and Drupal work; second spec document "SQRL Operating Details" near release; OWASP talks in Dublin (Sept 24) and Gothenburg (Sept 26).
- Sophos "RDP Exposed" honeypots: 10 honeypots on AWS, first login attempt after 1 min 24 s (Paris) to about 15 hours (Singapore), 4.3 million attempts in 30 days rising to about 205,000 per day; password guessing is the initial access for SamSam, Dharma, Matrix, BitPaymer and Ryuk; recommendation is to remove RDP from the Internet or require a VPN.
