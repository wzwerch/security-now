# Summary

At the start of the show's 14th year, Steve reviews August's Patch Tuesday (60 Microsoft fixes, 19 critical remote-code-execution bugs, two exploited in the wild: an Internet Explorer memory corruption flaw and a Windows shell path-validation flaw; also an Exchange mail-delivered flaw, a GDI font flaw, another LNK shortcut flaw, and 11 Adobe fixes). Skype gained Signal-protocol private conversations. Chrome's "update or remove incompatible applications" warnings are the step before Chrome 72 blocks third-party code injection. After the previous week's Google location-history controversy, a class-action suit and an EPIC complaint to the FTC followed and Google amended its wording. Microsoft seized six more fake domains tied to APT28 (84 total). Researchers at BSides showed "Turning Tables" page-table abuse of shared DLLs, USENIX papers covered ReDoS and browser-based mining, and the main item is Foreshadow (L1 Terminal Fault), which defeats Intel SGX without needing any exploitable gadget and was disclosed after Intel knew since January.

# Key points

- Patch Tuesday: 60 Microsoft flaws; exploited IE and shell path bugs; SQL Server, Edge PDF, Exchange, GDI font and LNK file flaws; Adobe's 11 fixes included Acrobat and Reader and Flash.
- Skype private conversations use Signal protocol (Android 8.15, Windows 8.28); Steve notes the endpoint remains the weak point and suggests a dedicated device for truly secure messaging.
- Chrome 68 begins naming incompatible injecting software (several antivirus and utility programs); Chrome 72 is slated to block injection; Edge already does.
- Google location tracking follow-up: class-action suit, EPIC letter citing the 2011 FTC consent order; Leo and Steve debate whether the two location settings were clear.
- Microsoft's Digital Crimes Unit took down six APT28 spoof domains (Senate, conservative groups, Office 365 lookalikes); 84 in total since 2016.
- Turning Tables (enSilo): shared read-only DLL memory across processes can be abused when a flaw exists in a commonly shared DLL.
- ReDoS: a carefully crafted 50-character input can block a vulnerable JavaScript server for ten minutes; 339 of tested Express sites (11 percent) were vulnerable.
- Coinhive: German researchers found it generated about 1.18 percent of mined Monero blocks, roughly a quarter million dollars a month; their fingerprinting found up to 5.7 times more miners than blocklists.
- Foreshadow / L1TF: speculation on missing page-table entries lets an attacker read from L1 cache across processes, VMs and SGX enclaves, bypassing earlier Spectre mitigations; fixes need microcode plus OS support; AMD says it is not affected; disabling hyperthreading is a costly interim mitigation; risk is mainly for cloud servers.

# Other segments

- Picture of the Week: a door keypad with its passcode printed on it.
- Listener feedback on lithium-ion charging (fast charging is fine, avoid heat and overcharge; smart chargers handle it) and a SpinRite/SMART question about old laptop drives with a stable relocated-sector count.
- Anniversary cake, a young viewer in the studio, and Leo's escape-room story.
