# Summary

Chrome received its third zero-day fix of 2022, another V8 type confusion found in use by Google TAG (desktop 100.0.4896.127); Steve again points out the risk of a Chromium monoculture. Microsoft's April Patch Tuesday fixed 128 flaws (10 critical, 47 remote code execution, 47 elevation of privilege including 15 in Print Spooler), with an exploited Common Log File System zero-day found by the NSA and CrowdStrike, a publicly disclosed User Profile Service race-condition bug, and 17 remote code execution flaws in the Windows DNS Server found by Yuki Chen. The WordPress Elementor plugin (over five million installs) had an arbitrary file upload problem introduced in 3.6.0 and fixed in 3.6.3, disclosed amid a feud with a vulnerability-tracking vendor. A repeat double-evaluation flaw in Apache Struts' OGNL (CVE-2021-31805) is a reminder of the Equifax lesson. Steve uses a Record article to argue that the old technology in US nuclear command systems has been an unintended protection, citing a 1979 false alarm caused by a training tape. Listener feedback shows Gmail also reveals unknown accounts at login, and Steve explains why router auto-updates and enterprise Autopatch differ. A SpinRite update describes new drivers and benchmarking. The main topic is CVE-2022-26809, a CVSS 9.8 integer overflow in the Windows RPC runtime that could enable a zero-click worm against 1.3 million exposed machines.

# Key points

- Chrome zero-day number three of 2022: type confusion in V8, fixed in 100.0.4896.127; Chromium-based browsers must also update; Google withholds details until patching is widespread.
- April 2022 Patch Tuesday: 128 fixes across Windows, Office, Exchange, Defender, Visual Studio and more; CVE for CLFS elevation of privilege (CVSS 7.8) exploited and reported by NSA and CrowdStrike; User Profile Service flaw (CVSS 7.0) publicly known; two 9.8 flaws (Windows Network File System and RPC runtime); Edge got 26 fixes.
- Windows DNS Server: Yuki Chen (top of the Microsoft researcher list) reported 18 flaws, 17 of them remote code execution.
- Elementor plugin: missing capability checks allowed authenticated users to upload files and run code; introduced in 3.6.0 (22 March) and fixed in 3.6.3; only about 30 percent of users were on 3.6.x after a month; Patchstack and Wordfence-type firms sell virtual patching; Steve repeats that WordPress core is solid and most flaws sit in free plugins (91 percent).
- Apache Struts and OGNL: OGNL is a powerful expression language that evaluates user-influenced input; the 2020 double-evaluation fix (CVE-2020-17530, Struts 2.5.26) was incomplete (CVE-2021-31805); update to Struts 2.5.30 or later and avoid forced OGNL evaluation on untrusted input; Equifax lost data on 143 million people in 2017 through an unpatched Struts.
- Nuclear systems: US nuclear command and control used 1970s IBM Series/1 computers with eight-inch floppy disks until about 2019; experts (Herb Lin and others) say complexity is the enemy of security and old, obscure systems are hard to hack; Stuxnet shows air gaps can still be crossed; the 1979 false alarm of 200 inbound missiles came from a training tape and was caught by human judgment.
- Login feedback: Gmail and other services (including password managers) also tell users that an account does not exist; Steve explains why feedback helps attackers enumerate accounts and compares a split guess to the WPS PIN flaw.
- Updates debate: for set-and-forget routers Steve favors automatic critical-only updates by default; for enterprises he prefers testing, so Windows Autopatch (rings, rollback) mainly makes sense for small businesses and reads to him like capitulation on Windows quality.
- SpinRite 6.1 work: 16 MB buffers speed up SSDs, but some spinning drives perform better with 127-sector transfers like the BIOS; new native drivers split transfers efficiently, benchmark both ways per drive and remember the best.
- CVE-2022-26809 (Windows RPC runtime, rpcrt4.dll, CVSS 9.8, discovered by BugHunter010 of Kunlun Lab): integer overflow in packet handling (GetCoalescedBuffer) that leads to a heap overflow; Microsoft marks exploitation as more likely; Akamai, Marcus Hutchins and SANS published patch analyses within days; no public exploit yet.
- Exposure: Will Dormann counted about 1.33 million reachable Windows machines; Censys found 1.3 million SMB hosts, 824,011 positively Windows (366,000 in the US, 144,622 in Russia); RPC can be reached via ports 135, 445 and others, so blocking 445 alone is not enough.
- Steve expects targeted use first rather than a worm, plus use in lateral movement toolkits; mitigation is patching, never exposing Windows services publicly, IP-restricted site-to-site rules and a WireGuard VPN (or port knocking) for roaming users.
