# Summary

Steve starts with the week's LastPass story: Tavis Ormandy found a message-hijacking flaw in the LastPass 4.x Firefox add-on that a malicious page could abuse to run vault actions in the background, which LastPass fixed almost immediately; a separate, year-old URL-parsing report was re-posted and confused the news. He then covers research (published ahead of DEF CON) showing that cheap non-Bluetooth 2.4 GHz wireless keyboards from several brands send keystrokes unencrypted and can be sniffed or injected into from a distance with inexpensive radio hardware; advice is to use wired or Bluetooth keyboards. NIST's draft guidance now deprecates SMS for out-of-band authentication, which Steve prefers to see replaced by time-based one-time codes. A quirk lets assistive-technology users still obtain the free Windows 10 upgrade after the public deadline. Errata cover Firefox's certificate store being manageable by a domain-joined employer, and TIFF still being widely used. The main topics are why phishing and site spoofing defeat all second factors by acting as a relaying man in the middle, how SQRL mitigates this (IP matching, and a client-provided-session design he later removed because of Microsoft's localhost restrictions), and a tutorial on packet filtering with multi-interface routers such as the Ubiquiti EdgeRouter X and pfSense.

# Key points

- LastPass: 4.x Firefox add-on flaw (not present in the 3.x line) fixed in a pushed update; the earlier URL-parsing report by another researcher had been fixed a year before; both required luring the user to a malicious site. Steve praises the vendor response and the Project Zero disclosure model.
- Wireless keyboards (Bastille Research, KeySniffer): eight brands using proprietary non-Bluetooth 2.4 GHz links with no real encryption allow eavesdropping and keystroke injection from hundreds of feet; dongles beacon continually so targets can be found; Logitech-style dongle pairing issues were reported earlier. Use wired or Bluetooth.
- NIST: SMS-based out-of-band verification must at least check the number is a real mobile number, and is deprecated for future guidance; SS7 weaknesses are the reason.
- Windows 10: the free upgrade ended in late July, but Microsoft's assistive-technologies page still supplied the upgrader; the Get-Windows-10 update KB was reportedly being withdrawn.
- Errata: a domain administrator can push a certificate into Firefox's store, so a VM is the more robust way to avoid a corporate interception proxy; TIFF persists in scanning, fax and archiving.
- Phishing and spoofing: a fake site relays the victim's credentials and then relays any second-factor challenge (QR code, TOTP, SMS, picture grid) to the real site, so HTTPS and MFA do not stop it; password managers help only because they will not auto-fill on a lookalike domain, and users learn to copy-paste manually.
- SQRL mitigation: the server embeds the requesting IP so authentication from a different IP fails; a localhost "client-provided session" (CPS) design would hand the session straight to the local browser, but Steve removed the localhost plumbing after Microsoft signalled restrictions, keeping CPS in the spec for a future browser-native or add-on client.
- Packet filtering tutorial: separate router ports can carry separate subnets with their own ordered rule lists (ACLs) matching source/destination IP and port; first match wins; stateful rules allow replies to established connections, so an IoT network can reach out but not into the trusted LAN; time-of-day rules are possible; order high-traffic rules first for speed.
- pfSense includes the Squid proxy, which Steve will use to test SQRL's proxy support.
