# Summary

The episode begins with a Chromium blog post on Chrome 92, which now classifies phishing pages up to 50 times faster at the median by counting a page's colour profile with a single hash map and summing consecutive pixels; all of it happens locally so no images leave the browser. Kaseya announced it had obtained a universal decryptor for the REvil attack, effective for all victims, and denied paying a ransom. Steve explains from the earlier "REvil's Clever Crypto" episode how a master key from the affiliate or the REvil gang would make this possible. SentinelLabs found a 16-year-old vulnerable driver (SSPORT.SYS, CVE-2021-3438) shipped with hundreds of HP, Samsung and Xerox printer models, which Steve uses to show how Windows' IOCTL design lets any third-party driver bug become a kernel-level privilege escalation. He praises GitHub for bringing advisory, dependency graph and Dependabot features to Go modules. The main topics are SeriousSAM/HiveNightmare (CVE-2021-36934, SAM and registry hives readable by all local users) and PetitPotam, an NTLM relay coercion attack that can let an attacker inside a network take over Active Directory via AD CS web enrolment. Steve's recurring theme is Microsoft shipping legacy protocols enabled by default.

# Key points

- Chrome 92 phishing detection: client-side colour-histogram comparison against stored hashes of known phishing pages; median speedup about 50x, 2.5x at the 99th percentile, average result in about 100 ms instead of 1.8 s, and requests slower than 5 seconds dropped from about 16% to under 2%.
- Kaseya obtained a universal REvil decryptor (confirmed working by Emsisoft) from a third party, said it paid no ransom directly or indirectly; Steve and Leo speculate about pressure on REvil and about NDAs for victims.
- HP/Samsung/Xerox printer driver SSPORT.SYS (CVE-2021-3438, CVSS 8.8): unvalidated size in an IOCTL string copy gave local users kernel-level code execution; reported February 2021, patched May 2021, and the code seemed derived from a Microsoft driver sample. Over 380 models affected since 2005.
- Steve's lesson: IOCTL interfaces deliberately cross privilege boundaries, so any flaw in any third-party driver can compromise the system; no practical architectural fix exists.
- Process Hacker (open-source, a Process Explorer alternative) alerted the researchers to the unexpected driver; Steve recommends it for noticing new services and drivers.
- GitHub extended its advisory database (150+ Go advisories), dependency graph and Dependabot alerts to Go modules; automated security pull requests reportedly patch dependencies up to 40% faster. Steve argues automated, dependency-graph-driven supply-chain maintenance is inevitable, like automatic Windows Update, despite the supply-chain risk.
- SeriousSAM/HiveNightmare (CVE-2021-36934): on Windows 10 1809+ and Server 2019+, the SAM and other config hives were readable by the Users group, so with a VSS shadow copy a low-privilege user could extract password hashes, DPAPI keys and machine secrets. The mitigation is to tighten the ACLs on the config directory and delete existing shadow copies; the episode discusses how to check ACLs and shadow copies.
- PetitPotam (researcher "topotam"): abuses MS-EFSRPC to coerce a Windows server such as a domain controller to authenticate to an attacker, enabling NTLM relay to AD CS web enrolment and full domain compromise. It works only inside a network, matters for enterprises with Active Directory Certificate Services, and disabling EFS did not stop it. Microsoft's guidance is to enable Extended Protection for Authentication and SMB signing and to harden AD CS.
- Steve's conclusion: NTLM is a "classic" broken protocol that Microsoft still leaves enabled by default; end users and home systems are not affected by PetitPotam.
