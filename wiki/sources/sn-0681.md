# Summary

Jason Howell's last week as guest host. Steve previews the first national Wireless Emergency Alert test, moved to October 3 because of a hurricane, then covers Chrome rolling back its hiding of the "www" prefix after complaints (with a revised version planned for Chrome 70), and a listener report of Comodo sales calls warning Let's Encrypt users about expiring certificates. A new 264-page NIST/DHS standard for BGP route origin validation completes the secure inter-domain routing set of RFCs. California's SB-327 IoT security bill would ban shared default passwords for devices with remote authentication. F-Secure researchers revived cold-boot attacks against BitLocker by editing BIOS settings to stop memory wiping, which makes sleeping machines risky. The Safari Ripper CSS link crashes iOS and macOS browsers, Twitter added a session and device list, Mirai gained more exploits, and Nexusguard reported a more than fivefold jump in average DDoS size. Steve closes with research on the browser extension ecosystem showing most users carry around 13-15 add-ons and that extensions compete, piggyback and remove each other.

# Key points

- Wireless Emergency Alert national test scheduled for October 3, 2018; presidential-level alerts cannot be turned off, unlike Amber and monthly-test alerts.
- Chrome 69's www and m trimming was rolled back; Chrome 70 plans to hide only www; critics want a standards discussion and a user opt-out; the first implementation also stripped embedded www labels by bug.
- Comodo sales call told a Let's Encrypt user he risked renewing every three months; Steve notes short-lived auto-renewed certificates also reduce the weight of broken revocation.
- BGP: RFC 8206 (BGPsec migration considerations), RFC 8210 (RPKI to Router protocol) and the new route origin validation document form the protection against hijacks and misconfiguration; adoption by routers will take time.
- California SB-327 (effective January 2020): "reasonable security features," plus a concrete rule that devices reachable beyond the LAN must have unique default passwords or force a password on setup; Robert Graham criticizes feature-adding as misguided.
- Cold boot: F-Secure's "ice-cold boot" reprogrammed the BIOS settings flash to disable RAM overwrite and allow external boot, then dumped memory keys from a sleeping laptop; mitigations are physical security, disabling S1-S3 sleep (BIOS or Group Policy) and hibernating or shutting down.
- Safari Ripper uses stacked divs with CSS backdrop filters to exhaust rendering; iOS 12 did not fix it.
- Twitter now lists connected apps and recently used devices; Steve urges periodic pruning of app grants.
- Mirai now has 16 exploits including Struts; Nexusguard: attack count up 29 percent, average size 26.37 Gbps (up 543 percent), maximum 359 Gbps, with IoT botnets such as Satori and Anarchy as the cause.
- Windows 10 Insider builds warn when starting installers for other browsers.
- Extensions: a study of 900,000 PCs showed a peak at 13-15 extensions per browser and some with 75-100; add-on vendors compete (for example toolbars drove 45 percent of one antivirus vendor's sales in 2012); Firefox 64 will put Remove Extension at the top of the extension menu; Steve recommends scraping the "barnacles" regularly.

# Other segments

- Listener defense of MikroTik routers (auto-update scripts and firewall configuration) and Steve's rebuttal that default home templates should be safe.
- OpenVPN privilege remark from a Debian user; Windows cannot drop privileges once running as system.
- SpinRite story: an SSD pass fixed a crashing camera server which then recorded a theft; Jason suggests "AllRite" as a product name idea.
- Chart of extensions per browser as Picture of the Week.
