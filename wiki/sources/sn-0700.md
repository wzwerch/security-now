# Summary

Episode 700 opens with Chrome's experiment to suggest the correct site when a user types a lookalike address (the example is paypai.com versus paypal.com), which Steve treats as a long-overdue defence against typosquatting. He then covers the Qualys findings in systemd-journald (three CVEs from late 2018) now that Capsule8 published a working proof of concept; they are local-only issues, but combined they give a local root shell, so Linux users should patch. Chrome 72 removes several old features (HPKP, window.open during page unload, FTP subresources) and further deprecates TLS 1.0/1.1 ahead of removal in Chrome 81. Facebook is criticised for paying teens and adults to install a VPN-style app that required its root certificate and was distributed through Apple's enterprise developer programme. Japan's NICT plans to try known default credentials against up to 200 million public IoT devices and notify owners, which Steve sees as a possible precedent for proactive defence. Firefox 65 broke for users of several antivirus products because their HTTPS-scanning root certificates live in the Windows store, not Firefox's own; Steve gives the enterprise-roots setting as a workaround. Ubiquiti devices expose an unauthenticated discovery service on UDP 10001 that is abused for weak DDoS reflection; Steve recommends disabling it. The show closes with Chrome's "Never-Slow Mode" prototype, Spectre-mitigation switches in Linux, errata on Cisco RV320 firmware ranges, a SQRL forum update and listener questions on SpinRite with USB drives and stealth VPNs.

# Key points

- Chrome "navigation suggestions for lookalike URLs": prompts "Did you mean ...?" for typo domains such as paypai.com; behind a flag in Canary 70, present but inert in stable Chrome 72.
- Picture of the week: Firefox Monitor warning on a forum site that had 200,000+ accounts compromised in 2018 (backed by Have I Been Pwned); Leo notes Google's new Password Checkup extension.
- systemd-journald: three flaws (CVE-2018-16864, -16865, -16866) found by Qualys; two memory corruptions and one out-of-bounds read information leak that defeats ASLR; Qualys reports a local root shell within minutes on average; Capsule8 published weaponised proofs of concept; Fedora and SUSE builds with stack-clash protection are not exploitable. Mostly a local risk, but Steve urges catching up on patches.
- Chrome 72: window.open during unload blocked regardless of the pop-up blocker; HPKP removed (under about 2% usage); FTP subresource loading deprecated; Chrome's deprecation process (console warnings, wait, monitor, remove).
- TLS 1.0 and 1.1 (MD5/SHA-1, RC4 and CBC weaknesses) are deprecated in Chrome 72 with removal planned for Chrome 81 in early 2020.
- Facebook paid users aged 13-35 (about $20 a month per the discussion) to install a research app that needed Facebook's root certificate, enabling full traffic interception; it used Apple's enterprise developer programme to bypass the App Store and Apple revoked it. Steve calls it ungoverned rather than sinister; still available on Android.
- Japan's NICT will, from mid-February 2019, try common default credentials on up to 200 million public IoT devices (routers, webcams, DVRs), then tell owners to fix them, ahead of the Tokyo 2020 Olympics; IoT was behind 54% of attacks NICT detected in 2017. Steve recalls being told years ago that a "sanitizing worm" would be illegal and suggests ISPs could scan their own customers.
- Firefox 65 added a man-in-the-middle detector; it flagged connections for users of Avast, AVG, Bitdefender, ESET and Kaspersky because Firefox uses its own root store; Mozilla paused the rollout and AVG/Avast patched. Workaround: security.enterprise_roots.enabled set to true in about:config. Steve notes that per-installation certificates are the only safe design (Lenovo's shared key was a past failure).
- Ubiquiti: Jim Troutman reported exploitation of the discovery service on UDP 10001 (56 bytes in, 206 out, about 3.67x amplification). Rapid7 found roughly 487,000 responding devices, many in Brazil, and thousands renamed with "HACKED-ROUTER-HELP-SOS" labels, probably by a well-meaning cleaner. No firmware fix yet; disable with the `ubnt-discover` service setting.
- Chrome "Never-Slow Mode" prototype enforces per-page budgets (image, script, CSS, font sizes, connection limit, long tasks over 200 ms pause execution); Steve likes the pressure on bloated pages but notes it is only a prototype.
- Firefox will stop running extensions in private windows by default, as Chrome, Opera and Edge already do, with per-extension opt-in.
- Linux kernel gains more switches (nospectre_v1, nospectre_v2, nospec_store_bypass_disable, PR_SPEC_DISABLE_NOEXEC) to turn off costly Spectre mitigations; STIBP reportedly cost PHP servers about 30%. Steve agrees closed systems may reasonably disable them; no in-the-wild Spectre use had been seen.

# Other segments

- Errata: Cisco RV320/RV325 command-injection flaw affects only firmware 1.4.2.15 to 1.4.2.19 (information disclosure 1.4.2.15 to 1.4.2.17), per a listener.
- SQRL: forum login with SQRL works; Rasmus Vind helped with the XenForo integration; a nightly sweeper deleted temporary associations because of an API documentation gap, now fixed; iOS, Android and browser-extension clients in progress.
- SpinRite works on USB-attached drives if connected at boot.
- Stealth/obfuscated VPN question: OpenWRT can act only as an OpenVPN client; self-hosting needs a server such as pfSense, or use a commercial service.
