# Summary

Microsoft changed course on Edge after press attention: it will no longer decrypt all saved passwords into process memory at startup (fixed in Edge build 148), having first called the behavior intended. Steve uses it to argue against storing one-time-password secrets in the same place as passwords. The disgruntled researcher "Chaotic Eclipse" (Nightmare-Eclipse) released two more Windows exploits, YellowKey (a BitLocker bypass via the Windows Recovery Environment, against TPM-only configurations) and GreenPlasma (privilege escalation); Steve judges it a vulnerability, not a deliberate backdoor, and mitigated by a BitLocker PIN. Google's Threat Intelligence Group reported the first threat actor zero-day believed to be built with AI and a broader shift to industrial-scale adversary use of AI. Canada's Bill C-22 on lawful access drew opposition from Signal, Apple, Meta and VPN providers. Steve shares a personal worry that conversational AI is more addictive and isolating than social media. Light segments cover the film Project Hail Mary reaching streaming and a dubious Casimir-cavity "free energy" chip. Listener feedback includes brute-force wallet recovery stories and a vibe-coded site that leaked an API key. The main topic compares OpenAI's still-forming Daybreak initiative to Microsoft's MDASH, a multi-model agentic scanning harness that found 16 Windows network-stack CVEs, patched the same day.

# Key points

- Edge password handling: researcher Tom Ronning showed all saved Edge credentials were decrypted into memory at launch and could be dumped (own user without admin, other users with admin). Microsoft first said "by design", then announced a defense-in-depth change rolled out in Edge 148 across all channels. Chrome and other Chromium browsers did not behave this way. Steve notes Microsoft's wording about admin control was inaccurate.
- Steve's advice: keep one-time-password secrets separate from the password manager (he uses OTP Auth on a separate iOS device); this preserves defense in depth.
- Chaotic Eclipse released YellowKey (BitLocker bypass on Windows 11 and Server 2022/2025 using crafted FsTx NTFS transaction files so WinRE drops to a shell with the volume unlocked) and GreenPlasma (privilege escalation), one day after Patch Tuesday, and teased a "big surprise" for the next one. Kevin Beaumont confirmed it works and called it a backdoor; Will Dormann clarified it exploits TPM-only auto-unlock and does not work with a TPM+PIN setup; it requires the original device. Mitigation: BitLocker PIN plus BIOS password.
- Google GTIG AI Threat Tracker: first observed actor using a zero-day exploit likely AI-developed (planned for mass exploitation, disrupted); PRC and DPRK actors using AI for vulnerability discovery; AI-assisted polymorphic malware and decoy logic (suspected Russia-nexus); autonomous malware such as PromptSpy that has models interpret system state and generate commands; AI-driven information operations (Operation Overload); anonymized premium LLM access via middleware and account cycling; and supply-chain attacks on AI environments by TeamPCP.
- Canada: Bill C-22 ("An Act respecting lawful access", introduced 12 March) opposed by Signal, Apple, Meta and VPN providers; Steve expects it to be watered down as in the EU and UK.
- Steve's worry about conversational AI: it appears to know you, remembers context, and could be more seductive and isolating than social media for lonely people; discussion with Leo of Richard Dawkins' consciousness piece, Eliza, Data in Star Trek, and "AI psychosis".
- Project: Hail Mary has grossed over $660 million and is available to rent or buy on Amazon Prime.
- Casimir Inc. (Harry "Sonny" White) says its MicroSparc chip harvests picowatt-level power from the quantum vacuum with commercialization planned for 2028; Steve is skeptical (links to Turbo Encabulator parody) and Leo notes the same researcher pushed the discredited EM Drive.
- Listener feedback: many wrote that Claude helped recover a forgotten Bitcoin wallet; Steve says his own 50 BTC wallet was overwritten by a Windows install and Leo says his case is different. Another listener showed a non-programmer's AI-built restaurant site exposed its Claude API secret key in client JavaScript, found by pointing a second Claude at the site; Steve's lesson is that AI does what you ask, so someone must know what to ask for.
- OpenAI Daybreak: a branded cyber-defense initiative combining OpenAI models and the Codex agentic harness for code review, threat modeling, patch validation and remediation; access tiers are GPT-5.5 default, GPT-5.5 with Trusted Access for Cyber, and GPT-5.5-Cyber with the most permissive behavior for verified red-team work. Steve sees it as a Mythos catch-up announcement with details still to come.
- Microsoft MDASH (multi-model agentic scanning harness), led by Taesoo Kim's Autonomous Code Security team (former DARPA AI Cyber Challenge winners): 100+ specialized agents across an ensemble of models in a prepare, scan, validate (debate), de-duplicate, prove pipeline. Claims: 21 of 21 planted bugs found with zero false positives on a private test driver, 96 percent recall on five years of MSRC cases in clfs.sys and 100 percent in tcpip.sys, 88.45 percent on the CyberGym benchmark. It found 16 CVEs in the Windows networking and authentication stack (including four critical RCEs in TCP/IP and IKEv2), fixed in the May Patch Tuesday. Limited private preview; Steve says it is genuinely significant and imagines Patch Tuesdays shrinking.
