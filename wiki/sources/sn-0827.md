# Summary

Steve, hosting with Mikah Sargent while Leo is away, first corrects last week's claim that the Windows print spooler can be stopped without losing printing: it cannot. He then explains how Microsoft's emergency fix for the second PrintNightmare flaw (CVE-2021-34527) is incomplete by design: the Point and Print feature can still allow unsigned driver installs unless two registry values are absent or zero, and Windows 7, 8 and equivalent servers remain affected. The Kaseya VSA supply-chain attack hit about 1,500 organizations, but because the REvil affiliate only pushed encryption (no network survey, no data theft, no backup deletion), many victims restored from backups and Coveware reported clients not paying. Other items: the Ransomwhere crowdsourced ransom-payment tracker, McAfee's analysis of a Word-and-Excel macro chain that disables macro warnings to load the Zloader banking trojan, KELA's study of a growing market for bilingual ransom negotiators and access brokers, and Microsoft removing the classic-Start-menu registry switch in Windows 11 build 22000.65. The main topic is Sodinokibi's cryptographic design: per-file Curve25519 key pairs combined by Diffie-Hellman into Salsa20 keys, a per-system key pair whose private half is encrypted to both an operator key (hardcoded, held by the REvil gang) and a campaign key (held by the affiliate), which enables per-file, per-system, per-campaign decryption and a master backdoor for the operators.

# Key points

- Print spooler: stopping the service disables printing; Steve now suggests running with it stopped and starting only to print if exposure is a concern. The 2021 patch cycle left a local privilege issue and remote code execution via the driver-install API (RpcAddPrinterDriverEx and the async variant); the first June fix (CVE-2021-1675) did not stop public exploits, the July out-of-band fix (CVE-2021-34527) was reported by Hacker News, Ars Technica and BleepingComputer as incomplete.
- Microsoft's bulletin states that systems with NoWarningNoElevationOnInstall set to 1 under the Point and Print policy key are "vulnerable by design"; administrators must ensure that value and UpdatePromptSettings are absent or 0. After the patch, non-admins can only install signed drivers; Windows 7, 8 and Server 2008/2012 stay vulnerable by design. Steve guesses unsigned legacy printer drivers prevent a stricter rule.
- Kaseya aftermath: roughly 1,500 organizations had files encrypted, but the affiliate did not exfiltrate data or delete backups, so many restored from backups; Coveware said none of its triaged clients needed to pay. Steve wonders if the attackers rushed before a patch.
- Ransomwhere (Jack Cable, Stanford graduate) tracks ransom payments by bitcoin address, about $60.3M recorded versus up to $350M estimated in 2020; top groups by payments include NetWalker, REvil, Ryuk, DarkSide, RagnarLocker, Egregor and Conti. Reports require a screenshot of the demand.
- Zloader macro bypass (McAfee): a Word attachment with no malicious code asks the user to "enable content", then VBA uses Dynamic Data Exchange to pull content from a remote spreadsheet into an Excel cell, turn it into a macro, disable Excel's macro warning via the registry, and download Zloader into memory (executed using rundll32). Steve criticizes treating email attachments differently from browser content and blaming users.
- KELA: ransomware-as-a-service now has four stages with specialists at each; demand is rising for English-speaking negotiators; access to compromised networks costs 25-115% more than a year earlier and brokers get 10-30% of ransom. Steve predicts second-tier groups will break the unwritten rules (refunds, honoring deletion promises) of the big gangs.
- Windows 11 build 22000.65 removed the registry value that restored the left-aligned Windows 10 Start menu.
- REvil vs Sodinokibi: REvil is the gang and Sodinokibi is the malware. Per Kaspersky and Acronis, Sodinokibi uses Salsa20 for files and elliptic-curve key agreement; it uses I/O completion ports with a thread pool (a highly efficient design), skips certain folders, files and extensions, encrypts local drives and network shares, and writes ransom notes per folder.
- Key hierarchy: (1) operator key pair with the public key hardcoded into the malware, private key kept by REvil; (2) campaign key pair with public key in the configuration, private key kept by the affiliate; (3) a per-system key pair whose private half is encrypted under both the operator and campaign public keys; (4) a per-file key pair, with the public half stored in a header on each encrypted file. The per-file symmetric Salsa20 key comes from Diffie-Hellman between the file's private key and the system public key, and is unique per file. Decrypting one machine requires its decrypted system private key; either the operator or the campaign private key can open it, so REvil can decrypt every affiliate's victims and sell a single universal decryptor if it chooses. Steve calls the design the work of professionals with no shortcut such as a hardcoded key.
- Practical advice: when ransomware is detected, disconnect machines immediately.
