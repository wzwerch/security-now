# Summary

Four weeks after the ProxyLogon patches, RiskIQ counted just under 30,000 Exchange servers still vulnerable, down from about 92,000 on March 10, and Steve expects only slow attrition now. Symantec found two ways (CVE-2020-27170 and CVE-2020-27171) to bypass Linux's Spectre mitigations through unprivileged eBPF programs, fixed in kernel 5.11.8. OpenSSL 1.1.1k fixed a high-severity denial-of-service crash triggered by a crafted TLS 1.2 renegotiation ClientHello (CVE-2021-3449) and a niche certificate-chain check bypass under the strict-verification flag. SolarWinds patched four more Orion flaws, which prompts Steve to ask whether to abandon or trust a product that has now been heavily scrutinised. Cloudflare launched Browser Isolation, which renders pages in the cloud and sends only the result to the user. A vendor survey highlights that API security is under-protected. The main story is the PHP project's Git server compromise: someone pushed two commits under the names of Rasmus Lerdorf and Nikita Popov that added an obviously labelled backdoor, and PHP responded by retiring its own Git server in favour of GitHub with mandatory two-factor authentication. Steve argues the incident was effectively a loud joke and a net benefit, not a stealth supply-chain attack.

# Key points

- ProxyLogon remediation: about 29,966 vulnerable Exchange instances per RiskIQ versus 92,072 earlier; the Defender mitigation may not be credited by version-based counts. Mitigation blocks new entry but does not necessarily evict an existing intruder.
- Spectre on Linux: the kernel verifier performed speculative out-of-bounds pointer arithmetic in eBPF, letting unprivileged programs read kernel memory (CVSS 5.5, kernels before 5.11.8, patches in Ubuntu, Debian and Red Hat from March 17 to 20). Remote exploitation through web JavaScript was described as possible; Steve notes many Linux appliances and routers will never be patched.
- OpenSSL CVE-2021-3449: servers with TLS 1.2 renegotiation enabled (the default) crash on a ClientHello that omits signature_algorithms but includes signature_algorithms_cert; all 1.1.1 versions affected, found by Nokia. Second flaw: with X509_V_FLAG_X509_STRICT and no purpose set (1.1.1h onward), non-CA certificates could be accepted as issuers; reported by Akamai. Both fixed in 1.1.1k.
- SolarWinds Orion update fixes four issues, including authenticated remote code execution through JSON deserialization in the web console and in the job scheduler, plus stored XSS and an open redirect; Steve notes deserialization trusts input that came from its own serializer.
- Cloudflare Browser Isolation (Zero Trust browsing) runs the browser's fetch, script and render work in the cloud and ships only visual output; Steve and Leo see a trend toward cloud-hosted computing (cloud gaming, virtual desktops).
- API security survey: 91 percent consider it a priority, only 19 percent test APIs for abuse, 64 percent lack robust API protection; Steve expects IoT growth to make network-API attacks common.
- PHP Git server (git.php.net) hack of March 28, 2021: two commits "fixing a typo" added code that evaluated the rest of a User-Agent-style header (misspelled HTTP_USER_AGENTT) if it began with "zerodium", with a comment claiming a 2017 sale; Zerodium's CEO called the culprit a troll. Steve reads it as designed to be seen.
- PHP response: git.php.net is discontinued; GitHub repositories become canonical, with organisation membership requiring two-factor authentication. Steve and Leo discuss the trade-off of consolidating on a few providers versus self-hosting, using password managers as a comparison.
- Steve's SpinRite 6.1 note: moving to 64-bit sector addressing lifts the old 2.2 TB (2^32 sector) limit and requires reworking much of the code.
