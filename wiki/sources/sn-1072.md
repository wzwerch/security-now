# Summary

Leo Laporte returned after RSAC. The episode opened with the sudden uproar over California's Assembly Bill 1043 (Digital Age Assurance Act, signed 13 October 2025, effective 1 January 2027), which obliges operating-system providers, including Linux distributions and SteamOS, to collect a self-declared birth date at account setup and expose an age-bracket signal (under 13, 13-15, 16-17, over 18) through an API; Steve argues it works best as an optional parent-controlled device feature and that it also defuses the VPN-evasion problem. Apple's iOS 26.4 now demands proof of age (credit card or ID photo) in the UK and South Korea. Russia plans to mandate its own NEA-7 5G encryption algorithm by 2032, which Steve ridicules as anti-standardization. A Ukrainian drone maker fed disinformation to a Russian bugged thermostat it knew about. Google moved its post-quantum deadline ("Q Day") to 2029, which Steve doubts is realistic but supports as prudent dual-crypto. The UK NCSC warned at RSA that vibe-coded SaaS replacements could be insecure, and Steve notes enterprises will increasingly build in-house instead of renting SaaS. Recorded Future's ClickFix research and Apple's macOS 26.4 Terminal paste warning led to a call for Microsoft to do the same, and Reddit may require biometric proof of humanity because roughly 15% of posts are AI. The main story: the LiteLLM compromise of 24 March, where malicious versions 1.82.7 and 1.82.8 appeared on PyPI after the TeamPCP group hijacked Trivy's GitHub Actions credentials; a bug turned the malware into a fork bomb, exposing it within hours (about 47,000 downloads in 46 minutes) before it could spread widely.

# Key points

- AB 1043: self-declared age brackets via an OS API, no ID or face scan, enforced only by the California Attorney General (penalties $2,500 negligent / $7,500 intentional per affected child); passed 76-0 and 38-0; Newsom urged amendments. Contrasts with Utah/Texas/Louisiana "commercially reasonable" app-store verification, which pushes toward ID collection. Linux backlash included a short-lived systemd date-of-birth field.
- Reason Foundation analysis (quoted at length): praises privacy-preserving signalling, suggests making the signal optional for parents; cites 2025 breaches at the Tea app and a Discord age-check vendor as proof that ID collection is a liability.
- Apple iOS 26.4 age checks in the UK and South Korea use account age signals first, then card or ID scan.
- Russia's NEA-7 5G algorithm bill: legacy algorithms (SNOW, AES, ZUC) tolerated until 2032; Russia is about 2% of phone sales and no tower gear supports it; Ukraine can fall back to LTE and 3G. Steve uses it to praise standardization.
- Ukrainian drone maker TechEx knew a thermostat with camera, microphone and router was Russian spyware and used it to feed disinformation.
- Google targets 2029 for completing PQC across products; Chrome, Cloud, Apple, Signal, Cloudflare (over half its traffic), AWS, Azure, Meta and Zoom already deploy PQC; Steve doubts quantum factoring is close but endorses hybrid schemes.
- NCSC CEO Richard Horne at RSA: AI-generated "SaaSpocalypse" could replace SaaS products but AI code must be secure by default; surviving SaaS will be hard to replace (critical, regulated, data-rich).
- Recorded Future Insikt Group: five ClickFix clusters (QuickBooks, Booking.com lures, etc.), OS-aware chains, expected to remain a primary access vector in 2026; mitigations are disabling the Run dialog via GPO and PowerShell Constrained Language Mode. macOS 26.4 adds a "Possible malware, Paste blocked" prompt in Terminal.
- Reddit CEO floats Face ID, Touch ID or passkey proof of humanity; Digg paused because of bots; Steve sees no solution to undetectable bots behind residential proxies; AI detectors are unreliable.
- LiteLLM: open-source LLM gateway (100+ providers, about 3.4 million downloads/day, 40k+ GitHub stars). Researcher Callum McMahon (FutureSearch) was hit when Cursor started an MCP server via uvx that had an unpinned LiteLLM dependency and pulled the malicious release minutes after upload; the .pth file spawned endless Python processes (fork bomb, about 11,000), and Claude Code helped him diagnose it. PyPI quarantined it quickly; 88% of dependents were unprotected.
- Trend Micro: three-stage payload (credential harvester for 50+ secret types including .env files, Kubernetes lateral movement, persistent backdoor), data encrypted before exfiltration to a typosquatted domain; part of the TeamPCP campaign across PyPI, npm, Docker Hub, GitHub Actions and Open VSX.
- Root cause: a misconfigured pull_request_target workflow let an actor steal Trivy's aqua-bot token in late February; Aqua's credential rotation on 1 March was not atomic, so on 19 March TeamPCP force-pushed malicious tags to Trivy-action and setup-trivy, and the stolen CI credentials let them publish LiteLLM. Lesson: security scanners hold broad secrets and are high-value targets; pin dependencies, use lock files with checksums, delay adopting fresh releases.
- Steve explains atomic operations and race conditions as background to the non-atomic rotation.

# Other segments

- Picture of the Week: rusty nails forming a Jacob's-ladder adapter for a mismatched power plug.
- Leo met Marcus Hutchins at RSAC (documentary "Midnight in the War Room") and recorded an RSAC tour on the TWiT feed; AI-based defense was the dominant RSAC theme; Claude Code source was reportedly leaked from Anthropic.
