# Summary

Senator Ron Wyden wrote to the US Attorney General asking that Apple and Google be allowed to disclose government demands for push-notification records; because every notification passes through Apple's or Google's servers, governments can obtain metadata linking anonymous app users to accounts, and Apple promptly said it would add these demands to its transparency reporting. Facebook Messenger now turns on end-to-end encryption by default using the Signal protocol. Steve reports six Iranian IP addresses scanning for default-password Unitronics PLCs, then Cisco Talos data showing that the most exploited vulnerabilities of 2023 are years old (CVE-2017-0199 and CVE-2017-11882 lead), and Veracode data showing about 38 percent of applications using Log4j still carry vulnerable versions two years after Log4Shell. A German appeals court ruled for DNS provider Quad9 against Sony, but Italian rights holders have made a new blocking demand that Quad9 has complied with. He explains Clear Web, Deep Web and Dark Web and the scale of DDoS-for-hire. Listener items cover Telegram contact-join notifications, a carrier asking users to install a root certificate, overlay networks for remote access and an old unsigned tool flagged by antivirus. The main topic is Harvard's neutral-atom experiment that created 48 logical qubits from 280 physical ones, which Steve says brings the end of RSA and elliptic-curve cryptography closer and argues post-quantum algorithms should be deployed in parallel with classical ones.

# Key points

- Wyden letter (6 Dec 2023): push notifications are routed via Apple Push Notification Service and Google Firebase Cloud Messaging; demands, sometimes under gag orders, yield metadata and occasionally content. Reuters sources say foreign and US agencies used it to deanonymize messaging users. Steve calls metadata the overlooked problem and cites Tor correlation attacks and third-party cookies as parallels.
- Messenger default end-to-end encryption is built on the Signal protocol and open-source libraries.
- Cyber Av3ngers continue scanning for Unitronics PLCs with the default password "1111"; the show notes list six Iranian IPs.
- Cisco Talos year in review: attackers favour old, widely deployed bugs; number one was CVE-2017-0199 (Office/WordPad RTF remote code execution, CVSS 9.3) and number two CVE-2017-11882 (Equation Editor); entries also date to 2010 and 2012. Steve wonders what unpatched, undefended systems still read email in 2023.
- Log4j: Veracode saw about 38 percent of 38,278 applications with insecure versions (2.8 percent Log4Shell-vulnerable, 3.8 percent on 2.17.0, 32 percent on end-of-life 1.2.x); 79 percent of developers never update third-party libraries after adding them; half of projects need over 65 days to fix high-severity flaws.
- Quad9 v. Sony (Dresden Higher Regional Court): ruling for Quad9, Sony pays costs, appeal not allowed (Sony could still complain to the Federal Court). Quad9 notes that resolver blocking could still be ordered as a last resort. New Italian demand from music-industry groups: Quad9 complied with a global block while preparing to contest.
- Dark Web explained: Clear Web (about 4 percent), Deep Web (login-gated, about 96 percent), Dark Web (hidden services reachable via Tor). Searchlight Cyber's DDoS-for-hire study found one service claiming 566,109 registered users; attacks sold at layer 4 or layer 7.
- Telegram notifies contacts when a new user joins if they uploaded the number, even if the new user denied contact access; Leo advises never sharing your contacts with third parties.
- A cellular carrier prompting customers to trust an additional root certificate implies a TLS-intercepting proxy; Steve says refuse.
- Pruning browser roots to about six CAs is preferred over UI colour indicators.
- For remote access to a home server, use overlay networks (Tailscale on WireGuard, or ZeroTier) instead of port forwarding; they traverse NAT and avoid bot login attempts.
- Old unsigned freeware such as API Monitor can trigger a couple of antivirus detections out of about 70 on VirusTotal; Steve found 0 of 71 and prefers finished, stable software.
- Quantum: Harvard/QuEra team (Lukin lab, DARPA ONISQ programme) published in Nature a logical processor with up to 280 physical qubits yielding 48 logical qubits using reconfigurable rubidium-atom arrays moved by laser tweezers, versus traditional ratios near 1000 physical to 1 logical; IBM's Condor has 1,121 physical qubits. Symmetric crypto (AES) and hashes are considered quantum-safe; RSA and elliptic curves are not. NIST aims to finalize post-quantum standards in 2024; Signal already runs post-quantum alongside classical crypto. Steve warns that harvested data (NSA Utah facility) is the long-term risk and that hybrid deployment should be rushed.
