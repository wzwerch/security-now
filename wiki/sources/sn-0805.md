# Summary

Three Chrome items open the show. Google removed the popular extension The Great Suspender (2 million plus users) after its maintainer role was apparently sold to unknown parties who added remote-code tracking. Chrome got an emergency fix for a V8 heap overflow exploited in the wild, linked to a North Korean campaign (reported by Google TAG and Microsoft) that targeted security researchers with a fake research blog, fake exploit videos, social-engineering via a malicious Visual Studio project, and a browser zero-day. A Croatian researcher found a malicious extension using Chrome's sync feature as a command-and-control and exfiltration channel. Microsoft's enterprise Defender ATP briefly flagged Chrome as a PHP backdoor, which Microsoft attributed to an "automation error". Steve describes his DOS-era SpinRite build workflow and a rewrite of its device discovery. WordPress plugin NextGEN Gallery (over 800,000 sites) had CSRF flaws leading to remote code execution; Steve recommends the Wordfence firewall. Plex Media Servers exposed via UPnP became an SSDP reflection DDoS vector (about 37,000 reflectors). Trustwave found three new SolarWinds Orion and Serv-U flaws, prompting Steve's argument that close scrutiny finds problems anywhere. The episode ends with the Oldsmar, Florida water-plant intrusion in which sodium hydroxide was remotely raised 111-fold and promptly reversed.

# Key points

- The Great Suspender: ownership transferred in 2020 to an anonymous party, a version fetched remote scripts, later versions requested broad web-request permissions and used a suspicious analytics domain; Google removed it from the Chrome Web Store and from installed browsers. The last tagged GitHub release before the transfer was considered safe. Lesson: extensions can go bad after being sold.
- Chrome zero-day (V8 heap buffer overflow, credited to Mattias Buelens, fixed February 4, 2021) was exploited in the wild; Google TAG and Microsoft reported a North Korean state campaign against vulnerability researchers using fake Twitter personas, a fake blog, a faked Windows Defender exploit video and a trojanized Visual Studio project; advice: compartmentalise research in separate physical or virtual machines.
- Malicious Chrome extension posing as a Forcepoint add-on abused Chrome sync (traffic to Google's own servers) as C2; mitigation is enterprise group policy to control which extensions may be installed.
- Microsoft Defender ATP wrongly flagged Chrome 88 files as PHP/Funvalget.A; free consumer Defender did not; Steve notes Defender increasingly distrusts unsigned freshly built executables.
- SpinRite development: Steve builds 16-bit DOS code with a vDos-style environment, packet driver, and HTTP fetch of zipped sources; SpinRite 6.1's "Discovering System's Mass Storage Devices" step was rewritten to enumerate PCI devices, ATA/AHCI drives and match them to BIOS devices by boot-sector hashing, and will become animated.
- NextGEN Gallery 3.5.0 fixes a logic flaw in a nonce-check function that let requests proceed when the nonce was missing, enabling CSRF, file upload with double extensions, and local file inclusion (RCE/XSS). Update and consider Wordfence.
- Plex Media Server SSDP/UPnP: default UPnP port mapping exposed about 37,000 reflectors with roughly 4.68x amplification; observed attacks from 2-3 Gbps single-vector up to 218 Gbps multi-vector; roughly 11 million DDoS attacks in the preceding period per NETSCOUT. Advice: disable UPnP/SSDP unless needed.
- SolarWinds: Trustwave disclosed CVE-2021-25274/25275/25276 (insecure Microsoft Message Queue use for remote code execution, insecure credential storage in Orion, and a Serv-U FTP local privilege flaw) with proof-of-concept published on February 9. Steve: other widely deployed products likely have equal flaws nobody has audited.
- Oldsmar, Florida water treatment: an intruder using remote access (reportedly TeamViewer) raised sodium hydroxide from 100 ppm to 11,100 ppm; the operator reversed it at once and downstream checks would also have caught it. Steve criticises both internet-exposed remote access and a control system that accepts absurd setpoints; the expert quoted advises disabling remote access or requiring on-site approval.
