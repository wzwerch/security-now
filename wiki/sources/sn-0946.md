# Summary

Steve first explains last week's connection drops as spontaneous reboots of a Netgate SG-1100 pfSense router caused by a tired power supply. He then reports on ADAMnetworks' default-deny DNS whitelisting plus outbound "Don't Talk to Strangers" firewall, which he saw demonstrated. News: another USD 4.4 million in crypto drained from 25 LastPass customers whose stolen vaults were cracked; Apple's iMessage Contact Key Verification; 20,000+ PIRG signatories asking Microsoft to extend Windows 10 support; HackerOne passing USD 300 million in payouts; CISA releasing Logging Made Easy; and SpinRite 6.1's second pre-release with zero open issues. The main topic is Citrix Bleed (CVE-2023-4966): an unauthenticated memory over-read in NetScaler's OpenID discovery endpoint leaks session tokens that bypass passwords and MFA, with mass exploitation after public write-ups and roughly 20,000 compromised sessions. Steve explains from Assetnote's patch diff how misuse of the return value of snprintf caused the leak.

# Key points

- Hardware lesson: a failing wall-wart power supply can look like a router firmware problem.
- ADAMnetworks: whitelist-based DNS filtering with an intercept page (checks 18 other filtering sources), local resolution for privacy, and an outbound firewall allowing only IPs previously resolved via the local resolver; claimed deployment on about 2 million endpoints. Steve has no hands-on experience and no pricing information.
- LastPass: attackers keep decrypting stolen vaults (likely weak passwords and low iteration counts) and taking seed phrases; total thefts now close to USD 40 million.
- Apple iMessage Contact Key Verification (iOS 17.2 preview): compare an eight-digit code out of band when a contact adds a device.
- PIRG says about 40% of roughly one billion Windows 10 devices cannot run Windows 11, raising e-waste concerns.
- HackerOne: 30 hackers earned over USD 1 million; 55% expect generative AI to be a top target; pentest engagements up 54%.
- CISA's Logging Made Easy (successor of an NCSC tool) offers free Windows log management.
- IPv6 and TLS 1.2: 99.9% of sites support TLS 1.2, only 64.8% support 1.3; IPv6 will move only when IPv4 runs out.
- ImageMagick lost its code-signing sponsor; CA/B Forum rules require hardware-protected OV signing keys since June 2023, making signing costly for open-source projects.
- Citrix Bleed: patch released October 10; Mandiant saw exploitation from late August; public proofs of concept around October 23 to 25 triggered mass exploitation; Kevin Beaumont tracked just over 20,000 NetScaler servers with stolen session tokens, and patching alone does not invalidate existing sessions.
- Root cause: snprintf returns the length that would have been written, and the code used that value as the response length, so the reply included memory beyond a 128 KB buffer; the attacker controls the HTTP Host header, which is inserted six times, making the overread easy to trigger. The fix adds a bounds check. Steve stresses wiping sensitive memory and treating secure coding with caution.
- Matt Davis feedback: separate admin and standard accounts per person are costly under per-account licensing.
