# Summary

Chrome 91 fixes 32 flaws (eight high severity), adds clipboard paste support, blocks port 10080, runs JavaScript up to 23% faster through the Sparkplug compiler and short built-in calls, and is gaining URL-bar commands; Google's MyActivity page can now be password protected and auto-deleted. In ransomware, Emsisoft's independent decryptor, which handles about 50 families and ran twice as fast as Conti's own tool for Ireland's HSE, points to a new niche for trusted third-party decryptors after the attacker supplies the key. Steve defends Amazon Sidewalk (going live June 8, on by default) as well engineered and heavily encrypted, criticises press hype, and shows how to opt out. Microsoft's alarm over a Nobelium (Cozy Bear/APT29) campaign against 150 organisations turned out to be phishing emails sent from a compromised USAID Constant Contact account that delivered an ISO plus Cobalt Strike Beacon. WhatsApp is suing India over message-traceability rules and fighting similar Brazilian proposals. The main segment dissects Epsilon Red, a clumsy ransomware assembled from redundant PowerShell scripts plus a small Go encryptor, entering via unpatched Exchange servers, with a REvil-derived ransom note and no evidence of data theft; at least one victim reportedly paid about $210,000. Steve warns that low-end copycats trade on the reputation of "reliable" ransomware crews.

# Key points

- Chrome 91 (desktop): 32 security fixes, bug bounties from $3,000 to $20,000, 23% JS speedup, clipboard paste, port 10080 blocked (NAT Slipstreaming mitigation), more URL-bar commands such as run safety check.
- Google MyActivity can be password protected; auto-delete choices of 3, 18 or 36 months or no saving; Steve turned history saving off.
- Emsisoft decryptor: faster and more trustworthy than attackers' tools; Colonial Pipeline ended up restoring mostly from backups after paying $4.4M because the DarkSide decryptor was too slow.
- Amazon Sidewalk (Episode 796 topic): low-bandwidth LoRa/Bluetooth mesh, layered encryption so neither host network nor Amazon can read the data; Steve sees no privacy flaw and thinks the press misrepresents it as WiFi sharing.
- Nobelium phishing: roughly 3,000 emails to 150+ organisations in 24 countries via a hijacked USAID Constant Contact account; HTML attachment dropped an ISO whose DLL launched Cobalt Strike; Steve criticises that mail attachments can do this at all and lists the many vendor names for the same group.
- WhatsApp sues India over "first originator" tracing for platforms with 5M+ users (530M WhatsApp users); Brazil has similar proposals; the Indian government says privacy is not absolute; Steve notes math is.
- Epsilon Red (Sophos analysis): Go-based RED.exe (UPX-packed, uses godirwalk, spawns a process per folder, encrypts everything without a file-type filter, appends .epsilonred) driven by numbered PowerShell scripts that kill security and backup processes, delete Volume Shadow Copies and event logs, uninstall AV and open the firewall only to RDP and Remote Utilities; installs Remote Utilities and Tor Browser for persistence; initial entry likely unpatched Exchange; extortion site on the clear web that has since vanished.
- Ransom note closely mirrors REvil's with grammar fixes; claims data theft but no exfiltration was observed; one payment of 4.29 BTC (about $210,000) on May 15.
- Steve's concern: amateurs exploiting the reputation of professional ransomware gangs, so victims cannot know whether paying will restore files.
