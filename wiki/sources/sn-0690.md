# Summary

The episode begins with Pwn2Own Mobile in Tokyo, where the team Fluoroacetate won Master of Pwn; across two days Trend Micro paid 325,000 dollars for 18 zero-days against phones including an iPhone X and Galaxy S9, with vendors getting 90 days to patch. Steve then summarizes an academic paper that systematizes transient execution attacks, finding seven new Spectre/Meltdown variants and showing some patches are incomplete. For machines whose vendors will never ship updated BIOS microcode, an open-source Intel Microcode Bootloader built on Intel's BITS can load current microcode from a USB stick at each boot. Mozilla announced breach alerts in Firefox backed by Firefox Monitor and Have I Been Pwned. Juniper saw malware infecting exposed Docker APIs with Monero miners. HTTP/3 will be HTTP over QUIC, running on UDP. Steve explains how 1.1.1.1 gets a TLS certificate by listing the IP address as a subject alternative name. The main segment responds to Troy Hunt's argument that "password killers" fail on usability: Steve agrees nothing will replace passwords until a free, open, zero-friction alternative exists, and explains why he believes SQRL, which he has just brought to a new managed-shared-access milestone, can coexist and spread incrementally.

# Key points

- Pwn2Own Tokyo 2018: NFC-triggered browser exploit on Xiaomi Mi 6, baseband heap overflow on Samsung Galaxy S9, JIT bug chains on iPhone X; 325,000 dollars awarded, 18 zero-days; baseband processors are under-examined.
- Transient execution paper: classification tree, Meltdown-PK and Meltdown-BR plus five new Spectre mistraining strategies, tested on Intel, AMD and ARM; some deployed mitigations can be bypassed. No in-the-wild exploitation known; main risk is shared cloud hosting.
- Intel Microcode Bootloader (based on BIOS Implementation Test Suite) loads current microcode for 392 CPUs from 1996 to 2018 at boot from USB; useful for unsupported motherboards. AMD has something similar.
- Firefox Monitor will warn on first visit to a site with a breach in the last 12 months and uses HIBP data.
- Docker API ports 2375/2376 are unauthenticated if exposed; malware living off the land installs Monero miners and scans internally for more.
- QUIC combines IP/TCP/TLS/HTTP/2 concepts, can set up a connection and request in one packet, encrypted by default with TLS 1.3; HTTP/3 will mandate it.
- 1.1.1.1 certificate uses a DigiCert cert with the IP in the SAN field; Let's Encrypt does not issue such certs.
- Listener topics: SSD data retention is years not weeks; temperature affects leakage; periodic read/rewrite refreshes cells; hardware-encrypted drives untrusted until audited; Windows 7 BitLocker never used hardware encryption; Samsung advises software encryption for non-portable SSDs; password change works by re-encrypting the master key.
- Troy Hunt: passwords survive because everyone understands them and businesses prioritize low friction; Steve concurs, SQRL is free, owned by nobody, can lock out passwords per site.

# Other segments

- Picture of the Week: a Jeep with an SQRL license plate.
- SQRL: delegating or sharing access via managed shared access; handling domain name changes by one-time migration.
- SpinRite listener testimonial about SMART warnings.
- Malwarebytes should only be used as a transient scanner, not installed alongside Defender.
