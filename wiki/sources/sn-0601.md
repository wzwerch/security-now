# Summary

The episode, recorded after an outage of Steve's cable connection delayed the start by 90 minutes, leads with "Cloudbleed": Tavis Ormandy of Google Project Zero noticed that Cloudflare's reverse proxies were returning chunks of uninitialized memory, including cookies, tokens and POST bodies, inside pages for unrelated sites, some of which got cached by search engines. Cloudflare disabled three features that shared the faulty HTML parser, worked with search engines to purge caches and published a detailed post-mortem; Steve judged the practical risk to any individual as very low but used it to underline the cost of handing TLS termination to a third party. Other items include a new unpatched Edge/IE flaw after Microsoft missed another 90-day deadline, the exposed CloudPets toy database, a New York airport's publicly reachable server backups, Chrome 56's TLS 1.3 rollout breaking users behind Blue Coat proxies, court rulings on fingerprint unlocking, Amazon resisting an Echo warrant, a drone-and-LED data exfiltration demo and an ESET macOS flaw. The closing segment explains what Google's practical SHA-1 collision (two different PDFs with the same hash) means: SHA-1 is already being retired, so this is a milestone rather than an emergency.

# Key points

- Cloudbleed: a Cloudflare HTML parser (generated with the Ragel tool) skipped past an end-of-buffer check because of a double pointer increment, leaking memory from other customers' sessions; Steve and Leo note that using greater-or-equal instead of equality in loop checks would have prevented it. Cloudflare said private TLS keys were not leaked.
- Cloudflare switched off email obfuscation, server-side excludes and automatic HTTPS rewrites; peak impact was around one in 3.3 million requests (about 0.00003 percent). Steve did not change his passwords but suggested extra vigilance and two-factor authentication; every customer was potentially exposed, not just those using the affected features.
- Ormandy contacted Cloudflare via a public tweet after failing to reach a security contact; Leo initially criticized this and then retracted. Later Ormandy and others accused Cloudflare of downplaying; Steve saw a responsible, fast response.
- Steve's wider lesson: services like Cloudflare see plaintext of all proxied traffic; he would still pick a provider with a strong response record, and he himself will not hand GRC's private keys to a third party.
- Project Zero published an Edge and Internet Explorer remote code execution flaw (table and CSS handling, tracked as CVE-2017-0037) after Microsoft missed the 90-day deadline; the SMB zero-day was also still open.
- CloudPets: Spiral Toys left a MongoDB with over 800,000 customer credentials and about two million voice messages exposed without authentication, discovered through Shodan; Troy Hunt noted many bcrypt hashes were still crackable due to weak passwords. A separate researcher showed the toys have no Bluetooth LE pairing so anyone in range can upload audio.
- A New York airport contractor left a server with eleven full disk image backups reachable on the internet from April 2016, containing staff email, HR, payroll, security plans and a credentials list.
- Chrome 56 enabled TLS 1.3 and broke connectivity behind Blue Coat v6.5 TLS-intercepting proxies, which mishandle the newer version; Google rolled TLS 1.3 back but affected clients could not auto-update. Workarounds were DNS or whitelist tweaks for Google's update host or temporarily capping TLS at 1.2 in a Chrome flag.
- A Chicago federal judge refused to compel suspects to unlock Apple devices with fingerprints, again showing split courts and the need for a Supreme Court ruling.
- Amazon moved to quash an Arkansas warrant for Echo recordings in a murder case, arguing First Amendment protection and the need for a compelling need.
- Researchers demonstrated exfiltrating data from an air-gapped PC via the hard-drive LED read by a drone camera (about 4 kilobits per second); the demo required planted malware and Steve judged it more of a curiosity.
- ESET Endpoint Antivirus 6 for macOS had a root remote-code-execution flaw (CVE-2016-9892) caused by an old XML parser and missing certificate validation on its licensing check; Steve says always-on AV that hooks encrypted connections expands attack surface, while on-demand scanners like ClamWin are less concerning.
- SHA-1 collision: Google produced two different PDFs with the same SHA-1 digest, a computation of roughly nine quintillion SHA-1 operations (thousands of GPU-years), building on Marc Stevens' 2013 theory. Steve refers to Valerie Aurora's chart of how hash functions weaken over time and says legacy crypto is hard to kill but SHA-1 is already being phased out; SHA-256 is the future.

# Other segments

- Crypto education links: Crypto101, Ed Felten's five-page encryption primer; GRC added a free crypto resources section to its Linkfarm page.
- GRC refreshed the old Quiet Canine page (GRC.com/tqc) for the personal dog-deterrent ultrasonic device.
- Listener SpinRite follow-up on a RAID 10 with timeouts fixed after a Level 2 run; Steve's own story of repairing his friend Sue's degraded RAID after a storm, using Image for Windows first, and a remark that RAID warnings should not say "press Escape to continue."
- Comment on The Expanse TV series; Cox repair banter and thanks for the late start.
