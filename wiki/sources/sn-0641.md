# Summary

Steve and Leo open with bitcoin banter and a supermarket recommendation joke, then Steve explains the Black Hat Europe research behind the Intel Management Engine USB/JTAG compromise: researchers decoded Huffman-compressed firmware, exploited a stack overflow despite stack cookies and non-executable stacks using return-oriented programming (no ASLR), bypassed code signing and used a PCH unlock to expose JTAG over USB, which was far more laborious than fears of casual walk-up takeover. Google Project Zero's Ian Beer released iOS 11.1.2 kernel debugging tools after Apple fixed the bug in 11.2. Microsoft's Project Sopris IoT security challenge drew criticism for handing hackers an undocumented black box. Other items include EV certificate name-collision tricks, a bogus MyEtherWallet app in Apple's App Store, a DNS typosquatting finder, a guide for segmenting networks with the EdgeRouter X, Microsoft's out-of-cycle malware engine patch, an Apple HomeKit flaw mitigated server-side, and Valve dropping bitcoin because of fee spikes. ProtonMail Bridge is announced, and the main topic is ElcomSoft's argument that iOS 11 weakened security by allowing the backup password to be reset with only the passcode.

# Key points

- Intel ME research: x86-based ME firmware became analysable once the Huffman tables were reversed; the team chained a stack overflow, ROP and a boot-time file-system weakness, then used the PCH to expose JTAG to every platform device; Intel had real defences (stack cookies, NX stack, code signing) but lacked ASLR. Not a trivial thumb-drive attack.
- Ian Beer (Project Zero) published an iOS 11.1.2 local kernel debugger and async_wake exploit after responsible disclosure; five of 15 fixes in iOS 11.2 were his. Steve notes Apple's lockdown also locks out researchers.
- Project Sopris: Microsoft Research's silicon-level IoT security board was tested by 150 hackers for 60 days with no verified exploits, but participants had little documentation; Steve calls it security through obscurity and wants open documentation.
- EV certificates: a researcher incorporated "Stripe, Inc." in another US state, bought an EV certificate from Comodo and showed the green company name in browsers; another obtained one for "Identity Verified". The CA/Browser Forum is discussing the issue.
- MyEtherWallet displays extensive responsibility warnings, similar to SQRL's no-recovery philosophy; a counterfeit app reached number three in Finance on the App Store before removal.
- dnstwist generates look-alike domains and checks registrations, MX servers and page similarity to detect typosquatting.
- A step-by-step PDF guide shows how to use the Ubiquiti EdgeRouter X for IoT network segmentation.
- Microsoft shipped an emergency malware protection engine fix for remote code execution as LocalSystem; Steve still prefers Microsoft's built-in AV.
- HomeKit flaw in iOS 11.2 could allow unauthorised control of locks and garage doors; Apple used a server-side mitigation and promised a client fix.
- Valve ended bitcoin payments because transaction fees approached $20 and prices swung; Steve explains the 1 MB block limit and fee auction.
- ProtonMail Bridge runs a local IMAP/SMTP server so ordinary mail clients get PGP-based end-to-end protection through ProtonMail; Leo prefers plain GPG.
- Listener answers: passcode-protected link resets are the best email-based approach; username as a password salt is acceptable though random is better; "I'm not a robot" at login is questionable and leaks activity to the provider; security.txt can show how to report bugs; WINE lets the DNS Benchmark and SQRL run on Mac and Linux.
- ElcomSoft critique: before iOS 11 a forgotten iTunes backup password could not be reset without wiping the device; iOS 11 lets anyone with the device and passcode reset it (Settings > General > Reset > Reset All Settings), then make a new encrypted backup with a known password and extract keychain data. Steve agrees Apple traded security for convenience, so the passcode is the last line of defence and should be at least six digits or alphanumeric.

# Other segments

- Steve moved GRC.com's registration from Network Solutions (held since 1991) to Hover without incident; a SpinRite story fixing Windows sound after scanning only the start of a drive.
- Picture of the Week: a supermarket shelf mimicking "customers also bought" recommendations; the holiday special is teased.
