# Summary

The penultimate episode of 2017 explains how Estonia sidestepped the Infineon RSA key flaw by remotely updating its ID cards to use elliptic-curve cryptography, which the chips already supported, helped by timestamped signatures. Two cryptomining stories follow: Loapi, an Android malware family from third-party stores that can overheat and ruin phones, and the Zealot campaign that targets Linux and Windows servers with known Struts and DotNetNuke flaws. Two vBulletin zero-days were published after the vendor ignored researchers. Mozilla pushed a promotional "Looking Glass" Mr. Robot add-on through its Studies feature, a Windows 10 image reportedly bundled a vulnerable Keeper password manager extension, and Project Zero showed that Windows proxy auto-discovery (WPAD/PAC) with the old JScript engine is a dangerous legacy. Steve also covers the FBI-announced origin of Mirai (college students trying to hurt rival Minecraft servers), a Chrome profile sync trick for merging someone's saved data with physical access, and then explains BGP, prompted by a short-lived hijack of routes for Google, Apple, Facebook and others by an unused Russian autonomous system.

# Key points

- Estonia ID cards: key generation must happen on-card for legally binding signatures, and a larger RSA key was impossible on the chip, so it migrated to ECC via remote update, retooled the service providers and relied on timestamped signatures to distinguish pre- and post-disclosure signatures. Steve's lesson: deployed crypto must be updatable.
- Loapi (Kaspersky): evolved from Podec, spread through non-Google app stores as adult or fake antivirus apps; performs ad injection, SMS fraud, DDoS and Monero mining that can swell batteries. Advice: be careful where apps come from.
- Zealot (F5): scans for Apache Struts and DotNetNuke weaknesses on servers and installs Monero miners using PowerShell or Python from the EmpireProject; servers are better miners than IoT devices.
- vBulletin 5: a file inclusion remote code execution flaw and a PHP unserialize deserialization flaw (CVE-2017-17672) published with proof of concept after no response from the maintainers; Steve keeps his own forum software on physically isolated hardware.
- Mozilla's Firefox Studies feature (on by default) installed the Looking Glass promotional add-on tied to Mr. Robot; Steve and Leo object; users can disable studies in Privacy and Security.
- Keeper: Tavis Ormandy found a fresh Windows 10 MSDN image included Keeper with a flaw letting any site steal passwords; Keeper fixed it within 24 hours (update to 11.4.4 or later); whether general users got it was unclear.
- WPAD/PAC: Windows asks the network for a proxy auto-config JavaScript file via DHCP, DNS and WINS and runs it with the old JScript engine; Project Zero built a reliable exploit chain; mitigations are disabling auto-detect, blocking at the border or answering locally.
- Mirai: the FBI traced it to three college students (one from Rutgers pleaded guilty) who wanted to attack competing Minecraft servers and DDoS-protection hosts and later sold DDoS; public release of the source let others hit Dyn.
- Chrome sync trick: with physical access, signing out the owner and signing in as another Google account and choosing to merge data copies saved passwords; Google treats it as intended behaviour.
- Listener items: Google's Advanced Protection can use an NFC YubiKey in place of Bluetooth; iOS 11.2.1 fixed the HomeKit issue; Silk Road bitcoins sold for $48 million would be worth billions; Steve notes swap should never sit on flash media.
- BGP: routers exchange routes with BGP over TCP, and the most specific prefix wins. One week earlier BGPmon saw 80 prefixes for Google, Apple, Facebook, Microsoft, Twitch, NTT and Riot Games announced by an unused Russian AS (39523) for two roughly three-minute windows. Earlier incidents: Pakistan Telecom's 2008 YouTube blackhole leaking globally; a 2014 bitcoin pool hijack; spammers briefly squatting on address space. There is no vetting of announcements and 50 to 200 updates flow per minute, so Steve expects state-level abuse.
