# Summary

Microsoft began rolling out Google's Retpoline technique in Windows 10 1809 (KB4482887) to reduce the performance cost of Spectre variant 2 mitigations on Broadwell-and-older Intel chips and AMD; Steve repeats that Spectre has never been seen used in real attacks and that his InSpectre tool can turn mitigations off. Adobe issued an emergency fix for a ColdFusion file-upload bypass (CVE-2019-7816) already exploited in the wild. Kaspersky's HTTPS scanning raised false alarms about Chromecast's self-signed certificates. The runc flaw CVE-2019-5736 allows Docker container breakout; Imperva found thousands of exposed Docker API ports and hundreds of hosts running cryptominers. Coinhive announced it would close on March 8, 2019 because Monero mining was no longer profitable. Wireshark 3.0 moved to the Npcap driver and gained loopback capture. The Thunderclap research showed that Thunderbolt/IOMMU protections are weak or disabled on most operating systems, with only macOS enabling them by default. Akamai's report counted tens of billions of credential-stuffing attempts. The episode ends with the first bug-bounty millionaire, 19-year-old Santiago Lopez on HackerOne, as evidence that bug hunting can be a career.

# Key points

- Retpoline (return trampoline) replaces indirect branches in kernel binaries to mitigate Spectre variant 2 more cheaply than IBRS; it is safe only where RET does not speculate from the indirect branch predictor, so it applies to AMD and Intel up to Broadwell, not Skylake and newer. Windows 10 1809 only; registry keys documented for early manual enabling.
- ColdFusion CVE-2019-7816: file-upload restriction bypass leading to code execution if a site accepts executable uploads and serves them; found by consultant Charlie Arehart from an attack on a client; all ColdFusion 2018, 2016 and 11 versions affected; Adobe patched within days. Interim mitigation: keep upload directories non-executable and not web-reachable.
- Kaspersky (free and paid) popped "cannot guarantee authenticity" warnings in Chrome because Chrome probes for Chromecast devices (TCP 8009, self-signed cert) and Kaspersky inspects the TLS; disabling encrypted-connection scanning avoided it; Kaspersky promised a fix. Leo and Steve again question third-party AV that intercepts TLS.
- Docker explained as containers sharing the host OS (versus VMs); runc CVE-2019-5736 lets a malicious container overwrite the host runc binary for root. Imperva saw about 4,000 exposed Docker ports on Shodan, about 400 still responding, with cryptominer images found; exposure should be zero.
- Coinhive (JavaScript Monero miner, 62% share of web miners, once about $250k a month) ended service March 8, 2019 after hash rate fell over 50% following a Monero fork and a roughly 85% price drop. Steve notes the abuse could not be policed but finds a consent-based model interesting.
- Wireshark 3.0.0: replaces WinPcap with the EV-signed Npcap NDIS filter driver, captures localhost loopback traffic and Wi-Fi without special hardware, and can decrypt TLS given a server key.
- Headless Chrome/Firefox command-line screenshot trick reported by BleepingComputer.
- Thunderclap (FPGA research platform): DMA-capable peripherals over Thunderbolt 3 / USB-C can read memory or hijack the kernel within seconds even with IOMMUs, because OS use is incomplete; IOMMU enabled by default only on macOS, absent on Windows 7/8/10 Home/Pro. Steve advises disabling Thunderbolt in BIOS unless needed; it needs physical access.
- Akamai's State of the Internet report: over 10 billion credential-stuffing attempts against retail and about 28 billion across industries from May to December 2018 (more than 115 million a day); bots can be 60% of web traffic; password reuse (for example after the LinkedIn breach) fuels takeover; a Ponemon survey found 71% say prevention hurts user experience.
- Bug bounties: Santiago Lopez passed $1 million on HackerOne; HackerOne passed $45 million paid out, hackers earned over $19 million in 2018, with 300,000 registered hackers. Leo asks for a future show on how to learn bug hunting.

# Other segments

- Origin of the names Gibson Labs and GRC and early domain registration anecdotes; Steve declines to squat on domains.
- Picture of the week: Shodan map of publicly exposed Docker ports (3,951; US 929, China 680).
- SQRL: Android and iOS clients restoring identities from printed rescue QR code and rescue code; user-experience volunteers sought; Steve plans a SQRL party at the TWiT studio; around 657 forum members.
- SpinRite on an SSD fixed intermittent camera-recording stalls; Windows mountvol command described for mounting and unmounting backup drives; origin of the word "doozy" (Duesenberg).
