# Summary

Steve starts with Java 7 Update 45, which fixed 51 vulnerabilities, 50 remotely exploitable, and advises removing the Java plug-in from everyday browsers and keeping it only in a browser of last resort. He reports that the major Internet governance organizations meeting in Montevideo (ICANN, IETF, IAB, W3C, Internet Society and the regional registries) called for ending US unilateral oversight, a fallout of the NSA revelations. Yahoo announced it will turn on HTTPS by default in January 2014. Lavabit's old certificate was revoked by GoDaddy, its server now prefers forward-secret ciphers, and its owner opened a short window for customers to retrieve mail and raised funds for his legal defence. New documents show the NSA harvesting about half a million contact lists a day from webmail and chat via upstream taps, and Bruce Schneier describes the FOXACID system that chooses exploits by target value. The W3C Do Not Track effort was close to collapse, a public fundraiser for a TrueCrypt audit was underway, the SecureDrop whistleblower system was open sourced, and a D-Link router firmware backdoor keyed on a special user-agent string was found. The main segment adds two SQRL protocol improvements: a retired "previous key" that is signed alongside the new key so sites can swap identities, and an Enforce option that makes sites reject a login if the IP asking to authenticate differs from the IP that was shown the QR code, defeating relay-style phishing.

# Key points

- Java 7u45 fixes 51 flaws; Java 6 gets no patches and attackers reverse-engineer updates to exploit old versions. Steve: Java should never have been a browser plug-in; remove it from the main browser, test with a harmless applet on GRC.
- Internet governance bodies called for globalizing ICANN and IANA functions and reducing US dominance; Leo thinks this is acceptable in principle.
- Yahoo to enable HTTPS by default on January 8, 2014, years after Google.
- Lavabit: GoDaddy revoked the compromised certificate (browsers now warn); Lavabit's servers had forward-secrecy ciphers prioritised; a temporary site let users change passwords and download archives, and the owner asked users to verify the new certificate chain through the browser rather than a number printed on the page itself. Steve repeats that email is hard to secure end to end.
- Washington Post slides: in a single day the NSA collected hundreds of thousands of address books from Yahoo, Hotmail, Facebook and Gmail (over 250 million a year), via passive taps at service providers, to map relationships.
- Do Not Track: the W3C working group was in revolt; the EFF said it had lost confidence. Steve values having the header in browsers anyway.
- Schneier: FOXACID servers serve exploits chosen by a cost-benefit analysis; operators follow a flowchart that stops at any anomaly; the NSA weighs detection risk but not the risk of leaks. Exploit family names such as Validator and Ferret Cannon are cited.
- Glenn Greenwald was leaving the Guardian for a new venture backed by eBay's founder.
- Matthew Green and others raised money for a public TrueCrypt audit (target 25,000 dollars, about 16,000 pledged); Steve backs the effort since open source is not the same as audited.
- SecureDrop, originally by Aaron Swartz, now managed by Freedom of the Press Foundation, uses Tor hidden services, separate source and document servers, a monitor, and an air-gapped Tails viewing station.
- A D-Link router firmware flaw: an authentication routine accepted a particular reversed-string user-agent as a bypass; exposure depends on remote administration being enabled.
- SQRL previous-key revocation: a client may hold one retired key; queries sign both new and old keys, so a site finds the account by the old key and replaces it automatically.
- SQRL anti-phishing: when logging in on the same device, the client adds a signed Enforce option; the site then fails the login if the requester's IP differs from the IP the QR code was served to. It stays off for optical scanning over cellular where the IPs naturally differ. Steve says this blocks relay phishing and calls it unprecedented.
- SQRL status: about 2,200 newsgroup posts, W3C interest, and talks at an HTML5 developer conference and an identity conference.
