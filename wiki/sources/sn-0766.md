# Summary

Firefox 76 added breach alerts and a safer reveal flow to Lockwise and video pop-out, fixed three critical issues and was followed by 76.0.1. Edge, Chrome and Firefox all offer ways to silence website notification requests. Steve stresses that WordPress and vBulletin owners must patch promptly: an attack wave of tens of thousands of IP addresses hit old WordPress plugin bugs, Elementor Pro had an actively exploited zero-day alongside a companion add-on flaw, and vBulletin shipped an unexplained critical patch. Black Hat and DEF CON go virtual in 2020. A Project Zero finding showed Samsung phones could be hit through the Qmage image format via MMS messages, and Zoom bought Keybase to build end-to-end encrypted meetings. Steve reorders his SpinRite plans to add UEFI support earlier. The main topic is Thunderspy, seven design flaws in Thunderbolt security that let an attacker with brief physical access bypass authorization and protections.

# Key points

- Firefox 76: Lockwise warns about breached sites and reused passwords and requires the OS account password before showing saved logins when no master password is set; picture-in-picture video pop-out arrives (still unreliable); 11 CVEs fixed including a worker use-after-free and a sandbox escape; 76.0.1 followed quickly. Steve notes Chrome shows saved passwords with a few clicks.
- Notification annoyance: Edge adds a "quiet notification requests" setting, and Chrome and Firefox have equivalent settings; some sites now detect blocking and pressure users to allow notifications.
- WordPress: Wordfence/Defiant observed attacks from over 24,000 IPs (20 million attacks on over half a million sites in one day) targeting old cross-site scripting and option update flaws in plugins and themes such as Easy2Map, Blog Designer, a GDPR compliance tool, Total Donations and the Newspaper theme. Separately, Elementor Pro (over a million sites) had an actively exploited flaw reachable through open registration, and Ultimate Addons for Elementor allowed bypassing that condition; Elementor Pro 2.9.4 fixed it.
- Steve's general lesson: modular, plugin-heavy systems cannot be assured secure, so maintenance and patching are the price; keep add-ons sparse and remove abandoned plugins.
- vBulletin: an unspecified critical access-control flaw (CVE-2020-12720) patched for versions 5.5.6, 5.6.0 and 5.6.1; the discoverer from Ambionics planned to present details at SSTIC in early June, so patching was urgent. Steve isolates his forum behind a physical firewall.
- Black Hat (1-6 August) and DEF CON (7-9 August) become virtual in 2020; DEF CON 29 is planned in person for 2021.
- Samsung Qmage flaw: Skia handling of Samsung's custom .qmg image format enabled a zero-click attack through repeated MMS messages (50 to 300 attempts to defeat ASLR); found by Project Zero and fixed in the May 2020 update; only Samsung devices affected.
- Zoom acquired Keybase; Zoom 5.0 uses AES-256-GCM with server-generated keys, and an end-to-end mode with host-controlled keys and a public key directory is planned for paid accounts, without phone bridges or cloud recording. Leo will miss Keybase.
- SpinRite: Steve is writing a new boot-media preparation system and now plans a SpinRite 7 with native UEFI boot (no DOS) before the larger rewrite (v8); testing builds read at about 258 MB/s.
- Thunderspy (Eindhoven University of Technology): seven flaws in Thunderbolt 3 security: firmware signatures checked only when written, weak device authentication, unauthenticated device metadata, legacy Thunderbolt 2 compatibility, unauthenticated controller configuration, SPI flash interface deficiencies that let security be disabled and updates blocked, and no security under Boot Camp. Nine attack scenarios under an evil-maid model include cloning authorized devices and obtaining DMA access; a Spycheck tool reports exposure. Steve concludes exporting a system's internal bus is inherently risky and that backward compatibility keeps impersonation possible.
