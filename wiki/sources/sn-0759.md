# Summary

Steve, back after an illness, opens with Microsoft's advisory about two unpatched remote code execution flaws in the Adobe Type Manager font library (Type 1 multi-master fonts), exploited in limited targeted attacks against every Windows version and not due for a fix until April Patch Tuesday; he describes the officially suggested mitigations. Mozilla reversed its removal of TLS 1.0 and 1.1 in Firefox so people could reach government COVID-19 information sites. The 0patch service released a micropatch for a GDI flaw that Windows 7 and Server 2008 will never receive officially. Google paused Chrome 81 and shipped only security updates, Tavis Ormandy found a serious flaw in Avast's JavaScript emulator (Avast disabled it), Kaspersky described the CookieThief Android trojan, and Pwn2Own ran virtually. The main topic is TRRespass: research showing that DDR4 Target Row Refresh defenses do not stop Rowhammer, six years after the attack was first shown.

# Key points

- Font zero-day: two bugs in the Windows Adobe Type Manager Library, reachable via the Explorer preview or details pane, documents, and WebDAV; used in targeted attacks. Mitigations: show icons instead of thumbnails, disable the WebClient service, or rename atmfd.dll (Windows 7/8.1 registry option also exists). Microsoft kept to its monthly patch schedule.
- Steve repeats the old advice never to download anything offered to you, particularly as COVID-themed attacks surge.
- Mozilla re-enabled TLS 1.0/1.1 in Firefox 74 for an undetermined period because some government COVID sites still depended on them; Netcraft counted around 850,000 sites without TLS 1.2 or 1.3.
- 0patch: a micropatch for the GDI+ remote code execution bug (patched by Microsoft on Patch Tuesday but not for Windows 7 or Server 2008) is available to subscribers, with no reboot needed and an exploit-attempt event logged. Steve is considering inviting the vendor on the show.
- Chrome 81 release postponed due to remote-work schedules; Chrome 80 updates (13 high-severity fixes) continue; Google Play app review times lengthened.
- Avast: Tavis Ormandy used his tool for running Windows DLLs under Linux to find a trivially exploitable flaw in the unsandboxed, privileged JavaScript emulator; Avast disabled it. Steve cites it as another reason to doubt third-party AV.
- CookieThief: an Android trojan that gains root to steal browser and Facebook app cookies and relays spam through a proxy on the victim's phone; Steve notes static cookies remain a weakness, contrasting with SQRL, and that OAuth spreads the impact.
- Pwn2Own spring 2020 went virtual (exploits submitted in advance): Team Fluoroacetate won again; successes against Safari/macOS (six-bug chain), Windows (use-after-free local privilege escalation), Ubuntu, Adobe Reader and VirtualBox; only a VMware Workstation attempt failed.
- COVID testing observations: RT-PCR tests are labor intensive and unscalable, antibody ELISA tests are emerging, and reported case counts are really counts of positive tests; the death curve lags by weeks.
- TRRespass (VU Amsterdam, ETH Zurich, Qualcomm): in-DRAM Target Row Refresh is a collection of undocumented mitigations; a black-box Rowhammer fuzzer found "many-sided" patterns that flip bits on 13 of 42 tested DDR4 DIMMs from all three major vendors, and LPDDR4 is also affected. The paper criticizes security by obscurity.
- Steve recaps six years of Rowhammer progress: JavaScript attacks, cloud VMs, Android root, network packets, ECCploit, RAMBleed, Jackhammer.
