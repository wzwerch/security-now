# Summary

Steve starts with June Patch Tuesday: two critical flaws, one in the Unicode script processor (needing WebDAV and exposed file-sharing ports) and one in the GDI+ image parser, which could become attacks on Windows XP once reverse-engineered. He argues all software has latent bugs and that exposure of known flaws is what matters; Leo notes that the XP-to-embedded registry trick did deliver an update. He then covers Google's "End-to-End" browser PGP extension (elliptic-curve keys, JavaScript crypto concerns), a new OpenSSL man-in-the-middle bug (a change-cipher-spec injection allowing a key-material downgrade that had been present for about 15 years, with six other fixes including DTLS crashes), and iOS 8's randomised MAC addresses before WiFi association. He debunks a Register story claiming Microsoft is not patching Windows 7 (new "safe" string functions simply exist only in newer libraries), reports that LACNIC has reached its last block of IPv4 addresses, and describes Netflix showing congestion notices to users and Level 3 data on saturated interconnects. Listener questions cover how datacenters bill bandwidth (committed rate plus burst, billed at the 95th percentile of five-minute samples), why Net Neutrality is about broken peering assumptions, whether SSL and SSH are still safe after Snowden (the math holds; the weak links are elsewhere), a CryptoLocker infection slowed by Microsoft Security Essentials, microphones, and hard drive head parking.

# Key points

- Patch Tuesday: remote-code flaw in usp10.dll (needs WebDAV plus exposed ports 139 or 445) and a GDI+ image-parsing flaw (kernel-resident GDI); Steve will watch whether exploits reach XP.
- XP using the embedded registry hack received the June updates; Microsoft published nothing about the embedded channel. Steve will test on a nonessential XP tablet.
- Steve: no operating system can be called "most secure" in advance; history judges, and users should update once flaws become public.
- Google End-to-End is a browser PGP extension creating only elliptic-curve keys but importing RSA ones; GnuPG 2.1 beta supports EC keys. Steve sees it as a worthwhile experiment that would have eased Snowden and Greenwald's key-management problem.
- OpenSSL disclosed seven problems, the worst a change-cipher-spec style handshake injection by a man in the middle that forces weak or null key material when both endpoints run vulnerable OpenSSL; Adam Langley found it present in code 15 years old.
- Steve criticises legal threats against researchers because the feedback loop of independent flaw discovery is how security improves.
- iOS 8 uses random MAC addresses while scanning for WiFi networks, defeating physical-store and street-level tracking; Leo notes iBeacon remains.
- The Register claim that Windows 7 lacks fixes present in Windows 8 is a non-issue: new safe functions (intsafe, strsafe-style bounded string handling) are just new API features, and programmers targeting older OSes cannot use them.
- LACNIC (Latin America and Caribbean) declared its IPv4 pool exhausted with about 4 million addresses left; new entrants will have to justify need, and Steve predicts large legacy holders (/8 blocks such as Merck's) will be pressured to return space.
- Netflix began showing in-app poor-connection notices attributed to the ISP; Verizon objected. Level 3 charts show a 100G interconnect saturated for most of a day versus one that merely peaks.
- Router buffering and quality-of-service tagging explained: when average input exceeds output, packets are dropped.
- Datacenter 95/5 billing: usage is sampled in five-minute windows, the top 5 percent discarded, the next value billed for the whole month; Steve has a 10 Mbit/s commit with burst to 100.
- Net Neutrality is framed as a breakdown of peering assumptions: free peering assumed symmetric value, but video streaming makes flows lopsided.
- Crypto "almost never breaks, it is everything else" (Shamir); SSL and SSH remain trustworthy and HTTPS adoption has grown since Firesheep.
- CryptoLocker case: Microsoft Security Essentials repeatedly removed the dropper over ten days and slowed encryption to about 500 files; an offsite backup allowed full recovery.
- Hard drives park heads at the hub or on ramps when power is lost, so moving a spinning-down external drive risks bearings rather than head crashes.

# Other segments

- Chrome memory bloat was due to add-ons, not Chrome itself.
- Reviews: "Edge of Tomorrow" praised, "Halt and Catch Fire" disappointing.
- SpinRite testimonial from Sweden about periodic system freezes cured by a scan.
- Leo's Heil PR 40 microphone discussion; trivia about the TrueCrypt announcement Latin acrostic conspiracy theory; ShieldsUP usage passed 59 million.
