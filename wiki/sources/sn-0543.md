# Summary

The show begins with a recurring IoT refrain: every IoT device should live on its own isolated WiFi network. Researchers showed that a Ring video doorbell, when taken off the door and put into setup mode, exposed the home WiFi password through a built-in module page; Ring fixed and pushed the firmware within weeks and Steve praised its response. Vectra Threat Labs showed that a cheap D-Link webcam could be given a persistent backdoor by reverse-engineering its firmware update process, and Amazon's optional cloud storage of WiFi passwords drew caution. Malvertising hit Forbes visitors who turned off ad blockers, a hardcoded SSH login was found in Fortinet's FortiOS firmware and described by the vendor as a management authentication issue, and a New York bill to ban phones the maker cannot decrypt was reintroduced. Steve covered Microsoft's official way to block the Windows 10 upgrade nag and a policy that new processor generations would be supported only on Windows 10. The main topic was Sean Cassidy's "LostPass" ShmooCon talk, in which a malicious page imitates LastPass's in-page login prompts to harvest the master password and a two-factor code; LastPass had already added mitigations, and Steve used it to argue that phishing deserves systemic fixes.

# Key points

- Ring doorbell: after removing the device and pressing its setup button, an exposed module configuration page returned the stored WiFi key in the clear; reporters disclosed privately, Ring replied within minutes and shipped a firmware update that auto-installed. Steve notes any physically exposed WiFi device faces the problem that the key has to be stored somewhere.
- IoT advice: put all IoT gadgets on a guest or separate WiFi network that cannot see the main network.
- D-Link $30 webcam: researchers dumped flash, analysed the firmware update check, and added a connect-back proxy while keeping the camera working, showing a persistent foothold on a tiny device with no endpoint protection.
- Amazon Echo setup can optionally save WiFi passwords to Amazon so other Amazon devices need no re-entry: convenience versus security.
- Forbes asked readers to disable ad blockers and a malicious pop-under (a fake Java update) hit many security researchers; the malvertising problem makes ad blocking a safety feature.
- Fortinet FortiOS carried a hardcoded SSH login; Fortinet said it was fixed in mid-2014 and not a backdoor, but later firmware still contained the same string, which Steve suspected was guarded by something like port knocking. The password itself is not recorded here.
- New York bill (reintroduced) would ban sale of smartphones that the manufacturer cannot decrypt on a court order.
- An estate-access story in Toronto: Apple demanded a court order for a deceased husband's Apple ID; Steve contrasted SQRL's rescue code and LastPass emergency access.
- Microsoft published an official policy-based way (and registry settings) to turn off the Windows 10 upgrade offer for Windows 7/8.1 Pro; the GWX Control Panel utility also got an update. Steve prefers the official method.
- Microsoft said future silicon (Intel Skylake onward, AMD, Qualcomm) will only be supported on Windows 10; Microsoft explained older Windows needs extra emulation shims for new hardware. Steve and Leo were unsure of the practical effect and wanted to test Linux as a comparison.
- Errata: it is Windows XP Embedded whose support ended; the POSReady variant continues until April 2019 and the registry trick still works.
- LostPass: a researcher cloned LastPass's HTML dialogs, forged a "you are logged out" notice, used the extension API and cross-site request forgery to force logout, then relayed master password and two-factor code to the real service (a man-in-the-middle phishing attack). It works because the dialogs live in the page viewport.
- LastPass fixes before the talk: block the forced logout, warn when the master password is typed into a non-LastPass page, always require email verification from new locations even with two-factor, and warn about master-password reuse on other sites. Steve says he is staying with LastPass; he called for browsers to give extensions a trusted UI channel that pages cannot imitate.
- Cassidy's wider point: evaluations of security software should include how easy it is to phish, and training alone is not enough.

# Other segments

- Steve reports good results in his sleep tracking project and plans a sleep page.
- Amazon Dash buttons and OEM-integrated reordering mentioned by Leo.
- Bragi in-ear headphones shipment held up by UPS because a blinking LED looked like active Bluetooth.
- Listener question about archiving video on hard drives: store drives, then power them up about yearly and run SpinRite Level 4; cloud cold storage is an alternative at monthly cost.
