# Summary

Steve revisits July's Patch Tuesday: Windows 10 updates from late June caused USB printers to be duplicated with a "Copy1" suffix and break printing by name, which he uses to argue that Windows is so creaky Microsoft can barely change anything. Microsoft confirmed it is resuming the default block of internet-sourced Office VBA macros in the Current Channel, and Steve scorns business complaints that signing macros would be too much trouble. Windows 11 now ships a default account-lockout policy against RDP brute forcing, though only 10 attempts and a 10-minute window. Steve lists the August conference calendar (Black Hat, DEF CON, the podcast's 17th anniversary), reports that SpinRite 6.1 now runs again after its deep re-architecture, notes that pfSense will add Tailscale support, and explains the YOURLS shortener behind grc.sc. The main topic is BitSight and CISA's disclosure of six vulnerabilities in the MiCODUS MV720, a cheap hardwired GPS tracker with remote fuel cut-off used in about 1.5 million vehicles across 169 countries, with a shared global API password, unencrypted traffic, default device passwords and unauthenticated commands, and a vendor that never responded.

# Key points

- July 2022 Windows 10 patch issue: duplicated USB printers ("Copy1") and printing failures by name; Microsoft's workaround involves matching printer ports. Steve's point: legacy architecture cannot be fixed without breaking dependencies.
- Office macros: after complaints from finance-sector users (Votiro's view that blocking hurt workflows), Microsoft resumed the default block of internet macros in Current Channel and updated admin documentation; Group Policy still allows exceptions and signed macros remain the sensible route. Leo calls it fail-secure versus fail-insecure.
- Windows 11 default account lockout policy (announced by Dave Weston): lock after 10 failed logons for 10 minutes with a counter reset every 10 minutes, aimed at RDP and other brute force, which the FBI is quoted as linking to 70-80% of network breaches. Steve wants the lockout to be indistinguishable from a normal failure and the thresholds stricter.
- August calendar: Black Hat USA (hybrid, August 6-11), DEF CON (August 11-14, cash-only, no ID), and Security Now's 17th anniversary on August 19.
- SpinRite 6.1 "is alive": the code is stripped of BIOS dependence and rebuilt around a device-independent mass-storage abstraction (first SATA/IDE via AHCI and bus mastering, later USB and NVMe); still much work remains; the original 1987 source file header was shown; log files may move to ASCII/UTF-8.
- pfSense 22.05 will add selectable Tailscale support; Tailscale is a WireGuard-based overlay network with NAT traversal and single sign-on, comparable to Hamachi.
- YOURLS (PHP and MySQL URL shortener issuing 302 redirects) powers grc.sc; Steve had moved away from bit.ly after episode-number short links were squatted.
- MiCODUS MV720: roughly 1 inch cube, about $26 online, marketed as looking like a relay, supports GPS tracking, geofencing, alarm disarming and remote fuel cut-off; 1.5 million units in 169 countries including governments, militaries and energy firms.
- BitSight found six flaws (two CVSS 9.8): a single hard-coded global master password for the API server, broken authentication that lets the API send SMS-style commands without the device password, a factory default device password that 945 of 1,000 sampled devices still used, sequential guessable device IDs, unencrypted HTTP and a custom TCP protocol, and an "adminip" command that lets an attacker repoint the tracker to a rogue server for persistent invisible control. Some SMS commands (including fuel cut) need no password.
- Disclosure timeline: BitSight contacted the vendor from September 2021; the vendor ignored requests for a security contact; CISA also tried in May 2022; BitSight and CISA published on July 19, 2022 with no fix. BitSight recommends disabling MV720 devices.
- Steve's lesson: cheap internet-connected devices place unearned trust in unknown remote services; the same backend likely affects other MiCODUS models, including newer 4G versions.
