# Summary

The episode closes year ten of the show. Steve reports that two free Stagefright test apps now exist (Zimperium and Lookout, with differing results) and that Samsung, LG and Google promised monthly Android patches; he stresses that ASLR only raises the cost of exploitation. He lists a Windows 10 tracking-disabler tool and a screenshot guide, and dismisses press speculation that the FBI "broke" TrueCrypt, which more likely involved a weak or disclosed password. A Firefox zero-day in the built-in PDF viewer, abused through a malicious ad to read local files, was fixed within hours (39.0.3, then Firefox 40); it undermines Steve's plan to rely on Sandboxie, since the sandbox does not stop reads. Other news: a Black Hat talk on a convoluted x86 System Management Mode flaw that Steve judges impractical, PushBullet adding end-to-end encryption, an Oracle security chief's post attacking customers for code analysis (later pulled), the EFF's Privacy Badger 1.0 with a Do Not Track policy, and the ad-blocking debate with Leo. Steve concludes that script-blocking has become too burdensome and proposes a community project: a tiny Linux image running in a disposable virtual machine for browsing.

# Key points

- **Stagefright testers:** Zimperium's app (with test media files) gives per-flaw results; Lookout's is simpler; both free; carriers and vendors pledge monthly patches. Steve: connected devices of any kind are computers needing an update path.
- **ASLR:** a mitigation that adds difficulty but is repeatedly bypassed; with small randomization ranges, large device populations still yield victims.
- **Windows 10:** an open-source tool disables the DiagTrack and push-routing services; a guide site mirrors the settings walkthrough from the prior episode.
- **TrueCrypt and the FBI:** a news site's suggestion of a break is unsupported; audits found no weakness, so the passphrase is the weak point.
- **Firefox PDF viewer zero-day (found by a security researcher on a news site ad):** bypassed same-origin protection to read local configuration, credential and history-type files on Windows, Linux and Mac and send them to a remote server without trace; Mozilla patched in hours; Firefox 40 mostly improves Windows 10 appearance and will be followed by a requirement for signed extensions.
- **Sandboxie limits:** it redirects writes but allows reads, so it would not have stopped this file theft.
- **"Memory Sinkhole" (Black Hat):** before Sandy Bridge, overlaying the APIC memory map on SMM memory could let a root-level attacker plant firmware rootkits, but requires deep platform knowledge; Steve calls the hype excessive.
- **PushBullet:** now supports end-to-end encryption with a user passphrase deriving a 256-bit key.
- **Oracle blog:** the security chief demanded customers not reverse engineer code and said reporters would get no credit; strong backlash and removal.
- **Privacy Badger 1.0 (EFF):** learns trackers by observing third parties across three or more sites, blocks or strips cookies, and honors sites that publish the Do Not Track policy.
- **Ad-blocking economics:** Leo cites rapid growth in ad-block use and publisher losses; both hosts discuss micropayments and annoying ads.
- **Flash 18.0.0.232** released again.
- **Quest for surfing safety:** script blocking and Sandboxie both fall short; idea of a small Linux VM (Tiny Core Linux mentioned) hosting Firefox or Chrome, reset on each use; listeners are asked to help.
