# Summary

The Picture of the Week shows PHP's loose comparison treating two different "0e..." MD5 hash strings as equal, which Steve uses to argue for strongly typed languages. Microsoft began force-feeding Windows 10 version 1809 users a feature update ahead of its May 2020 end of service, and hobbyists released a BypassESU tool to keep Windows 7/8 receiving Extended Security Updates, which Steve expects Microsoft to counter. He continues the memory-safety theme with a Microsoft engineer's positive experience rewriting a Windows component in Rust, and mentions Project Verona. Microsoft's iOS Remote Desktop client returned as 10.0.1 after a settings-wiping bug. Wladimir Palant's analysis showed Avast and AVG browser extensions sent users' full browsing context to Avast's servers, linked to the Jumpshot data business; Mozilla pulled the extensions. Steve praises WireGuard, newly merged for the Linux kernel, and mentions Mullvad's anonymous account model. The headline segment dismantles the so-called Linux/Unix "VPN hijacking" research as a noisy, impractical TCP-probing trick that cannot read or alter encrypted traffic.

# Key points

- PHP type juggling: hashes that look like scientific notation ("0e" prefix) compare equal under loose equality; use strict comparison or well-designed libraries.
- Windows 10 1809 users are being automatically moved to a newer feature release; LTSC and enterprise channels are exempt. Steve prefers LTSC.
- BypassESU: community tool (My Digital Life forum) to trick Windows 7/8 into taking Extended Security Updates after January 14, 2020; it violates licensing and will likely be broken by a Microsoft update; upgrading to Windows 10 remains an option.
- Rust at Microsoft: a Hyper-V engineer reports a good developer experience, compiler-enforced memory safety, performance on par with C++, and strict rules around `unsafe` and FFI wrappers; Microsoft is also working on Project Verona.
- Microsoft Remote Desktop for iOS v10 was pulled shortly after release for wiping saved configs, then re-released as 10.0.1; never expose RDP directly, use it behind a VPN.
- Avast Online Security and AVG equivalents (including the bundled secure browsers) sent URLs, titles, referrers, tab/window IDs, user IDs and more on each page load, unlike Safe Browsing's local list model; Avast owned Jumpshot, a clickstream data seller. Mozilla removed the add-ons; Chrome's store had not at time of recording. Steve and Leo see Windows Defender as adequate.
- WireGuard: simple, fast, modern VPN protocol using Noise, Curve25519, ChaCha20-Poly1305 and BLAKE2; Linus Torvalds praised it; merged toward Linux 5.6; Steve plans a deep dive in 2020.
- Mullvad VPN uses only WireGuard and numbered anonymous accounts; it sponsored Steve's OWASP SQRL talk in Sweden.
- "VPN-geddon": researchers claimed attackers on the same network could infer a VPN client's virtual IP, detect connections and hijack TCP streams on Linux, BSD, macOS, iOS and Android; Steve explains it requires a man-in-the-middle position, relies on challenge-ACK side effects, never exposes plaintext, and cannot inject valid encrypted data, so at most it leaks some metadata or annoys the stack. The press repeated the alarm without analysis.
