# Summary

A spending bill signed in March 2022 contains the Strengthening American Cybersecurity Act, which obliges operators of critical infrastructure (16 sectors) to report breaches to CISA within 72 hours and ransomware payments within 24 hours, with subpoena power for CISA; rulemaking may take up to two years. The maintainer of the popular npm package node-ipc added a dependency and later code that wiped files on machines geolocated to Russia or Belarus as a protest, one of about 21 similar protest-motivated changes, which Steve cites as a trust problem for dependency trees. A pen tester's Browser-in-the-Browser technique fakes a sign-in popup, including a convincing URL bar, using HTML and CSS, defeating the advice to check the domain. Microsoft documents Trickbot using compromised MikroTik routers as command-and-control proxies, reached through default credentials, credential stuffing and the old CVE-2018-14847. Tavis Ormandy found an infinite loop in OpenSSL's BN_mod_sqrt triggered by crafted certificates, fixed in 1.1.1n and 3.0.2. A CISA advisory describes Russian actors compromising an NGO via a dormant account that Duo let re-enroll, PrintNightmare privilege escalation, and a hosts-file change that made Duo fail open. A Windows user profile service privilege escalation (CVE-2021-34484, then CVE-2022-21919) was patched repeatedly yet remained exploitable, with 0patch micropatching it. Steve closes with a primer on why use-after-free bugs arise in manual, garbage-collected and reference-counted memory management.

# Key points

- Strengthening American Cybersecurity Act (2022): critical-infrastructure entities report incidents in 72 hours and ransom payments in 24 hours; passed the Senate unanimously; CISA gets subpoena power; 16 sectors from Presidential Policy Directive 21.
- node-ipc and "peacenotwar" (maintainer RIAEvangelist): the dependency added a peace message and later destructive code targeting Russian/Belarusian IPs; Snyk reported it on 15 March; the maintainer reverted after outcry; the incident highlights transitive dependency risk and protestware.
- Browser-in-the-Browser (mr.d0x): fake popup windows for single sign-on with spoofed address bar and ready-made templates; users cannot tell by sight; the real defense is not entering credentials into popups you cannot drag outside the main window, and password managers that match domains.
- Trickbot and MikroTik: routers compromised with default credentials, credential stuffing or CVE-2018-14847 (RouterOS before 6.42) get static NAT rules relaying bot traffic (for example port 449 to a C2 on port 80); Eclypsium counted hundreds of thousands of vulnerable MikroTik devices; Microsoft released a forensic scanner.
- OpenSSL: crafted certificate with invalid explicit elliptic curve parameters makes BN_mod_sqrt loop forever during parsing, before signature checks; affects 1.0.2 (end of life), 1.1.1 and 3.0; fixed in 1.1.1n and 3.0.2 on 15 March 2022; proof-of-concept was public.
- CISA/FBI advisory AA22-074A: Russian actors used a guessable password on an account un-enrolled from Duo MFA, re-enrolled their own device (a default), exploited PrintNightmare, edited the domain controller hosts file to point the Duo service to localhost, and relied on Duo for Windows failing open by default (changeable at install or via registry); fail-open is a risk in any MFA product.
- Windows user profile service elevation of privilege found by Abdelhamid Naceri: August 2021 fix bypassed, January 2022 fix bypassed, March 2022 update broke 0patch's micropatch until it was re-issued; unsupported Windows 10 versions stayed protected by the original micropatch.
- Use-after-free is a catch-all: manual free followed by a stale pointer, dangling pointers an attacker repurposes, and runtime garbage collector or reference-counting errors in engines such as JavaScript's; Leo notes it occurs with manual, garbage-collected and reference-counted schemes alike.
