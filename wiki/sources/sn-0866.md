# Summary

The episode, recorded on April 2022 Patch Tuesday, starts with a claimed zero-day in Nginx, the most used web server (33.2 percent of sites, about 45 percent of the top 1,000). The group BlueHornet said it had breached a few organizations through an LDAP injection and then threatened to sell the exploit; F5/Nginx replied that only the LDAP reference implementation, a Python daemon sample, is affected and that Nginx itself is not. Steve draws the lesson that reference code will be deployed as-is, comparing it to Intel's UPnP sample. Microsoft announced Windows Autopatch, a free service for Enterprise E3 and above that sorts machines into test, first, fast and broad rings and rolls out updates progressively with halt and rollback. Another npm protest change, in event-source-polyfill (used by about 135,000 repositories), shows anti-war messages to Russian users and underlines the fragility of dependency trees. Steve warns that Windows 10 20H2 and 1909 editions reach end of service in May. A digression covers Coinbase telling attackers whether an email has an account. Listeners suggested time-based port knocking and Fail2ban lockouts. The main item updates Spring4Shell: a week after disclosure it was in CISA's exploited catalog, scanned heavily, used to drop web shells and Mirai, and affected products from Cisco and VMware.

# Key points

- Nginx claim: BlueHornet (with a sister group) posted a two-stage exploit based on LDAP injection in the nginx-ldap-auth reference daemon; targets reportedly included banks; Nginx published a notice that only the reference implementation, which is not production grade, is affected, under three configuration conditions; the group then spoke of selling the exploit for around 200K in Monero.
- Lesson: never publish an insecure example you are not prepared to see used verbatim in production (the tyranny of the default); Apache's own early FAQ said the name meant "a patchy server".
- Windows Autopatch (planned for July 2022): Microsoft takes over update orchestration for Windows 10/11, drivers, firmware and Microsoft 365 Apps via four rings (test, 1 percent first, 9 percent fast, 90 percent broad), with halt and rollback; Steve questions how it learns from breakage and calls the context a sign of how brittle Windows updates became.
- Protestware in the npm package event-source-polyfill 1.0.26 (maintainer Yaffle): shows an anti-war message to Russia-based users after 15 seconds; the polyfill is only needed for Internet Explorer; over 135,000 repositories depend on it and it sees 600,000 weekly downloads; Steve argues such repeated incidents show how rickety package ecosystems (npm, Maven) are against an active adversary.
- Windows 10 20H2 (Home, Pro) and 1909 Enterprise/Education/IoT reach end of service in May 2022; next Patch Tuesday (10 May) is the last update for Home and Pro 20H2; Enterprise 20H2 gets until May 2023.
- Coinbase sign-in reveals "No Coinbase account exists for this email", enabling account enumeration and targeted phishing, right after a 2021 phishing wave hit more than 6,000 customers; Steve's rule is to ask for the password regardless and give a generic failure.
- Listener ideas on port knocking: a TOTP-style time-based knock sequence that solves replay, using the source port as extra entropy (16 bits more per packet), and Fail2ban banning any IP that touches three closed ports for a week.
- Spring4Shell (CVE-2022-22965, CVSS 9.8) update: exploitation needs a DataBinder-enabled endpoint, the sample form-handling code is vulnerable, CISA added it to its KEV catalog, Check Point saw 16 percent of organizations hit by attempts in four days and about 37,000 attacks over a weekend, Sonatype found 81 percent of recent Spring downloads from Maven Central were vulnerable versions.
- Spring4Shell exploitation outcomes: web shells for backdoor access and Mirai botnet downloads (Trend Micro, activity noted around Singapore); Cisco confirmed three affected products (Crosswork Optimization Engine, Crosswork Zero Touch Provisioning, Edge Intelligence) and VMware three Tanzu products.
- Root cause: the 2010 fix blocked access from a class to its classLoader; the new bug jumped from the class to the module instead, a possibility opened by JDK 9; one workaround is to run on JDK 8 if compatible; comparison to the Equifax Struts breach.
- Linux malware targeting rose 35 percent in 2021 according to CrowdStrike, and Mirai variants keep spreading via new Java and web flaws.
