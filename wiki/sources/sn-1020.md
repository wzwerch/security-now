# Summary

Steve covers a batch of April 2025 stories before the main topic. Microsoft's research team flagged Canon printer driver flaws (CVSS 9.4) that also matter for bring-your-own-vulnerable-driver attacks because the drivers are Microsoft-signed. He praises Fisher and Paykel's public IoT security page as an exemplary vendor stance, notes that only about 8 percent of 2.5 million French students clicked a phishing-test lure, and warns that the WordPress "must-use plugins" folder is being used by attackers to hide malware. BleepingComputer's reporting contradicts Oracle's denial of a cloud login breach, and Oracle Health also reportedly lost patient data without public disclosure. Utah's governor signed the App Store Accountability Act, AI crawlers are swamping open-source infrastructure, Microsoft removed the bypassnro script for local-account setup in a Windows 11 preview, and Gmail's new "end-to-end" encryption for business users is really client-side encryption with organisation-held keys. A CVSS 10 deserialization bug was fixed in Apache Parquet. After wide listener feedback (Microsoft per-core licensing pushing firms to Linux, DISA STIGs, 2FA re-prompts for sensitive actions), the main topic explains why Certificate Authorities must now validate domain control from several network vantage points to defeat BGP hijacking.

# Key points

- Canon printer drivers (reported by Microsoft MORSE): memory corruption during EMF recode processing, CVSS 9.4, no privileges or user interaction needed. Because the drivers are signed they are usable for BYOVD; Canon promised updated drivers. Expect blocklisting once replacements ship.
- Fisher and Paykel (a Haier subsidiary) publish "security by design/default/defense in depth", WPA3 by default, UL IoT Gold rating, penetration testing, PGP-capable security contact and advice to put IoT devices on a separate network.
- France's test: of 2.5 million students 210,000 clicked a fake game-cheats link, roughly one in 12 and far below the one-third seen in corporate tests.
- WordPress mu-plugins (wp-content/mu-plugins): files there run automatically on every site, are not listed normally and cannot be disabled in admin; Sucuri reports attackers using it since February 2025 for web shells, SEO spam and redirects, and many scanners skip the folder. Advice: delete the folder if unused.
- Oracle: a hacker (rose87168) claimed theft of about six million authentication records from Oracle Cloud single sign-on servers; BleepingComputer verified samples with affected companies and found the login server had run vulnerable Fusion Middleware 11g (CVE-2021-35587). Oracle denies any breach, and has filed no SEC 8-K for either that or the separate Oracle Health breach used to extort providers.
- Utah's SB 142 takes effect on 6 May 2026; states such as South Carolina and California are considering copies. Open question: treatment of already-installed apps. Steve prefers the Apple/Google style design where apps get only age signals.
- AI crawlers: open-source sites report up to 97 percent of traffic from AI bots that ignore robots.txt, spoof user agents and rotate residential IPs. Responses include Xe Iaso's Anubis proof-of-work challenge, blocking whole countries, the Nepenthes tarpit and Cloudflare's AI Labyrinth; Cloudflare sees over 50 billion AI-crawler requests a day.
- Windows 11 Dev build removes bypassnro.cmd, pushing users toward Internet connectivity and a Microsoft account during setup; Leo notes workarounds remain.
- Gmail client-side encryption (CSE): the browser encrypts a message with an ephemeral key fetched from a customer-run key access control list (KACL) server, and the recipient authenticates via an identity provider. It avoids S/MIME complexity and meets regulatory language, but organisation admins hold the keys, so it is not true end-to-end encryption. Steve repeats that decrypting in a browser is a large attack surface.
- Apache Parquet CVE-2025-30065 (CVSS 10): deserialization of untrusted data in versions up to 1.15.0 enabling remote code execution via crafted files; fixed in 1.15.1, found by AWS, no known exploitation yet.
- Listeners: Microsoft moving server and SQL licensing to per-core prompts firms to migrate to open source; DISA STIG checklists (STIG Viewer) are valuable hardening guides; request fresh OTP codes for sensitive actions; Bitvise recommended as an SSH client/server for Windows; the password-guessing odds for a six-digit code (about 693,000 guesses for 50 percent).
- MPIC main topic: Chrome-led CA/Browser Forum ballot SC-067 requires CAs to verify domain control from multiple network perspectives to defeat BGP prefix hijacks that fool single-vantage validation (a Princeton-documented attack with about 2 million USD in losses). From 15 March 2025 at least two remote perspectives; three by 2026 (with two Regional Internet Registry regions), four by June 2026 and five by December 2026. Steve explains best-effort packet routing, BGP route advertisement and the HTTP file-based domain validation model.
