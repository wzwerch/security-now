# Summary

The first episode of 2024 opens with SpinRite 6.1 still being polished (a Western Digital drive returning a bogus status byte made SpinRite stall near the end of a scan). Listener items include a reporting tool that lists which browser root certificates have actually been used, a note that DNS Benchmark triggers obscure antivirus detections because of its network behaviour, Nebula Mesh as a fully open-source overlay network, Edge staying resident after closing, and Steve's plan to build an email system and then start SpinRite 7 with native USB support. The rest of the show covers Kaspersky's 37C3 presentation of Operation Triangulation, a multi-year zero-click iMessage attack campaign against iPhones (up to iOS 16.2) that chained four zero-days. Steve concentrates on CVE-2023-38606: the attackers wrote to undocumented memory-mapped hardware registers near the GPU coprocessor, authenticated by a 20-bit custom hash based on a secret lookup table, to bypass Apple's Page Protection Layer. The feature existed across A12 to A16 chips, was referenced nowhere in firmware, and was mitigated in iOS 16.6 by denying those address ranges. Steve argues this is a deliberately designed and protected backdoor rather than "security through obscurity", asks why Apple built it, and warns that successor chips may carry similar mechanisms.

# Key points

- Operation Triangulation: named for a WebGL canvas fingerprint (a triangle) used to profile victims; it infected Kaspersky researchers' iPhones, which led to the multi-year investigation. Kaspersky has reported 30+ in-the-wild zero-days in Adobe, Apple, Google and Microsoft products.
- Attack chain at a high level: a malicious iMessage attachment exploited a flaw in an undocumented Apple-only TrueType instruction (CVE-2023-41990), then privilege-escalation in JavaScriptCore, a memory-mapping integer overflow (CVE-2023-32434) giving physical-memory access, the hardware bypass (CVE-2023-38606), and later a Safari stage (CVE-2023-32435) and kernel exploit before spyware was loaded and traces removed. Kaspersky called it the most sophisticated chain they had seen.
- Apple's Page Protection Layer (PPL) is meant to keep user code locked after signature verification, even with a compromised kernel; the hardware feature allowed writes that bypass it.
- Memory-mapped I/O explainer: peripherals appear in the same address space as RAM; in a huge sparse 64-bit map, undocumented registers cannot be found by scanning. The undocumented ranges were missing from Apple's device tree and surrounded the GPU coprocessor; each chip family (A12 to A16) needed its own unlock value, but the same secret table was used.
- The 20-bit hash used a 256-entry substitution table that Kaspersky only obtained from the malware. Steve's reasoning: knowledge of it must have come from whoever built the feature; it is not discoverable, so calling it obscurity is wrong; debugging features do not hash-sign DMA writes; and Apple's fix simply marks the ranges as denied.
- Mitigation: iOS 16.6 and later unmap access to those ranges at boot; users should keep devices updated. Leo and Steve speculate about possible government-compelled access (for example a National Security Letter) but state this is unproven; Steve prefers the simplest reading that Apple designed it and that its secret escaped. Unknowns: who the attackers were, whether other ARM silicon has similar features, and whether newer chips contain equivalents.
- Root-store tooling: a community "certutil"-style Qt/C++ tool parses browser history to show which root CAs were actually used (reporting only, Windows 7 compatible); manual removal is possible via the Windows MMC certificates snap-in. Seven CAs cover about 99.96 percent of unexpired certificates.
- DNS Benchmark (about 8.8 million downloads, 4,000 per day) is flagged by a few obscure engines on VirusTotal because its behaviour resembles a DNS flooder; its code has not changed in about five years and is signed.
- Nebula Mesh (from Slack, 2019): fully open-source, mutually authenticated peer-to-peer overlay network written in Go, in contrast to partly closed Tailscale.
- Microsoft Edge keeps background processes running after closing, probably for faster start.

# Other segments

- Picture of the Week: an improvised EU-to-US power adapter built from forceps, a padlock and keys.
- SpinRite 6.1 is days away; SpinRite 7 will target RTOS-32 for native USB; GRC will build a PHP-based email system first. Steve notes he has misspelled Kaspersky's pronunciation for years.
- A listener solved the Schrodinger's Bowls puzzle by breaking the cheaper top pane.
