# Summary

Steve opens with the US Federal Trade Commission's lawsuit against D-Link for marketing routers and IP cameras as secure while shipping hard-coded credentials, command-injection flaws, an exposed firmware-signing key and clear-text stored app credentials; he sees it as the start of consumer-protection enforcement over insecure IoT. Light items follow: a TV broadcast that triggered viewers' Echo devices, Google's forthcoming "invisible" reCAPTCHA that removes even the checkbox, and a caveat that the earlier "long passwords are enough" argument holds only for truly random passwords stored with slow hashing. He introduces the OMEMO end-to-end encryption extension for XMPP chat, warns about malware bundled with pirated or unofficial downloads (including a Windows 10 ISO with a delayed ransomware task and fake copies of GRC's DNS Benchmark), and explains why Cox emails some Benchmark users about a supposed botnet. The main segment examines the government's Russian hacking disclosure: the list of 876 IP addresses was full of false positives (Yahoo mail servers, many Tor exit nodes), which explains the Vermont utility scare, while a PHP web shell it named is a generic freely available tool. Steve concludes that independent security-industry research already attributed the underlying activity to two long-tracked Russian groups.

# Key points

- FTC v. D-Link: complaint alleges failure to protect against well-known web flaws, hard-coded credentials and backdoors, mishandling of the code-signing private key (published on a public site for about six months), and plain-text storage of mobile app credentials, contradicting marketing about strong security. D-Link said the claims were baseless. Steve expects such enforcement to reshape the market.
- Echo ordering: a child's request caused a dollhouse purchase and a TV anchor's remark reportedly triggered Echo devices across a city; Leo notes a purchase PIN is on by default and that orders may only have been added to lists. Wake words are limited to a few firmware-tuned choices.
- Invisible reCAPTCHA (beta): a page can bind the check to its own button or run it automatically on load, using Google's accumulated knowledge of the user; Steve notes it also acts as a tracking signal.
- Password caveat: a post demonstrated Hashcat combination and hybrid attacks cracking human-chosen 12-plus character passwords made of common words in minutes to hours, so length helps only when passwords are generated randomly, and servers must use a slow password-based key derivation function. Password length limits on a site may hint that plaintext is being stored.
- XMPP (Jabber) gained OMEMO, an extension adapting the Signal-style double ratchet for end-to-end encryption and group chat without server changes; clients include Conversations, ChatSecure and Pidgin. Leo laments Google abandoning XMPP.
- Unofficial downloads: a torrent of Windows 10 installation media was found with a scheduled task that fetches ransomware after 90 days; counterfeit builds of popular tools circulate.
- Cox warning emails: some ISP customers who run GRC's DNS Benchmark get notices of a Zeus bot infection because many parallel DNS queries resemble reflection traffic; Steve views the proactive scanning as positive though this is a false positive.
- Apple ATS follow-up: ATS requires ECDHE cipher suites, which some sites do not offer, so Steve calls the mandate aggressive.
- Norway began switching off FM radio in favour of DAB.
- RAID anecdote: a listener found SpinRite's exercise of new drives stopped a RAID array repeatedly going critical, likely because slow sector handling exceeded the controller's timeout.
- Government Russia report: DHS and FBI circulated 876 IP addresses as indicators; a security firm found thousands of hits against clean traffic, including Yahoo mail servers and Tor exit nodes. The Vermont alert was an employee checking Yahoo mail. Reporter Kevin Poulsen noted that long-tracked groups known as Fancy Bear (APT28) and the Dukes (APT29) already have thorough public technical profiles and are widely assessed to serve Russian state interests.
- PAS web shell: the cited PHP malware is an encrypted, password-protected PHP blob giving a file browser, database client, port scanner, brute-force tools, command line and server info page; it is freely downloadable and there is no known specific infection path.
- Steve explains server-side scripting (native extensions, client scripts, interpreted PHP) and why unfiltered content that reaches the PHP interpreter is dangerous.
