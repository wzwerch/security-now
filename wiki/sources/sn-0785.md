# Summary

Recorded from an alternate location after a local cable outage, this episode opens with a Firefox for Android fix: a researcher found that the browser's SSDP-based LAN discovery could be fed a crafted XML file whose embedded Android intents were executed with no user interaction, fixed in Firefox 79. Mozilla also confirmed that Firefox Send and Notes are gone for good, after Send had been pulled over malware abuse and staff were cut in a 250-person layoff. Steve then profiles DuckDuckGo, whose August 2020 numbers (2 billion searches) show rapid growth, and explains its no-tracking, no-filter-bubble model. The big security story is Zerologon: Secura disclosed a CVSS 10.0 Netlogon flaw patched in August, public exploits followed within hours, and CISA issued Emergency Directive 20-04 forcing federal agencies to patch domain controllers. Steve then reviews privacy gains in Android 11 and iOS 14. After errata and GRC news, the main topic argues that complex protocols need formal verification, illustrated by BLESA, a Bluetooth Low Energy reconnection weakness found by Purdue researchers using a formal model.

# Key points

- Firefox for Android (before 79) acted on Android intent URIs embedded in XML returned by LAN devices found via SSDP, letting an attacker on the same WiFi trigger app launches; the discoverer was Chris Moberly and Mozilla responded quickly. Advice: be on version 79 or later.
- Mozilla shut down Firefox Send and Notes permanently; Send had been abused by malware groups to host encrypted payloads under a trusted Firefox domain. Steve returns to Filemail for file transfer.
- DuckDuckGo reported 2 billion searches in August 2020 and an estimated 65 million users; it offers direct answers, takes results from partners such as Bing, and keeps no search history or IP, so everyone sees the same results.
- Zerologon (CVE-2020-1472): a flaw in the Netlogon Remote Protocol lets an unauthenticated attacker with network reach to a domain controller impersonate machines and reset the domain controller password, giving full Active Directory takeover. Root cause was a missing requirement for unique initialization vectors in the AES-CFB8 implementation.
- Secura withheld its exploit for six weeks, but reverse engineering of the patch and at least three public exploit scripts followed quickly.
- CISA Emergency Directive 20-04 required federal domain controllers to be patched by the end of 21 September 2020, citing exploit availability and that many were still unpatched after 30+ days.
- Microsoft's fix is two-stage: August update plus logging of non-Windows devices using insecure RPC, then enforced secure RPC at the February 2021 Patch Tuesday; admins can set exceptions but are urged not to.
- Android 11: one-time permissions, auto-revocation for unused apps, separate background-location permission with developer justification, and security updates delivered as modules through the Play Store.
- iOS 14: local-network access restricted per app by default, a per-network private WiFi MAC address, approximate location option, clipboard-access notifications (with an API to inspect clipboard type without triggering them), Safari breached-password checks and a tracker privacy report, and an orange recording-indicator dot.
- Steve ties these to the principle of minimum necessary permissions.
- BLESA: the Bluetooth Low Energy spec makes authentication on reconnection optional and lets it be bypassed if the client does not enforce it. BlueZ (Linux), Android's Fluoride stack and iOS were affected; Windows was not. Apple fixed it under CVE-2020-9770; the Android test device was still vulnerable and BlueZ planned to drop the weak code path.
- The finding came from a formal, automated model of the reconnection procedure; Steve argues protocols should be formally verified before publication, while noting that full automation becomes very hard as complexity grows.

# Other segments

- Errata: SMR (shingled magnetic recording) hard drives can legitimately use TRIM, correcting an earlier remark.
- Listener feedback: InitDisk revived a supposedly dead 2TB SSD.
- GRC news: new forum system running with SQRL login; the benchmark tool is named ReadSpeed, with pre-release testing in the newsgroup first.
- Aside: Steve's first offsite emergency recording in 15 years; TuneIn dropped non-UK shows in the UK; holiday best-of episode planned.
