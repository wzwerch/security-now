# Summary

The episode begins with the 555 timer chip nostalgia and then a heavy news load. The Badlock flaw disclosed that morning turned out to be modest: a possible denial of service on exposed SMB servers and a man-in-the-middle authentication downgrade that Microsoft rated important. A discussion draft of the Burr-Feinstein bill would compel any covered entity to provide data in intelligible form on court order, with an extremely broad definition of entity and of government; Steve frames this as a policy question (he coins "Decryption On Demand") separate from whether the technology can be built securely, and notes Hungary proposing to criminalise encrypted apps. The FBI director said the government bought an iPhone unlock tool from a private party that works only on a narrow slice of older phones. A paper showed Firefox extensions share one JavaScript namespace so that nine of the ten most popular add-ons could be abused through another malicious add-on. WordPress.com enabled HTTPS for all hosted blogs through Let's Encrypt. Researchers found remote code execution in a white-labelled CCTV DVR sold under dozens of brands and a different unit sold on Amazon with a malware iframe in its web page. The new Petya ransomware encrypts the NTFS master file table but had a weakness that allowed free key recovery, while ransomware payments in 2015 were about 24 million dollars. Britain's GCHQ stopped a smart-meter plan that used one key for 53 million meters. The main segment explains the Signal protocol that WhatsApp finished integrating.

# Key points

- Badlock: remote DoS on exposed SMB plus a man-in-the-middle downgrade of authentication channels (Microsoft: important); Steve says it is worth patching but not an emergency; the heavily marketed name and logo were modelled on Heartbleed.
- Burr-Feinstein draft: covers essentially any person providing a product or method for communication, storage or processing; requires provision of data in intelligible form to a government (including state and local) under court order; the draft does not mandate a method. Steve emphasises it compels loss of privacy rather than mandating weakened cryptography.
- Hungary proposed jail terms for using encrypted communication apps and obligations on providers to give access.
- FBI Director said the tool was bought from a private party, works on a narrow slice of phones excluding the iPhone 5s and later, and that the FBI might tell Apple how it worked; reporting suggests the missing Secure Enclave on the iPhone 5c is key.
- Firefox CrossFire research: all extensions share one JavaScript namespace, so a harmless-looking add-on can invoke or alter others; Adblock Plus resisted, but others including NoScript showed issues; Mozilla acknowledged the problem. Steve argues Firefox needs a rearchitecture.
- WordPress.com enabled automatic HTTPS for all its hosted domains using Let's Encrypt.
- CCTV: one DVR family (rebranded from a Chinese maker under about 70 names, with tens of thousands exposed on the internet) has a remote code execution flaw; a camera kit sold via Amazon contained a hidden iframe pointing to a malware domain. Advice: limit exposure by IP and treat IoT cameras as hostile.
- Petya: encrypts the NTFS master file table and boot record and shows a skull screen; its key derivation had a flaw so a free tool can recover the key; Steve warns the window will close.
- Ransomware numbers from DOJ and DHS: about 7,700 complaints since 2005 with 57.6 million dollars of damages; 24 million dollars paid in 2015. Adobe patched a Flash zero-day exploited against Windows 10.
- UK smart meters: GCHQ stepped in when plans proposed one decryption key for all 53 million meters; Steve repeats that complexity is the enemy of security.
- Signal protocol in WhatsApp: provides confidentiality, integrity, optional authentication, forward and backward secrecy (via key ratcheting), message unlinkability, deniability (the recipient could forge messages) and asynchronous operation. Uses Curve25519, triple Diffie-Hellman key agreement, a hash ratchet, and a server-stored pool of one-time pre-keys so the first message can be secure.
- The weak point is authenticating the peer: users must compare the 60-digit conversation code or QR code once, and must manually enable the setting that warns when a contact's security code changes. WhatsApp itself is closed source (though Android builds were shown reproducible), so you still trust the vendor; Steve says no real-world system gives absolute security and praises the design as industry-standard quality with open-source libraries.

# Other segments

- Steve moved his domain registrations to Hover after listener advice.
- Never10 v1.3 added detection and one-click deletion of a pre-downloaded upgrade payload of several gigabytes plus command-line switches; downloads passed 150,000.
- The Seriphos supplement used in the Healthy Sleep Formula sold out and Steve was working on a four-ingredient version.
- A Guardian long read on sugar and nutrition history, Peter Hamilton's new novel, a SpinRite recovery tweet, the James Gosling interview and PDP-8 talk.
