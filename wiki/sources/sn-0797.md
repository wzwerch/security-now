# Summary

A packed pre-holiday episode. Chrome 87 includes an optional Heavy Ad Intervention that blocks resource-hogging ads. Microsoft described Adrozek, a multi-browser malware that injects ads into search results and steals saved browser credentials, compromising 30,000+ PCs daily. "Double extortion" enters ransomware vocabulary. December Patch Tuesday fixed 58 flaws including 22 remote code execution bugs, while Microsoft declined to assign a CVE to a wormable zero-click Teams flaw because the product auto-updates. Cisco Jabber's earlier patch left three vulnerabilities, D-Link DSR VPN routers had unauthenticated command injection, and Forescout's Amnesia:33 uncovered 33 flaws in four open-source embedded TCP/IP stacks. A WordPress Easy WP SMTP flaw let attackers read password-reset emails from an exposed debug log. The Pwnie Awards, Flash's final release with a kill switch, and free JavaScript courses are covered briefly. The main topic is the SolarWinds compromise: FireEye disclosed its own breach and Red Team tool theft, then traced it to trojanized SolarWinds Orion updates (Sunburst) signed from March 2020, affecting about 18,000 customers, with Russian state involvement widely reported.

# Key points

- Chrome Heavy Ad Intervention (chrome://flags), with a privacy-mitigation setting that randomizes who gets it so the behavior cannot be used as a tracking bit.
- Adrozek adds extensions, patches browser DLLs, disables updates and installs a service for persistence; it harvests stored credentials from browsers.
- Double extortion: encrypt data and threaten to publish it (term attributed to Check Point).
- Patch Tuesday: 58 fixes, 9 critical RCE, Exchange and SharePoint among them, a Hyper-V SMB-packet flaw; none zero-days.
- Microsoft Teams: zero-click wormable chat-message RCE reported by Oskars Vegeris; fixed in October. Microsoft stated it does not issue CVEs for products that update automatically, which Steve criticizes as redefining vulnerabilities.
- Cisco Jabber (12.1-12.9): Watchcom found the September fixes only blocked specific injection points; new XSS-to-RCE via the Chromium Embedded Framework, NTLM hash leak via image tags, and command-line-flag injection through protocol handlers.
- D-Link DSR-150/250/500/1000AC VPN routers: Lua CGI interface lets unauthenticated users inject commands as root over WAN; patches exist, exposure is high. Advice: turn off WAN administration.
- Google had a roughly 45-minute authentication outage (internal storage quota issue), not an attack.
- Amnesia:33 (Forescout, presented at Black Hat Europe): 33 flaws in uIP/Micro IP, FNET, picoTCP and Nut/Net, with several 9.8-rated RCE bugs, affecting devices from about 158 vendors. Steve's takeaway: assume IoT is compromised and keep it on an isolated network.
- Easy WP SMTP (500,000+ sites): debug log with a random filename was reachable where directory listing was enabled, letting attackers harvest admin password-reset links; Steve restricts WordPress admin pages by source IP.
- Pwnie Awards highlights: BraveStarr (server bug), Samsung MMS zero-click (client bug), checkm8 (privilege escalation), Zerologon (crypto attack), TRRespass (innovation), CurveBall (epic fail for Microsoft).
- Flash: Adobe's final release includes a kill switch active in January 2021; major browsers remove it.
- SolarWinds: FireEye (CEO Kevin Mandia) revealed a nation-state breach on December 8 in which Red Team tools were stolen (with over 300 countermeasures released), then on December 13 tied it to trojanized Orion updates. The backdoor (Sunburst) lives in a signed Orion DLL, sleeps up to two weeks, mimics Orion Improvement Program traffic, uses DNS CNAME responses to find command servers, and avoids security tools. FireEye tracked the actor as UNC2452; signed trojanized updates date from late March through May 2020; SolarWinds said 18,000 of about 33,000 Orion customers installed them. Confirmed victims include DHS, Treasury and NTIA; reporting pointed to the Russian foreign intelligence service, which Russia denied. Orion holds many privileged credentials, so affected environments must treat them as compromised. Attackers appeared to target only high-value victims.
