# Summary

Steve opens with the Marvell Avastar 88W8897 WiFi chipset, used in game consoles, Surface laptops, Chromebooks and more, where fuzzing by Embedi's Denis Selianin found four bugs, two critical, allowing zero-click code execution over the air; fixing billions of devices is unlikely. The March Pwn2Own will for the first time target a Tesla Model 3 with prizes up to 250,000 dollars per major system, alongside virtualization, browser and RDP categories. Russia's regulator continues ineffective blocking and has started proceedings against Facebook and Twitter over data-localization law. Trend Micro found Anubis banking malware in two Play Store apps using motion sensors to detect analysis sandboxes. Google is restricting apps that request SMS and call-log permissions, pushing narrower APIs. Tim Cook's Time essay urged federal privacy law and an FTC registry of data brokers; Leo notes Apple's own incentives. A Facebook page lists the ad preferences and settings users can curb. Cisco small-business switches ship with an unannounced default privileged account (no patch yet; creating a level-15 account disables it). The main topic: research found many of the top free Android VPN apps leak DNS, request risky permissions or contain suspicious code; Steve recommends the open-source OpenVPN for Android client and then choosing a trusted OpenVPN server or service.

# Key points

- Marvell chip bug: reachable within WiFi range without credentials, can access system memory via DMA, details withheld; demo shown at a conference; vendor patching uncertain; affected products include PS4, Xbox One, Surface and Samsung Chromebooks.
- Pwn2Own 2019 adds Tesla Model 3 (gateway, autopilot and security controller, key fob, CAN bus, infotainment, WiFi/Bluetooth) with up to 900,000 dollars total; virtualization escapes, browsers and RDP also offered.
- Russia's Roskomnadzor previously caused collateral blocking trying to ban Telegram; now pursuing Facebook and Twitter; the internet routes around such blocking.
- Anubis targets 377 banking and other apps in 93 countries, posed as a currency converter and battery saver, and disguised its permission request as a system update.
- Google Play policy: SMS and call-log access only with a permissions declaration; alternatives like SMS Retriever; review criteria include user understanding and narrower alternatives.
- Tim Cook's four principles: data minimization, knowledge, access, and security, plus a data-broker clearinghouse run by the FTC.
- Facebook ad preferences page shows interests, advertisers and partner-data settings.
- Cisco 200, 250, 300, 350, 500 series small-business switches: a hidden default admin account stays enabled unless another level-15 user is created; critical severity score.
- Errata: expired certificate click-through still encrypts but loses authenticity; Steve's upstream speed is megabits, not gigabits.
- SpinRite machine advice: any old computer works, connect the drive directly to the motherboard; Java installer offering to uninstall unused Java is legitimate.
- VPN apps study: one in five of top 150 free Android VPNs flagged as potential malware, a quarter leak DNS, 57 percent request last known location; recommended: OpenVPN for Android plus a server such as pfSense or a reputable service; DNS must be routed through the tunnel.
