# Summary

Steve starts with a critical (CVSS 9.8) flaw, CVE-2021-3064, in Palo Alto Networks GlobalProtect VPN firewalls found by Randori; about 10,000 internet-exposed appliances are affected until PAN-OS 8.1.17 is installed. 0patch released a free micropatch for the Windows User Profile Service privilege-escalation bug that Microsoft failed to fix for four months, which leads Steve to explain race conditions and muse on the craft of finding the "best" solution when coding. He reviews November Patch Tuesday (55 flaws, two exploited zero-days in Exchange and Excel, a Kerberos regression fixed out of band) and Windows 11 fixes, with printing fixes promised for December. Ransomware enforcement news continues with the arrest of a crypto-exchange operator linked to Ryuk laundering and the 10-year sentence for the Methbot ad-fraud operator. Listener feedback touches Iomega Zip tools, Unix history and Unicode warnings in editors; SpinRite 6.1 nears its sixth development release. The main story is Blacksmith from ETH Zurich's COMSEC group: a fuzzer-found family of non-uniform Rowhammer access patterns that flips bits on all 40 tested DDR4 modules despite Target Row Refresh.

# Key points

- Palo Alto Networks PAN-OS 8.1 GlobalProtect portal/gateway bug CVE-2021-3064 (found by Randori, 9.8 severity) allows unauthenticated remote code execution via an HTTP request smuggling chain; patched in 8.1.17, about 10,000 devices exposed, details withheld for 30 days. Steve uses it to argue for autonomous updates on network devices.
- Microsoft's August fix for the User Profile Service bug (CVE-2021-34484) only blocked the original proof of concept; a variant remained unpatched through November, so 0patch issued a 23-byte micropatch free of charge for Windows 10 systems.
- Race conditions explained: bugs that depend on the timing of two actors (a ripple-counter sampling analogy, shared list manipulation) are rare, hard to reproduce and fixed with critical sections or avoiding shared mutable state. Leo adds that functional programming avoids side effects.
- Patch Tuesday (9 November): 55 CVEs (six critical), exploited zero-days in Exchange and Excel, four publicly disclosed ones (two RDP information disclosures, two 3D Viewer RCEs); 20 elevation-of-privilege, 15 RCE. Domain-controller Kerberos delegation (S4U2Self) failures were fixed by an out-of-band update.
- Windows 11 update KB5007215 (build 22000.318) fixes the expired-certificate app failures; Insider build 22000.346 fixes IPP-over-USB printer installs and the remote-printing errors, expected for December Patch Tuesday.
- Dutch police detained Russian exchange founder Denis Dubnikov on an FBI request for laundering about $400,000 of Ryuk ransom proceeds in 2018; Steve sees growing fear among those whose old blockchain trails can be traced.
- Aleksandr Zhukov ("3ve"/Methbot) was sentenced to ten years for an ad-fraud botnet and fake-site network that reached $3-5 million per day at its 2016 peak, hosted on more than 2,000 rented servers with leased or hijacked IP space.
- Blacksmith (CVE-2021-42114, paper "Scalable Rowhammering in the Frequency Domain"): non-uniform, frequency-based access patterns found by a black-box fuzzer bypassed Target Row Refresh on all 40 tested DDR4 DIMMs from the major vendors, with practical impact demonstrated against page table entries, an RSA key and sudo authentication logic. ECC and doubled refresh rates only help partially, and shipped DRAM cannot be patched. Code is on GitHub and an FPGA test platform is planned with Google.
- Steve recaps the Rowhammer lineage (SMASH, Drammer, Flip Feng Shui, Throwhammer) and notes MemTest86+ is still useful for memory testing.

# Other segments

- Picture of the Week: installing Windows 11 from 3,852 floppy disks; Steve shows his original Windows 1 disks.
- Listener feedback: a Mac collector reimplementing the old Trouble in Paradise Zip-drive tool; a professor assigned the IRQ segment to a computer architecture class; a retired Bell Labs patent attorney recalls filing the Unix set-user-ID and file-system patents; VS Code now renders hidden Unicode directional characters (follow-up to Trojan Source).
- SpinRite: drive-selection screen now shows estimated scan time; a SATA SSD reaches 573 MB/s, about 95.5% of the SATA 3 limit; a PDF preview is at grc.sc/845; the "poly-IRQ" workaround is in the next development release.
- Reflection on why coding is satisfying and why redoing a solution after learning the problem often yields a better one.
