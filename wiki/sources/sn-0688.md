# Summary

The episode begins with Armis's BleedingBit findings: two critical flaws in Texas Instruments Bluetooth Low Energy chips used in enterprise Wi-Fi access points from Cisco, Meraki and Aruba. One is a memory overflow reachable via crafted advertising packets (CVE-2018-16986); the other is a leftover over-the-air firmware download feature protected only by a shared hardcoded password on Aruba 300-series units. Google now requires JavaScript on its sign-in page so it can run a risk assessment, and Steve recommends running the Google Security Checkup. A claimed Edge zero-day with sandbox escape is noted, with Zerodium paying large sums for such bugs. Microsoft has made Windows Defender able to run sandboxed, which Steve and Leo enabled and argue makes third-party antivirus unnecessary. Microsoft is porting Sysinternals tools to Linux. Google's reCAPTCHA v3 replaces challenges with a background score, at a privacy trade-off. The Morris Worm turns 30. A ransomware demanding remote desktop access to "decrypt" is discussed. The main topic is PortSmash, a timing side channel across SMT/Hyper-Threading threads that stole an OpenSSL key in a proof of concept; Steve thinks scheduler changes and BIOS options make this manageable.

# Key points

- BleedingBit: TI BLE chip overflow bug and an OAD (over-the-air download) backdoor can let a nearby attacker take over access points and bypass network segmentation; advice is to disable Bluetooth on the APs and update firmware.
- Google sign-in now needs JavaScript (about 0.1% of users had it off); new account-recovery flow and Security Checkup that flags unused devices and third-party app access.
- Yushi Liang claimed an Edge sandbox-escape zero-day; Pwn2Own Mobile in Tokyo offers over half a million dollars in prizes; Zerodium pays around 50,000 dollars for an Edge zero-day, double with sandbox escape.
- Windows Defender sandboxing (available from Windows 10 1703) can be enabled via a machine-wide environment variable and verified in Process Explorer by the MsMpEngCP child process; Tavis Ormandy called it game-changing.
- Microsoft is porting Sysinternals tools to Linux, starting with ProcDump.
- reCAPTCHA v3 returns a risk score without user interaction and wants to be deployed on many pages, giving Google broad visibility.
- Morris Worm: released November 2, 1988, infected about 6,000 of roughly 60,000 hosts, used sendmail, fingerd and rsh/rexec plus weak-password guessing; led to the creation of CERT/CC.
- CommonRansom demands victims' RDP address and admin credentials to decrypt; Steve and Leo advise against; recovering data only by mounting the drive elsewhere as a last resort.
- Apple T2 chip: hardware disconnect of the microphone when the lid closes.
- Listener follow-ups on the vending-machine design (one-way authentication needs a keyed MAC, so the machine still needs a secret).
- PortSmash: SMT port-contention timing allowed stealing an OpenSSL TLS key between threads on the same core; OpenSSL already mitigated; risk is mainly shared VM hosts; OSes can avoid co-scheduling different processes on one core, or admins can disable Hyper-Threading in BIOS.
- Intel says it is unrelated to speculative execution and probably not Intel-specific.
