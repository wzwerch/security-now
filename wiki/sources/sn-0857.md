# Summary

The episode opens with the FBI advice to Beijing 2022 Winter Olympics visitors: leave personal phones and laptops at home and use a cheap burner device, because mobile apps from untrusted vendors and fake networks are a standing threat at Olympic events. Steve then covers a CVSS 9.9 Samba flaw (CVE-2021-44142) in the vfs_fruit module, found at Pwn2Own Austin 2021, fixed in 4.13.17, 4.14.12 and 4.15.5; it allows unauthenticated root code execution only where that module is enabled. A Uptycs analysis of the five most abused "living off the land" binaries on Windows, Linux and macOS illustrates why attackers reuse built-in tools. Microsoft has disabled the ms-appinstaller (MSIX) remote install scheme after Emotet used it to deliver BazarLoader, and has announced that Office will outright block macros in files with the Mark of the Web starting with version 2203. Steve pre-announces a small freeware tool to stay on Windows 10 (later Never11 / a more generic successor). The main item is Citizen Lab's reverse engineering of MY2022, the mandatory Olympics app, which fails to validate TLS certificates for several backend servers, sends some message metadata in plaintext, ships an inactive 2,442-word censorship list and was not fixed after responsible disclosure; Steve concludes the app is inept rather than malicious, and still a risk to carry.

# Key points

- FBI/CISA advice for Beijing 2022: take a burner phone, avoid required apps on personal devices, disable Bluetooth and Wi-Fi when unneeded; previous Games (Pyeongchang Olympic Destroyer, Tokyo phishing and fake streaming sites) show the Olympics attract heavy attacks.
- Samba CVE-2021-44142 (CVSS 9.9): out-of-bounds heap read/write in vfs_fruit (Apple interoperability via extended file attributes); not exploitable if the module is not enabled; update or remove the module; Steve says SMB should never face the public Internet.
- LOLBins (Uptycs): Windows PowerShell, mshta, regsvr32, WMIC, Equation Editor; Linux chattr, wget, setfacl, crontab, rm; macOS openssl, curl, sqlite, killall, funzip. Benefit to attackers: trusted, already present, unlikely to trip allow-listing or alarms.
- Microsoft disabled the ms-appinstaller protocol for MSIX packages (CVE-2021-43890, patched in December 2021 but still abused) after Emotet used it for fake "PDF component" installs delivering BazarLoader/TrickBot; Steve doubts a safe remote-install model exists.
- Office macros from the Internet: from version 2203 (April 2022) Access, Excel, PowerPoint, Visio and Word block macros in files carrying the Mark of the Web with no "Enable" button; older Office versions to follow; a Group Policy for this already existed but was off by default.
- Steve's Never11 plan: Windows 11 hardware limits are arbitrary (VMs install it freely), and a Windows Update target-version setting (KB5005101) allows staying on Windows 10; he built a test release in under a day.
- Citizen Lab on MY2022 (iOS 2.0.0, Android 2.0.1): certificates for several backend hosts are not authenticated, so voice audio, file transfers and health-customs forms (passport, medical, travel data) can be intercepted or spoofed; some chat metadata goes unencrypted on a non-standard port.
- Responsible disclosure on 3 December 2021 with 15-day response and 45-day fix deadlines got no reply; Citizen Lab went public on 18 January 2022 and update 2.0.5 fixed nothing and added a new "Green Health Code" feature with the same flaw.
- The app includes an unused list of 2,442 politically sensitive keywords; privacy policy does not say who receives health data; the IOC defended the app by citing app-store approval and "closed-loop" COVID measures.
