# Summary

Patch Tuesday brings twelve Microsoft bundles including critical remote code execution fixes in browsers and a graphics component. The headline story is Tangible Security's report on Seagate (and LaCie-branded) wireless hard drives, whose firmware had an undocumented Telnet service with a root account and default password, unrestricted file download, and unrestricted upload; Seagate acknowledged the issues but took months to produce a fix. Steve then covers the ad-blocking landscape ahead of iOS 9: the Adblock Browser app and the recommended non-default settings, a false alarm about Chrome defeating ad blockers on YouTube (actually a bug from a security fix), and G Data's finding of preinstalled malware on third-party-distributed off-brand Android phones. He answers how SpinRite is tested (a built-in "thrasher" that writes deliberate correctable and uncorrectable errors). In Q&A, Steve explains how to invert uBlock Origin's default so ads are allowed except on blacklisted sites, comments on ad networks asking sites to proxy ad assets through their own domain, defends Lenovo's ThinkPad line, discusses what tracking is really worth, why hard drives use glass substrates, how caching interacts with ad counting, why he favors vendor-managed updates, combining Google Contributor with uBlock Origin, how encryption of the boot partition would stop the Lenovo trick, and how multiple blocking extensions combine.

# Key points

- **Patch Tuesday:** twelve bundles, five critical, including IE, Edge and a graphics component that touches Windows, Office and Lync; a Hyper-V security feature bypass.
- **Seagate Wireless Plus / LaCie Fuel:** hard-coded root Telnet credentials, forced browsing to download any file, and unrestricted file upload to the sharing volume; firmware from late 2014 affected; owners should update.
- **Adblock Browser (Eyeo):** mobile app available; in its settings Steve advises enabling tracking, malware domain and social button blocking while leaving the acceptable ads concept off; earlier in the year Google removed the Android app from its store.
- **PageFair:** vendor that measures revenue lost to blockers; its FAQ does not discuss tracking.
- **Chrome and YouTube ads:** apparent blocker evasion was a bug from a webRequest API security fix, not a deliberate exemption; extensions all must allow a request for it to load.
- **Preinstalled Android malware (G Data):** 75 percent increase in six months; dozens of off-brand models (and some Lenovo, Huawei, Xiaomi units via gray-market resellers) shipped with infected firmware that injects into Facebook and Google Drive apps; not the case for mainstream carrier channels.
- **Click-to-play feedback:** listeners confirm choosing to run plugins only on demand works well in Chrome and Firefox.
- **SpinRite testing:** historically scratching platters with a pin; today a build-time thrasher writes deterministic correctable and uncorrectable sectors.
- **uBlock Origin blacklist mode:** set the "all" row in the global column to allow, then restore per-site columns; documented in the project's wiki page on dynamic filtering. The author prefers not to offer this because he sees tracking as the hidden bulk of ad harm.
- **Ad-network proxying:** networks ask sites to configure reverse proxies so ads appear first-party; fine for images but dangerous if scripts are served first-party because it undermines same-origin protections.
- **Legal fights:** Apple resisted a subpoena for iMessage content because it lacks the keys; Microsoft fought a demand for email stored in Ireland.
- **Lenovo ThinkPads:** listener notes the Think line avoided Superfish and the BIOS injection; Leo says IBM oversight may have lapsed.
- **Tracking debate:** Steve distinguishes counting (acceptable) from cross-site tracking; Leo worries ad blockers make small sites invisible to analytics.
- **Glass platters:** glass or glass-ceramic is only a smooth substrate under a sputtered magnetic layer; it shatters; slamming a drive on concrete can pulverize glass platters.
- **Caching:** expiration headers, no-cache metadata and serial-numbered assets keep proxies from distorting ad counts.
- **Updates:** a Richard Stallman style objection to vendor-pushed updates; Steve maintains secure self-updating is the better default for Internet-connected devices.
- **Secure boot and encrypted partitions:** an encrypted boot partition would defeat the Lenovo file-replacement trick but not firmware-supplied executables via the Windows Platform Binary Table.
- **Extension combination:** ad-blocking extensions act as a logical AND; any one can block.
