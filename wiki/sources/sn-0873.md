# Summary

The episode begins with Dvuln's analysis of Australia's New South Wales Digital Driver's Licence app: stored licence data is AES-encrypted with a key derived directly from a four-digit PIN, with no signature, no server-side validation and inclusion in phone backups, so the displayed licence can be edited easily. Steve sketches a sound design based on a signed X.509 certificate chained to a trusted CA. Next is the "Follina" Microsoft Office zero-day, an abuse of the ms-msdt: URL handler that Microsoft's MSRC initially dismissed; a registry workaround and Defender signatures arrived later. Other items: the Ghost Touch research (electromagnetic interference injects fake touches from about 40 mm), and the TrustPiD pilot by Vodafone and Deutsche Telekom, a carrier-level persistent identifier that Steve finds technically puzzling and objectionable. After listener feedback on ad blockers, post-quantum worries for cryptocurrencies, BLE lock mitigations and stacked encryption, the main topic is the DuckDuckGo browser controversy: researcher Zach Edwards found that DuckDuckGo's mobile browsers did not block some Microsoft (Bing, LinkedIn) trackers because of a confidential search-syndication contract. Steve concludes the intent was benign but non-disclosure was the mistake.

# Key points

- NSW Digital Driver's Licence (launched 2019, about 3.9M users): AES-256-CBC with a 4-digit PIN as key and no key derivation, so brute force takes minutes; data editable, re-encrypted and shown; QR code holds only name and under-18 flag; data included in iPhone backups; reports of underage users using fake digital licences.
- Steve's proposed fix: licence as a CA-signed certificate (photo, dates, name) delivered with an intermediate chain from a trusted CA, with signed subset data in QR codes for offline checks.
- Follina (CVE assigned later): Word remote templates plus the ms-msdt: protocol gives code execution even with macros disabled; reported to MSRC on April 12 and closed April 21 as not a security issue. Affected Office 2013 to 2021 and Microsoft 365; Protected View can be bypassed via RTF/Explorer preview (Will Dormann). Workaround: delete the ms-msdt protocol handler registry key; Defender signatures updated.
- Origin of the bug: a 2020 bachelor's thesis described the MSDT protocol abuse; name "Follina" came from an area code in the sample file (Kevin Beaumont).
- Ghost Touch: first contactless attack on capacitive touchscreens via EMI injecting taps and swipes on nine phone models up to about 40 mm; academic for now.
- TrustPiD: Vodafone and Deutsche Telekom pilot a carrier-injected persistent token for ad personalization with consent via banners; Steve cannot see how it works with HTTPS and SNI without TLS interception and calls it a privacy monster to strangle early.
- Safari ad blocking: 1Blocker leaks ads according to Leo; Firefox Focus as a Safari extension seemed to block more.
- Cryptocurrencies are mainly threatened via public-key signatures, not hashes; stacking three 256-bit encryptions adds strength rather than multiplying it.
- A listener suggests requiring an in-app confirmation to defeat BLE relay attacks on smart locks, at a convenience cost.
- DuckDuckGo: the browser (not the search engine) allows Microsoft trackers to load because of a search-syndication agreement with Microsoft with a confidentiality clause; the app store text over-promised. DuckDuckGo said it would update descriptions and seek to remove the restriction. Steve and Leo note only Google and Microsoft maintain full web indexes.
