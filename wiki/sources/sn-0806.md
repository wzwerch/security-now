# Summary

Steve follows up on the Oldsmar water plant incident with details from a Massachusetts advisory: attackers reached the SCADA system through TeamViewer installed on 32-bit Windows 7 machines that shared one remote password and appeared to be directly exposed to the Internet; the plant operators caught the sodium hydroxide change before the SCADA software alarmed. Chris Krebs suggested a disgruntled insider. February's Patch Tuesday fixed 56 flaws including an exploited Win32k elevation of privilege, critical Windows Fax Service bugs, and two TCP/IP stack remote code execution flaws (IPv4 source routing and IPv6 reassembly) that Steve uses to argue for turning off unused features. Adobe Acrobat and Reader needed an update for an in-the-wild exploit. The SHAREit Android app (over a billion installs) had unaddressed flaws disclosed by Trend Micro. Microsoft reported web shells doubling to roughly 140,000 monthly encounters, and a Responsive Menu WordPress plugin flaw affected over 100,000 sites. Steve shows SpinRite 6.1's new animated device-discovery screen and its BIOS association challenges. The main segment covers COMB (Compilation of Many Breaches): over 3.2 billion unique plaintext email and password pairs, with Steve's advice to delete dormant accounts, use a password manager, and let stale credentials age out.

# Key points

- Oldsmar: attackers used TeamViewer on shared-password Windows 7 machines with no apparent firewall; attack occurred twice about five hours apart; advisory mitigations include restricting remote access, one-way monitoring, firewalls with logging, patching, 2FA, VPN. Krebs told Congress an insider was likely. COMB data contained 13 entries from the plant's domain, but Steve sees no link.
- Patch Tuesday (February 9, 2021): 56 CVEs, 11 critical, 6 publicly known; Zerologon enforcement phase now active; exploited Win32k privilege escalation rated only 7.8; critical .NET Core / Visual Studio flaw; two Windows Fax Service remote code execution bugs; critical TCP/IP flaws (IPv4 source routing, IPv6 packet reassembly, both CVSS 9.8); also bugs in Windows DNS server, print spooler and codecs. Advice: remove unneeded Windows features, disable source routing, and update.
- Adobe Acrobat/Reader (2017, 2020, DC) update needed for an exploit in the wild.
- SHAREit (about 1 billion Google Play downloads): Trend Micro found flaws that allow data leakage and arbitrary code execution through the app's permissions; the publisher did not respond within 90 days. Advice: uninstall if unused.
- Web shells: small server-side scripts (ASP, PHP, JSP) planted for persistence and hard to spot among legitimate files; Microsoft saw an average of 140,000 monthly encounters from August 2020 to January 2021, nearly double the prior year; attackers rapidly exploit newly disclosed bugs (example: F5 BIG-IP CVE-2020-5902 within days).
- Responsive Menu WordPress plugin (100,000+ sites): three flaws, including arbitrary file upload and CSRF, leading to remote code execution via uploaded zip archives; Wordfence found them. Steve's advice: restrict plugins and sandbox WordPress.
- SpinRite 6.1: new screen that animates PCI/drive enumeration replaced the blank "Discovering System's Mass Storage Devices" screen; BIOS-to-hardware association by boot-sector hashing is tricky when drives have identical boot sectors; a USB boot hang on an AMD Phenom board is under investigation; a 25-second demo video was published.
- COMB (Compilation of Many Breaches): published around February 2, 2021; more than 3.2 billion unique plaintext email/password pairs built on an earlier 1.4 billion breach compilation plus collections such as Collection #1-5; CyberNews offered a lookup. Steve's takeaways: abandoned accounts are a liability, review the password manager, delete accounts you no longer need, and use strong unique passwords.
