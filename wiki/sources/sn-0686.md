# Summary

Steve opens with Zimperium's findings in the FreeRTOS TCP/IP stack (and the AWS and Wittenstein variants): several critical remote-code-execution bugs plus information leaks and a denial of service, patched in AWS FreeRTOS 1.3.2. He praises Amazon's over-the-air-update approach. Next, a Polish researcher disclosed three chained flaws affecting eight D-Link routers sharing one firmware base; D-Link said it would fix only two models and had not, so Steve advises treating unsupported routers as expired and disabling WAN-side administration. Drupal 7 and 8 received five fixes, two critical remote-code-execution bugs, and the LIVE555 RTSP server also got a critical fix. The Windows 10 1809 saga continues with a zip-extraction overwrite bug, and Steve now defers updates via Windows 10 Pro. A long-standing unauthenticated file-upload hole in the very popular jQuery File Upload plugin, caused partly by Apache ignoring .htaccess since 2010, was exploited in the wild for years. A Sucuri story shows how a discontinued share-count service's abandoned AWS S3 bucket was re-registered by an attacker to push mobile scam redirects to 800+ sites. The main topic is the libssh authentication-bypass flaw (versions 0.6 and later), where a client could simply claim success. The episode ends with a puzzler about securing an offline vending machine wallet.

# Key points

- FreeRTOS is the most-used embedded RTOS (about 28% in a survey); its TCP/IP stack had four critical RCE bugs, one DoS and seven info leaks, fixed by Amazon and Wittenstein, with technical details held back 30 days.
- Amazon's OTA-update tooling around FreeRTOS is cited as the right model for IoT patching.
- Eight D-Link routers share firmware with a directory traversal, plaintext admin password storage and a shell-injection flaw; combined they give full takeover. D-Link ignored a disclosure timeline from May to October.
- Advice: retire routers the vendor will not patch; disable WAN-side admin; Mirai-style botnets will add this quickly.
- Drupal 7 and 8: five vulnerabilities (mail backend injection and a Contextual Links bug are critical); update to 7.6 / 8.6.2 / 8.5.8.
- LIVE555 media server before release 0.93 has a critical remote execution bug.
- Windows 10 1809 zip extraction could overwrite or silently skip files; Microsoft reported about 1,500 insider cases of deleted files; Steve now defers feature and security updates using Pro.
- jQuery File Upload (7,800+ forks) allows unauthenticated uploads of executable files, found by Akamai's Larry Cashdollar; exploited for roughly three years.
- Apache disabling .htaccess by default since 2.3.9 silently broke the plugin's protection assumption (tyranny of the default).
- Abandoned AWS S3 bucket for New Share Counts was re-registered by an attacker; 800+ sites loaded the malicious script that hijacked the mobile back button.
- libssh 0.6+ authentication bypass: a client sending the server-side success message is accepted; about 1,800-1,900 internet-facing servers vulnerable; several public PoCs and scanners exist.
- Users of libssh include Red Hat extras, F5 BIG-IP, KDE SFTP, X2Go, Remmina; GitHub's usage is protected.
- Steve keeps his SQRL forum PHP server isolated on a separate network.
- Leo argues for type-safe languages to avoid such bug classes.

# Other segments

- Picture of the Week: a password prompt warning not to reuse your bank password.
- SpinRite story: a listener revived an old SAS RAID 0 Active Directory server using DOS drivers; Steve will keep config.sys driver support in SpinRite 6.x.
- Puzzler: design an uncrackable offline vending-machine wallet (Argenta machines whose app balance was trivially forged).
