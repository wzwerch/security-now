# Summary

Steve opens with the early ARPANET map as Picture of the Week, then covers the US BOTS Act, which criminalises circumventing ticket-purchase limits while explicitly protecting security research. The ransomware item is Popcorn Time, which offers victims a second route to free their files: infect two other people who then pay, with a charity-style sob story and a threat of file deletion after wrong key guesses. A command-injection flaw in a broad range of recent Netgear routers was exploitable from the LAN side through a crafted link, with beta firmware appearing. Further stories: a Yahoo Mail cross-site scripting bug paid out as a bounty, ESET's discovery that ad malware hid its payload in image pixels for two years, uBlock Origin arriving on Microsoft Edge, the New York Times recommending Signal, Bitdefender's closed-box security appliance, and the pending audits of OpenVPN. A long Q&A follows on exposing a Raspberry Pi VPN server, username-then-password login pages, stealth ports on mesh routers, ShieldsUP results behind a VPN, local port scanning with nmap, and VPN workarounds for the UK surveillance law.

# Key points

- BOTS Act (Better Online Ticket Sales): bans bypassing technical controls on ticket sites for events above 200 seats and reselling tickets obtained that way; enforced by the FTC and states, with an exemption for security research. Steve hopes the research carve-out becomes standard.
- Popcorn Time ransomware: demands about one bitcoin or offers a referral scheme requiring two further paying victims; claims a humanitarian motive and reportedly deletes files after four wrong key entries. Steve calls it social-engineering multilevel marketing.
- Netgear routers (many Nighthawk and R-series models): the web interface let a crafted URL run commands as root, so a malicious link followed from inside the LAN could open remote administration. Netgear had beta firmware for several models; CERT issued an advisory; a temporary mitigation was stopping the router's web server until patched.
- Yahoo paid a 10,000 dollar bounty for a stored XSS in Yahoo Mail triggered merely by viewing a crafted email; Steve is unimpressed by the company boasting of millions in bounties.
- ESET found an exploit kit (Steganos) active since 2014 that carried its malicious JavaScript inside ad images, defeating ad-network code review.
- uBlock Origin reaches Microsoft Edge in preview, with about 95 percent of the code shared with the Chrome and Firefox versions.
- The New York Times told readers to install Signal; Steve notes WhatsApp also uses the Signal protocol but shares data with Facebook, and that key-change notifications must be enabled and fingerprints verified. Bill Gates remarked Apple can access iMessage content.
- Bitdefender BOX: a home security appliance requiring agents on every device and annual fees; Steve is critical that no technical explanation is given and notes encrypted traffic limits what any box can inspect.
- OpenVPN 2.4 audits: OSTIF is crowdfunding an audit after the VeraCrypt one, and Private Internet Access separately hired Matthew Green.
- Q&A: do not put a VPN server on the router DMZ; forward a single non-default port instead. Separate username and password steps can leak valid usernames, like the WPS split-PIN weakness. Mesh routers without stealth ports can be made stealthy by pointing the DMZ at an unused address. A VPN user's ShieldsUP results describe the VPN provider's servers. For internal scans use nmap. UK users hiding behind an offshore VPN remain subject to a government determined to see traffic, and unencrypted DNS can leak.
- SMART data: SpinRite's raw error counts only gain meaning against a baseline; record numbers when a drive is new and compare later.
