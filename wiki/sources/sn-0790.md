# Summary

Chrome 86.0.4240.111 fixed an actively exploited zero-day, a heap buffer overflow in the FreeType font library's handling of PNG images embedded in fonts, introduced in 2015, so any software that renders attacker-supplied fonts with an old FreeType is potentially exposed; FreeType 2.10.4 contains the fix. Chrome also started suppressing abusive notification prompts. Firefox's Fission project, which brings per-site process isolation, is usable in Nightly, and Microsoft released a dev build of Edge for Linux. Microsoft keeps a list of 1,156 domains that no longer work in Internet Explorer and redirects such visits to Edge. WordPress force-updated the Loginizer plugin on over a million sites to close a SQL injection flaw, drawing complaints; Steve argues critical updates should not be optional and that features like IP allow lists and two-factor login belong in core. A new Group Policy lets administrators bypass Windows 10 feature-update safeguard holds. The main segment walks through the NSA's advisory listing 25 publicly known vulnerabilities used or scanned for by Chinese state-sponsored actors, nearly all in internet-facing remote access and web products with patches long available.

# Key points

- FreeType flaw (CVE-2020-15999) was found by Google Project Zero's Sergei Glazunov: image dimensions truncated to 16 bits lead to an undersized buffer. Project Zero's accelerated seven-day deadline applied; Chrome shipped a fix within a day. FreeType is also used by Android, iOS, macOS, Java, game consoles and Linux desktops.
- Chrome 86 also fixed four other issues (use-after-free in media, PDFium and printing, and a Blink bug). It was the third Chrome zero-day in about a year.
- Chrome suppresses notification prompts from sites showing abusive patterns, detected partly by crawlers that subscribe to notifications and check them with Safe Browsing.
- Firefox Fission (about:config fission.autostart plus WebRender) is available in Nightly; Chrome introduced site isolation in version 67 in 2018.
- Edge for Linux dev channel is available. Internet Explorer still holds roughly 5% share and uses a browser helper object to hand 1,156 incompatible sites to Edge.
- Loginizer (over one million sites) had an SQL injection flaw; WordPress used its long-existing forced-update capability (present since 3.7) to patch it, reaching about 89% of sites. A proof of concept was published afterward.
- Steve left WordPress hosting; he protected his own login page with an IP allow list and argues WordPress should make that native.
- New Group Policy "Disable Safeguards for Feature Updates" lets administrators override Windows Update compatibility holds.
- NSA top 25 list (Chinese state actors): Pulse Secure VPN file read, F5 BIG-IP management UI RCE, Citrix ADC/Gateway flaws, BlueKeep (RDP), MobileIron MDM RCE, SIGRed (Windows DNS), Zerologon, an NTLM MIC bypass, Exim, Exchange, several deserialization bugs (Adobe ColdFusion, WebLogic, Coherence, Zoho, Telerik), Atlassian Confluence and Crowd, CurveBall (CryptoAPI ECC certificate spoofing), a Win32k elevation flaw, Symantec Messaging Gateway (fixed in 2017), Cisco IOS XR CDP, and DrayTek Vigor. The common message: all were patched, the problem is the last mile of deployment.
- Steve explains deserialization as an interpreter problem: code trusts that the data it restores came from its own serializer.
- He assumes that for every publicized ransomware intrusion there are unreported non-ransomware intrusions; networks "are sieves".
