# Summary

Leo Laporte returns from vacation for a Q&A episode. Steve first updates listeners on his move from T1 lines to cable internet, then covers the headline story: researchers Charlie Miller and Chris Valasek showed that Chrysler vehicles with the Uconnect system can be reached over the cellular network from anywhere, allowing control of the entertainment system, transmission, brakes and engine via the CAN bus after firmware rewriting; about 471,000 vehicles were found exposed and the fix has to be applied by USB stick or at a dealer. A surprise out-of-band Microsoft update patched a kernel-level font parsing flaw that surfaced in the Hacking Team leak and reached back to very old Windows versions. A new paper, "RC4 No More," cuts the effort needed to recover cookie data from RC4 traffic from about 2,000 hours to about 75 hours, reinforcing Steve's theme that attacks only get better. The Q&A covers whether certificate authorities can stop malicious payloads, SQRL without connectivity, SQRL and domain changes, SQRL beside password managers, running as a limited user, Sandboxie, CryptoLocker, the Windows 10 upgrade nag and WiFi Sense, and a sonic dog deterrent project.

# Key points

- **Chrysler Uconnect:** remote attack reachable over a carrier network, demonstrated on a Jeep driven on a highway; research planned for the August conferences; Chrysler cannot patch over the air, so owners must check by VIN and install via USB or visit a dealer. Steve notes economics: automakers face little pressure to ship hardened code and cheap designs avoid isolating infotainment from vehicle controls.
- **OPM breach recap:** the stolen records include 1.1 million fingerprint images.
- **Windows font flaw:** a crafted OpenType/TrueType font processed in the kernel could allow remote code execution simply by displaying a web page; patched out of band, including for XP Embedded POSReady configurations. Fonts are effectively small programs; an independent reviewer found many bugs just by reading Adobe's font code.
- **RC4 No More:** improved statistical attacks using known biases in RC4 key streams reduce the needed requests (from about 13 times 2^30 to about 9 times 2^27) and time to about 75 hours at roughly 4,450 requests per second; still impractical but shows deprecation is warranted.
- **Q&A, certificates:** TLS and EV certificates give privacy and server identity, not safety of the content delivered.
- **Q&A, SQRL:** it needs internet connectivity on the authenticating device (same-device or cross-device); passwords remain as fallback; coexistence with password managers is expected; a domain change breaks the identity binding, but sites can keep the old domain for QR codes or migrate users during login.
- **Least privilege:** running as a limited user plus NoScript is better than either alone; limited users also keep CryptoLocker away from restore points.
- **Sandboxie:** a lightweight sandbox can substitute for script blocking by discarding all changes when closed.
- **CryptoLocker:** spread mainly by phishing email; defenses are backups, limited accounts, sandboxing.
- **Windows 10 upgrade nag:** suggestions to hide the icon or use a removal tool; Windows 10 also has WiFi Sense, which Steve says is enabled by default and shares Wi-Fi credentials with social contacts; Leo is more relaxed, noting convenience and that Android and iOS also sync Wi-Fi passwords. Steve recommends a separate guest network behind a firewall.
- **Portable Sound Blaster:** Steve's ultrasonic dog deterrent design is available in a Google group but not sold.
