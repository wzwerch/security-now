# Summary

The raw file's frontmatter title is garbled ("HOSTS: Steve Gibson & Leo Laporte"); the transcript header gives the real title, "Fast16.sys". The episode begins with a supply-chain compromise of the Bitwarden command-line tool: a malicious npm release 2026.4.0 of @bitwarden/cli was live for about 93 minutes on 22 April as part of the wider Checkmarx campaign that abuses compromised GitHub Actions. It stole developer and CI secrets, but Bitwarden reported no vault data or end users affected. Steve then notes reports of Cisco, Fortinet, Juniper and MikroTik gear failing at an Iranian nuclear site before US/Israeli strikes, and a Reuters report that Meta records employees' mouse and keyboard activity to train AI. He announces GRC's rebuilt e-commerce system and DNS Benchmark Release 5 with a "Consultant" license, shares thoughts on Claude's chatty style, and works through listener feedback on Certum code signing, whether AI-found bug waves will recur, Ubisoft's state-of-residence field, architecture knowledge for agentic coding, ASI, an AI-to-LLVM idea and Cloudflare 1.1.1.2/1.1.1.3 filtering resolvers. The main story is SentinelLabs' discovery of Fast16, a Lua-based worm and boot-start kernel driver from 2005 that patched numerical-simulation software in memory to produce subtly wrong results, probably state-built and aimed at nuclear-related modeling in Iran, predating Stuxnet by about five years. Steve's takeaway is admiration for its design and relief that the US appears to "give as well as it gets".

# Key points

- Bitwarden CLI: @bitwarden/cli@2026.4.0 on npm (22 April, 5:57 to 7:30 PM) carried a preinstall-hook credential stealer targeting GitHub/npm tokens, SSH keys, .env files, shell history, cloud secrets and AI coding tool configs, exfiltrating via a look-alike Checkmarx domain and GitHub commits. Bitwarden found no impact on vault data; a CVE is being issued. Researchers suggested it was the first compromise of a package using npm trusted publishing.
- GitHub Actions security is a recurring weak point in these supply-chain campaigns; Steve expects AI agents to be stationed at repository exits to vet releases.
- Iran: network devices from several Western vendors reportedly malfunctioned at the Isfahan site just before the strikes while the country was disconnected from the global Internet; the cause was unknown. Leo and Steve discuss how hard national Internet kill switches are (Starlink smuggling, Russia's efforts, Spain's LaLiga IP blocking).
- Meta is reportedly capturing US employees' mouse movements, clicks and keystrokes to train AI agents; the company says it is not for performance reviews.
- GRC: e-commerce system rewritten (previously a 2003 assembly-language system with a quantity-up-to-four field); now explicit Personal Use and Consultant (gold badge, also a site license) licenses with credit for prior purchases. DNS Benchmark Release 5 adds a proper menu bar, a more prominent Run Benchmark button and guided prompts.
- Steve dislikes Claude's praise of his questions and trailing follow-up questions; a Reddit anecdote about a company swapping five AI subscriptions for two junior devs because of cost; he predicts AI coding costs will fall like storage costs.
- Certum offers inexpensive code-signing certificates for open source (about $89 first-year set including hardware, about $29 per year afterward; cloud signing about $58 per year). Steve prefers holding his own hardware-bound certificate.
- Listener question on whether AI bug waves recur: Steve expects diminishing returns for ordinary bugs but notes deliberately engineered backdoors (combination-lock style) are exactly what future AI might expose.
- Ubisoft is adding a "state of residence" field to US accounts to meet differing state age-related regulations; Steve explains the federal-versus-state preemption deadlock. eM Client prompted about Salesforce and Return Path tracking pixels; Leo and Steve discuss that images and JavaScript in email should not load by default.
- Architecture and vocabulary matter when directing AI to write non-trivial software (OSI layering example); Steve predicts someone will build a turnkey "software construction set" like Bill Budge's Pinball Construction Set.
- 0patch told a listener it cannot patch the Defender RedSun zero-day because Defender is a protected process; Microsoft can fix it through routine Defender engine updates (follow-up to episode 1075).
- Cloudflare resolvers: 1.1.1.1 unfiltered, 1.1.1.2 blocks known malware/phishing/C2 domains (returns 0.0.0.0), 1.1.1.3 also blocks adult content. All are in the DNS Benchmark's built-in list; Steve measured 1.0.0.1 slightly faster than 1.1.1.1.
- Fast16: SentinelOne's SentinelLabs, hunting early embedded-Lua malware, found svcmgmt.exe (2005, Windows 2000/XP) with a Lua 5.0 VM, encrypted bytecode, a worm module ("wormlets", a service-control spreader using weak share passwords), a kill-switch that aborts if common security products are installed, and the boot-start kernel driver Fast16.sys.
- The driver intercepts file reads and patches executables compiled with the Intel compiler in memory using 101 rules; one rule injects floating-point code that skews calculations. Matches point to engineering/physics suites (LS-DYNA 970, PKPM, MOHID); LS-DYNA has been cited in reporting on Iran's nuclear-related modeling. Files on disk are never altered, so scans find nothing, and networked copies would agree on the same wrong results.
- Attribution clues: the name "fast16" appeared in the 2017 ShadowBrokers leak (drv_list.txt) with an unusual "nothing to see here" note, implying a friendly, deconflicted implant; SCCS/RCS version strings suggest veteran Unix government engineers. svcmgmt.exe on VirusTotal still has almost no detections. It does not run on Windows 7 or later.
