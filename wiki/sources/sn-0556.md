# Summary

Steve and Leo start with the "60 Minutes" demonstration of real-time cellular eavesdropping, which exploits the SS7 signalling system that links carriers; the weakness (no authentication in the MAP and CAMEL protocols) was already shown at a 2014 Chaos Computer Club talk and cannot be fixed easily. Steve separates this from the poorly examined baseband processor in phones. Next, court documents revealed that the RCMP had BlackBerry's single global key for consumer PIN-to-PIN messages, and BlackBerry's CEO responded with a vague "lawful access" statement. Apple ended QuickTime for Windows support just as Trend Micro's Zero Day Initiative published two unpatched heap-corruption flaws, so Steve urges everyone to uninstall it. The FBI reportedly found nothing significant on the San Bernardino phone. Steve revisits Threema versus WhatsApp/Signal, then covers Never10 1.3.1, a TV recommendation, Zeo updates and a SpinRite SSD recovery story. The main topic is the SMTP STS proposal (from Google, Yahoo, Comcast, Microsoft and 1&1), which Steve calls a horrible kludge that works around the lack of DNSSEC and still suffers from trust on first use.

# Key points

- SS7/MAP/CAMEL: the carrier signalling network has no authentication, so knowing a phone number lets an attacker track location and intercept calls and SMS; only end-to-end encrypted apps help, and metadata still leaks.
- Baseband processors (ARM-based, bought by Apple from Qualcomm) get little scrutiny and are probably buggy.
- SMS-based second factors are weak given SS7; Steve prefers time-based authenticator codes (he uses them at his registrar Hover).
- RCMP held BlackBerry's global decryption key for consumer BBM/PIN-to-PIN traffic (about one million messages decrypted in one case); enterprise BES customers used their own keys. Steve calls a single global key the worst possible design.
- BlackBerry CEO John Chen's blog post defended compliance with "lawful access" and criticised companies that put reputation first.
- QuickTime for Windows is deprecated by Apple; two remote-code-execution heap flaws disclosed by Trend Micro's ZDI will never be patched; advice is to uninstall (some editing software may still depend on it).
- CBS reported nothing of significance found on the unlocked San Bernardino iPhone.
- Threema vs. Signal/WhatsApp: Threema stresses authentication levels and no phone-number requirement; WhatsApp is closed source and ties identity to a phone number; Signal needs contact access.
- Steve's theme: convenience usually beats security, and absolute security exists only in theory.
- SMTP STS: proposal to publish a policy through a special DNS name plus an HTTPS-hosted copy; STARTTLS alone is vulnerable to active downgrade attacks; the proposal still has trust on first use, and Steve argues the effort should go into DNSSEC instead.

# Other segments

- Never10 bug fix to version 1.3.1 (a parser mistaken by "update" in a path); users reported recovering several GB of disk space.
- TV miniseries "The Night Manager" recommended.
- Zeo sleep headband: replacement bands planned and a new Android app in beta.
- Listener Simon reports SpinRite Level 2 revived a failing SSD.
- Leo discusses how TWiT measures podcast downloads (about 168,000 for the previous episode) and the show's 11th-anniversary history.
