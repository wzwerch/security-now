# Summary

Steve recaps March 2022 Patch Tuesday (71 Windows fixes, no known exploitation, plus 21 Edge fixes and a critical no-interaction Android bug) and an emergency Firefox update for two actively exploited use-after-free zero-days in XSLT parameter processing and WebGPU IPC (CVE-2022-26485 and -26486). Binarly found 23 flaws in Insyde's InsydeH2O UEFI SDK, used by many PC vendors, and HP disclosed 16 more; they can defeat Secure Boot and persist across drive replacement, so firmware updates matter. The Lapsus$ group stole about a terabyte from NVIDIA, leaked employee credential hashes and expired code-signing certificates that were quickly used to sign malware, and demanded open-sourcing of drivers. ProtonMail and Tutanota are praised for handling Russian customers fairly. Linux has seen a run of kernel bugs (Dirty Pipe, a cgroups release_agent container escape, and a netfilter hardware-offload flaw). Russia started issuing its own TLS certificates, which only the Yandex browser will trust and which Western users should never install. Patchstack data show WordPress plugin vulnerabilities growing 150 percent with almost all flaws in free plugins. The main topic is the EU eIDAS Article 45 proposal for QWACs, which would bind government-validated identity assertions to websites and possibly force browsers to trust national CAs; 38 experts and the EFF oppose it.

# Key points

- Patch Tuesday (March 2022): 71 fixes, 29 remote code execution, 25 elevation of privilege; three publicly disclosed but none exploited; Android bulletin included a critical remote code execution flaw.
- Firefox 97.0.2 and 98.0.1: two exploited use-after-free bugs (XSLT, WebGPU); use-after-free explained as confusion over who frees memory, often via reference counting errors.
- Binarly and InsydeH2O: 23 flaws in System Management Mode and other code (three rated 9.8) reachable through vendor firmware derived from Insyde's SDK; affects Fujitsu, Intel, AMD, Lenovo, Dell, ASUS, HP, Siemens, Microsoft, Acer and others; they can bypass Secure Boot and Intel BootGuard and give persistence; HP disclosed 16 additional flaws.
- NVIDIA breach by Lapsus$: about 1 TB taken, credentials of 71,335 accounts leaked (more than current staff count, so likely historical), data added to Have I Been Pwned; ransom demand to open-source drivers and remove the crypto-mining hash-rate limiter, with a threat to release chip design files.
- Stolen expired NVIDIA code-signing certificates were used to sign malicious drivers; Steve explains timestamped code signing and criticizes Windows for accepting expired-certificate kernel drivers without timestamps; the certificates were then blocked.
- Proton told Russian subscribers to prepay before payment networks cut off; Tutanota offered free renewals for users in Russia, Belarus and Ukraine; Steve contrasts this with Namecheap.
- Linux: Dirty Pipe (kernel 5.8 onward, found by Max Kellermann after tracing corrupt log files; fixed in 5.10.102, 5.15.25, 5.16.1), a cgroups release_agent escape found by Huawei researchers, and CVE-2022-25636 in netfilter offloading (kernels 5.4 to 5.6.10); rising complexity, not rot, is Steve's explanation.
- Russia's new national certificate authority: sanctions block Western CAs from renewing Russian sites' certificates; only the Yandex browser trusts the new root; Steve expects major browsers to blocklist it and warns Westerners not to add it.
- Patchstack 2021 report: reported WordPress vulnerabilities up 150 percent, 29 percent of critical plugin flaws never patched, only 0.58 percent in core and 91 percent in free plugins.
- QWACs (eIDAS Article 45): proposed browser banner "This website uses a QWAC", validated through a third-party web service and an ntQWAC blob; trivially spoofable by a malicious site unless built into browser UI; one variant would put national government roots into browser trust stores; opposed by 38 experts, EFF and the Internet Society; Steve suggests honoring Do Not Track instead.
