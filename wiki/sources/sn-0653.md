# Summary

The main story is memcached abuse: exposed memcached servers answer spoofed UDP queries with very large cached blobs, producing a 1.35 Tbps attack on GitHub (quickly mitigated through Akamai) and a record 1.7 Tbps attack a few days later. Steve explains that memcached (port 11211) was meant to be bound to localhost, yet Shodan listed about 87,800 exposed instances, that attackers can plant large values themselves, that attack packets come from the real memcached hosts, and that missing ISP egress filtering of spoofed source addresses is the root enabler. Earlier, Microsoft began delivering Intel Spectre variant 2 microcode through a Windows 10 1709 update (KB4090007) for a few Skylake parts, which will matter for owners of unsupported old motherboards. Other items: researchers' LTEInspector found 10 new 4G LTE attacks (including location spoofing via authentication relay) that are hard to patch; the IETF fight over a non-forward-secret TLS 1.3 option demanded by the financial industry; Trustico, a Symantec reseller, asked DigiCert to revoke 50,000 certificates and then emailed roughly 23,000 customer private keys, which it had generated and stored in browser JavaScript; Flash usage dropped from 80% to under 8% of daily Chrome users; and ComboJack clipboard-hijacking malware swaps cryptocurrency wallet addresses. Netflix's Lost in Space reboot is announced.

# Key points

- Memcached amplification: UDP lacks source verification so replies are reflected and amplified; fixes are binding memcached to localhost, firewalling port 11211, and ISP ingress/egress filtering. Defenders at large networks can block the source port quickly.
- Microsoft KB4090007: OS-loaded microcode update (Windows can patch microcode at boot like Linux), initially for a couple of sixth-generation Core CPUs on Windows 10 1709; Steve plans an InSpectre update to show the CPU ID.
- A branch target buffer side-channel from 18 months earlier could defeat ASLR in about 60 ms.
- LTEInspector: model-based testing of the attach, detach and paging procedures found 10 new and 9 prior attacks, eight validated on a test bed; authors withheld code and doubt backward-compatible fixes; Steve concludes app-layer encryption must be relied on.
- TLS 1.3: removes legacy baggage and provides forward secrecy; BITS/Financial Services Roundtable lobbied for a way to keep decryptable sessions in datacenters; purists reject any downgrade mode; TLS 1.0 and 1.1 are being deprecated by service providers.
- Trustico: a CA reseller that held customers' private keys and mailed them unprotected; DigiCert had to revoke under the CA/Browser Forum baseline rules; experts called it gross negligence and urged CAs to cut ties.
- ComboJack: PDF to RTF to HTA to PowerShell chain installs a clipboard monitor recognizing several cryptocurrency address formats and substituting attacker wallets.
- Flash is on track for end of life in 2020; HTML5 has replaced it.
