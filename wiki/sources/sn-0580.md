# Summary

Recorded the day after episode 579 with Fr. Robert Ballecer as guest co-host. Steve notes that Microsoft's Get Windows 10 remover (KB 3184143) is only offered as an optional update, and discusses Microsoft's announcement of Windows Defender Application Guard, which runs Edge inside a lightweight Hyper-V based container but initially only in the Enterprise edition. HP, after an EFF open letter and public outcry, will offer an optional firmware rollback of its ink-cartridge authentication that had been delivered as a "security update". Steve clarifies how a site can upgrade stored password hashes (wrap old hashes in the new one), shares a listener's CNAME trick for using a nice domain name with a free dynamic DNS provider, warns about the coming monolithic Windows 7/8.1 update model, and passes on a report that Firefox (and Chrome) constantly rewrite session-recovery data, wearing consumer SSDs. After errata and miscellany he and Fr. Robert answer listener questions covering Windows 10 DNSSEC support, the difference between HTTPS and HSTS, checking whether an ISP blocks port 1935, HTTP public key pinning, trust in Let's Encrypt's CDN, and an eBay account that cannot drop an old recovery phone number.

# Key points

- KB 3184143 removes the Get Windows 10 nag software but needs to be selected under optional updates; Microsoft's telemetry back-ports are separate and remain.
- Edge in a micro-VM (Application Guard): isolates the browser from the host using hardware virtualisation and group-policy-defined trusted versus untrusted sites; Enterprise only for now; Steve prefers a transparent design over Qubes OS's compartment-heavy approach, Fr. Robert notes vendors are pushing lightweight VMs as safer than containers.
- HP printers: an update that blocked non-HP ink was framed as a security update; EFF called it deceptive, over 10,000 people signed on, HP agreed to an optional rollback firmware. Parallel with Keurig's cup lock-in; Steve says terms should not change after the sale.
- Password hash migration: an operator can re-hash all existing stored hashes with the stronger function at once (chain old into new) rather than wait for each user to log in.
- Dynamic DNS hack: use a CNAME at your own registrar pointing to a free dynamic-DNS name at afraid.org so a home VPN endpoint keeps a friendly name.
- Windows 7 clean installs: the Microsoft community walkthrough remains the reliable path; after the next Patch Tuesday updates switch to monthly rollups, removing the ability to skip individual updates (such as the GWX or telemetry updates).
- SSD wear: Firefox's session-store interval (default 15 seconds) rewrites the entire recovery file continuously, measured at 10 to 12 GB per day; Chrome showed over 24 GB per day; Steve raises the setting to reduce writes and considers a RAM disk; Sysinternals-type monitors show per-process disk writes.
- SpinRite on SSDs: reads (Level 2) let the SSD's own ECC decide whether to refresh weak cells; a guest co-host reported running SpinRite against an Android phone exposed as mass storage.
- Windows 10 supports DNSSEC validation on the client but few zones are signed, so universal enforcement is not yet possible, like IPv6.
- HSTS tells browsers to use HTTPS for a site for a stated time; preload lists close the first-visit gap; HPKP (HTTP public key pinning) lets a site pin its certificate hashes for browsers, exposing interception proxies; Chrome already pins Google certificates; cPanel now supports Let's Encrypt.
- Checking ISP port filtering: switch the router from stealth to reply mode, scan with ShieldsUP, and use ID Serve to test outbound connections to a port such as RTMP's 1935.
- Let's Encrypt on Akamai: the issuance protocol authenticates the endpoints, so a CDN carrying it cannot forge anything.
- eBay recovery number: a user's old phone number cannot be removed, so Steve advises abandoning and replacing the account after stripping its data, while Fr. Robert notes that strict recovery rules can also protect owners.
