# Summary

The week was dominated by WannaCry, a worm-like ransomware that used the NSA-origin EternalBlue SMB exploit (patched by Microsoft in March) to spread across networks and the open internet, hitting organizations such as the UK's NHS, FedEx and Telefonica. Steve walks through its design: it encrypts files with a "WANACRY!" header, scans its local /24 and launches many internet-wide scanners for port 445, and checks a nonsense domain as an accidental or deliberate kill switch that a researcher registered to halt the first wave. He discusses why unpatchable or unmanaged old Windows systems made hospitals vulnerable, whether Microsoft or the victims are to blame, speculation about North Korean links, and Microsoft president Brad Smith's call for governments to disclose vulnerabilities. Before that, he covers the FCC's Net Neutrality comment system, a keystroke-logging audio driver on HP computers, Microsoft's rule that Windows Store browsers must use the Edge engine, the OpenVPN security audit, SIM-hijacking warnings from the Kraken exchange, Android's Project Treble, and NIST's new password guidelines.

# Key points

- The FCC claimed DDoS attacks on its Net Neutrality comment system; security experts saw no evidence and attributed the outage to the surge from John Oliver's segment plus spam comments. The site lacked bot protection.
- A Conexant audio driver on dozens of HP models (version 1.0.0.46 and earlier) wrote keystrokes into a world-readable log (C:\Users\Public\MicTray.log) that is overwritten at each login; the researchers at modzero found it, Steve believes it was left-over debugging for hotkeys, and the mitigation is to remove or rename the MicTray executable or place a read-only empty log file. He ties this to the permissive history of Windows global hooks.
- Microsoft's Store policy requires apps that browse the web to use the platform's HTML and JavaScript engines, so Chrome and Firefox cannot ship in the Store and Windows 10 S users effectively get Edge with Bing; Apple and Google have similar restrictions. Steve calls this a loss of browser diversity but a security trade-off.
- OSTIF and Quarkslab audited OpenVPN 2.4.0, finding one high-severity, one medium and five low issues, fixed in OpenVPN 2.4.2; the auditors judged the code generally well written.
- Kraken warned crypto users that attackers hijack phone numbers by social-engineering carriers, at least ten known cases in a month; Steve prefers TOTP over SMS and notes SQRL can request that sites disable other account recovery.
- Android O's Project Treble adds a stable vendor interface between the OS framework and vendor code (tested by a Vendor Test Suite), so device makers can update Android without silicon-vendor work; Steve calls it very welcome news.
- NIST's new digital identity guidelines drop forced periodic password changes and arbitrary composition rules, allow any characters, and require screening passwords against lists of common or compromised ones.
- Errata: AMT can be reachable over WiFi if it is provisioned for wireless; Ubiquiti released EdgeRouter firmware 1.9.11 fixing the UDP MSG_PEEK issue.
- Listener Q&A: DNS returns rotated IP lists for load balancing and fault tolerance; ultrasonic means just above hearing and many phone mics reach it; TOTP uses an HMAC of the time with a secret key; a DoD listener explains missile RAM doubling as cheaper than paying to fix leaks.
- WannaCry details: names vary (WannaCry/WanaCrypt0r/WCry); about 200,000 to 300,000 infections were reported and only around $53,000 in bitcoin had been paid; the code tries a TCP connection to an unregistered gibberish domain and stops if it connects; later variants removed that check. It spreads via a subtle size type error in SMB memory copy, suspected found by fuzzing. Infection of whole networks occurred from a single point of entry, possibly phishing, and many hospital systems run unsupported XP, which Microsoft patched anyway after the outbreak.
- Leo notes a theory that the attack may be state-linked given code similarities with the Lazarus Group; Steve has no opinion. Brad Smith blamed government stockpiling of vulnerabilities and called for a Digital Geneva Convention; Steve says the NSA's dilemma is real and that EternalBlue was only a powerful exploit that became a worm when combined with ransomware.
