# Summary

Steve opened with a review of recent news. iPhones that had their Touch ID hardware repaired by third parties were bricking with Error 53; Steve argued this is a defensible anti-tampering response to a possible interposed fingerprint reader, though Apple needs a better recovery process. He and Leo agreed that claims of the Amazon Echo constantly uploading audio are unsupported. Comodo's Chromium-based Chromodo browser, installed by default with its security suite, disabled the same-origin policy, and Comodo only blocked the specific proof of concept that Tavis Ormandy supplied. Google widened its Safe Browsing warnings to deceptive download pages and announced Chrome would pause non-essential Flash from September. A widely shared claim about Windows 10 phoning home turned out to be mis-summarised (the tester had disabled telemetry options and was running Enterprise). Check Point reported an eBay stored-script flaw using a six-character JavaScript obfuscation technique to slip past a filter that stripped alphanumerics, which eBay declined to fix. Senator John McCain wrote an op-ed against end-to-end encryption; Steve reminded listeners that metadata remains exposed. The Zeo sleep monitor sold out repeatedly after his plug. The rest of the show answered three router follow-up questions.

# Key points

- Error 53: devices with repaired or replaced fingerprint sensors lose function after update, since the secure enclave pairing is broken; Steve sees it as a physical-tampering defence, critics call it anticompetitive.
- Amazon Echo and similar devices listen locally for a wake word and then upload; traffic volume analysis shows no constant streaming, so the claim that an ad followed a conversation is far more likely coincidence or prior browsing.
- Comodo Chromodo: installed by default with Comodo Internet Security, replaces shortcuts, imports Chrome data, alters DNS settings and turns off same-origin policy, so any script could read cookies of other sites; Comodo fixed only one call after 90 days.
- Same-origin policy explained as the foundation of web security: script from one origin must not touch another origin's data.
- Google Safe Browsing now flags deceptive content such as fake download buttons and bogus player-update prompts; Chrome will pause non-central Flash from September 1.
- The Windows 10 "4,000 connections in 8 hours" report was misread: the tester had chosen custom settings, used Enterprise edition, and many endpoints were content-delivery networks. Steve still plans to stay on Windows 7 and described the official update that adds a policy to block the Windows 10 upgrade, which worked on a fresh install.
- Steve built a new Haswell machine for Windows 7 after Microsoft's new-silicon support statement.
- McCain op-ed urges changes so government can read end-to-end encrypted traffic; Steve notes weak coverage of the existing third-party encryption and the persistent exposure of metadata.
- eBay filter bypass: using only brackets, parentheses, exclamation and plus signs, JavaScript can be built that loads attacker-controlled script; blacklisting filters are weak versus whitelisting; eBay said it would not fix.
- Errata: Ethernet carries frames, not packets.
- Router Q&A: ports can be forwarded from one isolation router to another using its WAN address, with manually assigned addressing; overlapping LAN numbering works because of NAT but the interconnect network must differ; many WiFi routers can coexist, better on different channels; a shared printer can be placed on the IoT side with a mapped port, rather than on the shared interconnect network.
- SpinRite note: motherboards with buggy SATA BIOS code may need legacy IDE mode until SpinRite 6.1 stops using the BIOS.
