# Summary

The episode is devoted to Log4Shell, the maximum-severity (CVSS 10.0) flaw CVE-2021-44228 in the Apache Log4j 2 logging library. Beforehand Steve discusses the roughly four-hour AWS outage of the previous week, which he attributes to an internal congestion cascade after an automated scaling event, and which showed how brittle tightly coupled, capacity-trimmed networks have become. He then covers criminals in Canada hiding Apple AirTags on high-end cars to find and steal them, and Apple's rather weak "Tracker Detect" Android app. He retracts his earlier praise of Windows 11: Microsoft blocked tools such as EdgeDeflector from redirecting the `microsoft-edge://` scheme, so some features will always open Edge. Wordfence reported 1.6 million WordPress sites attacked from over 16,000 IPs via four plugins and fifteen Epsilon Framework themes, with attackers enabling open registration and making the default role administrator. The main segment explains that Log4j 2, in its default configuration, interpreted `${...}` expressions in logged text, including JNDI lookups that could fetch and run remote Java code, so anything an attacker could get logged (chat message, HTTP header, device name) became remote code execution. Steve stresses it was a feature rather than a bug, that exploitation began at least nine days before disclosure, that string-match filters are easily obfuscated, and that the only real fix is upgrading (2.15.0 disabled the lookups by default) and inventorying where Log4j hides.

# Key points

- Log4Shell, CVE-2021-44228, scored CVSS 10.0; Log4j 2 is embedded in Apache products (Struts, Solr, Kafka, Flink, Druid and others) and in Redis, Elasticsearch, Logstash and Ghidra, so most Java infrastructure is exposed indirectly.
- Root cause: default string substitution of `${prefix:name}` expressions in log messages, including `jndi:` lookups over LDAP and other protocols; fixed in Log4j 2.15.0, which restricts protocols and disables message lookups by default.
- Discovery chain: reported privately by Alibaba to Apache; abuse first seen in Minecraft servers (chat messages) during a bug bounty; Apple iCloud and Tesla vehicles were shown to make callbacks after a device name was changed, proving the exposure with harmless DNS probes.
- Cloudflare's CEO found the earliest exploit evidence on 1 December 2021, nine days before public disclosure; mass exploitation followed disclosure. Microsoft observed scanning, coin miners, Cobalt Strike beacons, credential theft and data exfiltration.
- Defenders' pattern matching for the lookup string is bypassed with obfuscation (nested lower/upper case lookups); even secrets in environment variables can leak via the lookup URL.
- Quebec took nearly 4,000 government sites offline as a precaution and the Canada Revenue Agency went offline; Steve sees this as understandable given the ransomware era.
- Huntress offers a free benign Log4Shell test page (callback-based) and a community GitHub list tracks affected software status; Leo mentions a canary-token alternative.
- Steve compares it to the Windows Metafile escape-code issue: by-design features turned hostile are the worst class of vulnerability. Leo notes that commercial users depend on volunteer-maintained open source.
- AWS outage: an automated capacity-scaling activity triggered a surge of retries and persistent congestion between internal and main networks; it hit Ring, Netflix, Prime Video, Roku, Amazon delivery apps and even the AWS status page. Lesson: pooled infrastructure creates large single points of failure.
- AirTag abuse: York Region police reported at least five cases where thieves tagged cars, located them at the owner's home, then used the OBD port to program a new key. Apple shortened the unknown-tracker alert delay from three days to hours; Apple's Android Tracker Detect app only scans on demand.
- Windows 11: no complete switch away from Edge; the `microsoft-edge://` association became locked in Insider builds 22483-22494 and the EdgeDeflector developer gave up.
- WordPress: attacks on Kiwi Social Share, WordPress Automatic, Pinterest Automatic and PublishPress Capabilities plus 15 Epsilon Framework themes; Wordfence blocked 13.7 million attempts in a day and a half. Advice: update, review administrator accounts, and rebuild from clean code if compromised.
