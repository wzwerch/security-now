# Summary

The episode starts with the full results of Pwn2Own Berlin 2025 (held at OffensiveCon): 26 exploits, 28 unique zero-days bought and reported to vendors, 1,078,750 dollars paid out, and STAR Labs SG as Master of Pwn, with big payouts for virtual-machine and container escapes and the first AI-category wins. Steve then covers a PayPal patent application for crawling newly registered domains and simulating checkouts to spot scam sites, and a long retrospective from Swiss iOS exploit developer Siguza ("tachy0n: the last zero-day jailbreak"), who explains that since iOS 14 Apple has been patching exploitation strategies (separated and sequestered kernel heaps, signed pointers and objects) rather than single bugs, so public iOS kernel exploits have effectively disappeared. Next is the surge of phishing that abuses the scripting allowed inside SVG images, which Steve compares to the old Windows Metafile flaw and wants email clients to stop executing. Listener feedback covers ECH blocking in enterprises, the Copilot pull-request story, a Linux dictation project, Windows Sandbox and ad blockers, and classic science-fiction films. The main topic explains use-after-free and reference counting, then summarizes researcher Sean Heelan's use of OpenAI's o3 to rediscover a known bug in the Linux kernel's ksmbd SMB server and, along the way, find a new remote zero-day (CVE-2025-37899) in the SMB logoff handler. Steve's conclusion is that AI-assisted code review before release could eventually remove the bugs attackers hunt for.

# Key points

- Pwn2Own Berlin 2025 (15-17 May): targets were fully patched, including Windows 11, Red Hat Enterprise Linux, VMware ESXi (first ever, 150,000 dollars), VMware Workstation, Oracle VirtualBox, Docker Desktop, Firefox, SharePoint, NVIDIA Triton and the NVIDIA Container Toolkit, plus AI targets such as Chroma and Redis; seven of the 28 zero-days came from the AI category. Several NVIDIA Triton bugs were already known to the vendor but unpatched. VM and container escapes pay the most because of their cloud relevance.
- Steve's takeaway: top researchers can break fully patched mainstream systems, and apparent security often rests on those people choosing not to attack us; listeners experimenting with AI might even find bounty-eligible bugs.
- PayPal patent application 18/521,909 (published 29 May 2025) describes crawling newly registered domains, simulating a checkout, detecting redirections and comparing destinations against known scam merchants; Steve likes the idea but hopes it will not be used to block others. Leo notes NextDNS already blocks newly registered domains.
- Siguza's account: the tachy0n exploit (iOS 13.0-13.5, shipped in unc0ver in May 2020) came from regression-testing old bugs after Apple reintroduced a previously fixed flaw; Apple then fixed it and added a regression test.
- From iOS 14 on, Apple split the kernel heap into separate "kheaps" for data and objects, sequestered virtual memory per zone, added guard pages and per-boot randomness, signed or pointer-authenticated sensitive structures, and used compiler type information. Result: exploitation strategies, not just bugs, were killed; no public kernel exploit exists for iOS 17 or 18. Leo adds that zero-click nation-state attacks (Pegasus, BlastDoor) were the likely motivation.
- SVG phishing: many vendors (Sophos, KnowBe4, Mimecast, Forcepoint, Cloudflare Cloudforce One and others) reported a spike in SVG attachments that embed JavaScript for redirects, base64-encoded fake login pages, or DOM injection into poorly sanitized upload portals. The SVG standard has allowed ECMAScript since 2001. Steve wants browsers and especially email clients to disable script execution in SVGs; Cloudflare reports manufacturing and financial services as top targets.
- Steve recalls the Windows Metafile (WMF) flaw as a similar intentional design feature that became a vulnerability.
- Healthcare security engineer intends to block ECH so the enterprise can inspect SNI rather than fully proxy TLS; Steve agrees that enterprises and home users have different privacy needs.
- Stephen Toub (Principal Software Engineering Manager at Microsoft) was the reviewer in the Copilot pull-request story; listeners suggest he may have been testing Copilot, and that better prompting would matter.
- Linux Dictation Project (Python and Whisper-based voice control for Linux) is promoted by its author, who has cerebral palsy and wants contributors.
- Windows Sandbox shows how awful the unfiltered web is (instant fake "PC infected" pop-ups); filtering extensions like uBlock Origin are valued but Manifest v3 limits them in Chrome-based Edge.
- Use after free explained: shared objects are reference counted; a task that uses a pointer after releasing its reference, or an object freed while another thread still holds a pointer, lets attackers exploit memory that has been reallocated.
- Sean Heelan's o3 experiment: with only the o3 API (no scaffolding), a benchmark of about 3,300 lines of ksmbd code (the Kerberos authentication use-after-free CVE-2025-37778), o3 found the bug in 8 of 100 runs (Claude Sonnet 3.7: 3; Sonnet 3.5: 0), with 28 false positives. With about 12,000 lines (all SMB command handlers) o3 found it once in 100 runs, but another run reported a new, similar use-after-free in the SMB2 logoff handler (CVE-2025-37899), where one thread frees sess->user while another still uses it. Signal-to-noise was about 1:50. Heelan concludes that for the first time o3 is good enough to help real vulnerability research and that LLMs resemble human auditors more than fuzzers or symbolic execution. Steve argues pre-release AI review could eventually leave attackers nothing to find.
