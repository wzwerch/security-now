# Summary

Windows Update briefly offered Windows 11 to ineligible PCs; Steve reminds listeners of his InControl tool for pinning a Windows version. He recommends PureText for pasting without formatting and describes Microsoft Edge Secure Network, a free Cloudflare-backed VPN capped at 1 GB per month. LastPass published forensic detail on its second incident: attackers compromised a DevOps engineer's home computer through a vulnerable third-party media package, installed a keylogger, captured the master password after MFA, and used the engineer's corporate vault to reach keys for the AWS S3 backups; the company also listed remediation steps. Signal's president said it would leave the UK rather than weaken encryption under the Online Safety Bill. A fast-growing malware flood hit PyPI, QNAP launched a bug bounty, and SpinRite testing uncovered BIOS USB bugs that corrupt memory when reading beyond 137 GB. The main item is the NSA's nine-page home network best practices guide, which Steve endorses nearly entirely.

# Key points

- A Windows Update bug offered Windows 11 upgrades to hardware-ineligible Windows 10 and 11 21H2 machines; Microsoft fixed it over the weekend and the installs aborted. Steve used InControl to set his machine to stay on Windows 10 22H2.
- PureText (SteveMiller.net) provides a hotkey for paste-without-formatting; Windows PowerToys is adding a "Paste as Plain Text" module.
- Edge Secure Network: encrypted tunnel (also for plain HTTP), masks IP and region, hides browsing from the ISP, 1 GB free per month with a Microsoft account; operated with Cloudflare, which deletes diagnostic data every 25 hours.
- LastPass incident detail: stolen credentials from the first incident were encrypted, so the attacker targeted one of four DevOps engineers with access to the decryption keys; the engineer's home PC was exploited via a vulnerable media software package (Leo hears Plex), a keylogger got the master password, and the corporate vault gave access keys to the S3 backups and databases. Remediation, with Mandiant: forensic imaging, home network hardening for the engineer, phishing-resistant MFA, rotating credentials and certificates, tighter IAM and IP restrictions, deleting obsolete users and SAML certificates, extra logging. Steve's lesson is that creeping complexity makes clean-up hard and suggests a role for a "holistic system reintegrator".
- Signal's Meredith Whittaker said Signal would "absolutely 100% walk" from the UK if the Online Safety Bill forced message scanning; Element's CEO warned it would damage trust in UK-made secure products; Steve expects Signal, Telegram and Threema to refuse while big platforms may be forced to comply, and thinks governments will eventually outlaw unscanned encryption.
- Phylum found an aggressive PyPI campaign (over 1,100 packages, published every few seconds) delivering a Rust-based payload via a Dropbox account; Steve sees reputation-based identity as the only long-term answer to poisoned open repositories, at the cost of anonymity.
- QNAP launched a bug bounty program with rewards up to 20,000 dollars; Steve says devices will need to phone home and auto-update.
- SpinRite: BIOS USB routines on some motherboards corrupt main memory when reading sectors beyond 28-bit LBA addressing (137 GB); Steve wrote test utilities (BIOSTEST, BIOSSCAN), and 6.1 will clamp USB access to 137 GB until SpinRite 7 gets native USB host controller support.
- The NSA's home network guide: keep all equipment and IoT devices updated, back up and disconnect external drives, limit administration to the internal network, disable remote administration and UPnP, use your own router rather than the ISP's, replace end-of-life routers, use WPA3 (or WPA2/3) with a passphrase of at least 20 characters and protected management frames, do not hide the SSID, segment main, guest and IoT Wi-Fi, mute or cover microphones and cameras, avoid public charging stations, and reboot routers, phones and computers weekly to flush memory-resident implants. Steve notes he had never recommended the reboot advice.
