# Summary

Steve announces the formal release of SQRL: the 17-page "SQRL Explained" PDF and version 1.0 of his Windows reference client are on GRC, with the on-the-wire specification still to come before he returns to SpinRite. He then covers SandboxEscaper's newest local privilege escalation, a second bypass of an April-patched AppX deployment flaw that he considers a crude hack, and BlueKeep updates: a private Metasploit module that defeats Network Level Authentication by pairing with Mimikatz, an NSA advisory, and Robert Graham's improved scanner. A new botnet, GoldBrute, brute-forces RDP servers using coordinated distributed guessing without using BlueKeep. The FBI warned that HTTPS and the padlock do not make a site trustworthy, which Steve says reflects how far public understanding lags. VLC 3.0.7 fixed 33 issues thanks to an EU-funded bug bounty. The main topic is Exim: Qualys found that versions 4.87 to 4.91 (about 57 percent of Internet mail servers, over 500,000) allow command execution as root, accidentally fixed in 4.92 in February 2019; the default remote exploitation path needs a connection held open for seven days, but local exploitation is instant.

# Key points

- SQRL: released 17-page explainer plus client v1.0 (small, multilingual-capable, self-updating); 1,300+ forum accounts; Steve argues SQRL leaves websites no secrets to keep and offers answers for "what if" scenarios; next steps are the protocol spec, then SpinRite.
- SandboxEscaper: another zero-day bypassing the fix for CVE-2019-0841 (AppX deployment hard-link issue) involving Microsoft Edge files; 0patch could not reliably reproduce it; Steve guesses her best work is being sold privately.
- BlueKeep: researcher produced a Metasploit module (kept private) achieving access in about 22 seconds even with NLA, via credential harvesting; NSA advisory urged patching; Steve notes 0patch's micropatch means servers need not be taken down.
- GoldBrute botnet: Java-based, in-memory only, reportedly used 1.5 million RDP hosts it found; one command-and-control server; distributes IP discovery and credential guessing across bots to defeat per-IP blocking; researchers saw 1.6 million unique addresses in six hours.
- FBI IC3 advisory: criminals increasingly use HTTPS certificates on phishing sites; do not trust a site because of the lock icon; Steve notes the padlock now only indicates encryption and a matching certificate.
- VLC 3.0.7: 33 security fixes including an out-of-bounds write and a stack overflow, attributed to the European Commission's FOSSA bug bounty program.
- Edge dev builds can re-open a page in IE11 mode; Mozilla rebranded services (Lockwise, Monitor with Have I Been Pwned, Send); Troy Hunt says HIBP is outgrowing a one-man operation.
- Exim CVE-2019-10149 (Qualys, "Return of the Wizard"): introduced with 4.87 in April 2016; remote command execution as root through a crafted undeliverable message whose bounce handling is mishandled; default remote path takes seven days; Debian ships Exim by default; the fix is to update to 4.92 or later.
- Qualys says faster exploitation methods may exist; Steve urges any Exim operator to update immediately.
