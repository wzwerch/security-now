# Summary

Steve notes that new Snowden slides use the term "upstream" for tapping fiber cables upstream of Internet companies, matching his earlier PRISM theory. A CNET article points out that Facebook still uses 1024-bit RSA keys while Apple, Microsoft and Twitter have moved to 2048; a researcher estimates dedicated hardware to break 1024-bit RSA could cost about a million dollars per device and take a year, easily within reach of a nation, while Google plans to switch by year-end and already uses forward secrecy and rotates keys every two weeks. Steve previews next week's technical episode on handshakes and perfect forward secrecy. He also discusses the supposed bugging of EU encrypted fax machines (Dropmire), which security researchers think used radio-frequency emanation side channels, the Ubisoft account database breach, a finding that only Google offers server-to-server encrypted mail among the four big webmail providers, Firefox 23 removing the UI switch for JavaScript and silently re-enabling it, and Google's experimental QUIC protocol, a TCP-like multiplexed transport over UDP with built-in encryption. He gives an update on SpinRite 6.1 (own memory manager, PCI enumeration, CD-based Mac boot soon) and recommends Stephen King's Under the Dome. Leo adds that Twitter will target ads using off-Twitter browsing. Listener questions cover whether the NSA can demand SSL keys, whether five zettabytes of storage is plausible, secure email, creating your own certificates, General Petraeus' shared Gmail draft trick, prism-break.org, and Chrome sync of extensions.

# Key points

- NSA slides describe "upstream" collection from fiber optic taps, corroborating the tap theory; Leo and Steve say governments can compel companies to hand over keys, so Steve urges key-authority-free tools.
- Facebook used 1024-bit RSA while others moved to 2048-bit; a Tel Aviv University cryptographer estimates a one-million-dollar custom machine can break one 1024-bit key per year, so nation-states can; Google's Adam Langley said Google could do it too and that it plans to move to 2048-bit keys by the end of the year; Google uses forward secrecy and rotates keys every two weeks, Facebook yearly.
- Steve's idea: capture everything and brute-force selectively, and certificate expiry allows rolling upgrades of key sizes.
- Dropmire: Snowden documents describe implants on the EU embassy's cryptographic fax machines; experts such as Markus Kuhn say the noisy image looks like compromising electromagnetic emanations, a side-channel attack that bypasses cipher strength.
- Ubisoft lost usernames, email addresses and hashed passwords; Steve says change passwords everywhere they were reused.
- Only Google of Google, Hotmail, Yahoo and AOL supports SMTP encryption between servers, so most mail is exposed to an upstream tap; Facebook only recently moved to default HTTPS, which hurt older taps.
- Firefox 23 is to block third-party cookies by default but also removes the JavaScript enable checkbox and re-enables JavaScript silently, drawing criticism; Leo notes confusion between Java and JavaScript.
- QUIC: a Google protocol that multiplexes streams over UDP with forward error correction, packet-aligned cryptography and zero-round-trip setup to avoid TCP head-of-line blocking; Steve is wary about firewalls and proxies.
- SpinRite 6.1 progress: extended memory manager to find a 32 MB buffer, PCI bus enumeration, plan for native PCI mode controllers, and a CD-bootable release for Macs soon.
- A listener's flash drive with checksum errors was repaired with SpinRite Level 4; Steve says writes at Level 4 are limited and not as dangerous to solid state media as feared.
- Twitter will let advertisers target users by off-Twitter activity and email addresses, with opt-out settings.
- Storage math: IBM estimates 2.5 quintillion bytes of data a day; listeners calculated that five zettabytes would need about a trillion terabyte-drives and 100,000 square feet seems too small, so Steve suggests tape or archival storage, or the NSA figure is not credible.
- A listener's rental application offered SSL upload but emailed the documents in the clear to the agent.
- Self-made certificates and PGP signing parties avoid trusting third-party CAs; Steve sees tools like Threema that exchange keys in person as the trend.
- Petraeus's shared Gmail drafts folder avoided mail leaving Google and illustrates metadata and tap avoidance.
- prism-break.org lists open-source alternatives to proprietary software; Chrome sync can propagate extensions between work and home machines, which is optional and granular.
