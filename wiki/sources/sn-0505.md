# Summary

After the RSA Conference, Steve reviews several disclosures. Skycure's iOS certificate-parsing flaw could repeatedly crash devices near a rogue Wi-Fi hotspot but was fixed in iOS 8.3 and was far from the headline claims. FireEye showed weaknesses in the fingerprint handling on Samsung Galaxy S5 and older Android versions, which Steve uses to caution that fingerprints are a convenience, not unspoofable secrets. Malwarebytes explained that CryptoWall spread for two months through malicious Flash ads on mainstream sites via the HanJuan exploit kit until Adobe patched a zero-day, and the campaign stopped the next day. Steve then reports that the popular iOS networking library AFNetworking defaulted to not validating the domain name in certificates, potentially affecting tens of thousands of apps including banking apps, and that a Yubico NEO had a PIN-validation logic error that led to free replacements. Other segments cover Amazon and Audi trunk delivery, an extended discussion of the ethics of ad blocking, a TrueCrypt installer fix for OS X 10.10, and personal asides. The ten listener answers cover brute-forcing unauthenticated encryption, hardware trust, SSD warranty returns, secure messaging with libsodium, NVMe and SpinRite, Wi-Fi location errors, removing RC4, SNI on shared hosts, TrueCrypt forks, and programming languages.

# Key points

- Skycure iOS flaw: parsing of a crafted certificate on a hotspot crashed iOS before 8.3 in a loop while in range; no permanent damage; AT&T devices auto-join a hotspot named for the carrier.
- FireEye talk on Android fingerprint security: data could be grabbed before reaching the trusted zone on Android 5.0 and older, the S5 exposed it more easily, and fake lock screens or enrolling extra prints were possible; Android 5.1.1 addressed it. Steve: fingerprints cannot be changed and can be compelled, so treat them as convenience.
- Malwarebytes: for two months from 10 December 2014 until the 2 February 2015 Flash patch, CryptoWall was delivered by malicious ads on sites such as news and how-to sites, targeting US residential IPs with no user action beyond Flash running. The campaign shut down quickly when the patch landed, showing criminals protect their infrastructure when payoff drops.
- AFNetworking (iOS) 2.x had validatesDomainName set to no by default, so any valid certificate for any domain would be accepted; an estimated 25,000 to 50,000 apps, including bank apps, were affected until fixed in a new release; SourceDNA offers a lookup tool but not a public list.
- YubiKey NEO (versions before 1.0.10) with the OpenPGP applet had inherited logic that used AND instead of OR in PIN checks, allowing operations without the PIN for a nearby attacker; Yubico replaced affected keys free of charge.
- Amazon, Audi and DHL pilot in Germany delivers parcels into car trunks with one-time keyless access; Steve is amused and notes keyless-entry bypass research for a later show.
- Ad blocking: sites earn from impressions, not only clicks, so blocking loses revenue; Steve prefers non-obnoxious ads and supports sites; Leo describes TWiT's limited ad policy and notes ads also carry malware risk.
- TrueCrypt 7.1a installer on OS X 10.10 refuses to install because of a version check that mishandles "10"; a few lines can be removed.
- Brute-forcing unauthenticated encryption requires heuristics such as checking that decrypted ASCII has no high bits set; Steve compares it with the Bombe that stopped on candidate settings.
- Hardware trust: drives and other devices made abroad contain firmware nobody can inspect; Steve thinks pressure may eventually favour open firmware.
- SSD warranty: SSDs often fail suddenly; ATA password-based drive encryption can be bypassed at the factory, so use external full-disk encryption before sending a drive back; smartphones raise the same issue.
- Secure messaging design: use a key server for public keys, a random symmetric key for the message, public-key encryption for that key, and a signature; libsodium (a portable NaCl) provides this, and there is a libsodium book on GitBook. Leo promotes Keybase for key verification.
- NVMe: new SSDs use a parallel NVMe interface instead of AHCI; Steve says SpinRite 6.1 enumerates the PCI bus and drivers like NVMe will come in later 6.x releases.
- Wi-Fi location can be wrong, for example when a plane's Wi-Fi provider is registered at its head office; Steve compares it to heuristics with false positives.
- RC4: Banks put RC4 first because it was the recommended mitigation for BEAST-style attacks on block-cipher modes (later followed by other attacks). Steve notes Windows allows disabling RC4 through registry settings, a Firefox developer build was disabling it, and SSL Labs planned to downgrade then fail servers still offering it by September.
- SNI (Server Name Indication) removes the old requirement of one IP address per HTTPS site; Leo reports TWiT will move to HTTPS everywhere using an EV certificate.
- TrueCrypt forks: the license forbids modification, but with the authors gone people proceed anyway.
- Leo discusses his programming path (assembly, C, Forth, now Common Lisp); Steve advises learning a language by solving a real problem.
