# Summary

Leo is back from vacation. Steve starts with the Presidential Alert test (now October 3) and Chrome's continuing address-bar experiments: the www prefix, a "file" chip for file URLs in Chrome 70, and Google search results briefly dropping www. Palo Alto Networks described Xbash, a Python worm packaged with PyInstaller that mines coins, builds a botnet on Linux, and deletes databases while demanding ransom it cannot honor. Trend Micro's Zero Day Initiative published a Windows Jet database engine exploit after Microsoft missed its deadline, Sabri Haddouche launched ReaperBugs.com to crash Chrome, Safari and Firefox with CSS tricks, and cryptographer Matthew Green announced he is leaving Chrome over automatic sign-in, for which an "Ungoogled Chromium" build exists. Securify's 19-month-old, ignored report of a Western Digital My Cloud authentication bypass was fixed within three days of publication. Further stories include Eric Schmidt's prediction of two Internets, unwiped servers from the bankrupt NCIX sold on Craigslist, the UK maximum fine on Equifax, and the new US ban on credit-freeze fees. The topic of the day is encrypted SNI, which Cloudflare deployed using a DNS-published public key.

# Key points

- Chrome 69 "identity consistency" signs the browser into the user's Google identity when logging into a Google service, without turning on sync; it can be disabled in chrome://flags; Green and others object to the lack of notice; Leo argues it matches user expectations.
- Chrome 70 will show file URLs as a "file" chip; Google tested hiding www in search results; Apple and Safari already shorten displayed addresses by default.
- Xbash: a self-spreading Python malware for Windows, Linux and macOS, linked to a Chinese-speaking APT; on Linux it brute-forces exposed services (databases, VNC, Telnet, RDP, Elasticsearch), deletes databases and posts a ransom note; about 48 victims paid roughly 6,000 dollars with no recovery. Steve's advice: never expose services that need not be public, and use random machine-only credentials.
- Jet database engine: Trend Micro's May 8 report, confirmed May 14, missed September Patch Tuesday, so a proof of concept was released September 20.
- ReaperBugs.com offers Reap Chrome, Reap Safari and Reap Firefox using nested CSS blending; Steve prefers resource controls to special-casing individual tricks.
- Ungoogled Chromium is a patch set that removes Google service integration and prebuilt binaries; third-party binaries exist for several OSes.
- Western Digital My Cloud NAS: a CGI call with flag=1 plus a username=admin cookie created an admin session without credentials; reported April 2017, ignored until public disclosure on September 18, 2018, patched in about three days.
- Exploitee.rs wiki collects hacks of old consumer devices such as Blu-ray players.
- Eric Schmidt expects a Chinese-led and an American-led Internet within a decade; Steve is skeptical because of economics, comparing to the global telephone system.
- NCIX bankruptcy: servers with 13 TB including card details of 258,000 customers were offered for 15,000 dollars; Leo recalls 2003 research on used drives.
- Equifax received the UK's maximum 500,000 pound fine; a new US law makes credit freezes free and extends fraud alerts to a year.
- Encrypted SNI: the Client Hello's server name is encrypted with a public key published in a DNS TXT record, authored by Rescorla, Oku, Wood and Sullivan; Cloudflare runs a test deployment for TLS 1.3 clients.
