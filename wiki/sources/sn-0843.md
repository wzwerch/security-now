# Summary

Jason Howell fills in for Leo. Steve counts two more actively exploited Chrome zero-days (CVE-2021-38000 and CVE-2021-38003), bringing the 2021 total to a record 16. Mozilla dealt with two malicious Firefox add-ons ("Bypass" and "Bypass XM") that abused the proxy API on about 455,000 installs to block Firefox updates, and added a fallback so update traffic bypasses add-on proxies. Steve then vents about Microsoft: October's updates again broke network printing (admins are swapping spooler DLLs by hand), a researcher showed that the fix for a profile-service privilege escalation only addressed the proof of concept, Windows 11 eligibility is decided by a machine-learning model, and the PC Health Check app is force-installed via Windows Update. Adobe shipped an out-of-band update fixing 92 flaws in 14 products, and DDoS extortion against VoIP providers continues. After listener feedback and SpinRite 6.1 pre-release benchmarks, the main topic is "Trojan Source": a Cambridge paper showing that Unicode bidirectional control characters can make source code look different to a reviewer than to the compiler, in many languages.

# Key points

- Chrome 95.0.4638.69 fixes two in-the-wild zero-days found by Google TAG: CVE-2021-38000 (insufficient validation of untrusted input in Intents) and CVE-2021-38003 (inappropriate implementation in V8), plus a use-after-free in WebTransport first shown at China's Tianfu Cup. This makes 16 Chrome zero-days for the year, the most since 2008; Steve attributes this to Chrome's dominance rather than poor quality, though he notes one fix took weeks after the report.
- Mozilla's "Securing the proxy API" post: add-ons "Bypass" and "Bypass XM" (455,000 users) used the proxy API to cut Firefox off from updates and block lists. Firefox 91.1 falls back to a direct connection for essential requests, a "Proxy Failover" system add-on was shipped, and add-ons using the proxy API must now declare it. Users of those add-ons should remove them.
- October's Windows updates (KB5006670 for Windows 10, KB5006674 for Windows 11) broke printing to shared network printers (errors 0x6E4, 0x7C, 0x709) on nearly every supported Windows version; admins replaced localspl.dll, win32spl.dll and spoolsv.exe with older copies, which gives up PrintNightmare mitigations.
- Researcher Abdelhamid Naceri published a new local privilege-escalation proof of concept showing Microsoft's August fix for CVE-2021-34484 (User Profile Service) only blocked the original demo, not the underlying bug; it needs a second account. Steve sees a pattern of patching symptoms and treating researchers as an annoyance.
- Microsoft says it uses a "latest generation machine learning model" to decide which Windows 10 devices are offered Windows 11; PC Health Check and Windows 11 Setup even disagreed on one machine. KB5005463 pushes PC Health Check onto Windows 10 and reinstalls itself after removal.
- Adobe released an out-of-cycle fix for 92 vulnerabilities (66 critical) across 14 products including Illustrator, Photoshop, Premiere and the XMP Toolkit; none were known to be exploited.
- DDoS extortion against VoIP providers (Voipfone, VoIP Unlimited, VoIP.ms, upstream Bandwidth.com) continues for weeks, with knock-on effects on police and NHS services; privacy-focused email providers were also targeted. Steve points out that missing egress filtering lets botnets spoof source addresses.
- Trojan Source (Boucher and Anderson, University of Cambridge): invisible Unicode Bidi override and isolate characters (RLI, LRI, PDI and others) reorder how code is displayed without changing what compilers see. Working examples exist in C, C++, C#, JavaScript, Java, Rust, Go and Python; a homoglyph variant also exists. Two CVEs were issued, and the authors disclosed to 19 vendors with a 99-day embargo; nine committed to patches and five paid bounties averaging about $2,246.
- A GitHub scan of commits found a few uses of similar techniques, such as concealing a call inside Ruby code. Recommended defenses: compilers and editors should reject or flag unterminated Bidi characters in comments and strings, and repositories and build pipelines should warn about them.

# Other segments

- Listener feedback: why swords are used in Dune (lasguns plus personal shields cause an explosion), a clarification that Microsoft's "SPM" means Security Program Manager, and more on exit-intent pop-ups.
- SpinRite 6.1 pre-release five benchmarks: a 1 TB SATA SSD completes a Level 2 scan in about 30 minutes, a 6 TB hard drive in about 9.3 hours, USB drives are much slower until the planned 7.1 release; a variable-name bug causing large-drive errors was found. SpinRite is moving off DOS to a 32-bit OS to support UEFI-only systems.
- Picture of the Week: PC Health Check says a Core i7 PC meets Windows 11 requirements while Windows 11 Setup says it does not.
