# Summary

On the show's ninth anniversary Steve explains the previous week's partial Internet outage, which also hit LastPass, eBay and Twitter. A Verizon mistake de-aggregated routes it normally advertised as one block and released about 170 extra prefixes into the global table; older Cisco Catalyst 6500 and 7600 routers, whose default memory partition holds 512,000 IPv4 routes, overflowed their fast TCAM and fell back to slow software lookup, causing patchy failures until the routes were withdrawn. Steve uses it to teach packet switching, address classes, CIDR, autonomous systems, longest-prefix match and why aggregation keeps routing tables small, noting the fix is a configuration change (IPv6 entries take two slots) and that Cisco had warned customers in May. News: researchers will present the "Gyrophone" attack, using smartphone inertial sensors sampled at 200 Hz on Android (Firefox lets sites read them at full rate) to recognise spoken digits with about 65 percent accuracy, speaker gender with about 85 percent; Delaware passed a law giving fiduciaries access to a dead person's digital assets; the HTTP Shaming site lists sites that lack HTTPS; Java now has an option to suppress sponsor offers; and a Microsoft update with font handling problems that broke restarts was withdrawn. Leo asks whether TWiT needs HTTPS after a demonstration of man-in-the-middle malware injection into a video; Steve says personalised sessions and forms must be secure, but ultimately only universal HTTPS prevents tampering. Steve reflects on how hard secure coding is (zeroing sensitive data on the stack) and explains SpinRite's origin: tower drift, low-level reformatting for interleave, and aggressive data recovery.

# Key points

- The outage: Verizon ASNs 701 and 705 leaked more-specific routes, pushing the global table past 512K entries; affected routers lost hardware forwarding; healed when routes were removed. Cisco's May advisory recommended repartitioning TCAM (for example 768K IPv4 and the rest for IPv6).
- Routing background: addresses carried in packets abstract connections; Class A, B and C simplified routing tables; CIDR (mid-1990s) allowed arbitrary prefix lengths; ASNs went from 16 to 32 bits; disaggregation of portable blocks forces extra global entries; longest prefix match chooses the most specific route.
- The IPv6 global table was only about 10,000 entries then and its larger space should reduce fragmentation.
- Gyrophone: Android Chrome and Safari cap sensor access at 20 Hz but Firefox does not; iOS samples at 100 Hz; results show digit, gender and speaker recognition, so lowering rates or requiring permission is proposed.
- Delaware HB 345 (from the Uniform Law Commission's UFADAA) treats digital accounts as assets heirs may access; Facebook offers memorialised accounts instead; Steve hopes a will can override it.
- HTTP Shaming (Tumblr) publicises sites using plain HTTP for logins or personalised content, with fast responses from TripIt and 1Password.
- Steve: static public pages less needy, but forms and personalised sessions must be HTTPS; GRC is in Chrome's preload list; StartSSL offers free one-year certificates though not universally trusted.
- Java's control panel now has "Suppress sponsor offers when installing or updating Java."
- Microsoft pulled a security update that, with font location issues, caused boot failures.
- SQRL: printed identity page with QR code and text, Android client interchanges identities; Steve insists on zeroing decrypted data before exit and verified OpenSSL-derived library code wipes buffers.
- SpinRite history: began after a failed servo drive was revived by tilting it (tower drift); early tools measured interleave; SpinRite re-low-level formatted tracks at optimal interleave, improving speed about fourfold, while using exhaustive data recovery (randomised head steps, "give me what you've got") and defect analysis; interleave code removed in SpinRite 5.
