# Summary

Leo records from Hawaii. Steve opens with a note that DigiCert suffered a breach in which about 30 EV code-signing certificates were fraudulently issued after a malicious screensaver reached support staff PCs, and promises coverage next week. The first story is Cybernews' discovery that the operators of the carding-validation service "Jerry's Store" used the Cursor AI coding assistant to build a dashboard and, because they never asked for authentication, exposed data on about 345K cards. The UK NCSC's CTO then warned organizations to prepare for a "vulnerability patch wave" caused by AI exploiting technical debt, which leads Steve to ask why CISA has been silent; an Axios scoop says CISA lacks access to Anthropic's Mythos, tied to politics around the Pentagon-Anthropic feud. A new Linux kernel local privilege escalation (found by Theori's AI) gives root through a four-byte page-cache write. Steve then analyzes how AI is breaking the bug bounty model (Internet Bug Bounty paused, curl and Node.js dropping payouts) and predicts bounties will fade as altruistic AI-assisted reporting suffices. Anthropic's Claude Security (a "mini Mythos" on Opus 4.7) enters public beta for enterprises, and OpenAI adds opt-in Advanced Account Security for ChatGPT with passkeys or hardware keys only. After a SyncTrayzor v2 tip, the main topic is Google's Chrome Prompt API and bundled Gemini Nano model, which Mozilla opposes on interoperability and terms-of-use grounds; Steve sides with Mozilla.

# Key points

- DigiCert breach teaser: roughly 30 EV code-signing certificates minted fraudulently via a social-engineering attack with a malicious screensaver on two support PCs, aggravated by an endpoint-security misconfiguration; DigiCert's post-mortem is praised as exemplary.
- Jerry's Store (carding market, admin apparently Chinese-speaking, hosted in Germany) used Cursor to build a stats dashboard; Cursor created an unauthenticated open web directory. About 145K valid and 200K invalid cards were exposed; cards sell for $7 to $18 each. Validation is done via low-value actions on big merchants (Amazon, Grubhub, Temu, Lyft). Lesson: AI builds what you ask for, not what you forgot to ask.
- UK NCSC CTO Ollie Whitehouse: expect a "forced correction" of technical debt; shrink the external attack surface first, enable automatic and hot patching, plan for frequent scaled updates, replace end-of-life gear, use risk-based prioritization such as SSVC, and adopt "update by default". Steve adds: make sure vendor update notices reach a human fast.
- Axios: CISA has no Mythos access (while CAISI and the NSA do), CISA has lost over a third of its staff, and the White House blocked Anthropic's expansion to 70 more organizations; Steve blames the Pentagon's "supply chain risk" designation of Anthropic after it refused to drop limits on mass surveillance and fully autonomous weapons. Leo notes reports of plans for government pre-approval of AI models.
- Linux "copy fail"-style local privilege escalation (CVE rated 7.8) found by Theori's AI-assisted system: an unprivileged user can write four bytes into the page cache of any readable file and gain root; a tiny public PoC exists. Debian, Ubuntu and SUSE patched quickly and Red Hat reversed its deferral.
- Internet Bug Bounty (HackerOne, since 2012, 80/20 split between researcher and project) paused new submissions in March because AI-driven discovery outpaces remediation. Daniel Stenberg: convincing AI slop is like a denial-of-service attack on maintainers; after curl dropped payouts the slop vanished but high-quality reports increased. Node.js also ended its bounty. Casey Ellis (Bugcrowd) says disclosure should become a baseline, rewards narrower. Steve predicts bounties wind down after Netscape's 1995 pioneering program as AI makes bug hunting fun and the stock of bugs is exhausted within months.
- Claude Security (formerly Claude Code Security): public beta for Claude Enterprise, uses Opus 4.7, traces data flows across files, gives confidence ratings, patch instructions, scheduled and directory-scoped scans, CSV/Markdown export and webhooks; partners CrowdStrike, Microsoft, Palo Alto, SentinelOne, Wiz and others embed Opus 4.7.
- ChatGPT Advanced Account Security (opt-in): passkeys or hardware keys only, password login disabled, email and SMS recovery disabled (OpenAI support cannot help recover), shorter sessions, login alerts, automatic training exclusion, YubiKey bundle via Yubico. Steve praises it as a model for the industry.
- Syncthing: SyncTrayzor v1 was archived in August; the maintained fork SyncTrayzor v2 (by GermanCoding) is recommended by Syncthing, and Syncthing v2 works alongside v1.3 installs.
- Chrome Prompt API: a JavaScript API (also in Edge, via the W3C Web Machine Learning Community Group) that lets pages prompt a browser-provided model; Chrome downloads Gemini Nano (about 4.3 to 4.7 GB, originally 22 GB recommended space) with no off switch. Mozilla (Jake Archibald) opposes it: interoperability risk because prompts are model-coupled, the requirement to accept Google's Generative AI Prohibited Uses Policy sets a bad precedent, and developer demand is overstated. Google's Rick Byers shares some concerns but prefers experimentation. A February report found Nano and Phi-4 mini often failed tasks (hallucination 6 to 17 percent).
- Steve's view: web standards should not be rushed or tied to one vendor's non-deterministic model and Flash-like legacy would follow; Leo adds that Mozilla now has an "Disable all AI features" switch and that Google dominates browser standards unilaterally.
