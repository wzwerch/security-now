# Summary

Steve starts with Microsoft's odd decision to push the Chromium-based Edge browser to Windows 7 and 8.1 consumer machines via Windows Update, then covers Google disabling 106 of 111 malicious Chrome extensions (about 33 million downloads) that Awake Security tied to one domain registrar. Zoom's third attempt to explain end-to-end encryption is critiqued: E2EE will be an optional add-on for all tiers with phone verification for free users. Microsoft released optional out-of-band updates for the June printing breakage. VLC 3.0.11 fixes a severe buffer overflow. Russia lifted its ineffective Telegram ban after an unspecified agreement. A zero-day in the web server shared by 79 Netgear router models allows root command execution from the LAN, even through a malicious web page. AWS disclosed a record 2.3 Tbps DDoS using CLDAP reflection. Steve announces the InitDisk freeware spun off from SpinRite work. The main story is Ripple20: 19 vulnerabilities in the Treck embedded TCP/IP stack, present in hundreds of millions of devices that will mostly never be patched.

# Key points

- KB4567409 installs the new Edge on Windows 7/8.1 Home-class editions, pins it to the taskbar and does not change the default handler; Windows 10 and 7 together were about 82% of desktops.
- Awake Security found 111 malicious Chrome extensions with about 33 million installs, 15,000+ domains, all registered via one registrar (GalComm); they captured screenshots, clipboard, cookies and keystrokes. Google disabled 106 in users' browsers. Steve's advice: every add-on adds risk, so prune extensions and apps.
- Zoom: AES-256 GCM transport encryption stays the default; E2EE beta planned for July, optional per meeting, free users must verify a phone number. Steve and Leo doubt anyone will trust Zoom's messaging after the earlier confusion.
- Microsoft shipped optional out-of-band updates (KB4567512/513/514 and later ones) for print spooler crashes; Steve criticizes making fixes optional when the breakage was forced.
- VLC 3.0.11 patches a buffer overflow in the H26X packetizer reachable with a crafted media file.
- Roskomnadzor lifted the Telegram ban from April 2018 after talks with Pavel Durov; details are not public. The earlier botched block hit about 19 million cloud IPs.
- Netgear: a stack buffer overflow in the HTTPD firmware-upload parsing (copy length taken from user input) affects 79 models and 758 firmware images dating to 2007; no stack cookies or ASLR, and it triggers before the CSRF check, so a malicious web page can exploit it. Found independently by GRIMM and VNPT ISC via ZDI; Netgear had fixed only 8 models when recorded. Keep remote administration off; Steve relies on a pfSense firewall.
- AWS Shield mitigated a 2.3 Tbps attack using CLDAP reflection (56-70x amplification), beating the 1.7 Tbps and 1.3 Tbps memcached records. Cloudflare noted 92% of attacks are under 10 Gbps.
- Errata on the show's age: episode 780 starts year 16; Steve calculates episode 999 landing around November 2024.
- InitDisk: new GRC freeware that rebuilds USB drives, can create bootable FreeDOS, written in assembler; a listener revived a "dead" 8 GB stick. A bare-metal storage benchmark is next.
- Ripple20 (JSOF): 19 flaws in Treck's TCP/IP stack, four critical (CVSS over 9) including IPv4/IPv6 length-handling and DNS issues; packets look valid, bypass NAT/firewalls and need no user interaction. Affected vendors include Cisco, HP, Intel and many industrial and medical makers. Disclosure was extended beyond 120 days. Mitigation is limited to network isolation and perhaps dropping fragmented UDP at the router.

# Other segments

- Steve shares a 1973 college dorm photo; discussion of Pentium 4 lacking NX blocking Windows 10 on an old test machine.
- GRC DNS Benchmark at nearly 5.8 million downloads; new GRC forums planned.
