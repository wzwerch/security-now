# Summary

A lighter news week lets Steve and Leo run a listener-feedback show while saving Apple's new security white paper for the next episode. News items: Bruce Schneier's remark that Apple's "goto fail" bug is exactly what a deniable backdoor would look like, with Steve and Leo pointing out the timing relative to Apple joining PRISM and Apple's silence on how the line got in; a fresh certificate-validation bypass in the GnuTLS library (fixed in new releases, widely used by Apache builds, Exim, Wireshark, CUPS and others); the Guardian's report that GCHQ with NSA help captured webcam stills from Yahoo chats in bulk under the Optic Nerve program; web.de and GMX tricking Firefox and Chrome users into removing ad blockers with fake alerts; Mt. Gox's formal bankruptcy and the Flexcoin hot-wallet theft of 896 bitcoin; and a Threema PIN-retry bypass on iOS. Steve also announces plans to internationalize SQRL with the Crowdin translation service. In the Q&A he explains NTP-monlist abuse notices, why one cannot forward the same ports to three Xboxes without UPnP, how SQRL differs from FIDO U2F and UAF, how a standard-user XP machine can stay in service after April 2014, and how to reuse SQRL's core signing idea inside an app.

# Key points

- Schneier: a one-line deniable bug like goto fail fits his criteria for a good backdoor (low discovery chance, deniability, minimal conspiracy). Steve notes Apple has not explained how it happened, and that Apple behaves like a consumer-product company in how little it discloses.
- GnuTLS flaw: a specially crafted certificate could bypass validation in all versions; fix in 3.2.12 and 3.1.22, or a patch for 2.12.x. Affected software includes Apache with GnuTLS, GNOME, Exim, Wireshark, Mutt, Lynx and CUPS. The discoverer (a Red Hat audit) called the code messy; Steve says OpenSSL is not much better.
- Optic Nerve: GCHQ saved a still image every five minutes from Yahoo webcam chats, over 1.8 million accounts in a six-month 2008 period, regardless of targeting, with NSA tools (XKeyscore) involved; roughly 11 percent of sampled images were sexually explicit, which GCHQ struggled to keep from analysts. Yahoo called it a new level of privacy violation.
- web.de and GMX showed a fake browser warning to induce users to uninstall ad blockers; Steve says sites may ask visitors to whitelist them but should not deceive them (the fake alert scrolls with the page, unlike real browser UI).
- Mt. Gox filed for bankruptcy; Coinbase's CEO argued Bitcoin's value is as an open payment network and that Overstock reported larger average baskets in bitcoin. Flexcoin shut down after losing 896 bitcoin from its hot wallet; cold-storage customers were to be repaid. Steve's lesson: keep coins offline and distrust exchanges.
- Threema bug (iOS): its optional PIN lock deletes data after ten failed tries, but only after the user dismisses a dialog, so killing and restarting the app allowed unlimited guesses. Steve notes similar timing pitfalls in SQRL design.
- NTP attack fallout: a listener hosting five of the roughly 45,000 abused NTP servers received an abuse notice; Steve points out victims can see the real addresses of reflectors, so they can notify owners.
- Xbox and UPnP: forward ports to only one internal IP at a time, so put the extra consoles behind their own NAT router and let UPnP work only inside that subnet.
- Password masking has legitimate uses (projectors, screen sharing); SQRL will mask by default with a Show toggle.
- FIDO versus SQRL: U2F is a second factor where the site stores the encrypted private key for each credential; UAF is very complex and based on the P-256 curve; SQRL derives a per-domain key pair from one master key using Ed25519-style curves, so there is no per-site secret to store.
- Windows XP after April 8, 2014: Steve says careful users (standard account, NoScript, no Flash or Java, NAT router, firewall) need not panic; Leo worries attackers are stockpiling exploits.
- Tinc VPN is a free, decentralized mesh VPN suggested by a listener as an alternative to Hamachi.
- Foxit Reader's installer reportedly bundled extra software and changed the home page; Steve warns that the Firefox built-in PDF viewer is still immature.
- A listener claims a freshly installed Java stays browser-enabled if it was enabled before; Steve concedes his earlier reading of the install dialog was wrong.

# Other segments

- SpinRite testimonial: a nonprofit's old NAS drive with important documents recovered; Leo's sponsor mention of Carbonite omitted.
- SQRL: all UI text will be moved to a separate string file and translated via Crowdin; a few UI panels remain before coding starts.
- Leo and Steve discuss the railroad puzzle game Rails; Steve mentions the EFF-recommended proxy vote at Apple shareholders.
