# Summary

In his third episode with Father Robert Ballecer as co-host, Steve covers a Patch Tuesday that includes fixes for further zero-days found in the leaked Hacking Team data (Flash, Internet Explorer, plus a separate Java fix). He explains why Flash should be removed from browsers, debating with Padre whether JavaScript would simply become the next target. A Hacking Team UEFI BIOS rootkit that reinstalls its agent after a disk swap is described, with the mitigation being enabled Secure Boot, current firmware and a BIOS password. An OpenSSL flaw in certificate chain retry logic, found by Google engineers and introduced only weeks before the fix, is explained as having had almost no real-world exposure. Steve summarizes a 34-page paper by eleven prominent cryptographers arguing that government "exceptional access" would undermine forward secrecy and raise unresolvable jurisdiction questions. The OPM breach turns out to include at least 1.1 million fingerprint images. The bulk of the episode is a detailed refresher on SQRL after 92 weeks of development: a master identity keyed hash producing per-site elliptic curve keys, challenge signing, a one-time-written rescue code, EnScrypt password protection, identity lock and rekeying.

# Key points

- **Hacking Team leak follow-up:** FireEye found a second Flash zero-day inside the 400 GB dump, which was quickly adopted by multiple attack groups (including ransomware delivery); Flash 18.0.0.209 fixes it; Mozilla briefly blocked old Flash versions.
- **Patch Tuesday:** a dozen Microsoft bundles including an IE zero-day from the leak, plus Adobe and Oracle Java updates.
- **Flash future:** Steve says JavaScript plus HTML5 can do everything Flash did; OccupyFlash.org is mentioned; Padre argues attackers will just move to the next target. Steve favors layered defenses (no gratuitous Flash, script blocking, accepting residual risk on trusted sites).
- **Hacking Team UEFI rootkit:** works on Insyde UEFI BIOS (laptops from several vendors) when Secure Boot is off and typically needs physical access; adds NTFS and boot-hook modules that reinstall its scout/soldier agents on reboot. Trend Micro's advice: enable Secure Boot, update firmware, set a firmware password. Padre found most of his lab laptops had Secure Boot disabled; out-of-band management features raise remote-attack worries.
- **OpenSSL fix:** a bug in how failed certificate-chain building leaked state into the retry could let a forged certificate appear valid in versions 1.0.1 and 1.0.2 released only about four weeks earlier; found by Adam Langley and David Benjamin; browsers use their own libraries and major distributions had not yet adopted the code.
- **"Keys Under Doormats"-style paper (eleven experts, 34 pages):** exceptional access mandates would reverse forward secrecy practice, create complexity-driven flaws, and raise unanswerable questions about which governments get keys; law enforcement has not given concrete requirements. Steve argues the ephemeral-key technology already exists globally so bans would only affect law-abiding users.
- **OPM breach:** at least 1.1 million of the 21.5 million records included fingerprint images, which cannot be changed; Steve contrasts this with Apple's hashed feature templates.
- **Windows 10 WiFi Sense:** reports differ on whether the latest preview build enables it by default; Padre's clean install had it off.
- **Adblock Plus bandwidth study:** a small Canadian university trial found 25 to 40 percent bandwidth savings; page-load anecdotes about tracking protection.
- **SQRL walkthrough:** per-site private keys derived with an HMAC keyed by the master identity; the public key is the site identity; login is signing a server challenge; no secrets stored at sites; 24-digit rescue code never stored; password-protected identity via EnScrypt (memory-hard, about five seconds); identity lock plus disable/re-enable and atomic rekeying for compromise recovery; open protocol with client and server implementations by volunteers.
