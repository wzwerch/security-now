# Summary

Leo returns after a month away. Steve shares a video of programming-language popularity over time, then covers November Patch Tuesday (73 fixes, including an actively exploited Internet Explorer scripting zero-day) and the approaching end of free Windows 7 patches, criticizing Microsoft's choice to sell security fixes only to enterprises. Checkra1n continues to mature through new betas. GitHub launches the Security Lab, with CodeQL made free for open source, a public advisory database and industry partners. A Boston federal court ruled suspicionless border searches of devices unconstitutional. A WhatsApp MP4 metadata overflow, ZombieLoad v2 against Intel's newest architecture, and the formation of the Bytecode Alliance around WebAssembly follow. The main topic is TPM-Fail: timing leaks in the ECDSA implementation of Intel's firmware TPM (patchable, remotely exploitable against a VPN) and in STMicroelectronics' hardware TPM (not fixable in existing chips, local only).

# Key points

- Programming-language ranking animation (grc.sc/languages) from Fortran dominance in 1966 to Python and JavaScript leading in 2019.
- November Patch Tuesday: 73 fixes, 13 critical; an IE scripting-engine zero-day exploited in the wild, also reachable through Office documents with ActiveX; nine Hyper-V fixes (four critical); Intel now aligns its patches with Patch Tuesday. Only December and January updates remain for Windows 7/Server 2008 outside paid ESU; a chart shows consumer usage skewing to Windows 10 while businesses stay on 7.
- Checkra1n reached beta 0.9.5 and is reportedly stable; it is tethered and not persistent across reboot, and unsigned code cannot survive because the secure boot chain remains intact afterward; risk is limited to a device briefly out of your control, so power-cycle it; newer A12/A13 devices are immune.
- GitHub Security Lab (with partners including Google, Intel, Microsoft, Mozilla, Trail of Bits, NCC Group, HackerOne, F5, Okta and others): free CodeQL, GitHub Advisory Database and API, private coordinated advisories, CVE requests and automated security update pull requests; statistics cited: 40% of new open source vulnerabilities lack a CVE at announcement, 70% of critical ones remain unpatched after 30 days, and security staff are outnumbered about 500 to one.
- Alasaad v. McAleenan: a Boston federal court held suspicionless warrantless device searches at US borders unconstitutional, requiring individualized suspicion of contraband; Steve notes secondary inspections still permit some searches.
- WhatsApp (CVE-2019-11931): a stack overflow in MP4 metadata parsing allowed remote code execution from a crafted video sent to a phone number; patched in new versions of all platform clients; earlier reminders of the NSO Group's WhatsApp-based Pegasus infections and a GIF library bug.
- ZombieLoad v2 (TAA / machine check related, covered by Intel advisory and Microsoft guidance) affects even Intel's Cascade Lake; Steve stresses no real-world exploitation in two years and a performance cost estimated up to 40% when mitigations are on.
- Bytecode Alliance (Mozilla, Fastly, Intel, Red Hat): generalizing WebAssembly into a secure-by-default, architecture-neutral runtime to make untrusted dependencies safer.
- TPM-Fail (tpm.fail): timing analysis of TPM 2.0; Intel fTPM leak allows 256-bit ECDSA/EC-Schnorr key recovery after about 1,300 observations in under two minutes; a remote attack recovered a strongSwan VPN server key after about 45,000 handshakes; STMicroelectronics hardware TPM leaked with fewer than 40,000 observations locally only; Infineon and Nuvoton chips were unaffected. Intel patched firmware; STMicro cannot patch deployed chips; Microsoft does not use ECDSA from the TPM for core features such as BitLocker.
