# Summary

Chrome 85 begins rolling out DNS-over-HTTPS on Android, upgrading automatically when the current resolver supports it. Firefox 82 will block drive-by downloads from sandboxed iframes, matching Chrome. Threema announced investment and plans to go fully open source with reproducible builds and multi-device support. A trivial flaw in the WordPress File Manager plugin, caused by a mistakenly renamed connector file, exposed hundreds of thousands of sites to takeover, with tens of thousands of attacks per hour. Facebook published a vulnerability disclosure policy for third-party code (21 days to respond, 90 days to fix) and a WhatsApp advisories page, CISA finalised a directive requiring US agencies to publish disclosure policies by early 2021, and Tor launched a membership program. Steve is not installing Intel's latest microcode. A small randomized trial on Vitamin D and COVID outcomes is mentioned. The main segment covers why IoT devices should be isolated after Steve bought several cheap cloud-connected devices, with concrete options.

# Key points

- Chrome for Android (Chrome 85) uses DoH automatically with known providers, falls back to regular DNS, offers manual configuration, and is disabled in managed environments; providers must scale for persistent HTTPS sessions.
- Firefox 80.0.1 fixed regressions; Firefox 82 will stop scripts in sandboxed iframes from triggering downloads unless the iframe allows downloads, as Chrome has done since 2019. Steve also sets Chrome to ask where to save downloads.
- Threema: new investor with founders retaining ownership; apps to become open source with reproducible builds and independent review; multi-device support planned without storing personal data on servers. Steve and Leo prefer it since no phone number is required and keys are user-managed (verification via QR public-key exchange).
- WordPress File Manager (v6.0 to 6.8, 700,000 installs): a development file named connector-minimal.php-dist was shipped renamed as .php and ran without access checks; v6.9 removed it; attacks grew to about 10,000 per hour and only a small share of sites had updated within days. Steve advises sequestering PHP-based servers from the internal network.
- Facebook disclosure policy: contact the maintainer, 21 days to acknowledge, 90 days to fix, with exceptions for active exploitation; CVEs requested where needed. WhatsApp advisories page lists CVEs because app-store notes are limited.
- US government: agencies must publish vulnerability disclosure policies by the end of Q1 2021 under a CISA directive; timelines are targets, not mandatory remediation deadlines.
- Tor Project membership program for organizations, with founding members including Avast, DuckDuckGo, Mullvad and Team Cymru, to give unrestricted funds faster than grant cycles.
- Intel microcode for many processor families (excluding Ice Lake) was repackaged by Microsoft but not pushed automatically; Steve sees little reason to install it given the lack of in-the-wild exploits and performance cost, and again suggests high-performance versus zero-leakage CPU families.
- A Spanish randomized double-blind study of 76 patients (published in JAMA) reported far fewer ICU admissions and deaths among those given Vitamin D; Steve links it as the shortcut of the week.
- IoT isolation: Steve bought a WiFi thermostat, a logging thermometer and smart plugs from cloud-dependent vendors; each makes a persistent outbound link he cannot inspect. Options: (1) router guest WiFi with no LAN or management access; (2) a spare 2.4 GHz-only access point on its own subnet via a router with separate interfaces (pfSense, Ubiquiti EdgeRouter X); (3) the two-NAT-router layout with insecure devices on the outer router; also disable UPnP, use an unguessable router admin login, and consider disabling the 2.4 GHz radio on the main network. Because the devices work through vendor clouds, isolation does not break phone control.

- SpinRite: the older IDE/ATA benchmark code was updated; AHCI and IDE drivers will be combined soon for broader testing.
