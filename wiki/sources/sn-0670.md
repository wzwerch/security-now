# Summary

Steve introduces VirusTotal and the case of a PDF carrying two undisclosed zero-days (an Acrobat JavaScript flaw and a Windows kernel privilege escalation) uploaded in March and patched in May; he suspects the upload may have been a deliberate test that no antivirus knew the exploit. Researchers from Ruhr University Bochum and NYU published "aLTEr", showing LTE's radio link encrypts user data in counter mode without integrity protection, so a fake cell tower can alter known fields such as DNS server addresses; the flaw cannot be patched and may carry into 5G, mitigated mainly by TLS above. Aleph Security showed browser Spectre mitigations in Edge, Chrome and Safari only slow information leakage to about one bit per second, while Firefox's approach held. UPnP-exposed routers now let DDoS attackers randomize source ports, defeating simple port-based filters. An unpatched WordPress path-traversal flaw needs an authorized poster. The episode ends with the WPA3 announcement: SAE replaces PSK, forward secrecy, opportunistic encryption for open networks (OWE), and QR-code based Easy Connect.

# Key points

- VirusTotal: free service running uploads through 70-plus AV engines; ESET spotted the anomalous PDF, Microsoft confirmed two zero-days with no final payload. Steve argues attackers may have uploaded it to test detection before a short spear-phishing run, noting the roughly 60-day patch window.
- aLTEr: three layer-2 LTE attacks; two passive (identity mapping, website fingerprinting via traffic patterns) and one active in which known plaintext positions in AES-counter-mode traffic can be XOR-modified to redirect DNS to an attacker's server. Requires a man-in-the-middle fake cell tower. 5G offers optional authentication, which downgrade attacks can bypass; the Diameter protocol replacing SS7 shows similar misconfigurations.
- Steve's takeaway: pervasive TLS with certificates is the real protection above insecure lower layers; he previews EFF's STARTTLS Everywhere initiative for the next episode.
- Spectre in browsers (Aleph Security): timer resolution reduction, jitter, SharedArrayBuffer removal and index masking only slow attacks; a proof of concept still reads about 1 bit per second in Edge, Chrome and Safari; Firefox was not defeated. The authors question whether such mitigations should remain.
- DDoS evolution: reflection attacks (DNS, NTP) are easy to block by source port; botnets now abuse UPnP-exposed routers to randomize ports, making floods harder to filter. GRC's ShieldsUP! UPnP test is again recommended.
- WordPress: a thumbnail-deletion path traversal known since November lets someone with posting rights delete core files; limited risk, a community hotfix exists.
- WPA3 (expected late 2019): SAE (Simultaneous Authentication of Equals) resists offline dictionary attacks related to KRACK on WPA2-PSK; forward secrecy; a 192-bit Enterprise mode; Opportunistic Wireless Encryption (RFC 8110) for open Wi-Fi; Wi-Fi Easy Connect using QR codes carrying a device public key. The spec is not publicly available; it is unclear if existing routers can be upgraded.
- Steve is dismayed that the Wi-Fi Alliance requires registration to download seven-page spec stubs.

- SpinRite listener question: recovered sectors can leave SMART reporting healthy because drives have spare pools; Steve's advice is to treat the drive as fine if it passes.
