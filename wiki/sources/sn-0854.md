# Summary

The episode begins with US government reactions to Log4j: the Pentagon redirected its HackerOne-run Hack the Pentagon bounty to hunt Log4j flaws across .mil sites (finding 17 previously unknown vulnerable assets, paying 500 dollars per find plus 500 for proof of exploitability), and the White House convened an Open Source Software Security Summit where Google proposed a marketplace matching company volunteers with critical open-source projects. Steve prefers directly funding proven programs (Project Zero, Zero Day Initiative, Pwn2Own, bug bounties) and jokes about a National Endowment for software quality. January's Patch Tuesday fixed 97 flaws, including six publicly disclosed ones such as bugs in bundled curl and libarchive; a much-hyped wormable IIS flaw (CVE-2022-21907) needed a non-default HTTP trailer-support setting, but the server updates then caused domain-controller boot loops and Hyper-V and ReFS failures and were pulled, and L2TP VPNs broke on desktop Windows. SentinelOne disclosed a remote kernel flaw in KCodes' NetUSB module, licensed into routers from Netgear, TP-Link, Tenda, Edimax, D-Link and Western Digital, listening on TCP 20005 on the WAN side; Steve set up a GRC ShieldsUP! shortcut to test for it. Chrome will implement the W3C Private Network Access standard to stop public sites from reaching LAN devices without a CORS preflight permission. Wordfence found three WooCommerce-related plugins from one author affecting 84,000 sites. The closing segment walks through Check Point's reverse engineering of an Iranian APT35 (Charming Kitten) Log4j campaign, a hastily assembled chain from log injection to a PowerShell backdoor with modular spying components.

# Key points

- Hack the Pentagon pivoted to Log4j within days; CISA's Eric Goldstein said crowdsourced scans found 17 vulnerable assets before intrusion; DDS and HackerOne praised the speed, Steve and Leo found the payouts low.
- Open Source Software Security Summit (13 January 2022): topics were preventing defects, improving finding and fixing flaws, and shortening patch delivery; Biden's executive order uses federal purchasing to require secure development practices.
- Patch Tuesday: 97 CVEs plus 29 Edge fixes (nine critical); Steve prefers reserving "zero-day" for in-the-wild exploitation, whereas Microsoft counts publicly disclosed ones. The curl flaw is a STARTTLS response-injection issue (IMAP/POP3) and libarchive's is a use-after-free.
- The "wormable" IIS HTTP Protocol Stack flaw required the non-default EnableTrailerSupport registry setting; press coverage overstated risk despite CVSS 9.8.
- Microsoft withdrew January server updates (boot loops on domain controllers, Hyper-V and ReFS problems) and L2TP VPN breakage affected Windows 10 and 11; Steve favors waiting before installing.
- KCodes NetUSB kernel module (found by SentinelOne's Max van Amerongen while preparing for Pwn2Own) is exposed on all interfaces; vendors were given patches in October 2021; no exploitation seen yet but Steve expects one because routers are Linux-based and the code is common. Advice: check via grc.sc/854, update firmware, block the port on WAN, or unplug.
- Private Network Access: browsers send a preflight with `Access-Control-Request-Private-Network: true` and the device must answer `Access-Control-Allow-Private-Network: true`; Chrome 98 (March 2022) warns in DevTools, Chrome 101 (around May) enforces, with a deprecation trial. It counters browser-as-proxy attacks on routers and internal servers.
- Wordfence: Login/Signup Popup (fixed in 2.3), Side Cart WooCommerce (2.1) and Waitlist WooCommerce (2.5.2) allowed arbitrary option updates via an admin-tricked action, covering 84,000 sites.
- Listener note about a QNAP ransomware wave; Steve urges leaving QNAP's software.
- APT35 chain: crafted user-agent or Authorization header leads Log4j to an LDAP exploit server, returned Java class launches a PowerShell download from a cloud storage bucket, the backdoor polls a command-and-control server, receives Base64-encoded PowerShell or C# modules (installed applications, screenshots, process list, system info, command execution, cleanup). Attribution rests on reused infrastructure (an "/Api/Session" endpoint), identical logging code with Google TAG's October 2021 report and the group's weak operational security. Steve judges it script-kiddie level yet effective, and says he will cut Log4j coverage.
