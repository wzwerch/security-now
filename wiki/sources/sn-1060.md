# Summary

Steve continues the previous week's code-signing theme with a blog post by Rick Strahl about the painful setup of Microsoft Azure Trusted Signing (cheap at about $10 or $100 per month, but with confusing tooling and certificates valid for only three days), plus listener reports of cloud-signing fees as high as 26.4 cents per signature. He plans to buy a roughly $129-per-year three-year certificate from a budget reseller before the March 1 limit. He explains the history of how Let's Encrypt bootstrapped trust by being cross-signed by IdenTrust, why starting a new CA is hard, and (the title topic) why three-day signing certificates are workable: code signing only requires the certificate to be valid when the code is signed, and a Timestamp Authority countersignature proves the signing time, so signatures stay valid after the certificate expires. The Logitech Options+ macOS outage from an expired certificate is discussed as probably an internal certificate rather than a timestamped code-signing one. Other items: California's DROP (Delete Request and Opt-out Platform) for one-stop deletion requests to 170 registered data brokers starting January 2026, with brokers required to process requests from August 1, 2026; an AI-generated National Weather Service map with fictitious Idaho towns; Steve fixing hMailServer crashes by moving iOS devices from Apple Mail to the eM Client app; a free 30-minute "Build with Andrew" course on AI coding; and Leo's live demonstration of building a Rust RSS reader with Claude Code. Leo also confesses he was phished out of three credit cards via a fake T-Mobile points text.

# Key points

- Rick Strahl's Azure Trusted Signing review: pricing $9.99/month (5,000 signatures) or $99.99/month (100,000 signatures), half a cent per extra signature; non-EV only; documentation poor, three toolchains, 5 to 8 seconds per signature; certificates last three days.
- Industry pricing complaints: certificates that cost about $180 for three years now cost around $1,000; a listener's company pays per signature in blocks and was quoted $30,000 for Azure setup by IT; Steve calls it a CA cabal and enshittification.
- Steve's plan: buy a 3-year FastSSL non-EV code-signing certificate (around $387) stored in his hardware token; EV no longer provides any benefit; he would never run a CA himself.
- Code signing versus TLS: TLS certificates must be valid at connection time; code-signing certificates need only be valid at signing, with a TSA countersignature binding a trusted UTC time; attackers could otherwise set the clock back. Never10.exe (signed 2019, certificate expired 2022) still validates.
- Let's Encrypt history: launched 2015 with an intermediate cross-signed by IdenTrust; its own ISRG Root X1 was added to root stores around 2018; the cross-sign root expired in 2021. Lesson: a new CA needs years to earn trust.
- DROP (California Delete Act): launched January 1, 2026; residents verify via Login.gov or Socure, provide identifiers (name, DOB, VIN, advertising IDs), get a DROP ID; brokers must process every 45 days from August 1, 2026; Steve's account showed 170 brokers, Leo's 89; Terms say shared data is used only for deletion matching.
- NWS posted an AI-generated wind map with invented towns "Orangeotild" and "Whata Bod" in Idaho and withdrew it.
- hMailServer crashes were traced to iOS IMAP clients and stopped after switching to the free eM Client mobile app (QR-code import from the desktop client); Steve also complains about sponsored app-store search results.
- Andrew Ng's DeepLearning.ai "Build with Andrew" is a free 30-minute vibe-coding tutorial; a listener runs several Claude Code instances for iOS, Android and backend development; Leo built a terminal RSS reader in Rust with Claude Code (Opus), noting Claude handled Gatekeeper quarantine and config path issues; mentions Google Opal, Ralph Wiggum loop tool and 'Awesome Claude' resources. Leo argues AI-written code tends to avoid classic mistakes like unsafe string copies.
- Phishing anecdote: Leo clicked a fake T-Mobile rewards text, entered three cards plus a texted verification code, and attackers added a card to a wallet within an hour; lesson that legitimate firms' promotional texts condition users.
