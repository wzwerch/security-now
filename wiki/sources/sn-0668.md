# Summary

Steve's 15-year-old Windows XP workstation died, forcing a move to Windows 7. He reviews a "mega" Patch Tuesday (about 50 fixes, 11 critical), including a remote code execution flaw in Windows DNS response parsing and one in the HTTP.sys stack of Windows 10 and Server 2016, and the Cortana lock-screen attack McAfee showed. Microsoft published its security servicing commitments separating security boundaries and features (always serviced) from defense-in-depth features. Other threats: the Zacinlo adware rootkit on Windows 10, Satori's strategy of weaponizing published proofs of concept, and clipboard-hijacking wallet malware. Chrome will end inline extension installs. The main topic is a new Intel-only information leak, Lazy FPU (floating-point) state restore, plus a status check of Spectre and Meltdown mitigations across Windows versions.

# Key points

- June Patch Tuesday: no Windows zero-days, but a DNS client (dnsapi.dll) remote code execution flaw affecting Windows 7 through 10 and servers, and an HTTP.sys flaw on Windows 10 / Server 2016; Steve urges prompt patching since patch diffing will produce exploits. The previously unpatched JScript zero-day was fixed too, along with the Flash zero-day via Office.
- McAfee showed that Cortana responds on a locked PC, letting a physical attacker run a script from a USB stick and even change the password; fixed, but Steve advises disabling Cortana on the lock screen.
- Microsoft Security Servicing Commitments: boundaries (network, kernel, process, user session, browser sandbox, same-origin, virtual secure mode) and security features (BitLocker, Secure Boot, Defender, crypto APIs) are serviced promptly and eligible for bounties; defense-in-depth items (UAC, AppLocker, DEP, ASLR) may wait for the next version.
- Edge will gain an option to block media autoplay (Chrome already does); Firefox plans it later in 2018.
- Zacinlo (Bitdefender, 104-page report): signed Windows 10 rootkit adware distributed via a free VPN app, mostly in the US, with man-in-the-browser TLS interception, ad replacement, ad fraud via hidden browsers, screenshotting and remote-install capability.
- Satori botnet exploded onto port 8000 scans after a proof of concept for XiongMai uc-httpd was published, then moved to D-Link DSL-2750B devices; its operators monitor forums for new proofs of concept.
- ClipboardWalletHijacker (360 Total Security): over 300,000 machines infected, swapping copied bitcoin/Ethereum addresses; small take so far (five bitcoin and 46 Ethereum transactions); advise checking pasted addresses.
- Chrome extension policy: inline installation from third-party sites blocked for new extensions from June 12, for existing ones from September 12, and removed in Chrome 71; installs must go through the Chrome Web Store. Android apps are faking popularity by naming developers "more than one million downloads".
- Mitigation status: Meltdown and Spectre v1/v2 mitigations are on by default in Windows 7, 8.1 and 10; Spectre v4 (speculative store bypass) mitigation is available for 7 and 10 but off by default (including on servers) due to performance cost; side effects include untranslated messages and blue screens on non-SSE2 CPUs. Six months in, no real-world exploitation is known.
- Lazy FPU state restore: Intel Core CPUs allow deferring restoration of floating-point registers on context switch; timing differences leak data between processes. Linux 4.9+, recent Windows Server 2016 and some BSDs are not affected; Microsoft planned a July fix. OpenBSD disabled hyperthreading by default over similar risk.

# Other segments

- Picture of the Week: "It's dead, Jim" 14-pin chip, tied to Steve's dead XP machine; he is rebuilding on a Windows 7 box (128 GB RAM, eight Matrox heads).
- SQRL: still finished; waiting only to enable SQRL login on its own forums.
- Listener asks about auto-reboot after SpinRite; Steve explains SpinRite's command-line options (autoexit) and a one-time boot override approach.
- Leo notes Microsoft Research's experimental E2 / EDGE processor design.
- Optane memory has finite write endurance.
