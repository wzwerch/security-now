# Summary

Father Robert Ballecer stands in for Leo. The show opens with news that macOS High Sierra accepted the username "root" with an empty password after a few attempts, a logon bypass later reported to work remotely over VNC and Remote Desktop; Steve also criticises iOS 11's poor quality. A comment on Comcast's net neutrality tweets precedes the news: two flaws in the Exim mail transfer agent (a use-after-free enabling remote code execution through crafted BDAT commands, plus a denial of service) affect a majority of internet mail servers, with over 400,000 found by Shodan; researchers found they could make 54 HP enterprise printer models accept malicious firmware by swapping in a non-encrypted drive and abusing an unsigned bundle format; 77% of 433,000 sites use JavaScript libraries with known flaws; and the ComputerCOP "child safety" spyware, which Treasury found to rely on forged endorsements, is still distributed by police. Firefox plans to warn when visiting sites listed in Have I Been Pwned. The remainder is listener feedback, including first-week experiences with Quad9, Telegram versus Signal, and how to sign IoT firmware properly.

# Key points

- macOS High Sierra root bug: entering root with a blank password a couple of times logged in with full privileges, local at first and then reported over remote desktop; Apple was expected to patch quickly. Steve says the multiple-failure branch evidently fails open.
- Exim (about 56% of mail transfer agents): versions 4.88 and 4.89 vulnerable to a BDAT-handling use-after-free enabling remote code execution; a second flaw causes DoS; fixed in Exim 4.90 per the discussion, and a proof of concept was public. Many forgotten servers will remain unpatched.
- HP printers (FoxGlove Security): the 54 enterprise models use FIPS encrypted drives, but replacing the drive with an unencrypted one lets the OS (Windows CE) be reinstalled in the clear; the proprietary .BDL firmware bundle used only CRCs rather than a cryptographic signature, so a patcher can create malicious bundles installable by web interface, TFTP or even print jobs on port 9100. HP issued firmware updates. Padre points out printers are trusted pivot points in networks.
- JavaScript libraries: 77% of 433,000 sites use at least one library version with a known vulnerability; jQuery appears on 82.4% of sites and 92.5% of those were vulnerable; the newest versions are clean, sites simply do not update.
- ComputerCOP: law-enforcement-distributed monitoring software that logs keystrokes in unencrypted files and emails them in clear text; Treasury found forged endorsements but the statute of limitations had expired and it is still marketed.
- Firefox will warn users visiting sites known to have been breached, using Troy Hunt's data (254 sites then listed); Padre worries users will ignore warnings.
- Bitcoin mining was estimated to use more electricity than 159 countries, increasing 30% in a month.
- Quad9 feedback: results mixed by location (fast in Utah, slower where no nearby point of presence such as Seattle); Steve recommends using it as the only resolver to preserve filtering, noting DNS fallbacks are sticky; 9.9.9.10 is unfiltered for research comparison.
- Firefox Quantum works with LastPass in Steve's testing; Telegram uses a homegrown, untested protocol versus Signal's open, vetted design; an Intel JTAG-over-USB interface may be a deliberate debug feature that was meant to be protected.
- SpinRite on smartphones: needs the phone to look like a USB drive, powered and attached at boot, with encryption disabled; works via BIOS until native USB support arrives in later 6.x releases.
- Firmware update security: updates must be verified with a public-key signature checked by a separate component before running, as Steve's SQRL client does.
