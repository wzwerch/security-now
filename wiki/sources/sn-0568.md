# Summary

Facebook added opt-in end-to-end encrypted "Secret Conversations" to Messenger using the Signal protocol, at the cost of features that need server-side message access. Russia's president signed anti-terror amendments that require communications providers to retain content and metadata and hand over information needed to decrypt it; the VPN provider Private Internet Access withdrew its Russian gateways after servers were seized and rotated its certificates. A wave of iPhone "lost mode" extortion in Russian was attributed to reused or phished Apple ID credentials. A serious firmware flaw in System Management Mode code, derived from shared BIOS reference code and affecting Lenovo, HP, Dell, Fujitsu and Gigabyte machines, could let a local administrator-level program install a persistent pre-boot rootkit after a researcher's uncoordinated disclosure. The Ninth Circuit's upholding of Nosal's CFAA conviction prompted a dissent warning that password sharing could be criminalised. Google began testing post-quantum key agreement (a combination of elliptic curve 25519 and the lattice-based New Hope) in Chrome Canary. Other items covered Pokemon Go permissions and trojanised APK installs, a ransomware early-warning idea called CryptoDrop, hidden voice commands, and Steve's FreeBSD servers. The Q&A reached one question, on isolating an exposed server, answered with managed switches that support access control lists or a multi-NIC pfSense firewall.

# Key points

- Facebook Secret Conversations: per-conversation, Signal protocol libraries, separate backend and storage; abuse reporting and secure storage details deferred to the next episode.
- Russia: providers must keep content six months and metadata three years and supply decryption information; law effective July 20; Private Internet Access removed Russian presence after servers were reportedly seized; Steve expects other services to leave rather than comply.
- iOS lost-mode extortion: attackers with leaked Apple ID credentials lock devices and ask roughly $30 to $50; recovery is a factory reset and restore.
- Lenovo SMM flaw: local code with admin rights can disable flash write protection and implant a boot rootkit; vulnerable code came from independent BIOS vendors based on Intel reference code; affected vendors included Lenovo ThinkPads, HP, Dell Latitude, Fujitsu and Gigabyte boards; the only mitigation is limiting admin malware and watching for firmware updates.
- Nosal CFAA case: password handed by an employee to a former employee counted as access without authorization; Judge Reinhardt's dissent says there is no limiting principle covering ordinary credential sharing like streaming accounts.
- Post-quantum: only public-key crypto is threatened, not AES; Google's CECPQ1 experiment concatenates elliptic-curve and New Hope key agreement, about 1.6 times slower.
- Antivirus: commentators argue products have become ineffective and add attack surface (Symantec kernel flaws); Microsoft's built-in Defender is considered sufficient for most.
- Pokemon Go: the early release requested full Google account access (later fixed); trojanised APKs with the DroidJack remote access tool circulated, and some media encouraged sideloading; Steve's weekly link points to Google's app-permissions page for auditing.
- CryptoDrop research (University of Florida, Villanova) proposes detecting ransomware behaviour early so only a few files are lost; Steve will review it next week.
- UC Berkeley and Georgetown researchers hid voice commands in noise-like audio that speech recognisers still understand.
- Isolation advice: a compromised public-facing server should be physically isolated using a Layer 3 managed switch with ACLs (Steve uses a Cisco SG300-10) or a multi-NIC pfSense firewall; VLANs are treated as organisational rather than security tools.
