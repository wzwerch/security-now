# Summary

The last show of 2020 covers Chrome 87 rolling back its insecure-form warning after false alarms on redirects, with a smarter version planned for Chrome 88. Firefox 85 will partition many client-side caches per site to defeat cache-based tracking and supercookies, following Apple and Google. Browsers again blocked a Kazakhstan government root certificate meant for interception. A 19-member Ransomware Task Force was announced. The Contact Form 7 WordPress plugin (over five million sites) had a file-upload sanitization flaw, and CISA warned of four new flaws in Treck's embedded TCP/IP stack, following 2020's Ripple20 findings. Steve announces the public release of the ReadSpeed benchmark, with a before-and-after SSD example showing SpinRite repairing slow regions. The main topic is the SolarWinds aftermath: a second, separately attributed backdoor named Supernova, evidence of a test run in October 2019, a Microsoft/FireEye/GoDaddy kill switch for Sunburst, and decoded DNS logs naming many additional victim companies.

# Key points

- Chrome 87 warned about insecure form submission even when the form went to HTTPS and only a later redirect was plain HTTP; Google disabled it and plans a corrected warning in Chrome 88 (around January 19, 2021). FTP removal continues in stages.
- Firefox 85 network partitioning will cover the HTTP cache, image and favicon caches, connection pools, stylesheets, DNS, HSTS, OCSP, TLS session data and more; Safari partitioned its HTTP cache in 2013 and Chrome partitioned in version 86. Mozilla expects some speed loss and the end of supercookies.
- Kazakhstan's interception root certificate was blocked by Chrome, Firefox, Safari and Edge for the third time (earlier 2015 and 2019); Censored Planet saw it affect Google, Facebook and Twitter services.
- Ransomware Task Force: 19 organizations including Microsoft, McAfee, Citrix, Rapid7, Team Cymru, Shadowserver and an insurer; aims at an industry consensus framework, with a website due in January 2021.
- Contact Form 7 (before 5.3.2): double-extension filename (for example a .php-like name with an image extension) bypassed the upload filter; fixed quickly. Steve again advises sequestering any WordPress host, using a private database and avoiding plugins.
- Treck TCP/IP stack (before 6.0.1.68): four new flaws including a 9.8-rated heap overflow in the HTTP server triggered by a negative content length, plus IPv6 issues; Treck's customers include HP, Schneider Electric, Intel, Rockwell and Caterpillar.
- Listener feedback on Flash preservation (Flashpoint, standalone Flash projector, Ruffle).
- ReadSpeed went public on Christmas Eve; InitDisk reached release 5 after a Windows 10 problem with unpartitioned USB drives. A before/after run on an OCZ Vertex 3 SSD showed SpinRite Level 3 rewriting error-corrected regions and raising throughput from about 300 to about 354 MB/s.
- Correction: SolarWinds Orion is software for Windows, not an appliance.
- Supernova: a second backdoor found in Orion's network monitoring code, a modified legitimate web-service DLL (a logo image handler) that compiles code passed as parameters in memory. It was unsigned, with a compile timestamp of March 24, 2020, and Microsoft judged it likely the work of a different threat actor. Palo Alto's Unit 42 analyzed it.
- Test run: the Sunburst actors injected a harmless code change into SolarWinds builds in October 2019, shipped to customers on October 10, apparently to test detection and distribution.
- Sunburst removed its initial backdoor once other persistence was established. It used a domain-generation scheme under avsvmcloud.com and a built-in kill switch triggered if the DNS answer falls in certain address ranges; Microsoft, FireEye and GoDaddy used this to disable it, while noting that actors had other backdoors in victim networks. DNS logs were decoded to identify further infected organizations including Cisco, SAP, Intel, Cox Communications, Deloitte, Nvidia, Fujitsu and Belkin. CISA said removing the actor would be highly complex.
- Steve restates his advice for network segmentation of IoT and sensitive systems and notes intrusion detection is evaded when malicious traffic mimics legitimate traffic.
