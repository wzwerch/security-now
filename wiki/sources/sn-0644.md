# Summary

The first show of 2018 opens with Princeton research showing that two ad-tech firms (Adthink's AudienceInsights and BehavioralEngine) ship scripts that plant invisible login forms so the browser's password manager autofills the visitor's email address and password; the values are hashed and sent off as a cookie-less cross-site tracking ID. The scripts were found on 1,110 of the top million sites. Steve then covers the flurry of kernel patches for Kernel Page Table Isolation (KPTI), which at this stage looks like an Intel-only speculative-execution flaw with roughly a 5% performance cost; AMD says it is not affected. A Swiss hacker released a macOS zero-day ("IOHIDeous") on New Year's Eve that gives any unprivileged local user full kernel read/write and can disable SIP. Satori, a Mirai variant, mass-compromised Huawei HG532 routers, and Trend Micro found 4,000+ Sonos speakers with web servers exposed to the Internet. A new study shows a third of the top 10,000 sites react to ad blockers. The closer is Matthew Green's analysis: Canon printers' failure with TLS 1.3 revealed that RSA's BSAFE library had shipped the Dual EC DRBG together with the NSA-authored "Extended Random" TLS extension, which looks like an NSA fingerprint.

# Key points

- Autofill abuse: hidden form fields trigger the browser to fill stored credentials; a change event lets the script hash and exfiltrate them without any submit click. Steve's mitigation is to blackhole the two tracking domains; the real fix has to come from browsers (only fill visible fields or require user interaction).
- KPTI: kernel developers hurriedly separated kernel and user page tables, a break from the long-standing shared-table performance shortcut. Linux patches landed with redacted comments; Windows got similar changes since November. Likely an Intel-only speculative-reference issue that leaks cache state and defeats KASLR. Details not yet public (embargo). Steve notes it does not look like Rowhammer.
- macOS IOHIDeous: a 15-year-old bug in the HID kernel driver, local privilege escalation to full kernel read/write on recent macOS releases; the researcher said he published after Apple's earlier fix attempt failed and the bounty offer was low. Apple was already aware. Leo objects to the non-coordinated release.
- Satori/Mirai variant exploited a Huawei HG532 router flaw reachable on a WAN port; exploit code was posted publicly and is expected to be adopted by other botnets (Reaper, IoTrooper). Advice: update firmware, consider an inner router behind a compromised-prone edge router. Steve notes 17,215 CVEs were logged in 2017.
- Sonos/Bose research by Trend Micro: more than 4,000 Sonos speakers exposed an internal web server to the Internet, leaking ARP data, music-service account details and allowing ping tools; Sonos fixed it quickly. Steve recommends segmenting IoT onto its own network.
- Steve's recurring idea: IoT devices that should never be reachable remotely could simply send packets with a TTL of 1 so they die at the first router.
- Ad-blocker study (University of Iowa and UC Riverside, to be presented at NDSS): about one third of the top 10,000 sites, and 38.2% of the top 1,000, detect or counter ad blockers.
- Thunderbird 52.5.2 fixes a critical buffer overflow; Steve urges users to update.
- Apple admitted that iOS slows older phones with degraded batteries; Steve complains about his iPhone 6 Plus and plans a discounted battery swap.
- Extended Random: an NSA-authored TLS draft that was never adopted but supplies more nonce data, acting as "rocket fuel" for exploiting Dual EC. Canon printers using RSA BSAFE revealed both were deployed; TLS 1.3 then reused the same extension code point and broke them. Steve treats this as strong circumstantial evidence of NSA involvement.
