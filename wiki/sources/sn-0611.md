# Summary

Steve starts with the follow-up on Intel AMT: researchers at Embedi found that the management web interface accepted a blank response to its HTTP Digest authentication challenge, so anyone could log in as administrator on machines with AMT network access enabled. Port scanning for the AMT port had already risen in March. On Patch Tuesday, Tavis Ormandy and Natalie Silvanovich disclosed a remotely triggerable type confusion in Microsoft's Malware Protection Engine (mpengine), which scans files automatically with system privileges and needs only for hostile content to touch the disk. Other items include May's Android patches, banks losing money in January when attackers redirected SMS verification codes over SS7, Google's response to a fake Google Docs OAuth phishing worm, a study finding 234 Android apps listening for ultrasonic tracking beacons, new legal rulings and proposals on compelled decryption in the US and UK, a US citizen pressured to unlock his phone at the border, the arrival of voice cloning, and a malicious HandBrake download. The show ends with pointers for submitting Net Neutrality comments at GoFCCYourself.com and DearFCC.org, plus listener feedback.

# Key points

- Intel AMT flaw: AMT runs a web server on ports 16992 and 16993 (and redirection ports 16994 and 16995, 5900 for VNC). The Digest authentication code compared the response using the client-supplied length, so an empty response always matched and granted administrator control. The AMT ports are only reachable from the network if AMT is provisioned; discovery pings on 623 and 664 cannot be disabled. Steve says affected systems are those with network provisioning enabled, mostly enterprise, and that using WiFi or a secondary NIC avoids the interface; SSH.com compared it to giving anyone on the intranet root. Intel was rushing out firmware patches.
- A SANS honeypot graph showed scanning of port 16992 rising in March, before public disclosure on May 1.
- Microsoft Malware Protection Engine (MsMpEng/mpengine) ran unsandboxed as SYSTEM, scanned files via a filesystem minifilter and included a JavaScript interpreter; a crafted file triggered a type confusion even if never opened. The fix arrives with engine version 1.1.13704.0 or later; Microsoft's May Patch Tuesday fixed over 20 issues with four critical on each platform.
- Google's May 5 Android patch level fixed 17 critical issues including media server and Qualcomm components; Leo shows Pixel devices updating while a Galaxy S8 lagged.
- SS7 abuse: in January attackers combined banking trojans with SS7 interception to redirect banks' SMS confirmation codes and withdraw funds; Steve again favors TOTP authenticators.
- Google phishing worm (May 3): emails offering a Google Doc linked to a fake OAuth app that requested contact access and spread itself; Google disabled the accounts and apps and promised OAuth policy changes. Steve calls OAuth a risky kluge and notes that SQRL's same-device "client-provided session" login avoids spoofing, and that Microsoft backed off blocking Edge's localhost access.
- Ultrasonic cross-device tracking: researchers found beacons in web media and in stores and 234 Android apps (including large brands) that constantly listen, with no disclosure in privacy policies.
- Amazon agreed to release Echo data in the Arkansas hot-tub case after the defendant consented. A Miami judge ruled that compelling a password is not a Fifth Amendment violation.
- UK leaked draft Technical Capability Notices would require communications providers to give real-time access on short notice; FBI director Comey said legislation on device encryption may be needed (Feinstein is also in favor).
- An Ars Technica story describes a US citizen, an activist, who unlocked his phone at SFO after border officers said they could keep it indefinitely; Leo says he would not carry an expensive phone abroad, and Steve suggests wiping or backing up before travel.
- Voice-cloning software is emerging; HandBrake for Mac 1.0.7 was served malware from an official mirror for a short time.
- A 1995 Usenet anecdote describes a missile program that deliberately leaked memory, supplying double the calculated leak because the missile ends its flight anyway.
- Net Neutrality comments: submit via GoFCCYourself.com (redirect to FCC proceeding 17-108) and the EFF's DearFCC.org.
- Listener items: SpinRite on an SSD showing hundreds of thousands of ECC corrections, FileApp for iOS as a file server, DNSCrypt still useful despite SNI, Image for Windows for backups, and Android per-app permission controls.
