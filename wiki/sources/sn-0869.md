# Summary

The US Defense Department finished a year-long bug bounty pilot for the defense industrial base (DIB-VDP), run with HackerOne: nearly 300 vetted researchers filed 1,015 reports against 348 systems of 41 organizations, producing 401 actionable vulnerabilities, which Steve notes is alarming given that 100,000 to 300,000 companies contract with the Pentagon. He then introduces the Open Source Security Foundation (OpenSSF), whose Package Analysis project dynamically scanned PyPI and npm and found more than 200 malicious packages in a month, mostly dependency-confusion and typosquatting probes plus Discord token stealers and reverse shells; he warns attackers will adapt. Connecticut's legislature passed a privacy bill that would join California, Colorado, Virginia and Utah, with opt-out signal recognition and a sunset of the "right to cure". A Moxie Marlinspike port-knocking tool whose rationale is that all network services contain vulnerabilities supports the previous episodes' theme. Listener feedback covers browser wallets versus password managers, SpinRite on Intel Macs, Netgate pfSense for IoT segmentation, and why Steve keeps printed authenticator QR codes. The main topic is Global Privacy Control, the successor to Do Not Track, which has legal weight in California and soon other states and can be enabled in Firefox and some extensions.

# Key points

- DIB-VDP pilot (DC3, DCSA, HackerOne): began with 14 companies and 141 assets and grew to 41 entities and 348 systems; 401 of 1,015 reports were actionable; roughly one actionable bug per system; shows both the value of sanctioned bounty programs and the scale of supply-chain exposure (the 2009 F-35 contractor breach is an earlier example).
- Steve's view: white-hat hackers will not probe government systems without legal cover or work for free, so governments should pay bounties comparable to the private sector.
- OpenSSF (Linux Foundation, 2020; members include Google, Microsoft, GitHub, Intel and many others) runs working groups, town halls and training; its Package Analysis project performs dynamic analysis of uploaded packages and stores results in BigQuery.
- Package Analysis first month: over 200 malicious packages on PyPI and npm; examples include discordcmd (installs a backdoor into the Discord client and steals the token), colorsss (token theft), roku-web-core/ajax and secrevthree (reverse shells), and random-voucher-code-generator (remote command via a server); many dependency-confusion packages used high version numbers and callbacks to burpcollaborator-type domains, likely from researchers seeking bounties.
- Limits: attackers can learn which signals are detected and route traffic through compromised routers; there is no reputation system for publishers, and reputation filtering would exclude newcomers.
- Connecticut SB 6 (passed the assembly, effective 1 July 2023 if signed): opt-outs for sales, targeted advertising and profiling; consent for sensitive data; parental consent for under 13 and ad limits for ages 13 to 16; opt-out preference signals such as Global Privacy Control must be honored from 2025; cure period sunset on 31 December 2024; California's sunset is 1 January 2023 and Colorado's 1 January 2025, hence the "3Cs".
- Moxie Marlinspike's knockknock (about a decade old): his rationale is that you are running network services with vulnerabilities, even OpenSSH has had remote bugs, so minimize exposure.
- Browser wallet versus password manager: a crypto wallet does not need a browser and safer containers exist, while password manager integration is practical and reduces clipboard and lookalike-domain risk; no widespread attacks on browser or extension password stores are known.
- SpinRite 6.1 is x86 assembly only, so it will not run on a Raspberry Pi; a Boot Camp Intel MacBook benchmark suggested about two terabytes per hour; Mac keyboard polling issues were fixed.
- Authenticator backups: Steve prefers authenticator apps that prevent key export and prints each QR code at enrollment to keep an offline archive, citing Bruce Schneier's write-down advice.
- Netgate SG-1100 (pfSense) is Steve's choice for a small router with separate LAN, WAN and auxiliary interfaces used to isolate IoT devices.
- Global Privacy Control: the Sec-GPC: 1 HTTP header (and navigator.globalPrivacyControl in JavaScript) tells sites not to sell or share data; the spec forbids sending it unless the user preference is set, avoiding the Internet Explorer 10 default-on Do Not Track controversy; California treats it as a valid opt-out under the CCPA (2021 Attorney General FAQ), and Colorado and Connecticut follow.
- Support: Firefox via about:config settings starting with privacy.global (set to true), Brave, DuckDuckGo, Privacy Badger, Disconnect, Abine and the OptMeowt extension from Wesleyan University's privacy lab (enable, domain list or disable); Chrome lacks native support; uBlock Origin's author declined to add it; Do Not Track history: proposed 2009, W3C working group disbanded 2019, Apple dropped support in 2019.
