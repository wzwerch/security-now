# Summary

With Jason Howell filling in for Leo, Steve first follows the race to turn checkm8 into a user-friendly tethered jailbreak (watch only the correctly spelled checkra1n site, since a look-alike domain hosts junk). He covers malware hiding payloads in WAV audio files, attributed to the Turla group and used for cryptominers, then Firefox 70's quieter padlock and EV handling, a switch to "strict" content blocking, Germany's BSI naming Firefox the only browser to meet its security requirements, and Mozilla's removal of inline script and eval from internal about: pages. Microsoft's open-source ElectionGuard voting SDK gets a bug bounty of up to $15,000. A critical remote buffer overflow in the Linux Realtek WiFi driver (reachable via Wi-Fi Direct Notice of Absence) is unpatched at recording time and also affects Android devices with Realtek chips. After YubiKey local Windows login and some sci-fi notes, the main topic is the biometric mess: Pixel 4 Face Unlock working with eyes closed and Galaxy S10/Note 10 ultrasonic fingerprint readers fooled by a cheap screen protector.

# Key points

- Checkm8 jailbreak work is underway for A5-A11 devices (tethered, no persistence); the genuine site is Checkra1n.com while a similar-spelled domain serves dubious pay-to-load apps.
- Turla (Waterbug) hid Meterpreter in WAV files; Cylance saw a Monero miner and reverse-shell code delivered similarly; payloads were either least-significant-bit stego in audible audio or XOR-scrambled binary behind a WAV header, which passes perimeter filters. Detection would need heuristics for non-audio-looking samples.
- Firefox 70: gray padlock for HTTPS, red slashed padlock on all HTTP pages, EV details moved into the identity dropdown; 80% of Firefox page loads are HTTPS. Steve notes his old "custom" content-blocking setting no longer gave the strongest defaults and recommends "strict".
- BSI (German federal cybersecurity office) tested Firefox 68, Chrome 76, IE11 and Edge 44 against a 21-point list (TLS, EV, revocation checking, HSTS, SRI, CSP, sandboxing, master password, telemetry controls, updates within 21 days, memory protections); only Firefox passed all; others lacked items such as a master password and telemetry blocking. Brave, Opera, Vivaldi and Safari were not tested.
- Mozilla applied a strict content security policy and removed eval in system-privileged contexts across 45 internal about: pages.
- ElectionGuard: free open-source SDK with end-to-end verifiability using homomorphic encryption; bounty up to $15,000 for the API SDK, specification and verifier reference implementation; Steve praises it as a step toward open voting systems.
- Realtek rtlwifi bug (found by Nico Waisman): missing upper-bound check on the Notice of Absence element count allows a nearby attacker to overflow a kernel buffer with no user interaction; only a crash demonstrated so far; four-plus years old; a fix was queued upstream; Android devices with Realtek chips are exposed and often never updated.
- Yubico released a free local Windows logon solution for Windows 7-10 using YubiKeys; Steve says to pair it with disk encryption.
- Pixel 4 Face Unlock can unlock with eyes closed; an eyes-open option appeared in leaks but not at launch, with a fix promised within months. Samsung confirmed a fingerprint bypass when third-party screen protectors are used on S10/Note 10 and promised a patch.
- Steve's analysis: biometrics only confirm a presumed identity (a soft yes/no decision), cannot be changed if compromised, and combining soft factors raises false-negative risk; he suggests testing whether other people can unlock your device.
