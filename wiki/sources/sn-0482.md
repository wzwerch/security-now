# Summary

Steve starts with the aftermath of November's Schannel patch (MS14-066): the four new TLS cipher suites Microsoft added proved buggy and caused crashes, so Microsoft issued a corrected version 2 that administrators of IIS servers must install manually; researchers are already fuzzing the TLS handshake and Steve warns the flaw looks wormable, comparable to Code Red and Blaster. Steve overrides cipher suite selection on his own servers, so he was unaffected. Firefox 33.1 adds a Forget button that clears the last five minutes, two hours or day of browsing, and a built-in DuckDuckGo search option. The Wall Street Journal revealed that US marshals fly small aircraft carrying cell-site simulators ("dirtboxes") that capture identifying data from many phones, to the dismay of the ACLU. AT&T ended its UIDH supercookie test but a mobile ad exchange already used Verizon's token, so Steve is unimpressed. The EFF, Mozilla, Cisco and others announced Let's Encrypt, a free automated certificate authority to launch in summer 2015 using the ACME protocol, with short-lived certificates in mind. WhatsApp for Android integrated TextSecure's end-to-end encryption, with key verification through QR codes or fingerprints; there are concerns about BitTorrent Sync's protocol leaking hash and IP data. The Q&A covers why Steve visits his data center, SQRL helper tools, 1,000-year M-DISC optical media, whether a destroyed hard drive can yield data, and how brute-force attackers know they have succeeded.

# Key points

- MS14-066 revision: Microsoft's new cipher suites added in the first release caused instability and had to be fixed; the patch was reissued and had to be redownloaded manually. Fuzzing of the TLS handshake had begun, and Steve expects exploit code and possible worms.
- Steve controls his server cipher suites manually and makes physical visits when updating servers after long gaps.
- Firefox 33.1 Forget button removes recent browsing data after the fact, which is harder to implement than a private mode; privacy mode still does not hide the IP address.
- Airborne dirtboxes: small planes from US airports fake cell towers to collect phone identifiers and location data; the government neither confirms nor denies; metadata needs no warrant.
- A driver in Florida jamming cell service for years was caught because carriers noticed a moving dead zone, an example that carriers can monitor such interference.
- AT&T ended its supercookie test but plans a code changing every 24 hours; Twitter's MoPub documentation showed advertisers using Verizon's tracking token. HTTPS prevents the header injection.
- Let's Encrypt (EFF, Mozilla, University of Michigan, Cisco, Akamai, IdenTrust): free, automated domain-validated certificates, ACME protocol (Automated Certificate Management Environment) over JSON and HTTPS, auditable configuration, use of Certificate Transparency to deter mis-issuance; EV certificates remain a separate high-assurance product. Short-lived certificates would make revocation unnecessary.
- WhatsApp for Android now uses TextSecure for end-to-end encryption, with key fingerprint verification, for around 600 million users; WhatsApp itself is closed source so verification is limited.
- BitTorrent Sync: conference researchers claimed probable client vulnerabilities and metadata leaks; BitTorrent disputed this, and the open-source Syncthing was mentioned as an alternative.
- Net Neutrality debate on TWiT (Brett Glass versus Sonic.net's Dane Jasper) was praised as informative.
- SpinRite and SSD disk encryption: running SpinRite Level 5 before full-disk encryption is reasonable, but the encryption and the testing will saturate SSD TRIM bits, so a TRIM-clearing step should follow.
- Steve answers whether SQRL will get drop-in libraries (yes), a demo login page at GRC (partly exists) and an iOS client (no; he must return to SpinRite 6.1).
- M-DISC: a DVD-format medium that etches into inorganic material, claimed to last up to 1,000 years and readable in normal drives but needing a special writer.
- Recovering data from a drive destroyed with snips or drilling is essentially infeasible except for nation-state labs and would require the intact platters and the original drive's read channel because the magnetic pattern is encoded and whitened.
- Brute-force success detection: for TLS traffic an attacker tests a decryption by checking authentication (the MAC); for stolen password hashes an attacker hashes guesses until one matches.
