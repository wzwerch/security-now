# Summary

The episode begins with Patch Tuesday (13 patches, three critical, including Edge and Internet Explorer), a satirical Onion piece, and Firefox 42's built-in tracking protection for private browsing. The main security stories are ransomware moving to servers (Linux.Encoder.1, which entered through an unpatched Magento shopping-cart flaw but used predictable encryption keys, so a decryptor exists), Power Worm ransomware that cannot decrypt even if paid, and Comodo disclosing improperly issued certificates for bare internal names. Microsoft and Mozilla said they may reject SHA-1 certificates as early as mid-2016. Steve recommends a Twitter app-permission cleanup, the NetWorx bandwidth monitor, Spybot Anti-Beacon for Windows telemetry and the Alarmed reminder app for iOS. The ten listener questions include a "secure email" site loading trackers, why malvertising beats user-generated content as an attack vector, whether zero-filling an encrypted volume helps attackers, router DNS-changer malware, shared and wildcard TLS certificates and Server Name Indication, using Let's Encrypt certificates for mail servers, advice for a new teenage Windows user, and Firefox for Android extensions.

# Key points

- Patch Tuesday: 13 patches, three critical (Windows Journal, Edge, Internet Explorer); Steve advises updating promptly.
- Firefox 42: tracking protection in private windows based on the Disconnect list, tab audio mute indicator, more ES6 support.
- Linux.Encoder.1: ransomware for Linux web servers that encrypts web directories after entering through vulnerable add-ons; in one case the entry was an unpatched Magento flaw. Check Point had disclosed the Magento chain months earlier and a patch existed since February; nearly 200,000 shops were affected. BitDefender found the malware derived keys from a time-seeded libc rand(), allowing a free decryption tool. Operators also threaten to publish stolen data.
- Steve ties the weakness to the importance of good entropy and recalls his earlier episode on harvesting entropy.
- Comodo audit found eight certificates for non-unique names (like "mailarchive") that violate CA/Browser Forum baseline requirements, probably requested for intranets; certificates for private IP addresses are similarly disallowed; expiration keeps such mistakes self-cleaning. A proper corporate CA is the right approach for intranets.
- Power Worm ransomware has a bug that produces no decryption key, so paying is pointless; restore from backup.
- SHA-1: Microsoft said it is considering June 2016 for blocking SHA-1 TLS certificates (previously January 2017), and Mozilla plans an untrusted-connection error in Firefox 43 for SHA-1 certificates valid from 2016 onward, possibly a cut-off as early as July 2016. Steve notes telemetry helps vendors pick dates.
- Maintenance tip: review and revoke Twitter application permissions, which never expire.
- Tools: NetWorx (free bandwidth monitor), Spybot Anti-Beacon (blocks Windows 10 telemetry and Wi-Fi Sense by group policy, with Leo noting you transfer trust to another vendor), Alarmed (iOS reminders).
- Listener: a "secure message" service's reading page loaded Facebook, analytics and ad trackers, leaking metadata about who read what.
- ProtonMail suffered a multi-day large DDoS; Steve notes DDoS mitigation is costly and the reported ransom paid was small by comparison.
- Why malvertising rather than user-uploaded content: sites filter uploads heavily and do not allow script, while ad networks can serve script and Flash on high-traffic sites.
- Zero-filling free space on a TrueCrypt/VeraCrypt volume gives attackers nothing; disk encryption uses tweakable ciphers designed against known-plaintext attacks.
- DNS Changer malware (Trend Micro report) targets home routers with default credentials; Steve says to change the router password and keep it in a note or password manager.
- A wildcard certificate for a top-level domain would be catastrophic and CAs refuse it; shared certificates from hosts are wildcard certificates enabled by Server Name Indication, supported nearly everywhere except obsolete clients.
- Let's Encrypt certificates can be reused for mail servers' TLS but not for S/MIME or PGP-style message security; secure mail ports are 465, 993 and 995.
- Advice for a teenager on Windows 10: no admin by default, use uBlock Origin, learn social engineering, never download something you were told you need.
- Firefox for Android supports full desktop-style add-ons such as uBlock Origin, LastPass and HTTPS Everywhere.

# Other segments

- SQRL progress: protocol finalized, documentation being rewritten, other client authors waiting; a suggestion to use SQRL to log into a password manager is under consideration; the term "rekey" adopted.
- PiDP-8 hobby kit and blinking-lights banter; reactions to the film Spectre and a TWiT discussion episode; a SpinRite oil-change analogy testimonial; Firefox iOS availability only in a few countries.
