# Summary

Steve presents Bruce Schneier's argument that contact tracing apps suffer from unavoidable false positives and negatives and cannot replace trained human tracers, then notes New York's scale problem of thousands of new cases daily. A DHS/CISA memo tells federal agencies to keep using the government's filtering DNS and not third-party DNS over HTTPS. Ben-Gurion researchers showed a PC power supply can be driven to emit data-carrying tones (50 bits per second). The SaltStack authentication bypass and directory traversal flaws let attackers control masters and minions as root; it was exploited within days, hitting several organizations including a DigiCert certificate transparency log. Shorter items cover Adobe's emergency patches, Mozilla's Firefox Private Relay, the UK NCSC dropping "whitelist/blacklist", Google's coming Chrome Web Store spam rules and Kaspersky's data on surging RDP brute force. The main topic is China's "New IP" proposal to the ITU, which Steve describes as identity-based, QoS-sliced and auditable networking that RIPE strongly opposed.

# Key points

- Schneier's critique: app definitions of contact are imprecise (walls, transmission rate), adoption is low (Singapore under 20 percent), alerts without testing are not actionable, so false confidence and distrust follow. Steve notes R-naught in New York barely fell below one even under lockdown, and contact tracing of thousands of cases per day is a huge human effort; he still plans to use the app.
- DHS/CISA memo: agencies must use the Einstein 3 Accelerated DNS sinkholing resolvers; E3A does not yet offer DoH/DoT, so browser DoH defaults need to be disabled until CISA provides an encrypted service.
- POWER-SUPPLaY: malware varies CPU load so the switching power supply's frequency produces tones that encode two bits at a time, readable by a smartphone up to about five meters away at up to 50 bits per second, without audio hardware.
- SaltStack (ZeroMQ master with request and publish servers on ports 4505/4506): F-Secure found an authentication bypass and directory traversal that give unauthenticated root command execution across the master and all minions; fixed in 3000.2 and 2019.2.4. A scan found over 6,000 exposed masters. Disclosure was slowed by an expired security GPG key. Exploitation began right after the advisory; victims included LineageOS, Xen Orchestra operator Vates, Ghost and DigiCert, whose CT Log 2 signing key was compromised (log set read-only, SCTs after the intrusion suspect). Attackers mostly installed cryptocurrency miners.
- Adobe shipped emergency fixes for Illustrator, Bridge and Magento covering 35 vulnerabilities.
- Mozilla's Firefox Private Relay (email alias extension) is in testing; Send file transfer already exists.
- UK NCSC will use "allow list" and "deny list" instead of whitelist/blacklist; hosts debate it.
- Chrome Web Store: from 27 August 2020 Google will remove extensions that duplicate others, keyword-spam, use misleading metadata, inflate ratings, have trivial single purposes or abuse notifications; the store lists over 200,000 extensions.
- Kaspersky saw RDP scanning rise from roughly 150-200 thousand to over a million attacks per day in some countries (Spain, US) from March 2020; Steve repeats: put RDP behind a VPN or use a very long generated password.
- New IP (Huawei-led ITU proposal supported by China, Iran, Russia, Saudi Arabia): variable-length addresses, identity/content/device-based routing, deterministic latency slices, encrypted sender identity with an auditing agent and "shutoff" protocol. Steve sees it as privacy-eroding and the antithesis of net neutrality; RIPE NCC's reply calls it flawed, premature and says evolution belongs in the IETF. Steve thinks any such network could only arise as a parallel overlay.
- SpinRite: the AHCI driver now enumerates and talks to drives on all ~50 tester systems (Intel, AMD, ASMedia, Samsung, Marvell controllers); legacy IDE/ATA support is being re-enabled and a drive benchmark freeware tool is planned. GRC's DNS Benchmark has passed 5.6 million downloads.
