# Summary

Steve starts with HP's continued silence a month after its printer firmware debacle, then reports that Windows 11 Insider builds will require SMB signing for all connections (Enterprise editions first), continuing Microsoft's removal of SMBv1. OWASP has begun a Top 10 for Large Language Model applications, mixing classic flaw classes with LLM-specific ones such as prompt injection and training-data poisoning. Russia's FSB accused the NSA and Apple of hacking diplomats' iPhones; Apple denied any backdoor, while Kaspersky's own "Operation Triangulation" findings describe a zero-click iMessage attack that deletes its traces, which led Steve to a new observation: the same strong iOS security that protects users also protects such exploits from discovery. Google launched a bonus race for full-chain Chrome exploits, US senators proposed a "Know Your App Act" that Steve considers pointless, Tor is testing a puzzle-based defense against DoS, and a survey shows most school districts have no dedicated security staff. The main topic is the Windows Platform Binary Table (WPBT), the Microsoft mechanism that lets motherboard firmware drop an executable into Windows at boot; Eclypsium found Gigabyte boards using it to fetch and run code over unauthenticated or poorly validated connections. Steve gives mitigations, including a generic registry setting that disables WPBT execution.

# Key points

- HP printer bricking: no resolution or public explanation after four weeks.
- Windows 11 Canary build 25381 (Enterprise) requires SMB signing by default for all connections, previously only for SYSVOL/NETLOGON; it blocks relay-style tampering but may break older devices. SMBv1 binaries are already being removed; Steve still relies on SMBv1 to network DOS test machines for SpinRite.
- OWASP Top 10 for LLM applications (draft 0.1): prompt injection, data leakage, inadequate sandboxing, unauthorized code execution, SSRF, over-reliance on LLM output, inadequate AI alignment, insufficient access controls, improper error handling, training data poisoning.
- FSB claimed an NSA operation hit thousands of Apple devices of diplomats, with Apple complicity; Apple denied it. Kaspersky documented Operation Triangulation: a zero-click iMessage attachment exploit, further stages and a full APT platform, deletion of message and exploit, no persistence but reinfection after reboot; traces back to 2019; still active on iOS 15.7. Kaspersky found it through network monitoring and offline backup forensics (using the Mobile Verification Toolkit).
- Steve's observation: iOS's strong protections equally shield such exploits from forensic discovery; Leo suggests an immutable system forensic log.
- Chrome Full Chain Exploit Bonus (June 1 to December 1, 2023): first full sandbox-escape chain eligible for triple reward (up to $180,000), later chains double ($120,000).
- Know Your App Act (Wicker, Scott, Lankford): app stores would show an app's country of origin, let users filter apps from "adversarial" countries and warn about them; Steve considers it over the top and ineffective.
- Tor is testing a client puzzle (CAPTCHA-like) that activates only when an onion service is under DoS.
- Consortium for School Networking survey: two of three school districts have no full-time cybersecurity staff and one in eight allocates no cybersecurity funds.
- Ukraine's SSU asked citizens to disconnect public-facing security cameras because Russia exploits them for missile targeting.
- Cyber mercenaries: a New Yorker profile of Indian hack-for-hire firm BellTroX; off-the-shelf spyware and hackers-for-hire lower the barrier for attackers.
- Listener feedback: Request-OTR could be abused by harmful sites to hide visits from parents; blocking .zip/.mov is best done via a DNS filtering service such as NextDNS, since the Windows hosts file lacks wildcards.
- WPBT (introduced in Windows 8, 2012) lets firmware inject a binary that Windows runs at boot. Eclypsium showed in 2021 that Windows accepts expired or revoked certificates for WPBT binaries and does not check revocation at that stage, and that this bypasses BitLocker.
- Gigabyte: firmware on hundreds of motherboard models drops GigabyteUpdateService.exe (when the APP Center Download and Install option is enabled in UEFI; default off) which downloads and runs payloads over plain HTTP or HTTPS with broken certificate validation. Gigabyte had suffered two ransomware breaches in 2021. Gigabyte released BIOS updates adding signature and certificate checks.
- Mitigations: update BIOS, disable the UEFI option, stop and disable the dropped service, and set the undocumented DisableWpbtExecution value under the Session Manager key (Steve's GRC shortcut grc.sc/926 supplies a .reg file). Steve's framing: Windows security is "Swiss cheese" and motherboards must be trusted absolutely.
