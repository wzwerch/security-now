# Summary

Jason Howell hosts with Steve while Leo is away. Apple's iOS 15.3 and macOS 12.2 fixed two zero-days: CVE-2022-22587 in the IOMobileFramebuffer (exploited, the third such bug in six months) and CVE-2022-22594, a Safari IndexedDB cross-origin leak that revealed other tabs and identity. Qualys disclosed PwnKit, an out-of-bounds condition in Polkit's SUID-root pkexec that has existed since May 2009: the program never checks for an empty argument list, which can be abused to run attacker-chosen code as root, giving any local user root on every major Linux distribution; working exploits appeared within hours, the NSA's Rob Joyce urged patching or removing the SUID bit, and Steve notes an Australian blogger had described the empty-argv quirk in 2013 without weaponizing it. Mass Log4j exploitation has been limited because every application uses the library differently, but Morphisec saw real attacks against Ubiquiti UniFi using a public proof of concept from Sprocket Security, ending in Cobalt Strike; Steve criticizes publishing script-kiddie-ready guides so soon. Zerodium added standing bounties for Outlook (400,000 dollars) and Thunderbird (200,000) zero-click remote code execution beside a 300,000 dollar WordPress pre-auth offer; Steve dislikes brokers who resell to state clients. The DRAWNAPART paper shows that timing differences among a GPU's execution units, measured by WebGL JavaScript, fingerprint devices and lengthen tracking by up to 67%. The title segment explains the Topics API in detail as the successor to FLoC under Chrome's Privacy Sandbox.

# Key points

- PwnKit (Polkit pkexec): affects all versions since 2009, reliable on x86 and ARM64, local only (not remote); mitigations are distribution updates or removing the SUID bit from pkexec; Qualys confirmed it on Ubuntu, Debian, Fedora and CentOS.
- Apple: first 2022 zero-days patched; Steve recommends updating, noting the Safari tab leak found by FingerprintJS.
- Log4j in the field: attacks seen against VMware Horizon and vCenter, Zyxel, SolarWinds Serv-U and now UniFi (Ubiquiti patched on 10 December, a day after disclosure); exploitation needs per-application customization, which slowed script kiddies until Sprocket Security published detailed guides.
- Zerodium: limited-time bounties (Chrome up to 1 million dollars for full chains in 2021, now Outlook and Thunderbird); it claims over 50 million dollars paid since 2015 and resells to government clients; base WordPress seems solid, the add-ons are the problem.
- DRAWNAPART: uses race timing among GPU shader units to extract a stable fingerprint from unprivileged JavaScript; researchers from Australia, France and Israel disclosed it to Intel, ARM, Google, Mozilla and Brave, and the Khronos group started a WebGL study group.
- Topics API design: the browser classifies visited sites (domain-level classifier) into a taxonomy of about 350 coarse topics, computes the top five per week locally with no server involved, adds one random topic, and keeps three weeks of history.
- Topics API disclosure rules: a calling site or ad script gets up to three topics (one per past week, random order); the per-site choice among the top five is determined by an HMAC of a per-user secret, the week and the site domain; 5% of the time a random topic is returned; topics are only visible to callers who observed the user on a site with that topic in the prior three weeks; only sites that call the API contribute; redirects do not count; disabled in Incognito, clearable with history, controllable at chrome://settings/privacySandbox, and sites can opt out via a Permissions-Policy header.
- Contrast with FLoC: FLoC broadcast an opaque cohort token to all sites. Steve likes Topics' transparency and user control, notes the EFF opposes any targeting, and worries only whether advertisers will accept the coarser data.

# Other segments

- Picture of the Week: Steve's assembly-language binary search routine from SQRL, used to talk about readable code.
- Tip: in Windows File Explorer, sort by Date then Shift-click Name to keep folders on top; applied globally via Folder Options.
- Listener feedback: translating buffer overflow into remote code execution, a reader who found the same overflow pattern in his own engine code after the NetUSB episode, why authenticator codes cannot be turned back into QR seeds (print the QR at setup), and computing passphrase entropy from dictionary size using logarithms.
- SpinRite 6.1: handling RAID-declared controller chips (ASMedia, JMicron, Marvell, Silicon Image) directly and adding a mini-benchmark to choose the fastest access method.
