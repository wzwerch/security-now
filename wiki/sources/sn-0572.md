# Summary

Steve surveys the news after DEF CON and Black Hat. Windows 10's Anniversary Update brings a pile of complaints: freezes, an unchecked incompatibility with certain McAfee products, dual-boot damage, and removed Group Policy options on the Pro edition; Leo counters that the Start-menu promotional tiles can be removed by hand. Windows 7/8 keys reportedly still upgrade to Windows 10 after the free offer ended. Apple announces a bug bounty of up to $200,000, which Steve welcomes. Check Point presents privilege-escalation flaws in Qualcomm code that affect most Android devices and were mostly patched already. Princeton researchers found ads using the HTML5 battery status API for tracking. A Tesla sensor-spoofing demo is judged unsurprising. Firefox is adding the Let's Encrypt root, LastPass pushes its authenticator, and GRC's DNS Spoofability Test is back after a gratuitous-ARP side effect of a new FreeBSD server. Steve explains RAID/BeyondRAID and what ZFS scrub is. The Black Hat items are the HEIST browser-based compression-size side channel, several HTTP/2 implementation attacks, and a teaser on the old Windows behaviour of leaking login credentials over SMB to any web page via IE and Edge, to be covered next week.

# Key points

- Windows 10 Anniversary Update: freezes, Edge not closing, McAfee compatibility check skipped by Microsoft, dual-boot partitions overwritten, Pro edition loses several Group Policy controls (consumer experience, tips, lock screen); Leo says suggested apps are only stubs that can be removed and that updates cannot be refused on a free upgrade.
- Unused or valid Windows 7/8 retail keys still upgraded to Windows 10 after the offer closed, per a Microsoft-watching journalist, with Microsoft declining comment.
- Apple bug bounty (announced at Black Hat): cash rewards up to $200,000; the argument is that it rewards researchers who want impact even though it cannot outbid criminal buyers.
- Qualcomm Android flaws (Check Point, DEF CON): local privilege escalation to root bypassing SELinux via a malicious but unprivileged app; most already patched, one slated for the September update; unlike Stagefright it needs an app install.
- Battery status API: reports charging state, level and time estimates; observed in the wild being merged into tracking fingerprints (Princeton study); present in Firefox, Chrome and Opera.
- Tesla/driver-assist sensor spoofing with ultrasonic and light tools: Steve regards it as expected and not a big deal.
- Let's Encrypt: Firefox is adding the ISRG root so cross-signing can eventually be dropped; Steve notes how far HTTPS adoption has come.
- LastPass Authenticator: TOTP plus one-tap push; Leo worries about nagging prompts, Steve notes the phone holds the codes separately.
- GRC found its DNS-based version checks and DNS Spoofability Test broken because new FreeBSD/FreeNAS machines sent gratuitous ARPs for an IP they did not own, similar to the mechanism CUJO uses.
- Portable Firefox keeps its own certificate store on removable media, an option against corporate interception.
- RAID explained: XOR parity gives single-drive redundancy; RAID 6 adds a second; rebuild times on large arrays make RAID 6 attractive; Drobo's BeyondRAID re-establishes redundancy on the fly, tags drives so they can be reordered, and allows mixed sizes.
- ZFS scrub is a manually started checksum verification of file-system blocks, not a surface-level read like SpinRite; both have different roles. Steve runs SpinRite on all new drives and found fresh drives that were already unhealthy.
- HEIST (Black Hat): lets JavaScript in a browser infer the size of encrypted HTTP responses via TCP window behaviour, enabling CRIME/BREACH-style compression attacks without being a network man in the middle.
- HTTP/2 implementation attacks (Imperva research): header-compression "HPACK bomb" memory exhaustion, slow-read, dependency cycle and stream multiplexing abuse, affecting major servers; implementation flaws, not protocol failure.
- Teaser: Internet Explorer and Edge will send the logged-in user name and a password hash to a remote SMB server named by a web page, behaviour known since 1997 that Microsoft considers by design; hashes were cracked in seconds by journalists; ISP blocking of Windows file-sharing ports and non-IE browsers mitigate it.
