# Summary

Steve begins with post-PRISM news. Britain's GCHQ is reported to tap fiber cables and share the data with the US, and testimony to Congress states that NSA rules treat encrypted communication as suspicious in itself, so it can be stored. Firefox 22 shipped with WebRTC (already in Chrome, with Microsoft pursuing a different standard) and with asm.js, a fast JavaScript subset that compilers such as Emscripten target; Firefox 23 is expected to block third-party cookies by default, and Leo notes advertisers may turn to browser fingerprinting. Bruce Schneier and the New York Times report that Skype ran a secret "Project Chess" to make calls available to intelligence agencies and that Skype joined PRISM in February 2011, before Microsoft's takeover. An EFF analyst's comment that data became valuable enough to keep forever is quoted. Snowden is reported to have given encrypted archives to several people as a dead-man's-switch. After a few TV notes, Steve gives a technical deep dive for SpinRite 6.1: SpinRite is a real-mode DOS program but needs 32 MB transfer buffers; he explains segments, the 286's protected mode and need to reset the CPU to return, the 386's fix, and how a cached segment descriptor limit survives a switch back to real mode, giving "extended real mode" (also called unreal mode) with 32-bit addresses to all memory. He argues this also lets double-buffered transfers speed up SpinRite, and announces that a later episode will cover Perfect Forward Secrecy in SSL.

# Key points

- UK GCHQ is reported to tap the fibers entering and leaving the country and share data with the NSA.
- Testimony: NSA procedures allow retention of encrypted communications because encryption is deemed suspicious; Leo notes this includes Tor. Steve ties this to the Utah storage capacity.
- Firefox 23 is slated to block third-party cookies; Safari already does; Microsoft keeps backing down, and Chrome will probably not. Fingerprinting could be disrupted by browser add-ons that scramble headers.
- Firefox 22 fixed 14 vulnerabilities, added WebRTC for plugin-free audio, video and file sharing, and asm.js, a compilable JavaScript subset running at about half native speed.
- Skype's secret Project Chess studied making calls available to intelligence agencies; per Snowden documents Skype joined PRISM on 6 February 2011; Schneier says corporate denials cannot be trusted.
- EFF's Dan Auerbach: storage became cheap enough that keeping user data forever is rational; Leo wears a Memoto lifelogging camera.
- Snowden reportedly distributed encrypted archives that unlock if he is harmed; the NSA says he forged digital keys to reach restricted areas.
- Intel history: 8088 had a 20-bit address bus using segment times 16 plus offset; the 286 introduced protected mode with descriptor tables but could return to real mode only by CPU reset (IBM used a hack with RAM in the clock chip); the 386 could switch back with a control register bit but did not reload the cached segment descriptors, which still carry 4 GB limits.
- Resulting trick: enter protected mode, load all segment descriptors with 4 GB limits, drop back to real mode, and use 32-bit registers to reach all of physical memory. IBM patented the idea in 1997 but earlier use (himem.sys, game developers) exists; Steve calls it extended real mode.
- SpinRite 6.1 plans: custom FreeDOS kernel with skipinit=1 to avoid a crash when FreeDOS probes every partition, PCI bus enumeration, own AHCI and IDE drivers, UDMA transfers, and buffers up to 32 MB (65,536 sectors) instead of the 63-sector BIOS limit so drives do not miss revolutions; SpinRite 7 will be a rewrite with file-system awareness.
- SpinRite was originally written as an interleave optimizer for early RLL drives, which required full surface analysis and data recovery.
- A tip from the New York Times that a refrigerator or stainless steel martini shaker acts as a Faraday cage for cell phones.
- Perfect Forward Secrecy and SSL will be the topic in two weeks.
