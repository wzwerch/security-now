# Summary

Steve follows up on Privacy Badger (it replaces embedded TikTok widgets and can run alongside uBlock Origin) and notes no new developments on eIDAS Article 45 beyond press coverage. Crypto news covers the Poloniex hot-wallet theft (about USD 130 million), the Raft protocol exploit (USD 3.3 million) and the Dutch operator of iotaseed.io who recorded the wallet seed phrases his site generated and stole funds, later sentenced to four and a half years. The main security story is Downfall (CVE-2022-40982), a practical speculative-execution leak in the Intel Gather instruction affecting Skylake through Tiger Lake; Intel's microcode fix may cost up to 50% performance in affected workloads and Intel had reportedly been warned in 2018. Other items: Russia preparing a formal VPN ban, two OpenVPN updates, SpinRite 6.1 finished after five release candidates, and listener questions on NAS backup, learning assembly, quantum threats to asymmetric crypto, and a plain explanation of root stores and interception. The final topic explains a UC San Diego paper showing a passive observer can recover RSA host keys from SSH and IPsec servers after a single faulty signature, linking the episode title to bit flips from cosmic rays or failing hardware.

# Key points

- Privacy Badger blocked nine third-party fetches on a news page including a TikTok widget; uBlock Origin blocked ten; Steve sees no conflict between the two extensions.
- Poloniex lost about USD 130 million (14th largest crypto hack); Raft lost USD 3.3 million; iotaseed.io stole about USD 1.9 million (returned by UK police) from users who used its suggested seed phrases.
- Downfall (Gather Data Sampling / Gather Value Injection) leaks the vector register file across processes on the same core; demos steal AES keys and kernel data; exploit code is public; Intel's microcode mitigation can cost up to 50% in some workloads. Cloud and shared hosts are most at risk; a browser-based path was suggested.
- Researchers note speculative execution flaws remain a recurring class; Bruce Schneier's "attacks only get better" is repeated.
- Russia is preparing a formal ban on all VPN services; OpenVPN released two security fixes, one touching memory.
- SpinRite 6.1: both DOS and Windows code are final after five release candidates; a scrollback log overflow at 113,359 lines was fixed; Steve now automates on-the-fly code signing at GRC with a hardware security module.
- Sophos firewalls apply hotfixes automatically, which supports Steve's call for auto-patching appliances.
- NAS backup advice: RAID 6, a second NAS at another site (Synology Hyper Backup or Drive ShareSync) and Syncthing to keep workstation folders mirrored.
- Quantum threat: only asymmetric crypto is exposed; going back to pre-shared symmetric keys would lose forward secrecy; browser-enforced deadlines are the likely migration path.
- Root-store explainer: certificates signed by trusted CAs are verified against the root store; a trusted interception appliance can forge certificates on the fly, which is exactly what Article 45 would give states.
- Fault attack: a single bad RSA signature (CRT with deterministic padding) lets anyone with the public key compute the private key via a GCD; the UCSD "Passive SSH Key Compromise via Lattices" paper extends this to SSH and IKE using lattices; of about 5.2 billion SSH records, over 590,000 invalid signatures led to 189 unique recovered RSA keys. Affected vendors named include Cisco, Zyxel, Hillstone and Mocana; OpenSSL-based stacks are hardened.
- Takeaway: ECC memory and software hardening matter for cryptographic code; bit flips arise from cosmic rays, failing power supplies or interrupt-handling bugs.
