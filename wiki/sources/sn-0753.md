# Summary

Steve corrects last week's worry: Microsoft Security Essentials signature updates continue on Windows 7 for years, so a third-party antivirus is unnecessary. The out-of-cycle fix for the black wallpaper bug, however, bricked Windows Server 2008 R2 machines lacking prerequisite updates by deleting boot files, while a Windows 10 update told some users they lacked permission to shut down. Google patched an Android Bluetooth daemon remote code execution flaw (CVE-2020-0022) that needs only the Bluetooth MAC address, but many older phones will never be updated. Clearview AI drew cease-and-desist letters from Twitter, Facebook, Google and YouTube, and the hiQ v. LinkedIn ruling on public scraping is discussed. NIST tested JTAG and chip-off extraction on destroyed Android phones with Cellebrite tooling, a new Ben-Gurion paper uses screen brightness as an air-gap exfiltration channel, and Leo relays the Washington Post report that the CIA secretly owned Crypto AG. The main topic is Chrome 80 changing cookie defaults to SameSite=Lax, which reduces cross-site request forgery and tracking but breaks some single sign-on flows.

# Key points

- MSE signatures continue to update on Windows 7 until about 2023; Steve and Leo suggest browsers and built-in antivirus suffice.
- KB4539602 fixes the wallpaper bug but requires the SHA-2 support update (KB4474419) and a servicing stack update first; without them Server 2008 R2 loses winload.exe and winload.efi and fails to boot; recovery by copying those files or running dism revertpendingactions.
- A Windows 10 monthly update caused "You don't have permission to shut down this computer" for some users; workarounds include log-off screen shutdown and a group policy tweak. February Patch Tuesday fixed 99 flaws including an IE zero-day. Windows 10's Start menu suggested Edge to Firefox users.
- CVE-2020-0022: Bluetooth RCE in Android 8.0, 8.1 and 9 (about two thirds of devices), a downgraded crash on Android 10; Bluetooth MAC often derivable from the WiFi MAC; Steve advises turning off unused radios and avoiding phones without update support.
- Clearview AI: claims 99.6 percent accuracy, relies on a First Amendment argument; Google, Facebook, Twitter and YouTube objected; the Ninth Circuit's hiQ ruling limited use of the CFAA against scraping public data but left other claims open; EFF calls for restrictions on police face recognition.
- NIST test of ten Android phones: JTAG and chip-off data extraction decoded with Cellebrite Physical Analyzer recovered deleted contacts, calls and messages; physical damage does not guarantee destruction, only wiping or destroying the memory chips does.
- Brightness covert channel (Ben-Gurion and Shamoon College): malware modulates screen brightness by a few percent, readable from camera footage; adds to the group's earlier fan, LED and speaker channels.
- Crypto AG: CIA and West German intelligence secretly owned the Swiss encryption vendor for decades (Thesaurus/Rubicon), a lesson for open, audited cryptography.
- Chrome 80 treats cookies without a SameSite attribute as Lax and requires Secure with SameSite=None; this blocks many CSRF and third-party tracking uses; Microsoft and others had to update ASP.NET, Exchange, SharePoint, Teams and OpenID Connect integrations; Mozilla and Microsoft plan to follow. Troy Hunt's blog explains the CSRF background; Leo doubts Google's motives since it has other tracking means.
- Microsoft reportedly backed off forcing Bing in Office 365 ProPlus.
