# Summary

Steve starts with Cloudflare's new at-cost domain registration, then the Justice Department's suit against California's net neutrality law SB-822, supported by the FCC chair, while Leo and Steve argue states acted within the space the FCC abandoned. Python is now the language of most attack tools (up to 77 percent of attacks in Imperva's summer data), and Cisco Talos' final report on VPNFilter added seven third-stage modules (traffic inspection, SSH, network mapping, DoS, port forwarding, SOCKS5 proxy, reverse VPN), showing it can pivot inside networks. Google answered the cookie-clearing and auto-sign-in uproar by promising a sign-in toggle and to delete its own auth cookies in Chrome 70. The previously discussed Task Scheduler zero day was adopted by GandCrab 5, ESET found the first UEFI rootkit in the wild (LoJax, from Fancy Bear), and the Go-based Torii botnet appeared with six persistence methods. The FBI-linked advisory on RDP abuse and a social-engineering trick to coax users into allowing browser notifications round out the news. The main story is Facebook's breach, where a bug involving "View As" and the video uploader let attackers obtain access tokens for any account, forcing a reset for about 90 million users and endangering Login with Facebook everywhere.

# Key points

- Cloudflare registers domains at wholesale cost (about 8 dollars for .com) with WHOIS privacy, for any Cloudflare account including free ones.
- SB-822 blocks ISP blocking, throttling and discrimination; DOJ sued on federal preemption grounds; 30 states have net neutrality bills.
- Python tools: more than one in five GitHub attack repositories; Imperva saw Python behind up to 77 percent of attacks; Steve plans a Python front end for SpinRite 7 on top of low-level assembly.
- VPNFilter: originally 500,000+ routers (Linksys, MikroTik, Netgear, TP-Link, later ASUS, D-Link, Huawei, Ubiquiti, ZTE); attributed to a state actor; hid its command server address in image EXIF data; final Talos report confirms it can attack hosts behind the router.
- Chrome 70 will offer a switch to stop linking web sign-in to browser sign-in, clearer sync state, and deletion of all cookies including Google's when clearing data.
- Edge's block-third-party-cookies setting had a bug fixed in a Windows update (Leo).
- GandCrab 5 used the patched Task Scheduler privilege escalation, illustrating how quickly zero days are weaponized; public dumping of the exploit is called irresponsible.
- LoJax (ESET): UEFI rootkit using a signed tool to write motherboard flash, surviving OS reinstall and drive swaps; defeated by Secure Boot and a current BIOS.
- Torii (Avast): brute-forces Telnet via Tor, written in Go for many CPU architectures, installs six persistence mechanisms, uses encrypted command channel; Steve urges "cut-and-paste" (non-memorizable) passwords and not exposing Telnet.
- RDP advisory: CrySiS, CryptON and SamSam abuse exposed RDP by brute force; stolen RDP logins sell cheaply; advise VPN access, certificates, non-default port and lockout policies.
- Browser notification prompts are used in fake "click Allow" overlays; grants persist even with the browser closed and can be revoked in settings.
- Facebook: the flaw dated from July 2017, was found through a spike in logins, affected 50 million accounts directly and 40 million more through token resets; executives were targeted; single sign-on turns one breach into many.
