# Summary

Steve opens with the apparent return of REvil: its "Happy Blog" leak site and negotiation portal came back online, and a purported operator said they had simply taken a break; Steve uses this to warn against treating speculation about why groups vanish as fact. Next is CVE-2021-40444, an actively exploited zero-day in the MSHTML (Trident) component that Office documents use to host web content through ActiveX; exploit write-ups and proofs of concept spread within days, so targeted attacks were expected to become broad spraying. He then walks through HP Wolf Security's survey of IT leaders and remote workers, showing how pandemic-era work from home pressured security. The Spook.js research shows a practical JavaScript Spectre attack that gets around Chrome Site Isolation because isolation is only per second-level domain. After listener feedback (free online copy of Michael Abrash's assembly book, a Verizon router adding an IoT network) and a detour into the simulation hypothesis, the main topic is the Meris botnet: about 330,000 hosts answering on a MikroTik-associated port, driving HTTPS layer-7 attacks that peaked at 21.8 million requests per second against Yandex. Steve explains the history of DoS attacks from SYN trickle through reflection to application-layer floods and why spoof-free but valid requests are so hard to filter.

# Key points

- REvil's leak site and negotiation portal returned in mid-September; a translated forum post said the coders had backed up and shut down servers after the main operator "UNKN" vanished, and a chat claimed it was only a break. Steve's lesson: note when speculation is all we have.
- CVE-2021-40444: MSHTML zero-day abused via malicious ActiveX controls inside Office documents, found by Mandiant and EXPMON. No patch at disclosure, Defender signatures were updated, and public exploit documentation followed quickly. Advice: be extremely cautious opening Office files from untrusted sources.
- HP Wolf Security survey: 91% of IT staff felt pressured to compromise security for business continuity; 83% called work from home a ticking time bomb; ransomware was the top concern (84%). Among workers, 48% said security measures waste time and 31% of younger workers had tried to bypass controls.
- Spook.js (University of Michigan, Adelaide, Georgia Tech, Tel Aviv): a JavaScript Spectre-style attack that can read data from other pages and extensions in the same process on Intel, AMD and Apple M1, including autofilled credentials. Cause: Chrome Site Isolation separates only by second-level domain, so sibling subdomains can share a process.
- Chrome response: Strict Extension Isolation (default since Chrome 92) puts each extension in its own process; developers can host untrusted user-supplied script on a separate registrable domain.
- Listener feedback: Abrash's "Zen of Assembly Language" is freely available online with the author's blessing; a Verizon G3100 router update added guest and IoT networks, which Steve praises.
- Simulation hypothesis (Nick Bostrom's 2003 paper, tied to the upcoming fourth Matrix film): Steve presents it as a serious philosophical question rather than a joke.
- DoS history: SYN trickle (Layer 4 state exhaustion, mitigated by stateless SYN cookies-style handling), SYN flood (Layer 3 router overload because SYNs are tiny), reflection/amplification via spoofed DNS queries (bandwidth exhaustion), then pooled protection from providers such as Cloudflare.
- Layer-7 floods consume dynamic page generation (scripts plus SQL queries) and are measured in requests per second; they cannot use spoofed sources because the TCP handshake completes.
- Meris (Latvian for "plague"), reported by Qrator Labs with Yandex: attacks growing from 5.2 to 10.9 and then 21.8 million RPS on 5 September 2021; Cloudflare saw a 17.2 million RPS attack in August. Roughly 328,000 hosts answered on TCP 5678, 42.6% in the US, mostly MikroTik routers across many RouterOS versions, so the entry vulnerability was unclear.
- Features: HTTP pipelining over HTTPS reduces connection setup cost, requests look valid, and blocking hundreds of thousands of non-spoofed IPs is operationally hard. Steve views the short Yandex bursts as a capability test.
- Leo and Steve note that routers are rarely patched or rebooted, so such botnets persist; Steve laments the complexity and cost the Internet must now add for defence.
