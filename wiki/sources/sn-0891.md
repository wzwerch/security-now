# Summary

Steve starts with Vectra's finding that Microsoft Teams (an Electron app) stores post-authentication tokens in plaintext on disk on Windows, macOS and Linux, which Microsoft declined to treat as urgent. Microsoft also rewrote Edge's SmartScreen library, and Russia's Roskomnadzor added SoundCloud to its block list. A new Exchange Server zero-day pair (informally "ProxyNotShell"), found by Vietnam's GTSC and exploited since August, remained unpatched with Microsoft's URL-rewrite mitigation already bypassed. Cloudflare launched Turnstile, a free, privacy-preserving CAPTCHA replacement usable without being a Cloudflare customer, and Google released the six-part "Hacking Google" video series. Listener feedback covers Honda key-fob replay attacks, password managers as phishing defence, Chinese and Russian software worries, whether public WiFi is still dangerous, an encrypting SD card, the Privacy Pledge, and an EU-hosted Google Analytics suggestion. The main story is two young researchers who found an HTTP request smuggling bug in Akamai's CDN that let them inject content into the shared cache of nearly any Akamai customer's site; Akamai paid no bounty, so they sold the findings to individual affected customers.

# Key points

- Vectra: Teams stores authentication tokens unencrypted in its local data, letting an attacker with file read access act as the user (Teams, SharePoint, Outlook via Graph) and bypass MFA; Vectra blames Electron's lack of built-in protected storage; Microsoft said it did not meet the bar for immediate servicing.
- Microsoft rewrote the Defender SmartScreen library in Edge from version 103; a temporary policy to revert is removed in Edge 108. Steve applauds the full rewrite.
- Roskomnadzor blocked SoundCloud, presumably for podcasts discussing the Ukraine invasion; Leo and Steve tried the block-list lookup form.
- Exchange zero-day (ZDI-confirmed two bugs, CVSS 8.8 and 6.3): requests resembling ProxyShell lead to remote code execution and an injected DLL phoning home with RC4-encrypted traffic; Microsoft's guidance copied GTSC's rewrite-rule mitigation, which was bypassed within days.
- Cloudflare Turnstile: invisible challenges (proof-of-work, proof-of-space, API probing, ML), no cookie use, support for Apple Private Access Tokens; Cloudflare says its managed challenges cut CAPTCHA use by 91%; critics note Google's CAPTCHA favours users with Google cookies.
- Google's "Hacking Google" series: Operation Aurora, Threat Analysis Group, Detection and Response, Red Team, Bug Hunters, Project Zero.
- Honda key fob replay: a listener's 2019 Accord was broken into; the dealer wanted $220 to reset the key system.
- Password managers help against phishing because autofill fails on lookalike domains.
- Steve and the Washington Post agree public WiFi is far less risky now that most web traffic is HTTPS; a VPN that tunnels all traffic or DNS over TLS adds protection; Leo notes the WiFi Pineapple can impersonate known networks and urges thinking about threat model.
- On Chinese-made software (EaseUS) and Russian software (Remote Utilities, Kaspersky), Steve and Leo advise against xenophobia while acknowledging supply chain concern.
- Swissbit encrypting SD card: a session key is generated per power-up and wrapped with a public key, so recorded footage is unreadable without the private key.
- Privacy Pledge (Proton, Threema, Brave, Tor Project and others) lists five privacy principles; Leo finds it very mild.
- Akamai flaw: sending a GET with a "Connection: Content-Length" header and an embedded second request made Akamai's first proxy strip Content-Length, split the request, desynchronize the response queue and cache a smuggled response for other users in the region; the researchers (Jacopo Tediosi and Francesco Mariani) demonstrated planting a script path on a PayPal demo host.
- Akamai had no bug bounty and offered only thanks; the researchers instead reported to individual customers, collecting about $25,200 from PayPal, $14,875 from Airbnb, $4,000 from Hyatt, and smaller sums; some platforms rejected reports. Akamai fixed it with filtering rules; the researchers are unsure other splitting tricks do not exist. Steve calls Akamai's lack of a bounty unconscionable.
