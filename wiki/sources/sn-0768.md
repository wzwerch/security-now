# Summary

Browser news opens the show: Firefox 77 will warn when pasted text exceeds a form field's maxlength (and Steve explains why password length limits are wrong), while Chrome 83 ships many useful but off-by-default features that Steve walks through enabling via chrome://flags (privacy redesign and safety check, third-party cookie blocking in Incognito, extensions menu, tab groups, secure DNS, full URL display). Adobe issued four emergency patches, and the unc0ver jailbreak exploits an unknown flaw across iOS 11 to 13.5. Researchers disclosed the NXNS attack, which uses malicious name server delegations to amplify DNS traffic up to 1,620 times, after vendors patched. The Bluetooth BIAS attacks show the standard itself permits impersonation of paired devices. A report of eBay probing visitors' local ports turned out to be fraud-detection scripting. Steve closes by arguing that because adoption would need around 80 percent and privacy fears dominate, voluntary contact tracing apps will not work, and that location-aware state apps are more useful.

# Key points

- Firefox 77 shows a red warning with the character count when input exceeds maxlength; sites silently truncating pasted passwords can break later logins. Steve: password length caps are indefensible; sites should hash (even client-side with salted PBKDF) and never see plaintext.
- Chrome 83 (after skipping 82): 38 security fixes; privacy and cookie settings reorganized; Safety Check (compromised passwords, Safe Browsing, version and extension checks) and Incognito third-party cookie blocking need flags to enable; extension toolbar puzzle-piece menu; tab groups with collapse; DNS over HTTPS flag; flag to restore full URLs (www, https) in the context menu.
- Adobe shipped out-of-cycle fixes for Character Animator, Premiere Pro, Audition and Premiere Rush.
- unc0ver jailbreak (iOS 11.0 to 13.5, excluding two version ranges) is polished and claims to preserve system security layers; Apple was expected to patch quickly. Zerodium paused buying iOS remote code execution bugs because of a flood of submissions.
- NXNS attack: an attacker-controlled authoritative server returns many nonexistent name server names pointing at a victim, so recursive resolvers retry against the victim; packet amplification up to 1,620. PowerDNS, CZ.NIC, Cloudflare, Google, Amazon, Microsoft, Oracle Dyn, Verisign and Quad9 patched before disclosure.
- Bluetooth BIAS: spec-level flaws (no mandatory mutual authentication, role switching, downgrade to legacy authentication) let an attacker who knows a paired device's address impersonate it on reconnection without the key; tested on 31 devices with 28 chips; the SIG is updating the spec and vendors can patch stacks, but many devices will not be updated.
- eBay's page runs ThreatMetrix fraud-detection JavaScript that probes 14 localhost ports for remote-access tools (VNC, RDP, TeamViewer, AnyDesk and others) via WebSockets, presumably to spot hijacked machines; Steve notes SQRL also uses localhost communication legitimately.
- Listener points: OFDMA sub-channels in WiFi 6 help low-bandwidth IoT devices; ISPs running their own DoH can still see queries.
- Contact tracing: modelers estimate roughly 80 percent adoption is needed; the platform design protects privacy but health officials need where and when, so state-run, location-based apps (like Utah's) are more useful; Leo says only a few states planned to use the Apple/Google API and agrees with Schneier that human tracing and testing are essential.
