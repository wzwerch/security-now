# Summary

Jason Howell co-hosts for the last time. Steve reviews April 2023 Patch Tuesday (97 flaws, one exploited zero-day in the Common Log File System driver, plus worrying MSMQ and DHCP remote code execution bugs), then reads a week of breach headlines (NCR, MSI, several crypto heists) and observes that cryptocurrency is the common thread. Google made its Assured Open Source Software service generally available for Java and Python at no cost. WhatsApp added Account Protect, Device Verification and a Key Transparency-based automatic security code check. A follow-up on the Vastaamo psychotherapy clinic: it went bankrupt and its CEO was convicted of criminal negligence. The main segment explains Google Project Zero's reverse engineering of NSO Group's zero-click ForcedEntry exploit, which abused iMessage's handling of fake GIF files to reach a PDF/JBIG2 decoder and then built a small virtual computer out of image-decompression logic operations to escape the sandbox. Steve calls it a remarkable and terrifying piece of engineering. KingsPawn spyware is deferred to a later episode.

# Key points

- April 2023 Patch Tuesday: 97 vulnerabilities (45 remote code execution, 20 elevation of privilege), plus 17 Edge fixes the week before. The exploited zero-day was in the Windows Common Log File System driver.
- MSMQ remote code execution (CVSS 9.8) when the service is enabled and exposed; Microsoft DHCP server RCE (CVSS 8.8, authenticated RPC, LAN only). Steve warns that patch reverse engineering lets attackers quickly target unpatched exposed servers.
- Weekly breach roundup: NCR Aloha outage by the AlphV ransomware gang, MSI hit by Money Message, Hyundai Europe leaks, irrigation system disruption in Israel during OpIsrael, and crypto losses (Hundred Finance $7.4M, GDAC $13M, Bitrue $23M, Yearn $11.6M, Terraport $4M). Steve notes cryptocurrency both enables ransoms and is itself a lucrative target.
- Google Assured OSS: free, curated, scanned, provenance-signed Java and Python packages (1,000+, including TensorFlow and Pandas) with SBOMs in SPDX/VEX; Google found 48% of new CVEs in the first 278 curated packages. Mandiant data: 17% of breaches start with a supply chain attack.
- WhatsApp Account Protect asks the old device to confirm moving an account; Device Verification uses a rotating security token and invisible challenge to detect cloned authentication keys (Steve's interpretation: a nonce that exposes two clients sharing one identity); Automatic Security Codes uses a public append-only Key Transparency directory for one-sided key verification.
- Vastaamo: clinic bankrupt, ex-CEO convicted of criminal negligence; the attacker had used a password to access an internet-exposed database, and earlier breaches in 2018 and 2019 had been hidden.
- ForcedEntry (analyzed by Project Zero with Citizen Lab samples and Apple): iMessage passed any file named .gif to the image library, which detects the real format, exposing 20+ codecs. The attackers used a PDF with an integer overflow in the Xpdf-derived JBIG2 decoder, then used JBIG2 logical operators (over 70,000 segment commands) to emulate a 64-bit computer for the sandbox escape.
- Project Zero called it among the most technically sophisticated exploits seen, showing NSO's capabilities rival nation states and that such access is purchasable.

# Other segments

- Picture of the week: needle-nose pliers "secured" with a cable running through their own wire cutters.
- Steve explains DHCP address allocation using his home and GRC networks as an example.
- Steve says he uses only iMessage and has little interest in social media.
