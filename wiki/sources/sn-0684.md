# Summary

Steve opens with the Windows 10 October 2018 feature update (version 1809), which deleted some users' Documents folders and was pulled; Leo later reports Microsoft traced it to Known Folder Redirection cleanup and estimated roughly one in ten thousand affected. Steve advises deferring feature updates 60 days where possible. A researcher chained two MikroTik flaws, the unauthenticated file read exposing a plaintext user database and a later authenticated code-execution bug, into a public proof of concept for root access to unpatched routers. Israel's cyber authority warned of WhatsApp takeover through the voicemail fallback for verification codes. Steve defends Google's handling of the Google+ API bug that exposed non-public profile fields of up to 500,000 accounts, then covers Chrome's extension tightening for version 70 and beyond, WiFi 6 naming, Intel's 9th-generation hardware Spectre/Meltdown/L1TF fixes, and big Adobe Acrobat and Foxit fix batches. The finale is the supply chain: Bloomberg's report of malicious Supermicro motherboard implants (denied by Apple and Amazon) plus a new report of a tampered Ethernet connector, with Steve judging the technique plausible and the problem broader than one vendor.

# Key points

- Windows 10 1809: some users lost user documents; Microsoft paused rollout; other problems included Task Manager CPU readings, Word not saving with add-ons, and some games; deferral of feature updates is only offered outside Windows Home; new Disk Cleanup can wipe the Downloads folder if ticked.
- MikroTik: the April Winbox file-read flaw exposes unhashed passwords, which unlock four Tenable-reported authenticated bugs including remote command execution as root; exploit source was posted; Mirai, miners and VPNFilter-type threats exploit these routers; Steve blames insecure-by-default policy.
- WhatsApp voicemail attack: after failed SMS verification WhatsApp calls with a spoken code; attackers retrieve it from voicemail using default PINs, then set two-step verification to lock out the owner; defenses are a strong voicemail PIN and WhatsApp two-step verification.
- Google+ (Project Strobe): a bug since 2015 let apps read non-public profile fields; logs kept only two weeks so exposure could not be confirmed; up to 500,000 accounts and 438 apps potentially involved; no evidence of misuse; consumer Google+ to be shut down; Steve thinks disclosure press was overblown.
- Chrome extension changes: inline install being removed (gone from Chrome 71); users can restrict extensions to click-activated or specific sites; extensions with obfuscated code barred (70 percent of blocked malicious extensions used it) with removal in January 2019; remotely hosted code under scrutiny; two-step verification required for developer accounts in 2019.
- WiFi Alliance renames 802.11ax as WiFi 6 and retroactively numbers earlier versions (ac is 5).
- Intel 9th-gen desktop Core: Meltdown (rogue data cache load) and L1TF fixed in hardware; Spectre variants 2 and 4 handled by microcode and software.
- Adobe fixed 47 critical Acrobat/Reader flaws (46 enabling code execution) and Foxit fixed 116, many found by Cisco Talos; PDF engines are huge interpreters.
- Supermicro/Bloomberg: allegation that subcontractors added tiny chips (possibly an extra SPI flash on the baseboard controller) to server boards; Apple and Amazon deny it; a security consultant said a telecom found an implant in an Ethernet connector in August; Steve notes NSA interdiction implants revealed by Snowden and that targeted shipments are easier to hide than mass tampering.

# Other segments

- SQRL progress: a generic SQRL Service Provider API, third demo site, and "managed shared access" feature.
- Question on SpinRite and encrypted drives (it works because it treats the drive as opaque).
- Banter on Google Wave and the Windows update names; Leo's Pixel Slate note.
