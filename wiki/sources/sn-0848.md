# Summary

Tavis Ormandy of Google Project Zero found a heap overflow in the signature-verification code of Mozilla's NSS library, present since version 3.14 (2012) and relevant to email clients, PDF viewers and many Linux and server products, though not Firefox itself. Dr.Web's analysis of cheap children's smartwatches found a trojanised updater, location exfiltration, default passwords and plaintext traffic, so Steve advises buying from reputable vendors only. Russia's Roskomnadzor banned six more VPN services, raising the total to 15. Microsoft restored a single "set default browser" control in a Windows 11 Insider build while pushing Edge pop-ups, Proofpoint described state actors adopting RTF template injection for phishing, and Google sued the operators of the Glupteba botnet, which falls back to the bitcoin blockchain for command-and-control. F-Secure found a wormable font-parser flaw (CVE-2021-39238) in about 150 HP printer models. After SpinRite debugging updates, the main topic is XSinator, a formal model and test site by German researchers that found 14 new classes of cross-site leaks (XS-Leaks) affecting every browser.

# Key points

- NSS signature verification flaw (patched in NSS 3.73 and ESR 3.68.1): heap overflow when handling DER-encoded DSA or RSA-PSS signatures in CMS, S/MIME, PKCS 7 and PKCS 12 handling; affects vendors such as Red Hat, SUSE, Oracle, Thunderbird, LibreOffice and others; Mozilla says Firefox itself is not impacted. Anyone shipping NSS should update.
- Children's smartwatches (Dr.Web study of four models, example ELARI KidPhone 4G): built-in update app with trojan functionality uploads location, SIM and phone data to a command server, can install apps; default password 123456, mostly unencrypted communication. Steve: avoid cheap trackers; Apple or other reputable vendors are safer though costlier.
- Roskomnadzor banned Betternet, Lantern, X-VPN, Cloudflare WARP, Tachyon VPN and Private Tunnel, joining nine earlier services (including NordVPN, ExpressVPN, ProtonVPN); the VPN vendors refused to connect to Russia's state database. Only Kaspersky's VPN complied.
- Windows 11 Insider build 22509 restored a one-click default browser setting; BleepingComputer found five Edge promotion pop-up messages in the registry.
- RTF template injection (Proofpoint): attackers abuse the RTF "template" control word to fetch a remote payload via URL when a document is opened; adopted by China-, India- and Russia-aligned APT actors in 2021, with lower antivirus detection than Office template injection.
- Glupteba botnet (over one million Windows machines, thousands added daily): spread through free-download sites, steals credentials, mines crypto, proxies traffic, and falls back to reading three bitcoin addresses on the blockchain to find new servers. Google sued two Russian nationals and worked with hosts to disrupt command servers.
- HP printers: CVE-2021-39238 (CVSS 9.3), a buffer overflow in the font parser exploitable via a crafted print job (potentially wormable), and CVE-2021-39237, a physical USB port flaw; around 150 LaserJet, PageWide and ScanJet models; firmware available since 1 November.
- XSinator (five German researchers, Best Paper at ACM CCS 2021): formal model of cross-site leaks, 14 new attack classes, 34 leaks tested across 56 browser/OS combinations. Leaks let a hostile page or ad infer a visitor's state on other sites (for example logged-in status via window.length, or a Gmail search hit via cache probing) despite the same-origin policy. Tab sandboxing does not help; Firefox and Tor Browser showed the fewest failures. Users can run the test at xsinator.com. Steve expects browsers to restrict such side channels over time.
