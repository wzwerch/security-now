# Summary

After explaining the PDP-8 clones with blinking lights behind him, Steve reports on a massive Patch Tuesday: 16 bulletins, with MS14-066 the standout. It fixes a privately reported remote code execution vulnerability in Schannel, the Windows TLS/SSL component present in every Windows client and server version, with Microsoft listing no workarounds or mitigating factors and the highest exploitability rating. Steve explains that servers, and potentially clients connecting to malicious servers, are at risk and that attackers will reverse-engineer the patch, so patching immediately is essential; the patch also adds four new TLS cipher suites, two with forward secrecy. Other fixes include 17 Internet Explorer issues, a TCP/IP privilege escalation and a font-parsing kernel flaw. He and Leo discuss President Obama's call for reclassifying ISPs under Title II for Net Neutrality. Steve recounts presenting SQRL at a DigiCert security summit in Las Vegas, where a lead FIDO architect called it the best-designed authentication system he had seen; the key idea is that with the Curve25519 family any random value works as a private key so the identity key can be derived by hashing the domain name with a master key. He warns about an easily exploited Belkin N750 router guest-network flaw (fixed in firmware 1.10.17) and shares a SpinRite success on a black-screen Windows boot failure. The main topic is Certificate Transparency: Google's public, append-only Merkle-tree logs of every issued certificate, designed so domain owners can detect rogue certificates and browsers can require inclusion, with Chrome planning to require it for EV certificates in early 2015.

# Key points

- MS14-066 (Schannel): remote code execution via specially crafted packets sent to Windows servers; affects all supported Windows server and client versions, no mitigations or workarounds, rated most likely to be exploited. Servers on IIS were the main risk, and malicious secure servers could attack connecting clients; reboot required. Apache and nginx servers are unaffected.
- The patch added four GCM cipher suites (two with ephemeral Diffie-Hellman for forward secrecy), which Steve welcomes.
- November 2014's other fixes: 17 IE vulnerabilities, a TCP/IP I/O control privilege escalation (publicly known), Windows audio, .NET, SharePoint, Remote Desktop, IIS security feature bypass, Active Directory Federation Services, a Japanese IME flaw and a kernel TrueType font flaw.
- Net Neutrality: Obama asked the FCC to reclassify broadband as a Title II common carrier after a court ruled the FCC lacked authority under its earlier rules; Steve favours some regulation because markets are unstable and most Americans lack ISP choice, while noting Title II is antiquated.
- SQRL talk at DigiCert's summit: a FIDO lead architect noted that choosing the Ed25519 curve lets any 32-byte value serve as a private key, so SQRL derives per-site keys from a master key and the domain without servers storing secrets, unlike FIDO U2F where wrapped random keys are held by sites.
- Belkin N750 dual-band routers had a guest-network web page flaw giving root access through a malformed POST; firmware 1.10.17 fixes it and a Metasploit module exists.
- SpinRite resolved a Windows 7 "black screen" boot failure in about an hour.
- Certificate system weaknesses: hundreds of trusted CAs, any of which could sign a certificate for any domain; incidents include DigiNotar, which was destroyed after concealing its breach, and an accidental CA-capable intermediate.
- Certificate Transparency (RFC 6962): Google's bots and CAs submit certificates to public append-only logs, organised as a Merkle hash tree so that membership and consistency can be proven with a small set of hashes; domain owners can monitor logs for unexpected certificates; browsers can eventually refuse certificates absent from logs. Several logs exist (Google, DigiCert and others) and Chrome intends to require CT for EV certificates starting around February 2015.
- Merkle trees are also used in BitTorrent-style file sharing and Bitcoin and were invented in 1975.
