# Summary

The promised "bone-crushing" Nightmare Eclipse exploit turns out to be LegacyHive, a User Profile Service elevation of privilege whose proof of concept was deliberately limited. July's Patch Tuesday fixed 570 vulnerabilities, the third record month in a row; Steve expects AI in the development path to eventually shrink the flow and notes Adobe has moved to twice-monthly updates. Okta's HollowByte shows that 11 bytes can make OpenSSL pre-allocate buffers and fragment glibc's heap; OpenSSL fixed it silently in June, but countless embedded copies (Steve's Synology runs OpenSSL 1.1.1u) will stay vulnerable.

1Password for Claude lets Claude log in on a user's behalf without ever seeing the credential, and an "Agentic Mode" locks the extension when an agent drives the browser. Bitwarden presents tools for agent credential access and shadow AI. Steve argues that credential use must be separated from credential management for agents. Agent Data Injection is a new prompt-injection class, and wp2shell is a rare pre-auth RCE in WordPress core fixed by forced updates. The main topic, from GuidePoint's Q2 2026 report, is ransomware groups using LLMs after the breach: FulcrumSec to make sense of stolen databases and DragonForce to fake legal counsel during negotiations.

# Key points

- LegacyHive lets a user mount another user's registry hive; Nightmare Eclipse says the PoC was stripped down (needs a second user's credentials) to prevent abuse. Steve doubts the claim. The series now includes RoguePlanet, BlueHammer, RedSun, YellowKey, GreenPlasma, MiniPlasma and UnDefend.
- July 2026 Patch Tuesday: 570 CVEs, 59 critical (48 of them RCE), 145 RCE and 254 elevation-of-privilege issues overall, three zero-days. Steve worries about a split between big publishers who can buy tokens and small ones who cannot.
- HollowByte (Okta Red Team): the 4-byte handshake header's length triggers an up-to-128K allocation before data arrives; randomized sizes fragment the glibc heap so memory stays bloated (a 1 GB nginx server was OOM-killed at 547 MB). Fixed by incremental buffer growth in OpenSSL 4.0.1, 3.6.3, 3.5.7, 3.4.6 and 3.0.21 without a CVE. Steve's advice: no open ports at home; update border appliances.
- 1Password for Claude (Mac, Claude desktop plus Claude in Chrome): biometric approval per login, the credential is injected into the page and never enters the model; access is scoped to the task. Agentic Mode hides the extension's UI from browser agents. Steve warns that persistent logins still give an agent all the user's power.
- Bitwarden's response: Secrets Manager, Access Intelligence to uncover "shadow AI", an Agent Access SDK for just-in-time human-in-the-loop access, and an MCP server. Cisco says 83% of IT leaders see agents deployed faster than security can support.
- Steve's concern: a cloud agent (for example one hosted in China) must see credentials in plaintext; systems must separate using a service from managing its credentials.
- Agent Data Injection (Seoul National University, UIUC, Largosoft): "probabilistic delimiter injection" inserts fake quotes, braces or tags into trusted fields so the model sees extra emails, buttons or tool results; even an escaped quote or dollar sign works.
- wp2shell (Assetnote / Searchlight Cyber via HackerOne): unauthenticated RCE in WordPress core since 6.9.0 (2 December 2025); fixed in 7.0.2 and 6.9.5 with forced automatic updates.
- Listener Rich Ingersoll points to Wiz's red, blue and green agents as a commercial version of the UK's Cyber Shield idea. GM is ending authenticator-app 2FA in favor of SMS or email, which puzzles Steve.
- A listener warns that AI will multiply the amount of code, much of it written by non-programmers without review; Steve sees the democratization as hugely positive anyway.
- GuidePoint GRIT: FulcrumSec used an LLM to untangle a victim's complex database schema, reverse SHA-256-hashed identifiers and a Caesar-shifted field, and wrote unusually precise negotiation messages. It claimed 1.3 TB / 700,717 files from Novo Nordisk with a $25 million demand and once used the victim's own OpenAI key. DragonForce claims to have lawyers on staff, almost certainly an LLM. AI also removes broken English as an attribution clue.
