# Summary

The episode is named for the CPU.fail site, which bundles four Intel data-sampling attacks (ZombieLoad, RIDL, Fallout, Store-to-Leak Forwarding) under the umbrella of Microarchitectural Data Sampling. Steve stresses the risk is mainly for cloud hosts running mutually untrusting code, that microcode fixes cost roughly 10 to 12 percent performance, and that disabling hyperthreading is the only other workaround. Before that he covers Microsoft's May patches, led by CVE-2019-0708, a pre-authentication, wormable flaw in Remote Desktop Services for which Microsoft took the unusual step of issuing a fix for Windows XP and Server 2003; he notes about 4.1 million Internet hosts answer as RDP servers and repeats that RDP must sit behind a VPN. He then reports on Red Balloon Security's Thrangrycat findings, a hardware design flaw in Cisco's FPGA-based Trust Anchor module that defeats secure boot across more than 100 product families, plus a chained remote command injection. Further items: a cryptocurrency theft snapshot, Matthew Green's rant about Bluetooth allowing 1-byte keys (context for the Titan BLE key replacement), iOS 12.3 fixes, and a Windows 10 System Restore failure.

# Key points

- CVE-2019-0708: RDP-related pre-auth remote code execution, wormable like WannaCry; affects Windows 7, Server 2008/2008 R2 and unsupported XP/2003 (KB4500705); Windows 8 and 10 not affected; Network Level Authentication gives partial mitigation.
- About 11 million addresses accept connections on port 3389 and roughly 4.1 million respond as RDP; Steve expects an exploit or worm within months and advises VPN-only access (certificate-based OpenVPN).
- Microsoft May Patch Tuesday: 79 vulnerabilities, 22 critical, including a critical DHCP server remote code flaw; Adobe fixed 83 issues in Acrobat/Reader and one in Flash.
- Thrangrycat (CVE-2019-1649): Cisco's Trust Anchor module FPGA bitstream can be modified, bypassing secure boot, reachable remotely when chained with an IOS XE command injection; hardware flaw hard to fully fix by software; Cisco's advisory described it as local-only and Steve found that misleading; Black Hat 2019 talk planned.
- 2018 cryptocurrency theft estimate of 1.7 billion USD, about 950 million of it from exchanges and infrastructure (CipherTrace via The Hacker News); Steve recounts losing 50 early mined bitcoins to a reformat.
- Matthew Green criticised the Bluetooth spec allowing negotiated key sizes down to 1 byte; Google and Feitian replaced T1/T2 Titan Bluetooth keys after Microsoft researchers found a pairing misconfiguration allowing nearby attackers to connect; USB and NFC keys unaffected.
- iOS 12.3 fixed 42 CVEs, about 20 in WebKit, including CoreAudio and kernel issues.
- Windows 10 known issue: restoring to a restore point created before May updates leads to a stop error and an unbootable system; recovery needs WinRE.
- MDS details: ZombieLoad (fill buffer), RIDL (line fill buffers/load ports), Fallout (store buffer, helps defeat KASLR), Store-to-Leak Forwarding; four CVEs (MSBDS, MFBDS, MLPDS, MDSUM); demonstrations include extracting AES keys, leaking across VMs and SGX; attacks hard to detect and AV unlikely to help.
- Steve predicts Intel will need to isolate state between hyperthreads at the microarchitecture level, possibly recovering performance in future silicon.
