# Summary

Steve opens with ZDI's disclosure of multiple critical, unauthenticated remote-code-execution bugs in the Exim mail server after more than a year of unanswered reports, with roughly 3.5 million servers exposed. He then covers malvertising appearing inside Bing Chat answers, Windows 11's general availability of passkeys plus new Custom App Control and firewall features, and a Wi-Fi beamforming side-channel paper ("Wiki-Eve") that he judges far too impractical for the headlines it received. Listener feedback includes why there is no Nobel Prize in mathematics, LastPass vaults leaking plaintext URLs as well as email addresses, blocking AI crawlers via robots.txt, a Syncthing tutorial, whether the Egyptian middlebox redirect could also lead to HTTPS pages, planning for family access to digital accounts, lithium-ion smart charging, KeePassXC for non-web secrets, and a reputation-based block on new software. The main topic traces why the server name in the TLS ClientHello was left in clear text, how ESNI tried to fix it using DNS-published keys, and how Encrypted Client Hello (ECH) with nested inner and outer hellos now ships in Chrome 117 and Cloudflare. Steve's judgment is that the privacy gain is worthwhile but it costs the Internet's former simplicity.

# Key points

- Exim: ZDI reported CVSS 9.8 out-of-bounds write flaws in the SMTP service on 14 June 2022, re-sent them in May 2023 and published a zero-day advisory on 27 September 2023 after the maintainers said "You do what you do"; about 3.5 million Exim servers are internet-exposed per Shodan, most in the US, Russia and Germany. ZDI's only mitigation is to restrict access to the service. Steve expects exploitation and a long patch tail.
- Malwarebytes found Bing Chat (GPT-4-based, with ads since March 2023) showing sponsored links that led to fake Advanced IP Scanner download sites; the conversational format lends misplaced trust to promoted links.
- Windows 11 now supports passkeys through Windows Hello (Settings, Accounts, Passkeys) and works with Edge, Chrome and Firefox; it is unclear how this coexists with browsers' own passkey stores. Passkeys remain hard to move between ecosystems. The same update adds firewall enhancements and a Custom App Control allow-listing option.
- "Wiki-Eve" (seven Chinese researchers): Wi-Fi 5 beamforming feedback information, sent unencrypted by phones, varies with finger motion and a trained model could infer single entered digits with 88.9 percent accuracy under tightly controlled training for one user and setup; Steve calls it theoretical and says headlines about stealing passwords on public Wi-Fi are exaggerated.
- There is no Nobel Prize in mathematics; the story that Nobel's wife had an affair with a mathematician is false because he never married; the Fields medal is the math counterpart.
- Steve will not join the fediverse and prefers consolidating channels (email lists, newsgroups, forums).
- LastPass also left stored website URLs unencrypted, so attackers can spot crypto-related users beyond email addresses.
- AI crawlers such as Common Crawl's CCBot can be blocked in robots.txt; Steve himself welcomes AI indexing of GRC. A "Syncthing Made EASY" video is the show shortcut. Steve and Leo agree that true randomness comes from physical entropy sources (reverse-biased diodes, Geiger counters, lava lamps), not from deterministic algorithms.
- A listener points out the Egyptian middlebox could have redirected to a malicious HTTPS site as well, which Steve accepts, meaning the HTTP hop is the vulnerable link.
- Planning for family: document access (Bitwarden emergency contact, Apple's Account Recovery Contact, a sealed paper with a backup security key) and revisit it periodically. A listener reports a Shop Pay card issue and suspicious calls after a Twitter DM; Steve treats it as anecdotal but unsettling.
- Windows Defender SmartScreen blocked a legitimate Bitwarden export, illustrating reputation-based blocking that Steve expects for ValiDrive's release the following week.
- Windows reset-with-clean-drive is not documented well enough to trust; Steve prefers encrypting a drive with VeraCrypt using a discarded gibberish password. Smart charging that limits laptop batteries to about 80 percent is sensible when mostly plugged in; Leo advises trusting manufacturer defaults.
- KeePassXC (open source, local files) is suggested for non-web secrets such as SSH keys and certificates instead of a cloud password manager.
- TLS ClientHello history: the Host header solved name-based hosting for HTTP; HTTPS needed the Server Name Indication (SNI) extension in the first handshake message, so eavesdroppers can see which site you connect to. ESNI encrypted only SNI using a key published in DNS (requiring DoH/DoT), leaving other metadata exposed and suffering from stale cached keys when Cloudflare rotated keys hourly.
- Encrypted Client Hello puts an encrypted ClientHelloInner as an extension inside a plaintext ClientHelloOuter; if decryption fails the ECH service provider returns a fresh public key so the client can retry. Chrome 117 enables ECH by default, Firefox is following, and Cloudflare launched ECH support for all customers. Enterprise and national filtering that relies on the visible hostname will be affected, and middleboxes may break, as happened with TLS 1.3.
