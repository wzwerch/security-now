# Summary

Leo opens with a story of Claude Code repairing his unbootable local AI machine (two EFI system partitions held different kernel versions). The first news item is the compromise of more than 400 Arch Linux User Repository (AUR) packages: modified build steps pulled in a malicious NPM package disguised as `atomic-lockfile` 1.4.2, whose preinstall hook ran a Rust ELF infostealer with an optional root-only eBPF rootkit. The analysis, by ioctl.fail, was static only. Steve walks through the long list of browsers, chat apps and developer secrets it harvests as a model of what an infostealer does.

Anthropic then disabled Fable 5 and Mythos 5 after a US government export-control directive barring foreign nationals from access. Anthropic said it had received the letter without specifics, that the apparent "jailbreak" amounted to asking the model to fix flaws in code, and that other models do the same. Leo and Steve see politics at play, and an open letter (freefable.org) urged restoring access. CISA published Binding Operational Directive 26-04, which sets patch deadlines of three days, 14 days, 60 days or "next upgrade" from a four-question decision tree. Steve discusses NPM v12's deny-by-default install scripts, with an inside critique that developers will click through approvals and attackers will relocate. Listener feedback covers career advice and the PHP rant (PHP as a teaching tool; a PHP Foundation security position). The closing topic is Microsoft's record June Patch Tuesday of about 200 Windows flaws plus 360 Chromium/Edge fixes.

# Key points

- AUR compromise: 400+ packages carried a Linux ELF credential stealer ("deps") delivered via an NPM preinstall hook; it persists through systemd units, reaches a Tor onion command server, and can hide itself with eBPF when root.
- Targets: Chromium-family browser cookies and local storage, Slack, Teams, Discord, GitHub, NPM and OpenAI tokens, SSH keys, shell history, Vault, Docker/Podman credentials and VPN profiles.
- Steve's lesson: infostealers aim to pivot from a developer's machine to employers or clients, as in the LastPass breach.
- Export-control directive received at 5:21 p.m. ET on the Friday after launch: Anthropic disabled Fable 5 and Mythos 5 for everyone; other models were unaffected. Anthropic argued its defence-in-depth, 30-day retention and thousands of red-team hours made Fable comparable in risk to deployed models.
- Anthropic admitted perfect jailbreak resistance is probably impossible for any provider. Leo reported the alleged jailbreak was only a "fix this code" request, and a researcher had made a "fix this code" T-shirt in the spirit of the 1990s crypto-export T-shirts.
- CISA BOD 26-04 "Prioritizing Security Updates Based on Risk" (10 June): public release, KEV listing, automatability and impact decide 3-day, 14-day, 60-day or routine patching for federal agencies.
- NPM v12 (July 2026) will disable automatic install scripts, require explicit options for git and remote-URL dependencies; `min-release-age` cooldowns already exist in NPM and other managers, and Leo uses a 14-day cooldown.
- The critique: widely used packages (esbuild, sharp, core-js, puppeteer, bcrypt) need install scripts, so approval becomes reflexive; VS Code's auto-run-tasks default change did not stop North Korean actors; malware will move to other execution paths and make detection noisier.
- Listener feedback: career advice for a new cybersecurity graduate (gain broad exposure first); a professor who teaches security with PHP; the PHP Foundation funding a six-month "Ecosystem AI Security Engineer in Residence". Steve clarifies his concern is the skill gap of typical PHP authors, not the language.
- June Patch Tuesday: about 200-206 Windows fixes (previous record month about 125), including 33 critical and 28 critical RCEs, six zero-days, with 65 elevation of privilege and 55 remote code execution flaws; Edge/Chromium added about 360 flaws. Without separating Edge the total would be near 566.
- Zero-days included GreenPlasma (CTFMON, CVE-2026-45586), YellowKey BitLocker bypass (CVE-2026-45585), a "Mini Plasma" Cloud Files driver fix from a 2020 CVE, and an Exchange OWA spoofing flaw (CVE-2026-42897) mitigated via the Emergency Mitigation Service.
- The HTTP/2 Bomb received a Microsoft fix (CVE-2026-49160 in HTTP.sys) plus a new `MaxHeadersCount` setting (default 200, range 50 to 65,535).
- A second BitLocker bypass, "Bitskrieg" (found by JonasL), was fixed within five days; Steve advises a boot PIN or hardware token because auto-unlocking TPM-only BitLocker remains vulnerable to boot-time attacks.
- The patch flood was attributed to AI-driven discovery (Microsoft's MDASH); Steve expects fewer bugs eventually as AI screens new code.
