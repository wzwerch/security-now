# Summary

Steve notes that the Windows 10 upgrade from Windows 7/8 is still free in practice, despite the 2016 deadline, with Leo adding caveats (image first, Microsoft has never confirmed it). He warns about a firmware bug in certain HPE SAS SSDs that bricks every affected drive at 32,768 power-on hours, fixed by firmware HPD8. A European Commission answer says it will not ban encryption and would assess US backdoor legislation against the Privacy Shield. CISA published a draft binding directive (BOD 20-01) requiring federal civilian agencies to run vulnerability disclosure policies. A Ryuk ransomware attack on managed service provider VCPI crippled around 110 nursing homes, prompting Steve's reminder about giving MSPs broad admin access. Firefox plans to enable anti-fingerprinting by default around version 72. SafeBreach disclosed unsigned-DLL loading bugs in Trend Micro, Kaspersky VPN and Autodesk software. After a brief Sync.com/Syncthing update, the main story is StrandHogg: Promon and Lookout found banking malware abusing Android's Task Affinity and task reparenting to impersonate any app, a design issue first described in 2015 research that Google had downplayed.

# Key points

- Windows 10 free upgrade: the Media Creation Tool still yields an activated "digital license" on Windows 7/8 machines (reported by Ed Bott); Steve and Leo advise imaging first; the next feature release was to be named 2004.
- HPE SAS SSD firmware defect (supplied by an SSD maker): drives with firmware before HPD8 fail unrecoverably at 32,768 hours, and drives commissioned together fail together, even in RAID. Affected ProLiant, Synergy, Apollo, MSA, StoreEasy and StoreVirtual lines; update tools exist for Linux, Windows and ESXi.
- EU/US: the Commission confirmed it would not ban encryption, noted GDPR names encryption as a protection, and said US legislation weakening it would be assessed for its effect on the EU-US Privacy Shield.
- CISA draft BOD 20-01: every federal civilian agency must publish a VDP, add at least one new system per 90 days, cover all Internet-accessible systems within two years, forbid "catch and keep" gag terms; not a bug bounty and not a national VDP; public comment via GitHub to December 27.
- VCPI (Wisconsin MSP) hit by Ryuk on 17 November; ransom reportedly about 14 million dollars which the owner said she could not pay; patient records, billing, email and payroll down, with patient care at risk. Lesson: MSPs often hold admin-level remote access to clients, so limit it.
- Firefox fingerprinting resistance (spoofed time zone/locale, rounded window size, reduced timer precision, blocked canvas extraction, limited fonts, sensors disabled) is available but off; default-on targeted for Firefox 72.
- DLL problems: SafeBreach found that Trend Micro Maximum Security, Kaspersky Secure Connection (VPN) and Autodesk services run as SYSTEM and load DLLs without safe loading or signature checks, allowing privilege escalation; all were patched. Background on DLL Hell and side-by-side assemblies.
- StrandHogg: malware abuses Android Task Affinity / allowTaskReparenting so a malicious app can overlay itself on a legitimate app to harvest permissions and credentials, without root. Promon found it in the wild with 36 malicious apps (BankBot variants) identified by Lookout; all top 500 apps and all Android versions (including 10) affected. It was introduced via dropper apps on Google Play; the 2015 USENIX task-hijacking paper described it. Advice: install only well-known apps.
