# Summary

The lead story is the "Nearest Neighbor" attack disclosed by Volexity: Russia's APT28 (GruesomeLarch) brute-forced Wi-Fi credentials of a US organization, then compromised a neighbouring company in a nearby building to use a dual-homed device as a wireless bridge, getting around multifactor authentication that protected the public-facing service. Steve's lesson is to log everything. Let's Encrypt turned ten, with about half a billion domains and up to six million certificates a day. The US Coast Guard warned about ship-to-shore cranes from ZPMC, which supplies about 80 percent of US ones, prompting a discussion of trust in Chinese-made infrastructure equipment. Further items: Pakistan blocked Bluesky and a council ruled VPN apps un-Islamic, a "repo swatting" trick abuses hidden GitHub/GitLab issue attachments to get repositories removed, and WatchTowr's analysis of the Palo Alto PAN-OS zero-days exposed poor design practices (about 2,000 firewalls compromised per Shadowserver). Six end-of-life D-Link VPN routers have an unauthenticated remote code execution flaw that will never be patched. Microsoft re-released Recall to Insiders, VulnCheck reported that 400,000 systems remain exposed to last year's most exploited bugs, and listener feedback covered hairpin NAT for malware labs, Cloudflare Tunnel versus Tailscale versus WireGuard, backdoor versus incompetence, and an InputStick USB/Bluetooth dongle. The main topic is Microsoft Office "Connected Experiences", an on-by-default setting that sends document content to cloud services for analysis and, in some cases, retention; Steve urges turning it off while Leo argues it is closer to spell-check style assistance than model training for others.

# Key points

- **Nearest Neighbor attack (Volexity, GruesomeLarch / APT28 / Fancy Bear)**: password spraying against an Internet-facing service yielded Wi-Fi credentials; MFA blocked remote use, so the actors hacked a nearby organization and used a Wi-Fi-capable host there to join the victim's enterprise Wi-Fi from the street side of the building; lateral movement used RDP and living-off-the-land tools; privilege escalation likely used the Print Spooler zero-day CVE-2022-38028. Takeaway: log everything, since you cannot know which logs will be needed.
- **Let's Encrypt at 10**: founded by ISRG (engineers from Mozilla, EFF and University of Michigan), uses the automated ACME protocol and domain-control validation; about 500 million domains and 90-day certificates; Steve recalls Firesheep and the old HTTP-then-HTTPS login model. Abuse by phishing sites was accepted as a trade-off.
- **ZPMC cranes**: Coast Guard notice (details restricted) and a congressional report call Chinese ship-to-shore cranes a possible Trojan horse; Steve notes no evidence of misuse, only capability; Leo warns against decoupling economically from China and notes US espionage in turn.
- **Pakistan blocks Bluesky**: first country-level block; Pakistani religious council also declared VPN apps against Sharia law.
- **Repo swatting**: attackers upload a malicious file to an unpublished issue on a victim's repo, then report the hidden file so the platform removes the repo.
- **Palo Alto Networks PAN-OS zero-days**: WatchTowr found the management interface built on PHP with an auth_prepend-style hack and a code comment calling it horrible; Shadowserver counted at least 2,000 compromised firewalls with web shells. Steve praises Palo Alto's communication but condemns the design.
- **D-Link end-of-life VPN routers**: DSR-500N, DSR-1000N (EOL 2015) and DSR-150, 150N, 250, 250N (EOL May 2024) have an unauthenticated stack buffer overflow found by researcher "delsploit"; no patch, no CVE; roughly 60,000 reachable devices. Earlier that month about 66,000 end-of-life D-Link NAS devices were similarly abandoned. Advice: replace, and avoid D-Link.
- **Windows Recall returns**: Insider preview 26120.2415 on Snapdragon Copilot+ PCs with opt-in, Windows Hello gating and encrypted storage; IT can disable it; new "Click to Do" actions on snapshots; Recall can mostly be removed through Windows Features.
- **Exploit longevity (VulnCheck/CISA)**: at least 60 threat actors used CISA's top exploited bugs of 2023; North Korea's Silent Chollima hit nine of 15 CVEs; over 400,000 systems still vulnerable.
- **Malware lab C2 spoofing**: a listener suggests hairpin NAT (NAT on the LAN interface) to redirect traffic for a hard-coded C2 IP to a local host, which Steve judges better than his extra-interface idea.
- **Remote access options**: Cloudflare Tunnel terminates TLS at Cloudflare so it is not end-to-end encrypted; Tailscale-style overlays are; plain WireGuard is light and iOS-friendly but needs an open port, so Steve would add port knocking (WireGuard first covered in Episode 744).
- **Backdoor versus incompetence**: intent cannot be proven; Steve thinks most are mistakes (old Cisco hard-coded accounts, the Windows metafile escape), because real backdoors would be better hidden.
- **ISP router in pass-through mode**: a Nokia ISP box left Ethernet ports without NAT or firewalling by default.
- **Office Connected Experiences**: optional connected experiences are on by default in Office; settings found under File > Account > Account Privacy > Manage Settings or via Trust Center privacy options; Microsoft states some content is retained while the account exists. Steve plans a "sacrificial lamb" Windows 11 test machine.

# Other segments

- InputStick: a USB dongle emulating keyboard and mouse that can be driven from a phone app, ordered by Steve and Leo for typing long strings (follow-up to last week's password question).
- reMarkable Pro review: Steve prefers the reMarkable 2 (color display, weight and stylus charging disappoint).
- Picture of the Week: escalators beside a staircase at a fitness center.
- Live Long and Prosper hand sign anecdotes; Advent of Code upcoming; GRC mailing list at 13,219 subscribers; Steve gets about 3,800 feedback emails and is working on DNS Benchmark and a "Beyond Recall" product.
- Reference to Security Now! episode 483 (Let's Encrypt introduction in 2014).
