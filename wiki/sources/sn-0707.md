# Summary

The headline stories are Operation ShadowHammer, in which trojanized, validly signed ASUS Live Update packages were served from ASUS's own servers from June to November 2018 and only acted on machines whose hardcoded MAC addresses matched a list of about 600, and the LockerGoga ransomware outbreak at Norsk Hydro, which forced the aluminium producer to run plants manually and restore from backup. Steve is skeptical that outsiders could have known the target MAC addresses and wonders about an insider or deeper access, while Leo argues for a nation-state intruder. Other items: a serious PHP deserialization flaw in the TCPDF library, early leaked builds of Chromium-based Edge, the FCC-driven SHAKEN/STIR call-authentication protocol, PuTTY 0.71, Mozilla possibly enabling the Windows root store when third-party antivirus is present, Microsoft's rename to Defender ATP with a Mac client, Windows Virtual Desktop, and the Windows 7 end-of-support notification dialog. The closing segment recaps Pwn2Own Vancouver 2019, where Fluoroacetate won Master of Pwn, escaped VMware from a browser, and then took the Tesla Model 3.

# Key points

- ShadowHammer: Kaspersky saw over 57,000 of its users receive the backdoored ASUS Live Update, estimated possibly over a million users overall; the malware was signed with two genuine ASUS certificates (the second used after the first neared expiry) and targeted only machines matching more than 600 MAC addresses found in over 200 samples. Symantec confirmed at least 13,000 infected customer machines. Kaspersky linked it to the ShadowPad/Winnti (BARIUM) actor and offered a MAC-check tool; ASUS had not responded to Motherboard. Full details were due at Kaspersky's SAS conference.
- Norsk Hydro: malware hit US systems first, then the whole 40-country network; plants went manual or stopped; the CFO said backups were good and payment was not the strategy. Kevin Beaumont identified LockerGoga, which does not need command-and-control traffic; one sample was once signed with a Sectigo (formerly Comodo) certificate that was later revoked; only 17 of 67 antivirus engines flagged an early sample.
- TCPDF (most popular PHP PDF library): PHP object deserialization via the phar:// wrapper allows remote code execution when attacker data reaches PDF generation (CVE-2018-17057, researcher Polict, building on Sam Thomas's work); 6.2.20 reintroduced the earlier bug, 6.2.22 fixed both; disclosed six months after the patch.
- Chromium-based Edge leaked build: looks like Chrome, uses SmartScreen instead of Safe Browsing and can install Chrome Web Store extensions; Steve expects SQRL support to follow.
- SHAKEN/STIR: signed caller ID across carriers; the FCC set an end-2019 deadline; AT&T and Comcast demonstrated the first inter-carrier authenticated call. Steve notes it stops spoofing but not robocalls themselves.
- PuTTY 0.71 fixes eight high-severity flaws that matter when connecting to a malicious server.
- Firefox experiments with automatically setting security.enterprise_roots.enabled when a non-Defender antivirus is registered on Windows 8 and 10.
- Microsoft Defender ATP for Mac in limited preview; Windows Virtual Desktop (Azure-hosted Windows 7 or 10 desktops, with Windows 7 updates through 2023) in public preview.
- Windows 7 end-of-support notice (KB4493132) states January 14, 2020 as the last day for updates and has a "do not remind me again" box; optional for now.
- SpinRite explanation: drives defend with ECC, SpinRite checks transient versus real defects by writing inverted data and reading back, and file-system-level defect management is no longer needed on modern drives.
- Pwn2Own Vancouver 2019: $545,000 across 19 bugs; Fluoroacetate (Amat Cama and Richard Zhu) won $375,000 and 36 points, including VMware Workstation host escapes (one chained from Edge inside a guest for $130,000) and Safari, Firefox and VirtualBox wins; new competitors included anhdaden (first Vietnamese winner), Niklas Baumstark and Arthur Gerkis; the Tesla Model 3 infotainment browser fell to a JIT bug ($35,000) after Team KunnaPwn withdrew its VCSEC attempt. Steve contrasts this disclosure route with selling to Zerodium.
