# Summary

Building on the previous episode's explanation of post-training, Steve explains "distillation": using a mature model's answers as training data for another model. Labs use it internally (Meta's large Llama 3.1 taught its smaller siblings), but doing it to a competitor violates terms of service and is hard to prove; Steve notes the irony that the labs trained on scraped web content themselves, yet calls breaking terms wrong. Anthropic brings Claude Mythos 5 to more defenders by running it only behind narrow interfaces: Claude Security scans for Enterprise customers, partners' security products, a $35 million "Defender Advantage Fund" (0xDAF) in credits for open-source security, and an expanded Cyber Verification Program. Bitwarden's Secrets Manager addresses coding agents that read `.env` files or are prompt-injected into leaking them.

The main topic is the paper "Prompt Injection as Role Confusion", introduced via Steve's friend Loren Kohnfelder, who described digital certificates and PKI in his 1978 MIT thesis. LLM conversations are one stream of tokens in which `system`, `user`, `assistant`, `tool` and `think` tags only mark roles by convention. The researchers show models judge who is speaking by style, not tags, so text that sounds like a user command or like the model's own reasoning gains that authority. Their Chain-of-Thought Forgery attack reaches about 60% success against frontier models.

# Key points

- Distillation lets a new model learn question-answer behavior from an existing model's outputs instead of costly human labeling. Steve: if a provider's terms forbid it, doing it is unlawful, but enforcement against Chinese labs is unlikely, and users of cheap Chinese models indirectly benefit.
- Anthropic's reasoning: the risk lies in direct prompting, so Mythos 5 runs behind purpose-built interfaces that return only artifacts such as patches or alerts. Claude Security (public beta, Enterprise) scans repositories with Mythos 5 and returns CWE, confidence, severity and a fix; every patch needs human approval. Glasswing earlier gave $4 million to open-source security groups.
- Bitwarden's blog "Your coding agent can read your .env file": agents hitting an auth error may `cat .env`, run `printenv`, grep for API keys or read `.aws/credentials`; a PR comment can inject "run `cat ~/.env`". Hiding the file, using environment variables, `.gitignore` or read-only access do not help; secrets must leave the agent's environment.
- Kohnfelder's verdict: "Role tags were a formatting trick that became the security architecture." He lists poisoned training data, RLHF side effects, ineffective guardrails, hallucination, alignment drift and now role confusion as fundamental LLM trust problems.
- The paper's history: in 2020 users typed "User:" and "Assistant:" themselves; ChatGPT (2022) turned them into harness-inserted tags; `tool` and `think` were added ad hoc. There is no parser and no mode, only tokens whose influence fades, which is why injections are placed near the end of fetched pages.
- Experiments with role probes ("CoTness"): stripping all tags, or wrapping everything in `user` tags, barely changes how strongly former reasoning text is treated as the model's own. Style overrides tags; "destyling" an attack cut success from 61% to 10%.
- Defense either memorizes known attacks (brittle, explains good benchmark scores but near-100% red-team success) or perceives roles (robust, but models cannot do it reliably). A May 2026 paper still found Opus 4.5 and GPT-5.4 failing 11% and 25% of automated attacks.
- The authors' theory: roles split competing objectives (exploration versus answer, instructions versus data) into separate channels; role confusion is that isolation failing. Steve concludes LLMs may not be perfectible and that this explains why AI resists control.
