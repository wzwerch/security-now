# Summary

Steve Gibson, joined by guest host Father Robert Ballecer, builds the episode around legacy software's long tail. The main story is the OneLogin breach, in which an attacker with stolen AWS keys spent about seven hours in a database holding user, app and key data, and customers were told to rotate essentially everything. Steve ties this to SQRL, which gives websites no secrets to keep, and explains SQRL's optional flags that refuse recovery and alternative login. A report claims the UK's Trident submarines run a Windows XP derived command system. Other items include an overhyped local sudo bug, Ethiopia shutting down the Internet during exams, a Verizon SIM-takeover that drained a victim's cryptocurrency through SMS second factor, 5 petabytes of open Hadoop file systems found via Shodan, the Fireball adware, and Chrome's WebRTC recording indicator gap. Steve then explains the double-encryption trick used to compare credit-card data without revealing the numbers, and why he keeps TOTP QR codes printed offline.

# Key points

- Padre demonstrated a thermal camera revealing residual heat on PIN pads (side-channel attack); advice is to add extra key presses or warm the pad.
- OneLogin (single sign-on provider): attacker used AWS keys for about seven hours; customers were told by private email to regenerate API keys, OAuth tokens, certificates, secure notes and have users reset passwords; public disclosure was criticized as opaque; decryption of stored secrets could not be ruled out.
- SQRL pitch: sites hold only data that verifies, never generates, a login, so a breach yields nothing; SQRL can work in two- or three-party mode; "client provided session" via a localhost server defeats man-in-the-middle spoofing; flags "request only SQRL login" and "request no SQRL bypass" let users forbid account recovery, which would have blocked the Verizon-style attack.
- Qualys found an obscure local privilege escalation in sudo (versions 1.8.6p7 to 1.8.20) tied to parsing of terminal info; patched by distributors, not remote, no known exploitation.
- WanaKiwi follow-up: WannaCry key recovery from memory works only in narrow, lucky conditions and needs both primes still intact.
- A think-tank report says UK Trident submarines use "Windows for Warships" (Windows XP based command system), illustrating legacy's long tail and monoculture risk.
- Ethiopia cut Internet access during national exams to prevent leaks; Steve notes this is only feasible in less Internet-dependent countries.
- Cody Brown lost about $8,000 of cryptocurrency after an attacker social-engineered Verizon into moving his number to a new phone; reinforces avoiding SMS authentication in favor of time-based tokens.
- Padre recounts a carrier SIM swap needing only IMEI numbers, and border agents asking for cloud apps on his phone.
- Shodan founder's script found 4,487 public Hadoop HDFS instances exposing about 5.1 petabytes without authentication, because Kerberos hardening is difficult.
- Check Point on Fireball: Chinese marketer Rafotech's adware on about 250 million browsers, able to download other malware; Steve recalls coining "spyware" in 2000 over Aureate adware and writing OptOut.
- Chrome WebRTC: stored per-site mic/camera permission plus a tabless pop-under means no recording indicator; Google declined to treat it as a bug.
- Other short items: Google Contributor's weak return, Google's ongoing end-to-end email encryption work, FCC straight-to-voicemail concern.
- Double RSA encryption is commutative, letting two firms match card numbers (PANs) without sharing them; a listener from a payments firm described it as related to homomorphic encryption ideas.
- TOTP QR codes: keep printed copies offline rather than on USB drives; prefer authenticator apps that refuse to export secrets.
