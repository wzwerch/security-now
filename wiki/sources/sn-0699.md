# Summary

Steve starts with a study showing that eight or nine of a person's social ties predict their online activity almost as well as their own data, then turns to a DNS hijacking campaign (FireEye links it to actors with an Iran nexus) in which stolen DNS-account credentials let attackers redirect domains, obtain valid Let's Encrypt certificates and run man-in-the-middle attacks; CISA issued an emergency directive requiring agencies to audit DNS records, rotate passwords, add multifactor authentication and monitor Certificate Transparency logs within ten business days. Steve muses that automatically issued certificates could carry a flag. Apple's iOS 12.1.3 and macOS updates fixed many code-execution bugs, and the Group FaceTime flaw let callers activate a recipient's mic or camera, with Apple disabling the group feature until a fix. abuse.ch's URLhaus coordinated takedown of about 100,000 malware sites, with large variation in hosting-provider response times. Chrome will block downloads from sandboxed iframes lacking a user gesture. Two Cisco RV320/RV325 router flaws (a configuration leak and remote command injection) were exploited within days of the patch, with thousands unpatched. The main topic is browser extension security: Chrome's proposed Manifest v3 could cripple uBlock Origin, uMatrix and Tampermonkey by limiting blocking web requests and remote code, while a French academic study found 197 extensions that web pages could abuse to read cookies, history and trigger downloads.

# Key points

- Social-graph prediction: knowing a handful of friends gives about 95 percent of the predictive power, a privacy implication for non-users.
- DNS hijack technique: compromise DNS account, change A, MX or NS records, obtain a certificate through automated validation; mitigations are MFA (not SMS) on DNS accounts, unique passwords, record audits and CT log monitoring; Let's Encrypt makes DNS the root of identity assertion; DNSSEC is not widely deployed.
- Earlier analysis found thousands of Let's Encrypt certificates containing "PayPal" in the name.
- Apple updates fixed arbitrary code execution in Bluetooth, kernel, WebKit, WebRTC, SQLite and more; Fluoroacetate credited via Trend Micro's initiative; shared code means iOS and macOS bugs overlap.
- FaceTime bug: adding oneself to a group call caused auto-answer; Apple shut off the group service pending a patch.
- URLhaus: 265 researchers, about 300 new malware URLs a day, 4,000 to 5,000 active at any time; some Chinese networks took more than a month to react; Emotet leads.
- Chrome 73 plans to stop iframe downloads without user action unless the sandbox attribute permits it.
- Cisco RV320/RV325: proof of concept published two days after the patch; Bad Packets found more than 9,600 of about 15,000 scanned devices vulnerable to the config disclosure; default credentials remain cisco/cisco.
- Manifest v3: replacement of blocking webRequest by declarativeNetRequest with a 30,000-rule cap would break uBlock Origin and uMatrix; forbidding remotely hosted code breaks Tampermonkey; discussion is open and Firefox may keep the flexible niche.
- EmPoWeb research: static analysis of message passing found 197 vulnerable extensions; Firefox and Opera removed most after disclosure.
