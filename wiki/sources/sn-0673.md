# Summary

Steve opens with another speculative-execution attack, SpectreRSB from UC Riverside, which abuses the hardware return stack buffer, defeats all deployed Spectre mitigations and even breaks Intel SGX; the authors suggest future CPUs keep speculative data in separate structures. He then updates the Rowhammer family: VU Amsterdam's RAMpage affects Android devices since the ION memory manager arrived in 2012, with a GuardION mitigation and an upcoming ZebRAM software defense. The leak of source code for the Exobot Android banking trojan, which needs no special permissions to learn the foreground app, is expected to spur copycats. Brannon Dorsey's write-up revived DNS rebinding, which exposes unauthenticated IoT devices such as Sonos, Roku and Google Home to scripts in a browser; Steve explains the attack and his DNS Benchmark rebind test. Other items include Venmo's public-by-default transaction feed, continued Russian phishing against US candidates, a rapidly built Huawei router botnet, Apple handing Chinese iCloud data operations to a state-owned firm, and a fifth undocumented Cisco backdoor. The main topic is the Data Transfer Project, in which Google, Facebook, Microsoft and Twitter build open-source service-to-service data portability, which Steve calls a sign of industry maturity.

# Key points

- SpectreRSB: attacks speculation through the return stack buffer rather than the branch predictor; bypasses existing mitigations and Intel SGX; Steve says current CPUs are fundamentally insecure while speculation remains.
- RAMpage (Rowhammer-style DRAM bit flips on Android since 2012) comes with a sideloaded checker app and GuardION; ZebRAM is a promised comprehensive software mitigation to be presented at OSDI in October.
- Exobot source was sold, then released freely; ThreatFabric calls it unusually potent because it identifies the foreground app without accessibility or usage-stats permissions.
- DNS rebinding: short DNS TTLs let hostile script switch a domain to a private LAN address and escape the same-origin policy; Armis estimated half a billion enterprise IoT devices exposed (switches, routers, streaming players, IP phones, cameras, printers, smart TVs).
- Defense: resolvers should refuse to return private or loopback addresses from public queries; OpenDNS offers this for IPv4; GRC's DNS Benchmark and its rebindtest names let users check; Sonos and Roku announced fixes.
- Venmo's default-public feed and open API let a researcher download about 208 million 2017 transactions; Leo advises setting transactions private.
- Microsoft reported that Strontium (Fancy Bear/APT28) used a fake Microsoft domain to phish staff of three US congressional candidates; Steve urges security training for campaign staff.
- A hacker calling himself Anarchy took over about 18,000 Huawei routers in a day via a 2017 UPnP flaw and was moving to Realtek routers; Steve wants Internet-facing appliances to auto-update by default.
- Apple completed moving Chinese iCloud data to a Chinese state-owned operator; Steve sees it as inevitable given Chinese law, while noting users could pick US storage when setting up.
- Cisco removed a hard-coded root password in Cisco Policy Suite (rated 9.8), the fifth undocumented backdoor found; Steve doubts it is still accidental.
- Optional missing Windows 7/8.1 and Server patches fix a network-monitoring stop error, an SQL Server port-reuse failure and a stuck web publishing service.
- Firefox 63 will default to asking before autoplaying media.
- Data Transfer Project: data models per vertical, data adapters (exporter/importer pairs), authentication adapters (OAuth likely), and Task Management Libraries, all open source; transfers go provider to provider without passing through the user's bandwidth.

# Other segments

- Erratum on the PortaPow USB data blocker, which contains a charge-detection chip.
- SQRL progress: Steve is learning the web-forum platform needed to host SQRL support forums.
- Listener SpinRite testimonial about drives still working after 12 years; show nears its 13th year.
