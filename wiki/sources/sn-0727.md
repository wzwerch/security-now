# Summary

With Jason Howell filling in for Leo, Steve covers conference news. The Black Hat keynote by Dino Dai Zovi urged security teams to "start with yes" and make security a shared responsibility. Microsoft announced an Azure Security Lab with rewards up to 300,000 USD, doubled its Azure DevOps bounty maximum to 40,000 USD, reported 4.4 million USD paid in a year, and published safe-harbor terms; Apple raised its top bounty to 1 million USD (up to 1.5 million for pre-release bugs), extended the program beyond iOS and promised pre-jailbroken research iPhones. The Chaos Computer Club defeated a hotel's smartphone key system through replay of Bluetooth Low Energy exchanges, which Steve says a simple nonce-and-signature design would prevent. Eclypsium showed more than 40 signed drivers from 20 vendors that expose arbitrary hardware and kernel access to user-space programs. Cat-and-mouse continues over Chrome 76's incognito behavior as sites detect its RAM-based file system by quota size and timing. Steve gives SQRL calendar news, a SpinRite rescue story, and previews the file-sync follow-up, noting heavy listener interest in Syncthing, which he already runs behind NAT with direct connections.

# Key points

- Black Hat keynote: work backwards from the job to be done, seek leverage through automation and feedback loops, culture beats strategy; security engineers should write code and use blame-free post-mortems.
- Microsoft: Azure Security Lab (isolated hosts for attacking IaaS scenarios; top prize 300,000 USD), Azure DevOps bounty doubled to 40,000 USD, 100,000 USD for identity/OpenID flaws, 250,000 USD speculative-execution program through year end, safe-harbor terms; top bug hunters list led by researchers from Qihoo 360's Vulcan team.
- Apple: top reward 1 million USD for a zero-click kernel compromise with persistent control, 50 percent bonus for pre-release bugs, scope widening to macOS, watchOS, tvOS, iPadOS, iCloud later in the year, and a Security Research Device Program of pre-jailbroken iPhones; Steve sees this undercutting gray-market buyers such as Zerodium, Cellebrite and Grayshift.
- Hotel mobile keys: researchers wirelessly sniffed a BLE key exchange and replayed it to open doors; hotel and vendor unnamed; Steve sketches a challenge-response with a per-lock secret ratchet using libsodium primitives.
- "Screwed Drivers" (Eclypsium, DEF CON): over 40 signed drivers from vendors including AMI, ASRock, ASUS, AMD/ATI, Biostar, EVGA, Getac, Gigabyte, Huawei, Insyde, Intel, MSI, NVIDIA, Phoenix, Realtek, Supermicro and Toshiba let low-privilege code read/write privileged hardware resources; Microsoft points to HVCI/memory integrity and Application Control blocklisting.
- Incognito detection: Chrome 76 backs its file system API with RAM; sites such as the New York Times detect it via the fixed 120 MB quota and uniform write timing; Google says it will keep closing detection routes; Steve argues paywall sites cannot have both anonymity and metering and floats micropayments.
- Syncthing: most-recommended tool by listeners; Steve runs it on a Drobo and two workstations behind NAT with direct peer connections via public discovery/rendezvous servers; other tips from listeners include VeraCrypt containers inside Dropbox and SyncBack.
- SQRL: calendar of OWASP talks at grc.com/calendar; Steve will be away for two Tuesdays and will pre-record a file-sync results episode for early October.
- SpinRite: a bookkeeper's dead XP machine recovered; legacy FoxPro upgrade lookup to be retired after SpinRite 6.1 ships.
