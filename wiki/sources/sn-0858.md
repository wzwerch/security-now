# Summary

Steve starts with the first Chrome zero-day of 2022 (CVE-2022-0609, a use-after-free in animation, fixed in 98.0.4758.102) and Apple's third zero-day of the year, a WebKit use-after-free fixed in iOS/iPadOS 15.3.1 and macOS and Safari. CISA added the Apple flaw to its Known Exploited Vulnerabilities catalog with a short federal deadline and also pushed agencies to finally fix the July 2021 SeriousSAM Windows bug (CVE-2021-36934), whose fix also requires deleting old volume shadow copies; the catalog's list of older bugs, many from 2014 to 2020, shows how long exploited flaws linger. February Patch Tuesday fixed 51 flaws with no critical ones. A Leo/Steve digression explains use-after-free and manual versus automatic memory management. Adobe issued an out-of-cycle fix on Super Bowl Sunday for Magento 2 (CVE-2022-24086, CVSS 9.8), expected to be exploited by Magecart-style card skimmers. The WordPress plugin PHP Everywhere was found to allow any logged-in user to run PHP (three CVSS 9.9 CVEs), prompting Steve to warn against third-party add-ons. Google reported a record 8.7 million dollars in bounties for 2021, and Project Zero statistics show average fix time down to 52 days. Microsoft is removing wmic.exe, and Steve formally releases InControl, a tool that pins Windows Update to a chosen version and release.

# Key points

- Chrome CVE-2022-0609 (use-after-free, exploited in the wild) fixed in desktop 98.0.4758.102 along with seven other fixes; 16 Chrome zero-days were patched in 2021.
- Apple fixed a WebKit use-after-free exploited in the wild across iOS, iPadOS, macOS and Safari (15.3.1); CISA gave federal agencies until 25 February 2022 under BOD 22-01.
- SeriousSAM (CVE-2021-36934): overly permissive ACLs on the Security Accounts Manager and other system files in Windows builds from October 2018 to July 2021; after patching, old volume shadow copies must be deleted; CISA set a 24 February deadline eight months after the fix.
- CISA's catalog then held about 16 older entries (Apple OS X, HTTP.SYS, D-Link DIR-645, SMBv1, Office, Win32k, LNK shortcuts, Apache Struts, SMBv3) with an August deadline for most.
- February 2022 Patch Tuesday: 51 fixes (50 important, one moderate, no critical), including DNS server, SharePoint, HEVC codecs, four Print Spooler elevation bugs and a Win32k privilege escalation flagged as likely to be exploited; other vendors patched the same day.
- Use-after-free explained: memory freed while a stale pointer remains; garbage collection and reference counting reduce but do not eliminate the risk; Steve prefers manual allocation in small assembler programs.
- Magento 2 / Adobe Commerce CVE-2022-24086: unauthenticated remote code execution fixed by emergency patch on 13 February; Sansec expected mass exploitation; Magento powers about a third of e-commerce and Magecart groups target it to plant card skimmers; around 100,000 sites still run end-of-life Magento 1.
- WordPress plugin PHP Everywhere (CVE-2022-24663, -24664, -24665, CVSS 9.9 each, about 30,000 sites): subscribers could run arbitrary PHP via shortcodes; Steve notes core WordPress is solid but add-ons are not, and isolates PHP software on a separate firewalled server at GRC.
- Google Vulnerability Reward Program 2021: 8.7 million dollars total, Android nearly 3 million (top single chain 157,000), Chrome 3.3 million for 333 reports, an unclaimed 1.5 million prize for a Titan M compromise, and the new bughunters.google.com portal.
- Project Zero 2019-2021: 376 reports, average time to fix 52 days (down from 80), fastest Linux 25 days and Google 44, slowest Oracle 109; Microsoft, Apple and Google account for about two thirds of reports; Chrome fixes average about 30 days versus WebKit 72.7.
- Microsoft is removing the deprecated wmic.exe from Windows 11 Dev channel builds (build 22523 onward) in favor of PowerShell; Steve advises moving scripts to PowerShell.

# Other segments

- Picture of the Week: two cave dwellers joking about writing "Stone Age" on checks; a digression on handwriting and signatures.
- GRC: InControl (originally StayPut) released as 82 KB of assembly; it sets six registry keys to target a Windows major version and feature release without disabling Windows Update, and reports partial configurations.
- Announced for next week: a deliberate, profitable BGP hijack.
