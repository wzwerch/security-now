# Summary

The show is dominated by the now-public Meltdown and Spectre disclosures, which Steve frames as an industry-wide catastrophe that follows from a general law: any shared short-term performance optimization lets a clever task infer other tasks' recent history by timing itself. Before that, he covers an odd Microsoft policy: the January 2018 Windows updates are offered only to machines whose antivirus has set a compatibility registry key, which also affects people running no AV, and AMD Athlon-era Windows 7 machines were failing to boot after the patch. Mozilla's claim that Firefox Quantum with tracking protection loads news pages far faster is discussed with caution. Western Digital My Cloud NAS drives were found to have a hard-coded backdoor, unrestricted upload and CSRF bugs; firmware fixed them in November. The Wi-Fi Alliance announced WPA3 (opportunistic encryption, protection against weak passwords, easier IoT setup, a 192-bit suite) again developed behind closed doors. Let's Encrypt reported 46 million certificates, wildcard support coming in 2018, and Steve notes the abuse of automated domain-validated certificates. The main segment explains Meltdown (cache and TLB state leaking across the user/kernel boundary), mitigations (flush on transition, PCID tagging to recover performance, timer fuzzing), and Spectre (out-of-order execution, branch prediction and speculation), with the SpecuCheck tool and Intel's microcode promises.

# Key points

- Meltdown mitigation cost: a graph from Epic Games shows one server's CPU load rising about 2.7x after the kernel patch; impact depends on how often a workload crosses the user/kernel boundary.
- PCID (process context identifiers) lets the OS tag cached translations per process instead of flushing, recovering most of the lost performance; Linux support existed but was unused until now, and old chips lack it.
- Spectre class: speculation (out-of-order execution, branch prediction, running both branches) leaves footprints; proofs of concept read kernel memory at roughly 2 KB/s. The LFENCE instruction can block speculation at critical points; compilers may insert it.
- High-resolution timers (RDTSC) enable the measurements; fuzzing timer resolution in VMs is another global mitigation; hardware timestamp access can be restricted.
- Intel promises microcode updates for 90%+ of chips within a week; older (Haswell and earlier) parts may stay slower; OEM firmware pipelines will take weeks to months. Simple ARM controllers, Raspberry Pi and Apple Watch lack speculation and are not affected; cloud multi-tenant systems are the main danger.
- SpecuCheck, a small command-line Windows tool, reports which speculation mitigations are active; Steve may write a friendlier one.
- Microsoft update gating: updates require an AV-set registry key; Defender counts; users without AV must set the key manually. Microsoft blamed incorrect AMD documentation for boot failures on older Athlon/Sempron machines.
- Mozilla's page-load test (top 200 news sites) showed private browsing with tracking protection at about 3.2 s versus about 7.7 s for Chrome; tracking protection effectively acts as an ad blocker and may break social widgets.
- WD My Cloud and some D-Link-related firmware: hard-coded admin account, upload flaw giving web shells, CSRF, wormable; update to the fixed firmware. A Metasploit module exists.
- WPA3 announced at CES 2018; closed process worries Steve; he speculates about Diffie-Hellman-based opportunistic encryption.
- Let's Encrypt: certificates more than doubled, HTTPS page loads rose from 46% to 67% in a year; wildcards and ECDSA roots planned; Steve flags fraud abuse of automatic DV certificates.

- Listener success story: a Bitcoin Faucet fraction from 2009 sold for a few hundred dollars.
- Listener tip: Firefox Session Manager add-on for saving tab sessions.
- Resolution of last week's photo: the fine print said the UK TV networks would drop off "in a matter of minutes, probably."
