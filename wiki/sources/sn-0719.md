# Summary

The headline story is that the Exim flaw from last week is now being exploited by a worm: Cybereason reported a campaign that uses compromised servers to scan for others, plants an SSH key for root access, removes competing miners and installs a cryptominer, hiding payloads behind Tor services and a disguised file. Shodan showed millions of Exim servers still running vulnerable versions despite a quick initial drop in vulnerable share. Steve also covers RAMBleed, a Rowhammer-derived side channel that reads other processes' memory (even with ECC memory) and was shown leaking an RSA key, and previews the Linux "SACK Panic" TCP flaw that can remotely crash any Linux kernel from the last decade. June Patch Tuesday fixed 88 flaws, and Microsoft started blocking Bluetooth LE devices that use a sample key from the specification, which Android had mistakenly used. Tavis Ormandy published a Windows SymCrypt certificate-handling denial-of-service after Microsoft missed his 90-day deadline by a day, prompting a debate between Steve and Leo about rigidity. Bitdefender obtained GandCrab's key database and released a decryptor, Yubico replaced FIPS keys with an entropy flaw, and Steve updates SQRL (glossary, "Ask" feature) and SpinRite speed expectations.

# Key points

- Exim worm: began within days of Qualys' disclosure; Cybereason counted over 3.5 million potentially vulnerable servers; the attack installs persistence via cron, an SSH key, a Python port scanner and a miner; Microsoft confirmed it targeting Azure VMs. Fix: update Exim to 4.92 or later and check for unexpected SSH authorized keys.
- RAMBleed (University of Michigan, Graz, others): uses Rowhammer-induced flips in the attacker's own memory to infer secret bits in adjacent rows; works despite ECC because correction delays are detectable; demonstrated leaking an OpenSSH RSA key at a few bits per second; mitigations include DDR4 with targeted row refresh; primarily a cloud concern.
- Linux TCP SACK Panic (found by a Netflix engineer): combining selective acknowledgment processing with tiny maximum segment size values triggers a kernel panic remotely; patch kernels or temporarily disable SACK; affects kernels from about a decade back and embedded Linux devices.
- Patch Tuesday: 88 fixes, 21 critical (13 scripting memory corruption), plus four SandboxEscaper-disclosed privilege escalations; Flash fix.
- Bluetooth: BLE specification sample long-term key found hardcoded in Android 7 to 9 (CVE-2019-2102); Windows June update blocks pairing with devices using well-known keys; Steve says implementers should blacklist spec sample keys.
- Project Zero issue 1804: crafted X.509 certificate can hang Windows SymCrypt modular inverse; Microsoft asked to ship in July after the 90-day mark and Ormandy disclosed; Leo called the deadline rigid, Steve defended deadlines.
- BlueKeep: DHS/CISA issued its own warning and confirmed exploitation on Windows 2000; still no worm; Steve reiterates miners are likelier and explains why Exim suits a worm (a week-long attack needs parallelism).
- GandCrab: Bitdefender obtained the key database and released a decryptor for versions 1, 4 and 5.
- Yubico FIPS YubiKeys 4.4.2/4.4.4: leftover self-test data reused as early random bits; replaced with 4.4.5; the risk is greater for shorter ECDSA keys.
- Facebook's planned Libra cryptocurrency was announced; Steve will review it later.
