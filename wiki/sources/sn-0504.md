# Summary

Steve opens with a short TrueCrypt follow-up: audit team member Tom Ritter said he still uses TrueCrypt, and Steve advises sticking with the final 7.1a release (archived at GRC) until compatibility forces a move to a fork, noting that version 7.2 only decrypts and removes volumes. The news covers the Patch Tuesday IIS bug in the kernel-mode http.sys driver, where a malformed HTTP Range header causes an integer overflow that can crash the server. Other items: Google's downloadable search history (Leo points out Google Takeout), Chrome 42 disabling the NPAPI plugin interface, an iOS networking library that skipped certificate checks, and the independent audit of the Let's Encrypt system. A longer exchange concerns whether TWiT can adopt HTTPS given its caching setup and the risk that ISPs will demand intercepting certificates. The main topic is how the Great Firewall works as a passive monitor that injects forged TCP resets, and how researchers established that the Great Cannon, which hijacked traffic to Baidu to attack GitHub pages, sits in the same network location and shares software traits with it.

# Key points

- TrueCrypt: Tom Ritter, one of the auditors, publicly said he still uses TrueCrypt; Steve recommends 7.1a while it works and warns the later 7.2 only supports removal. VeraCrypt and others are forks aiming at compatibility.
- IIS http.sys flaw: Windows 7-era and later IIS parse the HTTP Range header in kernel code; an end-minus-start-plus-one calculation on 64-bit values lacks an overflow check, so a crafted Range value crashes the machine. Microsoft labelled it remote code execution, but only crashes and some memory disclosure were known. Netcraft counted tens of millions of public IIS servers, active scanning began soon after the patch, and disabling kernel caching was a workaround (Steve was not exposed because his content is dynamic).
- Steve's design point: moving code such as GDI or part of a web server into the kernel for speed raises risk.
- Google's search history can be downloaded as JSON; Leo notes this has long been available through Google Takeout and the dashboard.
- Chrome 42 disables NPAPI by default (removal planned with Chrome 45); Java and Silverlight depended on it, while Flash uses Chrome's Pepper API; Netflix had moved to HTML5.
- The AFNetworking library for iOS (version 2.5.1) skipped certificate validation until 2.5.2; SourceDNA found about 1,500 affected apps with roughly two million installs and offered a lookup tool.
- Let's Encrypt: automated free certificates via the ACME protocol and the Boulder server software; the TrueCrypt auditors were hired to audit it; targeted for mid-2015. Steve describes the domain-ownership challenge as a file placed on the web server.
- HTTPS and caching: Leo says TWiT's caching layers complicate HTTPS; Steve predicts ISPs that profit from watching traffic (he cites an AT&T fee to avoid it) may eventually ask customers to install interception certificates, comparable to Superfish.
- Twitter now allows direct messages from anyone; Steve enables it.
- SQRL: Steve met a Yubico executive; they remain interested in a SQRL-compatible solution. He notes that a site could use SQRL to link a real-world identity when needed, and that FIDO needs a username first.
- Great Firewall: a passive "man on the side" system at China's border ISPs that watches packets for banned strings and, on a match, sends forged TCP reset packets in both directions using the observed addresses, ports and sequence numbers.
- The Great Cannon, in contrast, is an in-path man-in-the-middle that can intercept requests to or from selected IP addresses and substitute its own responses. It was first used publicly in March to turn visitors' browsers into attackers against two GitHub pages offering censorship-circumvention tools; China had earlier blocked all of GitHub for only about two days because of developer outcry.
- Researchers used TTL-limited probes to show the Cannon sits behind the same routers and hop counts as the Firewall, and its forged packets share odd TTL characteristics, implying common software. Steve notes it works only over plain HTTP and cannot see into HTTPS.
- Steve muses that he could treat China-hosted domains as a black hole, and that pressure against encryption may grow.
