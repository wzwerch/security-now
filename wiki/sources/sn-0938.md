# Summary

Steve shows first screenshots of ValiDrive, a quick freeware tool he wrote after the previous week's discussion of fake flash drives; it non-destructively checks that every part of a USB drive really stores data. He then reports that Google's Topics system has also reached Android, where the device notes interests from apps used. Apple's 2024 Security Research Device program, which loans specially fused iPhone 14 Pro units to vetted researchers, corrects his earlier claim that Apple cannot be examined. The main security story is a University of Wisconsin-Madison paper showing that the coarse permissions of browser extensions, even under Manifest V3, give them access to plaintext passwords and other secrets in page source on many high-traffic sites, and that a proof-of-concept extension passed Chrome Web Store review. Listener feedback covers GPC on mobile, Microsoft's attitude to the Secure Time Seeding bug, VirusTotal false positives and reputation-based antivirus, the history of uBlock versus uBlock Origin, ReadSpeed and USB drives, ARP spoofing and the case for HTTPS, and reporting exposed data to CISA. The episode closes with Apple's reply to the Heat Initiative explaining why it abandoned iCloud CSAM scanning, and what that means for EU surveillance legislation.

# Key points

- ValiDrive (named by a listener) reads, inverts, writes and verifies sectors across a drive and restores them, so it can be run on drives that hold data; it was in tester hands two days after the idea and Steve expects a release within days, with a monochrome mode for colorblind users. GRC's DNS Benchmark has over 8.5 million downloads.
- Fake drives typically report a large capacity but have only enough real storage (for example 32 GB behind a "2 TB" label) to hold the file allocation table; destructive command-line checkers already exist.
- A new-user prompt on Android describes Topics derived from recently used apps, which apps can later query for personalized ads, with an opt-out; Steve backs Topics as the cleanest compromise if it eventually replaces tracking.
- Apple's Security Research Device Program (applications through 31 October 2023) loans a modified iPhone 14 Pro for 12 months allowing custom kernels, arbitrary entitlements and shell access; eligible countries exclude China, Russia and North Korea, and findings are considered for Apple Security Bounty.
- The Wisconsin paper "Exposing and Addressing Security Vulnerabilities in Browser Text Input Fields" found about 1,100 of the top 10,000 sites keep user passwords in plaintext in the DOM and about 7,300 more allow the DOM API to read input values; examples include gmail.com, cloudflare.com, facebook.com, citibank.com, irs.gov, capitalone.com and amazon.com for different secret types. 12.5 percent of extensions hold the needed permissions and 190 already touch password fields.
- The researchers' unpublished proof-of-concept extension, posing as a GPT assistant, passed Chrome Web Store review while staying within Manifest V3 rules; Google's response treated properly permissioned access to password fields as not a vulnerability. Proposed fixes are a JavaScript package for sites and a browser warning when extensions touch sensitive fields.
- Password managers inherently need this field access, illustrating the trade-off between usability and security.
- Steve and Alex Neihaus attribute Microsoft's handling of the Secure Time Seeding bug to cost-cutting and hubris rather than malice.
- VirusTotal rarely errs by majority vote but newly built unsigned programs, like ValiDrive, may get a few false positives (3 of 66 engines) and a "not commonly downloaded" warning in Windows; modern antivirus relies increasingly on file reputation, and Steve now code-signs releases with hardware-stored certificates. A listener points out that submitting a URL lets a malicious server serve VirusTotal a clean file, so users should download then upload the file themselves.
- uBlock Origin does not support the Acceptable Ads list (the original uBlock does); Steve corrects himself and recounts how Chris Aljoudi took over the original uBlock repository and Raymond Hill (gorhill) started uBlock Origin.
- ReadSpeed (DOS) cannot test USB or NVMe drives; those come with SpinRite 7 on the RTOS-32 base.
- Listeners note that ARP spoofing lets attackers on shared Wi-Fi redirect traffic and TLS also detects corruption; Steve agrees HTTPS is better but still not enough with a hostile extension, and he and Leo hope HTTP survives for suitable uses.
- Anyone finding exposed sensitive data can report it to CISA at its web form or by email; a listener's report of an exposed SQL dump was redirected there.
- Industrial users prefer single-level-cell SD cards for reliability.
- Apple's reply to the Heat Initiative (written by Erik Neuenschwander) says scanning every user's iCloud content would create new attack surfaces, open a slippery slope to other content and government demands, and risk false accusations; Apple instead expanded on-device Communication Safety and a Sensitive Content Warning. Steve notes this contradicts the EU chat-control style proposals still pending, which he expects to be enacted as law around the end of 2023.

- Picture of the Week: a flooded road and park with a dry island around the storm drain, captioned about hiring the mayor's nephew.
