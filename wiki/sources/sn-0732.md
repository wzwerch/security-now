# Summary

Recorded out of order (the hosts had already taped episode 734), the episode follows the DNS-over-HTTPS rollout: Chrome 78 will auto-upgrade a user's existing DNS provider to its DoH endpoint only for six named providers, in contrast to Mozilla's Cloudflare-by-default approach, which drew criticism from OpenBSD and network administrators. Chrome 77 has already removed visible EV indicators and the www prefix, which Steve calls the death knell for EV certificates. He notes iOS 13.0 ships with a known lockscreen bypass slated for 13.1, covers Mozilla's Cloudflare-backed Firefox Private Network beta, and the 79-fix September Patch Tuesday (more CTF and RDP client fixes). Practical tips include Chrome Remote Desktop and Windows Controlled Folder Access, and a critical Exim bug (CVE-2019-15846) exploitable via a malformed SNI. The main story is Simjacker, an SMS-delivered attack against the S@T browser in SIM cards used for tracking by a surveillance vendor.

# Key points

- Chrome 78 beta DoH trial: upgrades to DoH only if the user already uses CleanBrowsing, Cloudflare, DNS.SB, Google, OpenDNS or Quad9; falls back on failure; flag to opt out; not on Linux or iOS. Steve praises preserving the user's DNS choice.
- Mozilla's default-to-Cloudflare DoH plan met objections: OpenBSD disabled DoH in its Firefox package and some admins fear leaking corporate DNS names to one provider.
- Chrome 77 hides EV company names (only in the certificate details) and trims www; Steve expects EV's longer-validation cost to become hard to justify.
- iOS 13.0 contains a FaceTime/VoiceOver lockscreen bypass exposing contacts (reported July 17 too late for the golden master); fixed in 13.1; it requires physical access. Steve likes the new built-in swipe keyboard; Leo highlights iOS 13's location-permission reminders.
- Firefox Private Network: a beta browser-only VPN/proxy extension (US desktop) using Cloudflare servers, with stated deletion of proxy data within 24 hours.
- September Patch Tuesday fixed 79 flaws (17 critical): another CTF/Text Services Framework privilege fix (input validation between TSF server and client), four RDP client RCE fixes (some already disclosed or exploited), and a VBScript engine flaw.
- Chrome Remote Desktop recommended as a free, NAT-traversing way to help non-technical relatives.
- Exim 4.92.2 fixes CVE-2019-15846: a crafted SNI during TLS handshake can give root-level access to servers accepting TLS; Exim runs roughly 60% of Internet mail servers and advertises its version, making it easy to find.
- Firefox tip: set browser.tabs.unloadOnLowMemory to true to cut memory use.
- Windows Defender's Controlled Folder Access and Ransomware Data Recovery (OneDrive) are off by default but useful anti-ransomware options; Steve found training CFA noisy.
- Simjacker (AdaptiveMobile Security): an SMS with spyware-like code abuses the S@T browser in SIM cards (SIM Application Toolkit) to make the SIM issue proactive commands to the handset; it returns location and device data by SMS without user awareness, can also dial, send messages, open a browser and disable the SIM; exploited for at least two years by a private surveillance company, with 100-150 numbers targeted per day in one country; potentially over a billion users, independent of handset make; defense lies with carrier-level filtering.
