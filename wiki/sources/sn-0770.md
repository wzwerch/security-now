# Summary

Firefox 77 fixed several high-severity bugs and expanded WebRender, but its automatic DNS over HTTPS rollout overwhelmed provider NextDNS and a county government's proxy, so Mozilla paused the automatic provider selection in 77.0.1; Steve explains why persistent TLS connections per browser are far heavier than UDP DNS. IBM announced it is leaving general-purpose facial recognition, Cisco Talos found two path traversal flaws in Zoom's chat (GIF and code snippet handling) fixed in 4.6.12, and the CallStranger flaw in the UPnP SUBSCRIBE feature allows traffic reflection and data exfiltration from vulnerable devices. Microsoft began replacing legacy Edge with the Chromium-based one. After listener feedback and SpinRite boot tool progress, Steve examines the confusion after Zoom's CEO said free users would not get end-to-end encryption so the company could cooperate with law enforcement, followed by contradictory explanations from Alex Stamos and a Zoom spokesperson.

# Key points

- Firefox 77: five high-severity fixes (three allowing code execution) and broader WebRender (Rust 2D renderer) use. The DoH rollout (the secondary provider NextDNS in particular) overloaded; Mozilla issued 77.0.1 and disabled automatic provider selection to roll out gradually. Steve links the trouble to DoH needing a long-lived TCP/TLS connection per browser, unlike stateless UDP DNS, and recalls SQRL's own experience with persistent connections.
- IBM CEO letter: IBM will no longer offer general-purpose facial recognition or analysis software and opposes its use for mass surveillance or racial profiling; calls for a national dialogue and bias auditing.
- Zoom client (Cisco Talos): CVE-2020-6109 (GIF fetch from non-GIPHY servers with unsanitized filenames) and CVE-2020-6110 (unvalidated zip extraction of code snippets with partial path traversal) allowed planting files on a victim's machine through chat; fixed in Zoom 4.6.12.
- CallStranger (CVE-2020-12695): UPnP SUBSCRIBE lets an attacker make a UPnP device send traffic to arbitrary destinations, enabling DDoS reflection, data exfiltration past DLP and LAN port scanning. Affects many routers, printers and Windows and Xbox stacks, though the miniupnp library since 2011 and pfSense are not affected. Mostly a LAN-side risk, uncertain on WAN exposure; a researcher's scanner sends results to an outside server. Steve's lesson: every connected device needs an update path.
- New Microsoft Edge is being pushed via Windows Update (KB4559309) with the legacy one hidden and not removable.
- Listener feedback: Steve says he will eventually release SpinRite's code publicly; Chrome has an "ask where to save" download option that prevents silent drive-by downloads; a 32-character password limit is acceptable though any length limit is probeable; a Windows 10 2004 upgrade slowed a listener's laptop.
- COVID dashboards (endcoronavirus.org states and countries) recommended.
- SpinRite: the InitDisk utility now confirms the target USB drive by physical removal and reinsertion, and the FAT root directory sizing was fixed after tester torture-tests.
- Zoom E2EE debate: after the previous week's design paper, CEO Eric Yuan said free users would not get end-to-end encryption partly to work with law enforcement. Alex Stamos explained all users get AES-256 encrypted content with Zoom-held keys, true E2EE will be opt-in for business tiers (identity verification being the aim), and Zoom does not hand keys to police; a Zoom spokesperson then said AES-256 GCM covers all users, and Pro-tier plans were undecided. Steve and Leo found the messaging contradictory and unreassuring, noting that whoever holds the keys could in principle comply with legal demands.
