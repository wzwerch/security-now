# Summary

A light news week, so the episode is built around listener feedback and one long topic: Apple's new PQ3 protocol for iMessage. Steve opens with a blog essay on Voyager 1's apparent end (corrupted flight-software memory, no spare copy of the code on Earth, 45-hour round trips), a Humble Bundle of Cory Doctorow books supporting the EFF, and a tip that Ctrl+K forces a search from the browser omnibar. Feedback revisits last weeks' email-link login idea: listeners pointed out that it still depends entirely on email security, so Steve now prefers emailing a short one-time six-digit code, and concludes that any "forgot password" bypass makes other login hardening largely theatre. Other feedback covers bcrypt's 72-byte password limit (fixable by pre-hashing), mapping a hash onto a restricted alphabet for legacy mainframe password rules, persistent versus session cookies, and Apple's password-rules JSON on GitHub. A listener who found an ancient nginx banner on a major company's login page and was offered a small bounty in exchange for silence was advised to report to CISA/CERT. The main topic is PQ3: Apple's four-level scale, hybrid Kyber768 plus elliptic-curve design, formal proofs, and periodic post-quantum rekeying roughly every 50 messages (at least weekly). Steve finds the claim of uniqueness over Signal overstated, since Signal's double ratchet has long rekeyed, and suggests Signal remains fully adequate.

# Key points

- Voyager 1: a blog essay describes gibberish from the flight-data software in December 2023; no copy of the original software exists on Earth, so a fix is uncertain.
- Browser tip: Ctrl+K in Firefox, Chrome, Edge and Brave forces the omnibar text to be treated as a search, not a URL.
- GRC news: SpinRite 6.1 forum feedback, plans for directly downloadable bootable images for non-Windows users, an email list system under construction, and code-signing certificate reputation being built by cosigning GRC freeware. ValiDrive became GRC's most downloaded freeware (about 2,200 per day).
- Microsoft's trusted-root programme appears to be ending special treatment of EV code-signing certificates from August 2024; TLS EV certificates continue but have no visible browser distinction.
- Email-link login: a link bound to IP address or cookie does not help if an attacker can read the victim's mailbox and request the link themselves; Steve now suggests an emailed six-digit one-time token instead.
- Password "forgot" flows make email the real root of trust, so other factors add little if that bypass exists.
- bcrypt truncates at 72 bytes, a problem for multibyte characters; pre-hashing with SHA-256 or SHA-512 avoids it.
- Legacy backends with tiny character sets can be served by hashing with a modern PBKDF (e.g. Argon2) and mapping bits or successive remainders onto the permitted alphabet.
- Apple publishes password-manager-resources on GitHub with a JSON format for site password rules; adoption has stayed low.
- Persistent cookies act as long-term login tokens (Firesheep era showed the risk of unencrypted cookies); "trust this browser" converts session cookies to persistent ones.
- Responsible-disclosure case: a company running nginx 1.12.2 (with a known remote code execution CVE) offered a $350 bounty with a silence clause; Steve advised filing with CISA/CERT-CC with the full email thread, which the listener did.
- Listener Earl notes the encryption debate lacks hard data on how often encryption actually blocks prosecutions; Steve suspects a workable compromise already exists.
- PQ3: Apple ranks messengers Level 0 to 3; Signal (PQXDH) is Level 2, PQ3 claims Level 3 because of ongoing post-quantum rekeying. Design: Kyber (ML-KEM) Kyber768 keys in the Secure Enclave, hybrid with ECC, formally verified (Tamarin, ETH Zurich; game-based proof by Stebila), rollout with iOS 17.4 and macOS 14.4.
- Post-quantum ratchet adds over 2 KB per rekey, so it happens about every 50 messages and at least every seven days.
- Steve's view: marketing overstates the gap, Signal's double ratchet has provided forward secrecy since 2013, and the "Telegram is Level 0" classification is disingenuous.
- Teaser: next week covers the Morris II zero-click GenAI worm research.
