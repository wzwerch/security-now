# Summary

Steve begins with Symantec, still on probation, being caught by a researcher scanning Google's Certificate Transparency log: 108 certificates from three Symantec-owned authorities were issued improperly, nine for domains whose owners had not authorised them. He then covers Tavis Ormandy's discovery that Cisco's WebEx Chrome extension (over 20 million users) could be driven by any website to run arbitrary programs, Cisco's quick patch limiting the trigger to its own domain, and the recommendation to isolate such extensions in a separate browser profile. Also covered: a notable iOS 10.2.1 security update with many WebKit fixes, the LastPass metadata controversy (a long-known design tradeoff), the SEC examining Yahoo, a proposed US breach-notification law that never passed, and a Finnish developer's demonstration that hidden form fields can harvest browser autofill data. Further items are the coming Tor hidden-service redesign, China's quantum-entanglement satellite, a Shodan report claiming about 200,000 sites still vulnerable to Heartbleed (Steve doubts the AWS part), a legal argument that choosing which finger to use is testimony, and the large Pwn2Own 2017 prize table. The main topic is how to calculate password entropy with logarithms to compare random words against random characters.

# Key points

- Symantec invalid certificates: three CAs (Symantec, GeoTrust, Thawte) issued 108 certificates with improper validation, found only because Symantec had been required after earlier mistakes to log every certificate; revocation protects little because browsers fail open. Steve praises certificate transparency.
- Cisco WebEx Chrome extension: a hard-coded magic identifier in its manifest let any site invoke a native helper to launch programs without user interaction, including through ad frames. Cisco shipped version 1.0.3 within a day, restricting use to *.webex.com; Steve notes that cross-site scripting on that domain would bypass the protection, and suggests using a separate Chrome profile or removing the extension.
- iOS 10.2.1 fixed kernel, libarchive and numerous WebKit bugs, including cross-origin data exfiltration and code execution; many found by Google Project Zero.
- LastPass metadata: an article claimed the vault is not fully encrypted; Steve explains that email address, login IP and some URL data used for features like history, bookmarklets and country restriction are intentionally outside the encrypted blob and the history option can be disabled.
- Yahoo: the SEC began investigating the handling of past breaches; a 2015 bill requiring breach notice within 30 days and fines up to 1,000 dollars per person per day never left committee.
- Autofill leakage: a page can lay out form fields off-screen so that Chrome, Safari, Opera and extensions such as LastPass fill profile data (address, even card details) into fields the user never sees. Defence: disable autofill and remove stored sensitive profiles; Firefox lacked the feature at the time.
- Tor next-generation hidden services: onion addresses are not published in directories; a key derived from the address is used instead, with ed25519 keys and 50-character addresses, so only those who already know the address can find a service. A conference paper had shown over 100 of about 3,000 directory nodes behaving suspiciously.
- China launched a quantum satellite (Micius) distributing entangled photons; Steve cautions that practical uses are far off.
- Heartbleed after nearly three years: Shodan counts roughly 199,500 vulnerable sites, but Steve suspects it misjudges AWS-hosted servers because it infers vulnerability from version strings.
- Fifth Amendment angle: a defendant argued that picking which finger unlocks a phone is a testimonial act; Steve calls it clever.
- Pwn2Own 2017: over one million dollars across five categories, including VM escapes from guest to host on VMware and Hyper-V (100,000 dollars) and browser exploits worth 80,000 for Edge and Chrome, 50,000 for Safari and 30,000 for Firefox, reflecting perceived difficulty.
- Echo wake words now include Computer; Amazon ads reportedly carry a spectral notch that stops devices responding.
- SpinRite cable-error counter can also reflect a damaged drive, not only a bad cable.
- Password entropy: with equally likely independent items, combinations equal dictionary size raised to the number of items; bits per item equal log of the dictionary size divided by log 2. A 95-character alphabet gives about 6.57 bits per character; a 100,000-word list gives about 16.6 bits per word, so several random words match fewer characters than one might think, and sites with length limits favour high-entropy characters.
