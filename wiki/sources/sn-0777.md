# Summary

Steve revisits the F5 BIG-IP TMUI remote code execution flaw: CISA now reports scanning and confirmed compromises, and F5 says unpatched devices are likely already compromised. From this he proposes that vendors run a dedicated, promotion-free Twitter account for vulnerability notices so whole security teams see them. The Twitter hack update says attackers accessed the DM inboxes of up to 36 of 130 targeted accounts, prompting calls for end-to-end encrypted DMs, ideally designed with Signal's team. An audit found GnuTLS 3.6.x before 3.6.14 used wrong data as a session ticket key, enabling passive decryption of many TLS 1.0-1.2 connections. Garmin suffered a five-day outage from the WastedLocker ransomware, attributed to Evil Corp, which raises sanctions questions. A Cisco ASA/FTD web services path traversal was patched but under active exploitation with most devices unpatched. He mentions the Bloatbox Windows 10 debloater, an errata on CVE numbering, and concludes with unexpected findings from his hyper-accurate storage benchmark.

# Key points

- F5 BIG-IP: CVE-2020-5902/5903 patched around 1 July; mitigation workarounds were bypassed; proofs of concept appeared within days; CISA saw scanning from 6 July and confirmed two compromises; US Cyber Command urged immediate patching. Steve: open a fast vendor-advisory channel and never skip it.
- Twitter: DMs of up to 36 accounts accessed, including a Dutch elected official; Senator Wyden urged E2EE DMs. Steve suggests reusing the Signal protocol rather than inventing a scheme; Leo doubts Twitter DMs fit secure messaging.
- OpenSSL alternatives: BoringSSL, LibreSSL, s2n, Google's Tink, and GnuTLS (used by apt, curl, Wget, Git, CUPS, Samba, Synology and others). CVE-2020-13777: since release 3.6.4 (2018) session ticket encryption used a predictable key until first rotation, so passive decryption and trivial TLS 1.3 interception were possible. Action: check which installed packages link to affected versions and update.
- Garmin: services encrypted on 23 July 2020; Garmin did not name the malware but sources pointed to WastedLocker from Evil Corp (Dridex/BitPaymer lineage, sanctioned by the US Treasury in December 2019). Reported ransoms for such gangs run from 500,000 to 10 million dollars. Sky News said Garmin obtained a decryption key. Steve notes targeted, pre-reconnoitered attacks are an escalation and recommends offline backups, patching and anti-phishing.
- Cisco ASA/FTD web services directory traversal (CVSS 7.5): file reads from the WebVPN/AnyConnect file system, no workaround, public exploit and active attacks; Rapid7 found about 85,000 exposed devices with only about 10% apparently rebooted since the patch and 27 of 398 Fortune 500 instances patched. Steve's golden rule: web management interfaces are dangerous.
- Bloatbox: new open-source Windows 10 debloater; Steve warns that some options remove needed components.
- Errata: CVE sequence numbers no longer indicate order because many CNAs hold blocks.
- Benchmark findings: hard-drive throughput falls as the head moves inward (the back of a 10 TB Seagate ran at roughly 46% of front speed); results repeat to four digits. One SSD was slower at its front, suggesting localized wear levelling. Identical drives showed different, repeatable profiles, likely due to sector remapping around defects. A tester found a SATA III SSD on a SATA II port and doubled throughput by moving it.
