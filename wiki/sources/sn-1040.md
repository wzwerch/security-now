# Summary

The episode opens with a discussion of bug bounties (Leo notes a UAE start-up offering government-backed millions for mobile exploits) and then covers a German Federal Court of Justice (BGH) ruling that revives Axel Springer's claim that Adblock Plus infringes copyright by altering a page's in-memory DOM; Mozilla warns that this could threaten all browser extensions. Steve links it to a list of AI copyright lawsuits and the idea that AI summaries are the "ultimate ad blocker", with licensing deals (for example AP to Google Gemini) already forming. He then reports that the UK appears to have dropped its demand for an Apple backdoor, Microsoft 365 now limits new tenants to 100 external emails a day to curb spam, Russia is testing blocks on Google Meet, and Bluesky has blocked Mississippi IP addresses rather than comply with HB1126's age-verification law. Security items include an AI-confusing prompt used in phishing mail, a Go module that steals credentials from its own users, Linux desktop malware by APT36, Apple's critical DNG decoder flaw (CVE-2025-43300), and a trivial Docker Desktop container escape (CVE-2025-9074). After listener feedback on Syncthing and offsite backup, Steve devotes the main segment to Marek Toth's DEFCON 33 DOM-based extension clickjacking against 11 password managers: he considers it a known class of attack and an inevitable usability-versus-security trade-off, not an end-of-the-world zero-day.

# Key points

- Germany: the BGH sent Axel Springer v. Eyeo (Adblock Plus) back for re-examination of whether DOM/CSS/bytecode is a protected computer program and ad-blocking an unlawful modification. Mozilla's Daniel Nazer warns of effects on accessibility and privacy extensions; Steve argues the logic could extend to tracker-blocking DNS filters and says AI summarisation is a far bigger threat to ad revenue.
- AI litigation overview: cases include Advance Local Media v. Cohere, Andersen v. Stability AI, Bartz v. Anthropic, Getty v. Stability, Kadrey v. Meta, Dow Jones v. Perplexity, Thomson Reuters v. ROSS; outcome hinges on fair use and will likely reach the US Supreme Court. Licensing (AP to Gemini) may create a new content-for-AI ecosystem.
- UK/Apple: DNI Tulsi Gabbard tweeted that the UK withdrew its demand for a backdoor into encrypted Apple cloud data; no formal confirmation; the EU is pressing ahead with its own chat-scanning plans.
- Microsoft 365: new tenants limited to 100 external emails per day because spammers abuse the default onmicrosoft.com domain; custom domains avoid the limit but start with no reputation.
- Russia: repeated Google Meet outages are read as tests for a block.
- Bluesky blocks Mississippi IP addresses because HB1126 (Walker Montgomery Protecting Children Online Act) requires age verification and parental consent for all users; the Supreme Court's earlier age-verification ruling allowed it to take effect. IP geolocation misfired for some out-of-state mobile users. Steve sketches a privacy-preserving QR-code/token flow using a digital ID, but notes TruAge as it stands over-discloses.
- A phishing campaign hides a long "think deeply" prompt in emails to slow AI-based spam scanners; Leo tested a similar prompt and ChatGPT simply asked a clarifying question.
- Socket found Go module golang-random-ip-ssh-bruteforce, which scans for SSH on port 22 but sends every credential it cracks to the author's Telegram bot (the author is a Russian-speaking actor "IllDieAnyway").
- Linux desktop malware: APT36 (Transparent Tribe) targets Indian government Linux users through .desktop launcher files disguised as PDFs inside a ZIP, followed by a Go backdoor with persistence and anti-analysis checks. Steve expects more Linux malware as European governments adopt Linux desktops.
- Apple CVE-2025-43300: out-of-bounds write in the DNG lossless JPEG decoder (RawCamera.bundle), exploited in targeted attacks as a zero-click vector; fixed in iOS/iPadOS 18.6.2 and 17.7.10 and macOS 15.6.1, 14.7.8, 13.7.8. Root cause is a mismatch between the declared samples-per-pixel and the data actually supplied.
- Docker Desktop CVE-2025-9074 (found by Felix Boulet, fixed in 4.44.3): the Docker Engine API on the internal network (192.168.65.x:2375) was reachable unauthenticated from any container, allowing creation of a privileged container that mounts the host disk; no bounty exists for Docker. Lesson: authenticate every control-plane endpoint and test network isolation assumptions.
- Feedback: Syncthing is the answer to offsite backup (encrypted receiving folders are in beta); Sync.com is Steve's zero-knowledge cloud option (TNO / pre-Internet encryption); a listener reports AI scraping can save hosting costs for small WordPress sites; a Synology native Syncthing package broke on upgrade to 2.x; ChatGPT can maintain a recipe cookbook; travel advice is to carry a cheap burner phone rather than unlock a main phone at borders.
- Clickjacking talk (Marek Toth, DEFCON 33, 9 August 2025): overlaying invisible password-manager autofill UI under a fake cookie banner so a click triggers autofill of credit card or identity data; 11 managers were named (1Password, Bitwarden, Dashlane, iCloud Passwords, Keeper, LastPass, LogMeOnce, NordPass, Proton Pass, RoboForm and others). It works only for data the manager would offer on a site (new unknown sites), not full vault dumps. Bitwarden 2025.8.1 and 1Password 8.11.7 shipped mitigations; 1Password says the only full fix is a confirmation prompt, which users previously rejected. Steve: browser-based autofill can never be absolutely safe; keep the extension locked on unfamiliar sites.
