# Summary

Mikah Sargent filled in for Leo Laporte. The lead story was H&R Block Business 2025 tax software, which installs an unconstrained root CA ("WK ATX ServerHost 2024", valid to 2049) into the Windows trust store, ships its private key in a DLL and leaves it behind after uninstall; a researcher (Yifan Lu) demonstrated man-in-the-middle with it and H&R Block closed his report as out of scope. Steve guessed the motive is a local web server UI and sketched a safe design (per-install ephemeral keys, short-lived name-constrained root, private key discarded after signing, `hrblock.localhost`). Next: a cyberattack that took down Intoxalock's breathalyzer calibration system for about ten days, locking some drivers out of their cars; Firefox 149's free built-in VPN (50 GB/month in four countries); Jscrambler's finding that TikTok and Meta ad pixels collect hashed identifiers, cart details, form structure and even partial card data, sometimes before or despite consent; Russian businesses begging to get Telegram and WhatsApp back; and an OpenClaw token phishing campaign aimed at developer crypto wallets. Cisco's CVE-2026-20131 (CVSS 10.0, Secure Firewall Management Center, Java deserialization) was exploited as a zero-day by Interlock ransomware from 26 January, 36 days before the 4 March patch, per Amazon Threat Intelligence; Steve used it to argue for defense in depth and IP filtering of management interfaces. Ubiquiti patched a CVSS 10.0 path traversal in UniFi. The main topic was bucketsquatting: abandoned Amazon S3 bucket names re-registered by watchTowr Labs received over 8 million requests from government, military and corporate networks, and AWS has now introduced account regional namespaces, which only help new buckets.

# Key points

- H&R Block Business 2025 installs a root CA with a 2049 expiry and no identifying name, embeds its private key in a DLL, and does not remove it on uninstall; anyone can mint trusted TLS or code-signing certificates for affected PCs. Firefox warns on the researcher's demo site unless the software was installed.
- H&R Block's disclosure handling: reported 10 March, asked for a video proof of concept, then closed as out of scope on 20 March while noting similar findings from internal assessments. Steve calls for audits of the trusted root store and laments weak software liability.
- Steve's safer design: generate unique 4096-bit key pairs at install, short-lived (90-120 day) constrained root, sign a local-only server cert, then destroy the root private key; uninstaller removes the root.
- Intoxalock: cyberattack on 14 March took calibration and reporting offline; firmware enforces lockout without calibration; 10-day extensions only in some states; service restored by 24 March. Steve suspects ransomware and warns about exfiltrated sensitive driver data.
- Firefox 149 (24 March) adds a free VPN/proxy and side-by-side page view; Firefox desktop share fell from 6.3% to 4.2%; legislators have discussed restricting VPNs because of age-verification evasion.
- Jscrambler: TikTok and Meta pixels hash emails and phone numbers deterministically (re-identifiable), capture product names, prices, cart totals, checkout form structure, and Meta's Automatic Events can capture visible card details; data can leave before consent tooling blocks it, creating GDPR/CCPA exposure and handing competitive data to ad platforms.
- Russia's private sector is asking the government to lift bans on Telegram, WhatsApp and other foreign messengers needed to work with foreign partners.
- OpenClaw phishing: GitHub issue spam tagging developers with fake token promises, leading to wallet-draining sites. Advice: never connect a wallet holding meaningful funds to an unverified service; use a small secondary wallet.
- Cisco CVE-2026-20131: unauthenticated remote code execution as root via insecure deserialization in Secure Firewall Management Center web interface; Amazon MadPot honeypots found Interlock exploiting it from 26 January; Amazon also found Interlock's misconfigured staging server and noted its ransom notes cite data-protection regulations. Targets skew to education, engineering/construction, manufacturing, healthcare, government.
- Steve's lesson: a fully patched system was still compromised for five weeks; restrict management interface exposure (geo/IP filtering, least privilege) because "your security needs security".
- Ubiquiti UniFi gateway/management app: CVSS 10.0 path traversal exposing configuration files and allowing takeover; update.
- watchTowr Labs (February 2025 research, revisited): about 150 abandoned S3 buckets re-registered for roughly $400 received more than 8 million requests in two months for updates, binaries, VM images, templates and VPN configs, from NASA, other governments, military, banks and Fortune 500 firms; AWS sinkholed the buckets, CISA fixed a cisa.gov case.
- S3 uses a flat global namespace (3-63 characters, DNS-like) and recycles deleted names; Azure and Google Cloud already had protections. AWS's new account regional namespaces append an account-specific suffix that other accounts cannot create and can be enforced via IAM/SCP, but it is opt-in and not retroactive, so old buckets remain squattable.
