# Summary

Steve judges the President's NSA reform speech as mostly deferral (an EFF scorecard gave it 3.5 of 12) and argues that the only credible fix for bulk phone metadata is making carriers retain it and answer targeted, approved queries. He then explains the Target breach: a 23-year-old Russian author's BlackPOS malware ran on Windows XP Embedded point-of-sale terminals, scraped card data from memory, staged it on an internal server using weak credentials, and passed it through a hijacked FTP host to a Russian server over about two weeks (11 GB), with antivirus not detecting it. For CryptoLocker, a Dell SecureWorks write-up details how it enumerates drives, uses 72 file extensions, a unique AES key per file wrapped by an RSA key, and records every encrypted file in the registry; bitcoin tracing implies about 41,900 bitcoin, over 40 million dollars, from perhaps 200,000 to 250,000 infections, and Steve expects imitators. Personal items include TSA pre-screening, the free MailStore Home email archiver, a USB quantum-noise random generator for GRC's password page, and plans for a fast drive-wiping product "Beyond Recall" after SpinRite 6.1. He reports that SQRL's password encryption uses chained Scrypt iterations to take a chosen number of seconds. Listener questions cover router firmware, VPNs, TrueCrypt key sizes and XP.

# Key points

- Obama NSA speech: EFF scored it 3.5 out of 12, with only FISA court reform items positive; Steve favours carriers holding metadata for around ten years and responding to authorised queries, and notes bulk collection has produced no clear terrorism win.
- Target: BlackPOS memory-scraping malware on about 40,000 XP-Embedded terminals, internal passwords guessable, staging via a hijacked FTP server; undetected by antivirus into mid-January; six more retailers were reportedly affected.
- CryptoLocker internals: uses Windows CryptoAPI (so strong crypto), GetLogicalDrives and drive-type checks (later also removable drives), rescans for new drives periodically, ransom lowered successively to 0.3 bitcoin, command server polled every 50 minutes; estimated 41,928 bitcoin collected. Carbonite staffed a dedicated recovery team, noting its storage has no drive letter.
- TSA PreCheck takes a short interview and fee; a listener recommends the DHS Global Entry programme, which also covers re-entry and has nearer offices.
- MailStore Home: a free Windows tool to archive and index mail from IMAP, Exchange, Gmail and local clients, which relieved Steve's Eudora archive.
- GRC will seed its Perfect Passwords generator from a USB quantum random device; Steve plans Beyond Recall, a wipe tool built on SpinRite 6.1 technology, priced around 19 dollars; one listener uses SpinRite to revive failed drives before wiping them with DBAN.
- Backblaze data shows Hitachi drives with far lower annual failure rates than Seagate; warranties have shrunk from three years to one.
- SQRL password handling: Scrypt (memory-hard, 16 MB working set) is chained and XORed, with a time or iteration target (5 seconds on a phone, up to 30 seconds for exported identity keys) so GPU, FPGA and ASIC acceleration is impractical; three independent implementations match, and a downloadable test tool is coming.
- VPNs protect the local network segment (cafe Wi-Fi, hotel, ISP) but are not global anonymity; mail polled through the tunnel still reveals the exit point.
- Router firmware: given the port 32764 and UPnP scandals, consider replacing ISP firmware with Tomato or DD-WRT/OpenWRT; the 32764 service is in the router itself, so a PC firewall cannot block it. The number 32767 is the signed 16-bit maximum, explaining an old BASIC overflow.
- TrueCrypt: the 256-bit master key is random and encrypted under the password; attackers guess passwords, not keys; chaining ciphers gives extra key material.
- XP end of support: Steve resents ending patches for shared code that is already fixed for newer Windows; Microsoft will only extend antimalware signatures, not Security Essentials itself.
- SSL Labs now rewards HTTP Strict Transport Security (GRC rates A+), and Chrome preloads GRC as HTTPS-only; forward-secrecy green status may require older DHE suites.

# Other segments
