# Summary

Microsoft paid a $10,000 judgment to a travel agent whose business was disrupted by an unauthorised Windows 10 upgrade, then dropped its appeal, and replaced the upgrade prompt with a clearer Decline option. A Virginia judge ruled in the Playpen case that a person has no reasonable expectation of privacy in an IP address or in a networked computer's identifying data, a decision the EFF called dangerously flawed. Steve notes an optional Windows 7 rollup that fixes the very slow Windows Update behaviour, and that Comodo tried to register trademarks for "Let's Encrypt" before backing down under public pressure. Sophos reports pure-JavaScript ransomware delivered via disguised .js files and Word macros, so Steve recommends showing file extensions and re-associating .js with Notepad. Researchers showed that PC fan speed changes can leak about 10 bits per minute from an air-gapped machine to a nearby phone microphone. A Netgear router firmware flaw can reveal the admin password unless password recovery is enabled. The Q&A covers ENDBRANCH details, SQRL usage questions, why "hardware firewalls" are really software, anti-phishing drills, Windows 10 free-upgrade entitlements, Steve's development tools, HTTPS inspection proxies, fake "secure message" email claims and ways to isolate Intel ME.

# Key points

- Teri Goldstein v. Microsoft: after a failed forced Windows 10 install harmed her business she won a small-claims judgment; Microsoft did not appeal. Never10 reached about 1.365 million downloads.
- Playpen case: FBI ran a Tor-hidden site and used a "Network Investigative Technique" on visitors; the judge ruled no reasonable expectation of privacy in IP addresses or in a networked computer ("broken blinds" reasoning); EFF expected it to fail on appeal.
- Windows 7 update slowness: optional rollup KB3161608 fixes a bug; users must opt into optional updates to get it.
- Comodo applied to trademark "Let's Encrypt" (ISRG's name) and dropped the effort after backlash; Steve again recommends DigiCert and Hover.
- JavaScript ransomware: executed by Windows Script Host when users double-click disguised .js files; libraries such as Stanford's JS crypto avoid dropping an executable; mitigations are unhiding extensions and opening .js in Notepad.
- Air-gap exfiltration via fan speed (4100/4500 rpm shifts) reaches only about 14.4 kilobits per day but suffices for stealing a key.
- Netgear: many routers reveal the web GUI password when password recovery is disabled, via the LAN or enabled remote admin; workaround is to enable password recovery with junk answers until firmware updates arrive.
- ENDBRANCH applies only to indirect calls and jumps, not intra-function relative branches (reader correction accepted).
- SQRL could be wrapped as a browser plugin or hardware token; its Windows client keeps a password to prove user presence.
- "Hardware firewall" versus "software firewall" is a false distinction; Steve runs pfSense on small hardware with proxy, port shifting and ARP-table views.
- Phishing simulations by a hospital's IT team are endorsed as effective training.
- Windows 10 free-upgrade entitlement: upgrading once before July 29 attaches a licence to the machine, so Steve suggests imaging the system first, upgrading, confirming activation, then rolling back.
- Steve's tooling: Brief editor, MASM, Visual Studio 6 for debugging, SoftICE under DOS with a NetWare share for SpinRite, libsodium compiled with newer Visual Studio for SQRL, and his own C AES-GCM code.
- HTTPS inspection proxies see passwords; authentication cannot defeat a man in the middle.
- Emails claiming "sent securely" prove nothing without end-to-end encryption; opportunistic STARTTLS can be downgraded.
- Intel ME mitigation ideas: use a separate add-in NIC or Wi-Fi, since ME shares only the built-in NIC; newer versions share a MAC with the OS; a better fix would be a BIOS off switch.
