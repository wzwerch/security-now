# Summary

After a light opening about earwax removal, Steve surveys the wave of vendors rushing in to fill the gap left by Lavabit and Silent Mail: Kim Dotcom's Mega promising encrypted mail, Moxie Marlinspike's TextSecure (which stores pregenerated "prekeys" on a server), Wickr, Cackle, and the Swedish app Heml.is, with Steve skeptical of vendors who will not explain their cryptography. He explains that the "no password is safe" headlines stem only from HashCat lifting its 15-character password length limit, and that cracked phrases such as a movie quote and a Lovecraft sentence show that passphrases built from published text are weak, so random passwords from a manager are best. He describes the NSS SSLKEYLOGFILE debugging variable, which makes Firefox and Chrome write session keys to a file that Wireshark can use, and relays news of Steve Ballmer's departure and of the New York Times DNS hijack caused by spearphishing of a domain reseller partner. In the Q&A he covers traffic analysis of VPN servers, Linux versus Windows risk, Yahoo's decision to recycle dormant email addresses, why flash drives cannot be securely wiped because of wear leveling, whether PGP keys come from a server, putting PGP in the mail server instead of the client, ETag-based cookieless tracking, and the German concern about Windows 8 and the TPM.

# Key points

- Mega, TextSecure, Wickr, Cackle and Heml.is all announced secure messaging; Steve notes email-style store-and-forward makes key agreement hard, and warns against vendors that withhold algorithm details, quoting one with an implausible "16,384 bits" claim.
- HashCat had always limited passwords to 15 characters for GPU optimizations; supporting longer ones costs about 15 percent performance. Researchers cracked phrases that were quoted in Wikipedia articles, so famous sentences are not good passphrases. Steve recommends long random passwords held in LastPass with a strong master password.
- NSS (used by Firefox and Chrome) will log TLS session keys to a file when the SSLKEYLOGFILE environment variable is set; it is a developer debugging feature and should be removed after use.
- Steve Ballmer announced his departure; Steve recalls him fondly and notes about a third of PCs were expected to still run XP at end of support.
- The New York Times site went down after attackers spearphished staff of a reseller partner of an Australian domain registrar and changed DNS records.
- Traffic analysis can link VPN input and output flows because web traffic is bursty and a lightly used server gives little cover; Tor adds hops and deliberate delays to defeat this.
- Windows is attacked far more than Mac and Linux, but browser plugins such as Java and PDF readers can hurt any OS; Adobe's sandboxing quieted PDF exploits.
- Yahoo began recycling dormant (about one year idle) addresses; because sites verify identity by email, new owners could take over password resets of the previous owner's accounts. Steve and Leo suggest owning a personal domain.
- Flash drives and SSDs use wear leveling and remap sectors continuously, so old data copies persist and cannot be securely overwritten from software; write only encrypted data (TrueCrypt, AxCrypt, BitLocker, FileVault) from the start.
- PGP keys are generated locally by the client (for example Mailvelope in the browser) and private keys never leave the user; the passphrase still protects them.
- Putting PGP in the mail server reintroduces a trusted party that can be compelled; encryption must be end to end, from device to device, and HushMail is an example of the server model.
- ETag cache tracking: a server can embed unique values in the ETag headers of cached resources so browsers return a persistent identifier without cookies.
- The German government warned about Windows 8 and the TPM; the TPM is a crypto chip and identity vault with no API to export secrets, and the real issue is trusting any closed-source operating system. Steve plans to cover Secure Boot.

- xkcd autocomplete cartoon mentioning Java updates; Bob Bosen's animated video of the ARP poisoning episode.
