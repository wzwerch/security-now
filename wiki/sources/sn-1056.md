# Summary

Steve opens with Home Depot ignoring a researcher's warning that a leaked GitHub token had given write access to hundreds of private repositories since early 2024, fixed only after TechCrunch intervened. He then uses a GNOME Shell extensions reviewer's complaint about AI-generated, needlessly defensive try/catch code to argue that LLMs copy patterns without understanding them and can spread code bloat through training loops. Veracode-style figures for 2025 show open-source repository malware nearly doubling (about 207,000 critical-malware packages, obfuscation up sharply), with npm holding about two thirds of the ecosystem. A Strider report counts 2,723 Chinese papers on US power-grid vulnerabilities and heavy US reliance on Chinese inverters and batteries. Google details five China-nexus clusters exploiting React2Shell (CVE-2025-55182) with tunnelers and backdoors; further React fixes cover denial of service and source exposure. Apple's iOS 26.2 patches two WebKit zero-days, Let's Encrypt marks ten years and heads for a billion active sites, and Steve reports on the first ten days of GRC's DNS Benchmark v2. Listener mail covers birthday-disclosure risks of age tokens, openness versus attestation, false positives in IP-based bot checks, character-set entropy, and a router answering pings. The main topic is Australia's ban: facial age estimation has proved easy to fool and wrongly rejected some older teens, support in Australia is broad, and Steve restates that privacy-preserving, device-based age assertions are the least bad option.

# Key points

- Home Depot: a researcher (Ben Zimmermann) found an employee's GitHub token exposed since early 2024 giving write access to hundreds of private repositories and cloud-related systems; Home Depot had no disclosure channel, ignored emails and a LinkedIn message, and revoked the token only after TechCrunch asked. Whether logs show misuse is unknown.
- GNOME extension review: reviewers will reject packages with unnecessary AI-style code (for example a try/catch around a guarded call of a function that always exists). Steve's point: AI replicates patterns without understanding, and unneeded but non-failing code never gets corrected, so it can be amplified when re-ingested for training; he expects future coding-specific AI to clean it up. Leo relays a Discord debate that defensive code is not always wrong.
- 2025 repository malware: npm about 65.5%, NuGet about 20%, PyPI about 13%; 86.8% rise in malicious submissions year on year; 206,632 packages with critical malware, about 4,200 targeted-organization packages, 58,000 with known-bad URLs, nearly 930,000 with precompiled binaries, 161,000 running suspicious install-time code, about 5,000 typosquats and about 62,000 spam packages; obfuscation up roughly twelve-fold; dependency-confusion attacks fell. Install-time downloads make later changes possible.
- China and the grid: Strider found about half of inverters and battery systems imported 2015-2024 came from a high-risk PRC maker (examples CATL, Huawei, Sungrow), 86% of surveyed utilities use at least one, and at least 225 of the 2,723 Chinese papers examine attacks on the US grid, including simulations of the western grid. Steve likens it to nuclear deterrence.
- React2Shell exploitation (Google Threat Intelligence, 12 December): UNC6600 delivering the MINOCAT tunneler (with cron, systemd and shell-profile persistence), UNC6586 using SNOWLIGHT/VShell, UNC6588 using COMPOOD disguised as Vim, UNC6603 using HISONIC via Cloudflare Pages and GitLab for config, UNC6595 using ANGRYREBEL.LINUX with anti-forensics, plus cryptominers and Iranian-based actors; AWS names Earth Lamia (UNC5454) and Jackpot Panda. Patching the server does not remove an implant already installed.
- New React fixes from researcher scrutiny: two denial-of-service bugs and a source-code exposure.
- iOS 26.2 fixes two WebKit zero-days used in an extremely sophisticated attack against users on versions before iOS 26.
- Let's Encrypt: first public certificate September 2015; one million per day by 2018, billion total in 2020, now about 10 million per day, a billion active sites expected in 2026. Steve worries about a single point of failure now that CA/Browser Forum certificate lifetimes are shrinking despite Mozilla's Bloom-filter revocation work, and expects to move from DigiCert.
- DNS Benchmark v2 first ten days: release 2 fixed a string-buffer overflow with the 50x/100x modes, release 3 detects Wine older than version 9 (SHA-256 signature check) and added Ctrl-C copy of dialog text; about 215 KB; users with fast local router caches may change resolver choices; update check offers a download link rather than self-installing.
- Age-token feedback: age-group credentials reveal birthdays when someone joins age-gated services on the day they become eligible; attestation requirements disadvantage open-source and de-Googled operating systems (Play Integrity is reportedly used in the EU wallet); an expert listener says age checks are as harmful as Chat Control.
- botcheck caveats: dynamic IPs and carrier-grade NAT can make GreyNoise results reflect other users; routers that answer ICMP echo by default (MikroTik example) can be set to drop pings, which Steve favours despite protocol purists (stealth mode originated with ShieldsUP!).
- Entropy: 62-character alphabets give about 5.95 bits per character because unused bit patterns are not tested.
- Australia after the ban: facial estimation fooled by makeup, scrunched faces or an adult in front of the camera; some 16-18 year olds blocked; many teens and parents relieved; Australian listener reports little disruption and strong public support driven by teen suicide cases; platforms apparently use other signals (for example account age) for adults. Steve: facial estimation should not be used for a go/no-go decision; ideal is one-time verification with a trusted proxy that keeps only the birth date and biometric binding, with Apple best placed to provide it. Leo chooses to resist rather than accept.
