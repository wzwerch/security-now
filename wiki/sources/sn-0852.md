# Summary

The first episode of 2022 opens with more Log4j news: Apache released 2.17.1 on 28 December for a fifth flaw (CVSS 6.6) in which an attacker able to influence the logging configuration, for example via a remote configuration file, can run code. Steve and Leo discuss why writing working code differs from writing secure code, why authors cannot see their own mistakes, and the value of red teams and bounties. Microsoft's hastily released Log4j scanner in Defender for Endpoint produced false-positive "sensor tampering" alerts. China's industry ministry suspended a cybersecurity information-sharing partnership with Alibaba Cloud for six months because it told Apache before telling the government, in breach of the two-day reporting rule. The US Department of Homeland Security widened its bug bounty to Log4j but offers only 500 to 5,000 dollars. RSA Conference was postponed to June, a survey shows municipal bond analysts consider local governments badly prepared for cyberattacks (so insurance costs will rise), and DuckDuckGo announced a desktop browser built on the operating system's own rendering engine rather than a Chromium fork. The title story: Exchange Server 2016 and 2019 stopped processing mail on 1 January 2022 because a malware-engine version string like 2201010001 no longer fits a signed 32-bit integer, and Microsoft's quick fix was to number the engine as December 33rd 2021 (version 2112330001).

# Key points

- Log4j 2.17.1 (Java 8) fixes the fifth issue in a month, reported by Checkmarx's Yaniv Nizry; Kevin Beaumont criticised the fast public disclosure. Deep Java dependency trees (seven to nine layers) keep making each new fix hard to roll out.
- Secure coding needs a different mindset from feature coding; peers, red teams and paid bounties find what authors cannot. Steve notes open-source dependence on unpaid, often not security-trained maintainers, and praises moving away from C where possible.
- Defender for Endpoint's new Log4j file scanner raised false sensor-tampering alerts on Windows Server 2016; Microsoft said to ignore them. Steve judges a quick imperfect scanner better than a late one, noting earlier Defender false positives (Emotet, Cobalt Strike, PHP backdoor).
- China's MIIT suspended the Alibaba Cloud partnership for six months because the ministry learned of the flaw on 9 December, 15 days after Alibaba reported it to Apache on 24 November; Alibaba promised better compliance. Steve ties this to China's mandatory two-day vulnerability reporting rules.
- DHS expanded "Hack DHS" to Log4j-related flaws but pays 500 to 5,000 dollars; Steve considers that unattractive compared with criminal incentives. DHS saw no breaches of federal agencies yet.
- RSA Conference 2022 was moved from February to 6-9 June with vaccine proof and mask rules.
- DuckDuckGo handled 34.8 billion queries in 2021 (up 47%) and plans a desktop browser using OS rendering engines; Steve is skeptical about extension and password-manager support.
- Fitch and HilltopSecurities: in a survey of 150 municipal bond analysts, 63% said local governments are hardly prepared for cyberattacks and 0% said prepared; cyber was a top-five bond-market issue for 29% (12% in 2020). Expect higher insurance premiums, reduced coverage and taxes.
- Y2K22: Exchange stored the engine version, whose first two digits encode the year, as a signed 32-bit integer (max 2147483647), so 2201010001 failed with "Can't convert to long", stalling mail queues. Fix: a PowerShell script (Reset-ScanEngineVersion.ps1) resets the version to 2112330001, which Microsoft called "rolled forward". Steve says an unsigned integer would only delay the problem until 2044.

# Other segments

- Picture of the Week: a listener ran GRC's ShieldsUP! from a Tesla browser and saw all ports stealthed.
- James Webb Space Telescope finished unfolding its sunshield (Leo).
- SpinRite: GitLab now used for tracking known problems; an ASRock AHCI-mode chipset bug and a Supermicro/Xeon timebase issue (halting the CPU stopped the timestamp counter) were found and worked around.
- Opinions on The Matrix Resurrections (poor) and Don't Look Up (good); Steve notes the SpinRite-style version counter has about three years to its own overflow-style concerns for the show episode count.
