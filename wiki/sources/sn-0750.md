# Summary

Google now lets iPhones act as account security keys over Bluetooth (via the Smart Lock app), alongside Android phones, and Gmail reportedly blocks over 100 million phishing emails daily. Attorney General Barr continued attacking Apple over the Pensacola shooter's phones despite Apple's detailed account of the data it supplied. A new Internet Explorer zero-day in the legacy JScript engine was being exploited in targeted attacks; Steve shows how to deny access to JScript.dll as a stopgap. Microsoft released the Chromium-based Edge. The FBI warned that nation-state actors used the Pulse Secure VPN bypass against a municipal government and a financial entity, with Iranian actors also noted. A separate, under-noticed critical pre-auth RCE in Windows Remote Desktop Gateway (UDP fragment handling) was patched. The main topic is CurveBall (CVE-2020-0601), a Windows CryptoAPI bug that accepted attacker-chosen elliptic curve parameters, allowing spoofed certificates and signatures; the NSA reported it, and public proof-of-concept code appeared quickly.

# Key points

- Google: iOS 10+ devices can serve as FIDO-style security keys for Google accounts using BLE (no pairing needed), requiring an unlocked phone, the Smart Lock app, and 2-Step or Advanced Protection; only one built-in key per account.
- Apple/FBI: Apple says it supplied many gigabytes of iCloud and account data within hours; Barr wants a way into the locked phones; Leo notes GrayKey-type tools may already reach newer iPhones.
- IE zero-day (CVE-2020-0674): memory corruption in the old JScript engine (jscript.dll), invocable by sites even when IE is not default; no patch yet and Windows 7 would not receive one; mitigation is to take ownership of jscript.dll and deny Everyone access (reversible), with possible side effects such as Media Player MP4 or Microsoft Print to PDF issues.
- New Edge (Chromium based) released for Windows 7/8.1/10, macOS, iOS and Android, with tracking-prevention levels and a media-autoplay block setting.
- Pulse Secure: FBI says attackers reached a US municipal network and a financial research network in August 2019, harvested credentials from plaintext logs, and kept footholds after patching; the segment lacking MFA was the only one breached; Travelex was hit by Sodinokibi after ignoring a warning.
- Windows RD Gateway pre-auth RCE (UDP transport, port 3391) from improper handling of fragmented UDP, affecting Server 2012-2019, rated critical, with no workaround; patch and keep RDP behind a VPN.
- CurveBall: since mid-2015, Windows 10 and Server 2016/2019 Crypt32 did not validate explicit ECC curve parameters (the generator), so a certificate could vouch for itself and mimic a trusted root's public key; affects TLS, code signing and email; Windows 7 and Firefox (own crypto library) are not affected; Chrome updated; PoCs by Saleem Rashid, Kudelski Security ("Chain of Fools") and Ollypwn; the NSA disclosed it, which Leo contrasts with its NOBUS doctrine.
- Steve replaced GRC's EV certificates with a single DigiCert OV certificate with wildcards.
