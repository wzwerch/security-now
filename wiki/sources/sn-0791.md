# Summary

The Chrome FreeType exploit from the previous week turned out to be half of a chain: Project Zero revealed that attackers then used a second, previously unknown zero-day in the Windows kernel cryptography driver (cng.sys) to escape the browser sandbox and gain elevated privileges. With a seven-day deadline expired, Project Zero published details and a crash proof of concept while Microsoft planned a fix for the following Patch Tuesday; Windows 7 users without paid updates are left to third-party micropatches. Microsoft reminded customers to apply the August 2020 update for Zerologon. Google announced a VPN for Google One subscribers (Android first), open-sourcing the client, promising an audit and no logging of traffic, and using RSA blind signing to separate subscriber authentication from VPN use. Steve mocks CERT's Vulnonym proposal to give vulnerabilities auto-generated adjective-noun names. WordPress 5.5.2 patched ten flaws but broke fresh installs, and the rollback accidentally pushed a 5.5.3 alpha to some sites. The main segment covers Google's plan to create its own Chrome Root Store and Root Program instead of relying on each operating system's certificate store.

# Key points

- Chained exploit: FreeType heap overflow for initial code execution in Chrome plus a Windows cng.sys privilege escalation reached through device I/O controls. Google's Chrome fix closed the front door, but the Windows flaw stayed open until Microsoft's next Patch Tuesday and affects Windows 7.
- 0patch is expected to offer micropatches for unsupported Windows 7; Steve notes it publishes details of its patches.
- Microsoft's Zerologon reminder (CVE-2020-1472): deploy at least the August 2020 update and follow the guidance; Zerologon was recently used in a real Ryuk intrusion.
- VPN by Google One: client open source, server-side authentication to be open sourced, third-party audit underway, no logging of traffic or IP, minimal service-quality logging; RSA blind signatures prove subscription without revealing identity. Steve notes Google cookies still identify users once traffic exits the VPN. Google cited that about a quarter of internet users used a VPN in a month in 2019.
- Vulnonym: CERT/CC proposes neutral names from CVE IDs through a Cantor pairing function, with example outputs from a Twitter bot such as odd animal-and-adjective pairs. Steve and Leo find them unmemorable; Steve argues names like Heartbleed help communication.
- WordPress 5.5.2 (released to about 455 million sites) fixed ten vulnerabilities, one allowing takeover via a precisely timed database denial of service, but broke new installs; attempts to pull it caused some sites to receive a 5.5.3-alpha build. Steve concludes automatic updates are needed yet the process must be careful, and sees Microsoft's notify-defer-force approach as a reasonable compromise.
- Chrome Root Program: Chrome will move to a common certificate verifier and its own Root Store on Android, Chrome OS, Linux, Windows and Mac (not iOS, due to Apple rules). Initial contents mirror existing trusted CAs per the Common CA Database. Priority goes to widely trusted CAs with recent keys, annual audits (including WebTrust), TLS-only hierarchies, and public vetting via Mozilla's mozilla.dev.security.policy forum.
- Enterprise admins who tightly manage OS root stores grumbled about yet another store; Steve notes Firefox has always had its own.
