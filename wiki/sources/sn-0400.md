# Summary

For the 400th episode Steve first catches up on the week. Microsoft's April patch caused blue screens for some Windows 7 users, mostly with Kaspersky software, and was pulled; Steve blames the deep hooks of security products, including Kaspersky's built-in HTTPS interception that breaks certificate checks. Oracle then shipped a Java update fixing 42 flaws, 39 of them remotely exploitable without credentials, and for the first time Java checks applet signatures and shows a trust dialog before running unsigned code. Safari 6.0.4 added per-site permission for Java. Kaspersky statistics put Java in half of all exploit-based attacks in 2012, ahead of Adobe Reader and far ahead of Windows and IE. A worm-like botnet of roughly 90,000 WordPress sites grows by guessing common admin passwords. The Hugo Teso "PlaneSploit" talk claimed control of aircraft systems through the unauthenticated ADS-B and ACARS protocols, but regulators said it only worked in simulation. The main topic is a refresher on VPNs: encrypted tunnels, why all traffic including DNS goes through them, PPTP versus OpenVPN, and OpenVPN on DD-WRT or Tomato routers. Steve says he vetted the new TWiT sponsor proXPN, an OpenVPN provider, and found it recommendable.

# Key points

- Microsoft's April Patch Tuesday update triggered blue screens on Windows 7 systems running certain third-party software (mainly Kaspersky), so it was withdrawn; Steve says intrusive security software is more to blame than Microsoft.
- Kaspersky installs its own certificate authority and proxies HTTPS on the client, which breaks certificate validation and hides EV indicators.
- Oracle's Java update fixed 42 holes, 39 of them exploitable over a network without credentials; Oracle admitted not all known problems were fixed but said none unpatched were being exploited.
- New Java behaviour: unsigned or self-signed applets now trigger a trust dialog, ending silent drive-by execution; Steve points listeners at his unsigned Big Number Calculator applet as a test.
- Kaspersky data: Java was involved in 50 percent of exploit-based attacks in 2012, Adobe Reader 28 percent, Windows and IE about 3 percent. Old Java installs lack auto-update, so the exposure will linger.
- Safari 6.0.4 adds site-by-site permission to run Java applets, similar to what NoScript does for scripts.
- A WordPress worm-botnet of about 90,000 sites tries the thousand most common passwords against admin logins and then scans for more victims; WordPress had no login lockout at the time.
- Hugo Teso (N.Runs) showed at Hack in the Box a toolset (SIMON and an Android app called PlaneSploit) abusing the unauthenticated ADS-B and ACARS aviation protocols; EASA and the FAA said it was demonstrated only in simulation. Steve thinks old protocols designed without security are plausibly weak and notes Teso withheld details.
- SSL Labs feedback shows that people only fix weak security when forced to.
- Steve praises Opera for low memory use compared with Chrome (about 50 MB versus 250 MB) and for proactively avoiding the RC4 header-repetition weakness; Adobe announced it will contribute to Google's Blink engine.
- Bitcoin fell sharply (about 90 dollars that morning) and Mt. Gox paused trading for 12 hours; Steve recommends a Gizmodo piece on hardware mining farms.
- VPN refresher: a tunnel encrypts all traffic including unencrypted email and DNS lookups, and gives the client a virtual interface and an address on the remote network.
- PPTP and L2TP use well-known ports and are easy to block; PPTP is built into iOS and Android, whereas OpenVPN needs a client.
- OpenVPN servers can run on routers flashed with DD-WRT or Tomato, letting a roaming laptop join the home network securely. Steve runs OpenVPN servers at home and at GRC.
- proXPN (Netherlands, OpenVPN, free capped tier plus paid tier with PPTP) is the sponsor Steve says he checked and is comfortable recommending.
- Leo asks whether the IMEI sticker on a phone is a risk; Steve says no, it is also readable in the phone.

# Other segments

- Steve gives the SmushBox crowdfunding campaign its last mention, noting it was oversubscribed.
- Humorous CAPTCHA parody site CRAPCHA and an Ellen DeGeneres "Password Minder" sketch; Leo is moving his mother to LastPass.
- Ask Mr. Wizard's animations for the earlier VPN episodes (14 and 17) were updated.
- Listener ran SpinRite from VirtualBox on a Mac.
- GRC certificate fingerprint service passed 40,000 users; Steve hints at a better follow-up to handle servers with varying certificates.
- Anniversary chatter (400th episode, TWiT's eighth anniversary); Q&A planned for next week.
