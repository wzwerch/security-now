# Summary

Steve is concerned that the Rhode Island retirement fund sued Google as a shareholder over its Google+ API leaks, since punishing responsible disclosure could discourage it. Signal's developers published a response to Australia's Assistance and Access law: there is nothing to hand over, and countries that force backdoors risk isolating their own citizens. Steve and Leo discuss how a law could be satisfied by OS-level hooks before encryption and after decryption. The PewDiePie fan hacker again blasted printers, this time about 100,000. A DHS inspector general report found US border agents leave copied traveler device data on thumb drives. ESET found an Android trojan that abuses the accessibility service to move money out of PayPal after the user logs in, even with two-factor. Other items: confusion over the WordPress 5.0 release versus its concurrent security release, Facebook's disclosure of a photo API bug affecting about 6.8 million users, the annual worst-password list, free decryptors for weakly written ransomware (InsaneCrypt/Everbe, Hidden Tear derivatives), Microsoft patching in-the-wild zero-days four months running, and Firefox 64. The main topic is Magellan, a Tencent Blade Team SQLite remote code execution bug reachable wherever attacker-controlled SQL can run (it worked against Chrome's WebSQL and a Google Home); Steve shows how to audit a Windows system for bundled SQLite libraries and urges patched apps.

# Key points

- Rhode Island pension fund suit over Google+ leaks may chill voluntary disclosure; Leo suggests indemnifying companies that report flaws.
- Signal: no contacts, social graph or message contents stored; open source and reproducible builds; blocking or banning the app is circumvented easily; the law could drive companies away from Australia.
- Ideas floated for compliance: per-device escrow in a single-vendor ecosystem or OS-level plaintext access; Steve expects 2019-2020 to settle the question.
- PewDiePie printer spam round two: PRET toolkit used against 100,000 printers; even a newspaper site was defaced; advice to fix exposed printers.
- CBP in 2015 onward may search devices warrantlessly, and at 67 of 328 ports copy data; OIG found uncleared thumb drives at three of five ports inspected.
- Android trojan disguised as battery optimizer abuses accessibility permissions to hijack the PayPal app; lesson is to avoid installing unneeded apps.
- WordPress 5.0 (block editor) was followed by a security release fixing seven issues across versions back to 3.7; the "password indexing" headline was overblown.
- Facebook photo API bug lasted 12 days, potentially exposing photos of 6.8 million users to up to 1,500 apps.
- Worst passwords: 123456 and password still on top; "monkey" slipped to 18th.
- Decryptors exist for InsaneCrypt/Everbe and dozens of Hidden Tear variants; check Bleeping Computer before paying.
- Microsoft patched zero-days used by state-sponsored groups in September through December 2018, including FruityArmor.
- Firefox 64: full distrust of Symantec certificates, contextual extension recommendations, multi-tab selection, RSS removal, about:performance.
- A listener's router firmware update check reported nothing though updates existed, suggesting malware blocking updates; verify on the vendor's site.
- CoAP follow-up: a simpler fix is returning a pseudorandom pairing number per requester IP.
- Magellan: affects SQLite before 3.26.0 and Chromium before 71; Steve found SQLite DLLs in several apps (including Adobe Reader and Python) using a recursive search for sqlite*.dll; risk depends on whether SQL can be driven by untrusted content; no in-the-wild use seen.
