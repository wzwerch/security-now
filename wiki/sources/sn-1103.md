# Summary

A Linux kernel use-after-free race in TCP (focused on multipath TCP, present since kernel 4.4) was found by Anthropic in early October and quietly fixed; ratings range from 5.1 (Red Hat initially) to 9.8, and an unreleased Claude built an exploit in 53 minutes, though Internet jitter makes it hard to use. Steve takes the obscurity of such finds as a sign the low-hanging fruit is gone. Cisco's president Jeetu Patel gave 27-year-old Padmanabhan "Paddy" Krishnamurthy unlimited tokens to rewrite 98% of Cisco's code in 24 months; Steve thinks Cisco's real problem is insecure-by-default policy. Anthropic's Alex Matrosov and Google found CVE-2026-97631, a 16-year-old ICMP buffer overflow in EDK II's PXE driver; AMI's public pull request forced early disclosure.

North Korea's TraderTraitor (per TRM and Chainalysis) stole $6.3 billion from Binance via a DevOps engineer's laptop and more; about $3 billion was frozen and Binance is covering losses. Attackers drained $2.7 million from 710 Polymarket international wallets via compromised monitoring vendor DebugBear. OpenAI, Google, Microsoft and Anthropic will honor a new shared robots.txt token for opting out of AI training; Google's orbital TPU satellite produced a haiku. Steve withdraws his "stealth updating" idea, praises Cloudflare Tunnels for taking servers off the Internet, discusses whether books contain knowledge, shares a 30-person startup's AI-driven breach, and calls an AI "kill switch" a political fantasy. The main topic: reverse engineer Xusheng Li (Binary Ninja) used AI to show that encrypted USB drives and their software from Lenovo, Netac, KakaSoft, Nexcopy and SecZure offer fake or backdoored protection.

# Key points

- Linux MPTCP flaw: mitigations include blocking the IP options; cloud Linux was patched early; Ubuntu was criticized as the slowest distribution.
- Cisco plan: Patel wants more young "Energizer bunny" hires and welcomes "tension"; Steve recalls Cisco's optional hardening guide instead of secure defaults.
- CVE-2026-97631 (CVSS 9.5): the PXE Base Code driver copies ICMP errors into a 504-byte field with broken bounds, allowing ring-0 code execution before Secure Boot and TPM measurements; exploitation needs local network position, timing during a PXE boot and knowledge of the firmware build. HD Moore (now at Dragos) calls it a "forever" bug on unsupported hardware. Steve: disable PXE if unused and block ICMP across boundaries. Related: LogoFail, PixieFail, PKFail, BootHole, BlackLotus.
- Binance: most of the theft occurred in 20 minutes, four times the 2025 Bybit record; about $2.4 billion may be unrecoverable. Polymarket refunded $3.9 million (theft plus pause losses).
- robots.txt: Anthropic's Kevin Kelley proposed at the IETF a `User-Agent: __usage_ai-training` group with `Disallow`/`Allow` paths; Anthropic supports it now, Google and Microsoft next year, OpenAI in coming months; Meta is noncommittal; Perplexity previously evaded blocks with stealth crawling. Steve recommends Kevin Roose's book *The AGI Chronicles*.
- Google's Project Suncatcher ran Gemma 4 on orbital TPUs; twin interconnected satellites are planned for 2027. Voyager 1 reaches one light-day from Earth on 18 November.
- Listener Matt Olan uses Cloudflare DNS, WAF and Tunnels so servers make only outbound connections; Steve likes that sites can later leave Cloudflare. Startup employee Jordan B. says AI-driven scanning found his firm and Claude Enterprise refusals pushed them to a self-hosted abliterated model.
- USB findings: Lenovo's ThinkPlus FU100 fingerprint drive held an unencrypted SD card (the fingerprint only enabled USB; Lenovo called it a "weakness"); SecZure software had hidden accounts "Buffer" (password 123456) and "System" (SECZURE.COM) that decrypt everything; NetacFileLock used a fixed AES key embedded in the program, logged passwords, used ECB-style blocks and MD5, and in "fast mode" encrypted only a third of files. AI (Codex via Binary Ninja's MCP server) found Netac's flaw in seven minutes. Steve explains proper design (on-device random master key wrapped by a PBKDF-derived key) and distrusts fingerprint unlock; he recommends open-source encryption.
