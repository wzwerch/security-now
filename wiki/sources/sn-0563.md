# Summary

Steve opens with a "reality check": added security features are not the same as security, and Windows 10 is the same old NT code under new UI, which is why most flaws affect all versions. That is illustrated by a local privilege-escalation zero-day in win32k.sys, affecting Windows from 2000 onward, offered on a Russian forum for $95,000. He then explains the University of Michigan "A2" research, an analog charge-pump trojan added to a chip layout that can switch off memory protection after a trigger pattern and that is very hard to detect. The June Android bulletin again fixed critical Mediaserver and WebM flaws plus several Qualcomm driver issues. Never10 passed one million downloads. Mark Zuckerberg's old Twitter and Pinterest passwords were found through LinkedIn leak data, and Facebook Messenger plans opt-in end-to-end encryption like Allo. Steve answers a reader question on SQRL by describing the Identity Lock Protocol with a rescue code. The main topic concludes the IoT series with Rapid7's tests of ten Internet-connected baby monitors, which showed enumerable object IDs, default Telnet/web credentials, account-registration bypasses and unreachable vendors.

# Key points

- Security features versus security: new code means new bugs; Windows 10 shares code and vulnerabilities with older versions; stable "if it is not broken, do not fix it" systems like Debian stable are praised.
- win32k.sys zero-day: "write-what-where" local privilege escalation, defeats sandboxing and exploit mitigations; sold openly for $95,000; Trustwave notes zero-days becoming commodities.
- A2 hardware attack (University of Michigan, IEEE S&P best paper): a capacitor-based analog trigger inserted by a fab can give an unprivileged process full memory access; static analysis would not find it; proposed monitors are not a full defence.
- June Android bulletin: critical remote-code-execution flaw in Mediaserver reachable through email, web and MMS, plus dozens of driver and privilege issues; Mediaserver parsers act as interpreters of file metadata.
- Some users disabled Windows Update entirely to avoid Windows 10; Steve advises running Never10 and then updating; Never10 downloads surpassed 1,000,000.
- Zuckerberg's old accounts on Twitter and Pinterest used a weak reused password that surfaced through the LinkedIn data.
- Facebook Messenger will offer opt-in per-conversation end-to-end encryption; Steve expects most users to prefer features.
- Self-driving challenges per the New York Times: unpredictable humans, bad weather, detours versus detailed maps, road discoloration versus potholes, and ethical trade-offs.
- SQRL identity lock: a lock value derived from a random rescue code is stored per site so only the rescue code can rekey an identity, while anyone with the client can disable SQRL logins at a site without the code; this addresses reader fears of attackers rekeying and locking users out.
- Rapid7 baby monitors: iBaby cloud service exposed other users' videos through an eight-hex-digit serial object ID; devices run always-on Telnet or web servers with admin/admin or user/user; Philips In.Sight streams proxied through a cloud provider with enumerable hostnames and ports and XSS flaws; Summer Infant's service let anyone register an account into a camera group without authentication; Lens Peek-a-View and others had open default servers and no contactable vendor.
- Advice: put IoT devices on a separate network; do not rely on being behind NAT because UPnP and local malware can expose them; marketing claims such as "military-grade encryption" mean nothing.
