# Summary

Steve quotes Stacey Higginbotham's Consumer Reports letter urging Microsoft to extend free Windows 10 security updates past October 2025 and to fund recycling, noting 46% of Windows users were still on Windows 10 and the TPM 2.0 requirement is artificial. He then summarises a GAO report on about 500 overlapping Pentagon cyber organisations, a Washington Post finding that DeepSeek returns weaker or refused code for requests tied to groups China disfavours, WebAssembly 3.0, Firefox 143 and Firefox for Android's DoH option. Security headlines cover a CVSS 10 Microsoft Entra ID flaw that let forged "actor tokens" impersonate users in any tenant, Chrome's sixth zero-day of 2025 (CVE-2025-10585 in V8), Google's finding that DDR5 remains vulnerable to Rowhammer despite TRR and ECC, Samsung fridges showing ads, China telling firms to stop buying NVIDIA chips, and hundreds more malicious npm packages (including the Shai-Hulud worm per Leo). Feedback addresses 0patch subscription lapses, whether user training can stop phishing, link-rewriting email filters, backup strategies and Android versus Apple memory protections. The main segment examines the pending age-verification wave (UK, Brazil's Digital ECA, US states) and the IAB/W3C workshop, then demos Spain's and the European Commission's open-source prototype using W3C Verifiable Credentials and OpenID4VP, which proves only "over age X" without identity, and which Steve judges the right design.

# Key points

- Consumer Reports letter (16 September 2025): Windows 10 ends 14 October 2025; about 646.8 million users (46.2%) remained on it and 200-400 million PCs cannot run Windows 11; Microsoft's free option requires Rewards points and the paid option costs $30 per year. Steve says Windows 11 is largely the same OS and the cutoff is arbitrary; Leo expects Microsoft to relent.
- GAO: DoD cyberspace operations involve about 500 organisations, 61,000 personnel and 9,500 contractors, with overlapping training; DoD agreed to consolidate; separately about 22,000 cyber jobs are unfilled.
- Washington Post / CrowdStrike research: DeepSeek refuses or produces code with more security flaws when prompts mention Falun Gong, Tibet, Taiwan or the Islamic State.
- WebAssembly 3.0 formally released; Safari lags. Steve explains Wasm as a stack machine akin to Forth and a compiler target.
- Firefox 143: fixes two sandbox escapes in 2D Canvas, adds taskbar-pinned web apps on Windows, Copilot sidebar choice, camera preview in permission prompts, more fingerprinting protection, and a prompt to keep or delete private-window downloads; Firefox for Android adds native DoH (Android itself supports DoT since 2018 and DoH since 2020). EFF Cover Your Tracks still shows Firefox as unique.
- Entra ID (Dirk-jan Mollema): undocumented Actor tokens combined with the legacy Azure AD Graph API failing to validate the issuing tenant let a token from the attacker's lab tenant act as any user, including Global Admin, in any tenant, without logs in the victim tenant; reported in July, fixed and assigned a CVE on 4 September, CVSS 10.0. No abuse detected by Microsoft.
- Chrome 140.0.7339.185/.186 fixed CVE-2025-10585, a type confusion in V8 found by Google TAG and exploited in the wild (sixth Chrome zero-day of 2025), together with three other high-severity bugs; Google shipped within a day.
- Google's DDR5 Rowhammer research: TRR and ECC mitigations are probabilistic and bypassable once understood; a JEDEC standard called PRAC (Per Row Activation Counting) will arrive in future DDR5 and LPDDR6; Steve calls it a kludge for a fundamental density problem first reported by Carnegie Mellon in 2014.
- Samsung's large-screen refrigerators started showing unsolicited ads; China's government told companies to stop buying and testing NVIDIA chips; about 300 more malicious npm packages were removed (Leo identifies a self-spreading worm called Shai-Hulud).
- Listener points: 0patch micropatches stop applying when a subscription lapses; training users not to click is unrealistic because business email requires links, so least-privilege design and link-rewriting protection services are better; RAID 6 plus continuous versioned sync beats juggling external drives; a $39-50 prepaid Android phone is a cheap test device; Apple's MIE is a costly, "Ahab-like" investment that Android makers are unlikely to match (Leo notes GrapheneOS uses MTE heavily).
- Gmail marked Steve's weekly email (about 18,865 recipients) as spam for one night; recipients were asked to mark it not spam.
- Age verification landscape: Brazil's Digital ECA (signed September 2025, effective March 2026) requires reliable age checks, bans self-declaration and ties fines to revenue; the UK Online Safety Act already does; the US Supreme Court allowed Texas's adult-content verification (June) and let Mississippi's broader law take effect on procedural grounds. IAB/W3C workshop on age-based restrictions is scheduled for 7-9 October 2025 in London (not recorded).
- Spain's system (announced early August) and the EU prototype at ageverification.dev: the user obtains an over-age credential (W3C Verifiable Credential, a signed JSON object, presented via OpenID4VP) from a national ID or bank identity, stores it in an app protected by a six-digit PIN, and shows a QR code to a website; only the over-18 claim plus a signature is revealed, with no name or birth date and no activity tracking. Steve sees the hard part as the identity anchor linking the credential to a real person and preventing credential sharing.
