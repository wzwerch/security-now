# Summary

Steve first closes out ProxyLogon news: Microsoft Defender updates now automatically apply a URL Rewrite mitigation to vulnerable Exchange servers and reverse known malicious changes, and Black Kingdom ransomware joined DearCry against unpatched servers. Firefox 87 will send a trimmed Referer header (origin only on cross-origin requests) by default. F5 BIG-IP/BIG-IQ iControl REST authentication-bypass and remote code execution bugs were mass-scanned days after researchers published proofs of concept, and a chained cross-site scripting and SQL injection pair in MyBB forum software allowed forum takeover. Steve argues researchers should delay proof-of-concept releases until exploitation is already visible. China's advertising association developed the CAID identifier to sidestep Apple's App Tracking Transparency, and Apple warned developers testing it. The main topic is Google's Federated Learning of Cohorts (FLoC): the browser assigns users to interest cohorts of thousands based on recent browsing, recomputed weekly, to replace third-party cookies. Steve is cautiously open to it as non-tracking, while the EFF argues it adds fingerprinting, cross-context exposure and discrimination risks; Leo questions whether the cohort would really be exposed to sites.

# Key points

- Microsoft Defender Antivirus and System Center Endpoint Protection now automatically mitigate the main ProxyLogon CVE by adding an IIS URL Rewrite rule, as a no-reboot stopgap for unmanaged servers, 16 days after the emergency patches.
- Black Kingdom ransomware, delivered via PowerShell from ProxyLogon-compromised Exchange servers, was seen by MalwareTech and ID Ransomware in 30-plus submissions, following DearCry.
- Firefox 87 switches to the strict-origin-when-cross-origin Referrer Policy, stripping path and query from the Referer sent to other sites; the old no-referrer-when-downgrade default is a relic of the HTTP/HTTPS mixed era.
- F5 BIG-IP/BIG-IQ: five critical flaws (iControl REST authentication bypass and RCE, CVSS up to 9.8) were patched March 10; public PoCs derived from the Java patch led to mass scanning from March 19.
- MyBB 1.8 chain: nested auto-URL stored XSS plus SQL injection in the theme manager yields RCE when an admin opens a crafted private message; fixed March 10, details published eight days later. Steve assumes state actors keep technology-to-target indexes ready.
- Steve proposes researchers hold PoC code until skilled attackers have reverse-engineered the patch, since patch release is not patch application.
- Apple's iOS 14.5 App Tracking Transparency requires opt-in for the advertising identifier (one analysis found 99 percent of users declined); Google's app privacy labels were finally published; France's regulator declined to block ATT on antitrust grounds.
- China Anonymization ID (CAID), developed by the Chinese Advertising Association and tested by ByteDance, Tencent and others, would let advertisers track iOS devices without the IDFA; Apple sent warning letters to two developers.
- Google's FLoC: cohort ID computed locally (SimHash-style) from browsing history, thousands of users per cohort, 8-bit trial IDs but 16-bit suggested, recomputed weekly, exposed to JavaScript; part of the Privacy Sandbox with bird-named proposals. Google stated it would not build alternative per-person identifiers after cookies end.
- EFF objections: new fingerprinting head start, cross-context exposure of interests to sites that already know who you are, and discrimination and predatory targeting. Steve and Leo see it as better than tracking but are unsure who gets to read cohort IDs.
