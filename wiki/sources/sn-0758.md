# Summary

Steve, recovering from an illness he suspects was COVID-19, discusses the March 2020 Patch Tuesday, which fixed roughly 117 flaws including 25 rated critical (a .LNK remote code execution bug, Media Foundation memory corruption, ChakraCore, VBScript and GDI+ issues). The main story is SMBGhost: details of a wormable remote code execution flaw in SMBv3.1.1 compression (CVE-2020-0796) leaked through partner advisories even though Microsoft had pulled the fix from Patch Tuesday. Microsoft then issued an advisory and a patch two days later, and the patch (KB4551762) triggered many installation failures and performance complaints. Steve also points to BleepingComputer's list of free tools offered during the pandemic, a WhiteSource report on open source vulnerabilities, and the proposed EARN IT act, which would make Section 230 protection conditional on providing lawful access to encrypted content.

# Key points

- March 2020 Patch Tuesday: about 117 vulnerabilities, 25 critical, all remote code execution. Highlights include CVE-2020-0884 in .LNK handling (which AV scanners tend to skip), four Media Foundation bugs, ten ChakraCore bugs, two VBScript bugs and two GDI+ bugs. Steve likens Microsoft's patching to a Three Stooges plumbing sketch.
- SMBGhost (CVE-2020-0796): a flaw in how SMBv3.1.1 handles compressed packets, affecting Windows 10 and Server versions 1903 and 1909 only. It was exposed when Cisco Talos and Fortinet published summaries, then Cisco removed theirs.
- Two theories for the leak: Microsoft's partner program (MAPP/CVRF) shared an early list from which the CVE was later pulled, or the CVE data leaked through the API that vendors scrape.
- Kryptos Logic's scan found about 48,000 internet-exposed vulnerable Windows 10 hosts; scanners to detect the condition appeared on GitHub. Most home users sit behind NAT routers and are not exposed.
- Microsoft's workaround was setting DisableCompression for the SMB server (no reboot, no performance cost since Windows did not yet use compression) and blocking TCP 445; the workaround does not protect clients.
- KB4551762 failed to install for many users with various 0x800 errors, and some who installed it reported CPU or disk spikes and freezes. Steve suggests Microsoft was right to pull it initially; a Windows 10 in-place upgrade is a last-resort repair. Leo notes third-party software hooking the OS may explain the uneven failures.
- BleepingComputer's Lawrence Abrams maintains a list of vendors offering free pandemic-era tools (Adobe, Cisco, Cloudflare, Google, LinkedIn, Microsoft, Zoom and others).
- WhiteSource report: open source vulnerabilities rose by nearly half in 2019 after being flat in 2017-2018; cross-site scripting was the most common class except in C, where buffer errors dominate; over 85 percent were disclosed with a fix. The GitHub Security Lab is cited as a private reporting channel. The report also notes that CVSS v3 scores run higher than v2, making prioritization harder.
- EARN IT act (Graham and Blumenthal): would strip Section 230 liability protection from platforms unless they follow "best practices" approved by the Attorney General and others, which critics (EFF, ACLU) say would effectively force encryption backdoors under a child-safety pretext.
