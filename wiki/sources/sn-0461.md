# Summary

The EFF's Open Wireless movement wants people to share their WiFi openly using audited replacement router firmware that uses a published client certificate (EAP-TLS) so that guests still get encrypted links, while weakening the link between an IP address and a person; Steve and Leo like the idea but note ISP terms of service, local-network exposure, and that a published certificate does not prevent a fake hotspot. Apple's Touch ID API gives apps only a yes/no answer; Steve is pleased for SQRL. Google's Adam Langley announced BoringSSL, a fork of OpenSSL kept to avoid maintaining 70 patches (alongside OpenBSD's LibreSSL). Google also began offering domain registration. The US House voted 293 to 123 to bar the NSA from using defense money for warrantless "backdoor searches" and for requesting encryption backdoors, and the Supreme Court (Alice v. CLS) held that running an abstract idea on a computer is not patentable. Steve shares a story of Google hiding bulk index transfers in the free 5 percent of 95th-percentile billing. Listener questions cover blocking sites without intercepting HTTPS, whether SQRL could carry real-world identity, HTTPS everywhere, iOS 8 MAC randomisation breaking retail analytics, Azure's public IP requirement, mixed secure and insecure forms, constant-time comparison in cryptographic code, reuse of a passphrase across TrueCrypt volumes, a Google Docs sharing link scare and CBC error propagation.

# Key points

- EFF Open Wireless: free firmware with open, EAP-TLS-based encrypted guest access, argued to protect owners from being tied to traffic; ISP terms of service often forbid sharing, and users of open hotspots should still use HTTPS.
- Touch ID API for third parties returns only success or failure, enough for SQRL reauthentication.
- BoringSSL is Google's fork of OpenSSL for its own needs (Chrome, Android); it will import upstream and LibreSSL fixes but promise no API stability. Steve speculates Google may use it for its certificate revocation work.
- Google Domains launched in beta with free private registration; Leo notes DNS query limits; Steve keeps GRC at Network Solutions with strong account protection.
- House amendment (293 to 123) blocks NSA funding for warrantless searches of Section 702 data and for mandated backdoors; it still needs the Senate and President.
- Supreme Court's Alice Corp. v. CLS decision (written by Justice Thomas) invalidated a computer-implemented escrow patent but avoided a broad rule on software patents.
- Google reportedly moved index data coast to coast in two nights a month so that usage fell within the unbilled 5 percent; Steve calls it a clever hack.
- Correction: GHash.io is a commercial operation renting hash power, not a pool, which Steve finds more worrying for Bitcoin.
- SQRL translation effort has about 405 translators for 57 languages through Crowdin.
- Cold-treating a failing drive in a refrigerator let SpinRite complete a Level 4 pass for a PowerMac G4 recovery.
- To block sites on a school network, use DNS and IP blocking (for example, OpenDNS with other DNS blocked) rather than TLS interception; VPNs bypass any filter.
- SQRL only proves "the same entity returned"; binding it to real-world identity would be a separate service.
- Dave Redekop's firm believes HTTPS-only would have prevented every financial cybercrime case they investigated; Steve notes barriers (certificates, SNI, shared hosting) are still too high.
- iOS 8 random MAC addresses are meant to break Wi-Fi retail analytics; hashing the MAC in the vendor's system still allows tracking.
- Azure requires a public IP for each virtual machine, which helps explain its IPv4 consumption.
- Forms delivered over HTTP but submitted over HTTPS are unsafe because the form target can be altered; LastPass can warn before filling insecure forms.
- NetBSD's GCM code compared authentication tags with a non-constant-time memcmp; timing attacks are real, including across virtual machines on the same host. Secure code XORs and accumulates over the full length.
- Reusing one long passphrase across TrueCrypt volumes is fine technically because each has an independent random master key, but cracking one reveals all.
- A Google Docs link shared as "anyone with the link" was reportedly viewed by unknown visitors; Steve recalls SpinRite download links leaking through download accelerators.
- CBC corruption affects only the rest of a packet's chain; disk encryption uses XTS, not one long chain.
