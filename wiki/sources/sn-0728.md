# Summary

The episode marks the start of the podcast's 15th year. Steve first covers August 2019 Patch Tuesday (93 flaws, 29 critical, none known to be exploited) and a side effect: Symantec and Norton security products only understood the old SHA-1 signatures, so Microsoft stopped offering the updates to machines running them. He then describes how Kaspersky products had for four years injected a per-installation identifier into every page viewed, making users trackable. Tavis Ormandy's finding that the undocumented Windows CTF text-services protocol has no access control is covered next, followed by a coordinated ransomware attack on 23 Texas local governments. Steve discusses browsers dropping Extended Validation indicators, Chrome removing FTP, and Google's push to shorten certificate lifetimes, which he argues is a poor substitute for working revocation (OCSP stapling). Netflix's discovery of eight HTTP/2 resource-exhaustion flaws follows, plus file-sync and SQRL news, and the episode closes with the KNOB attack, which forces Bluetooth BR/EDR peers to negotiate an encryption key with a single byte of entropy.

# Key points

- Patch Tuesday (Aug 2019): 93 fixes, 29 critical; four remote code execution bugs in Remote Desktop Services (two wormable) found internally by Microsoft after BlueKeep; also fixes in Chakra, Hyper-V, graphics, DHCP client and Office.
- Microsoft ended SHA-1 co-signing of Windows updates; Symantec Endpoint Protection and Norton only checked SHA-1, so they blocked valid updates and Microsoft withheld the patches from those machines.
- A patch also broke VB6, VBA and VBScript applications until an optional follow-up update.
- Windows 7 and Server 2008 R2 reach end of extended support soon; Steve doubts Microsoft will hold the line given its still large install base.
- Kaspersky (free and paid) injected a script containing a user-unique GUID into every page since late 2015, visible to any page script and usable by advertisers; after disclosure it became a per-version ID.
- CTF (part of the Windows Text Services Framework, present since XP) has no authentication; any process, even sandboxed, can join another session and hijack apps or the login screen. Tavis released a research tool and a Project Zero write-up.
- 23 Texas local governments were hit simultaneously by one ransomware actor on Aug 16; an analyst calls it the first coordinated targeting of multiple governments in one state.
- Chrome 77 and Firefox 70 move Extended Validation identity out of the address bar; research showed users do not act on it and entity names can collide.
- Chrome is deprecating its remaining FTP support (DisableFTP flag planned).
- A Google-proposed CA/Browser Forum ballot would cut maximum certificate lifetime to about one year; Steve notes Chrome does not do real revocation checking and favors OCSP stapling plus UI rewards, and worries about erosion of identity assurance towards ACME-style domain-only certificates.
- Netflix found eight HTTP/2 implementation flaws (data dribble, ping flood, resource loop, reset flood, settings flood, zero-length header leak, internal data buffering, empty frames flood), all availability-only; coordinated with Google and CERT.
- KNOB (USENIX Security 2019): an on-path attacker alters the Bluetooth BR/EDR key-length negotiation so both sides use a 1-byte-entropy key, which is then brute-forced; it targets controller firmware, was shown on 14+ chips (Intel, Broadcom, Apple, Qualcomm), and the authors see no reason for the negotiation to exist.
- Steve restates that Bluetooth pairing between unauthenticated devices is inherently weak without an out-of-band channel.
