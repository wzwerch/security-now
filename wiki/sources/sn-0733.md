# Summary

Recorded on a Saturday before Steve's SQRL trip, the episode first explains why cryptocurrency mining malware revived in 2019: Monero's price recovered, and its ASIC-resistant proof of work suits hijacked PCs and servers; Steve lists a string of mining campaigns. He then walks through Alert Logic's 2019 SMB threat report covering 4,000+ clients: misconfigured encryption, year-old unpatched flaws, SSH/HTTPS/HTTP as the most attacked ports, two thirds of systems on soon-unsupported Windows, and old Linux 2.6 kernels. Independent Security Evaluators' SOHOpelessly Broken 2.0 found 125 new CVEs and remote root on 12 of 13 consumer routers and NAS boxes, with Synology the clear exception. Steve urges updating Chrome 77 after a critical use-after-free fix, shares SpinRite listener notes, and closes with MITRE's CWE Top 25 list built from CVE data, headed by memory buffer errors and cross-site scripting.

# Key points

- Monero rebounded to about $115 in 2019 from a 2018 collapse; reported campaigns include Rocke/Pascha rivalry, Nansh0u (50,000+ Windows MySQL/phpMyAdmin servers), RIG exploit kit, BlackSquid and a related family spreading via EternalBlue, AESDDoS botnet pivoting to mining, Plurox, LoudMiner (QEMU/VirtualBox), Android ADB abuse, WatchBog and Smominru.
- Bitcoin's SHA-256 work favors ASICs, so malware operators prefer Monero.
- Alert Logic: 13 encryption misconfigurations account for 42% of issues; AWS encryption problems affect 33% of scanned SMB instances; 75% of top unpatched vulnerabilities are over a year old; SSH (22), 443 and 80 account for 65% of vulnerabilities, with OpenSSH issues dominating missing patches; over 66% of scanned devices run OS versions going out of support by January 2020 (Server 2008, Windows 7); about half of systems run a 2.6 Linux kernel with at least 69 known flaws.
- Advice: disable SSH password logins in favor of keys, move SSH off port 22, and keep OpenSSH current.
- SOHOpelessly Broken 2.0 (ISE): 13 devices from vendors including ASUS, Netgear, QNAP, Synology, Zyxel, Lenovo; command injection and XSS were most common; one device authenticated by trusting the 127.0.0.1 source; Synology DS218j had only two minor CVEs; Netgear, Synology, Xiaomi and QNAP now have bounty programs. Steve recommends a pfSense edge firewall (Netgate SG-1100).
- Chrome 77.0.3865.90 fixed one critical and three high bugs, all use-after-free, exploitable by merely rendering a crafted page; rewards of $20,000 per bug; Steve found his Chrome had not auto-updated and used Help > About.
- MITRE CWE 2019 Top 25 in order: buffer errors, XSS, improper input validation, information exposure, out-of-bounds read, SQL injection, use after free, integer overflow, CSRF, path traversal, OS command injection, out-of-bounds write, improper authentication, null pointer dereference, incorrect permission assignment, dangerous file upload, XXE, code injection, hard-coded credentials, uncontrolled resource consumption, missing resource release, untrusted search path, deserialization of untrusted data, improper privilege management, improper certificate validation; plus a "cusp" list including infinite loops, race conditions, SSRF, double free and open redirect.

# Other segments

- Windows OS distribution chart in the SMB base: Server 2008 and Windows 7 about two thirds of systems.
- SpinRite notes: using SMART under load to vet new drives, a drive overheated in a makeshift test rig, and cache bypass on SSHD drives.
- Travel logistics (Dublin and Gothenburg OWASP talks, Boston event, upcoming file-sync episode).
