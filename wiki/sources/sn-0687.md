# Summary

Steve first covers Microsoft's acknowledgement of the Windows 10 October 2018 Update zip bug: copying or moving from a zip into a folder with duplicate names silently skips the copy, and a move can lose the file; a fix is promised for early November. Leaked Google contracts show Android makers must provide at least four security updates in the first year and patch regularly for two years, with a rolling 90-day window and the threat of withheld approvals. SandboxEscaper released another Windows 10 local privilege escalation zero-day, this time in the Data Sharing Service, with a demo that deletes a boot-critical driver; Microsoft said it is in scope for a bounty and 0patch already offered a micropatch. Radware's DemonBot abuses unpatched Hadoop YARN REST APIs to mine crypto and launch DDoS. The US DoD expands its bug bounty to hardware, which Steve doubts. Trend Micro sees a few hundred Docker hosts with exposed API ports being infected. A cheap DDoS-for-hire front end (0x-booter) is described. Firefox 63 surfaces tracking protection, still off by default. An X.Org format-string privilege escalation affects Linux and OpenBSD. The episode closes with the answer to the vending-machine puzzler: a signed-transaction protocol with a nonce, using the phone only as a relay to headquarters.

# Key points

- Microsoft: zip copy/move bug in Windows 10 1809 skips overwrites silently; moves may delete the source; recommended workaround is to extract first; fix expected in November.
- Google's Android OEM contracts (leaked via The Verge): at least four security updates in the first year and updates in year two for popular devices launched after Jan 31, 2018; devices must be covered against vulnerabilities older than 90 days; non-compliance can block future phone approvals.
- SandboxEscaper dropped a Windows 10 / Server 2016 / 2019 privilege escalation via dssvc.dll with public source; 0patch has a micropatch; Steve praises the skill and hopes she gets hired.
- Unpatched Hadoop YARN REST API still exploited seven months after public PoC; DemonBot spreads by spraying, not by worming, and is used for mining and DDoS.
- DoD GAO report follow-up: Hack the Pentagon expanded to hardware under a 34 million dollar contract with Synack, HackerOne and Bugcrowd; Steve suspects classified systems make this hard.
- Docker Engine community edition with exposed ports 2375/2376 abused to install coin miners; peak around 425 hosts; malware scans internally for lateral spread.
- 0x-booter DDoS for hire: nine plans from 20 to 150 dollars, advertised capacity 424 Gbps, about 17,000 bots, built on leaked Mirai-style code.
- Windows cumulative fix KB4462933 is a non-security grab bag; Steve keeps deferral on Windows 10 Pro.
- Firefox 63 exposes content blocking (Disconnect.me lists, basic or strict) in the UI, off by default; Steve recommends enabling it and notes it speeds up page loads.
- X.Org server log-file option format-string bug allows local file overwrite; needs console access, so mainly matters in multi-user environments.
- Errata: it should be dot-dot-slash for directory traversal; RTOS also implies real-time response guarantees.
- Listener note: do not treat the inside of the intranet as safe ("assume breach").
- Puzzler answer: the phone-held balance cannot prevent double spending, so a third party must hold or confirm state; vending machine signs a transaction with a hardware-protected secret and a one-time nonce, the phone relays it to headquarters over the internet, headquarters debits and re-signs, the machine verifies and dispenses and discards the nonce.
