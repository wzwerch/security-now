# Summary

Steve opens with a Starlink satellite train video and a note on the Raymond Chen "Rhythm Nation" story, where a 17-year-old hard-drive resonance anecdote received a CVE (CVE-2022-38392); he questions how low the bar for CVEs has fallen. The serious news starts with a Realtek eCos SDK flaw (CVE-2022-27255), a stack buffer overflow in the SIP application layer gateway reachable from the WAN with one UDP packet, affecting tens of millions of routers and IoT devices from over 60 vendors that will largely never be patched. Google then disclosed mitigating a record 46 million requests-per-second HTTPS DDoS attributed to the Meris botnet. Chrome (CVE-2022-2856, the fifth in-the-wild zero-day of the year) and Apple (two zero-days, six for the year) shipped urgent updates, and RubyGems began requiring MFA for its most downloaded gem maintainers. After listener feedback on domain-registration contacts and the podcast's effect on careers, the main topic is Cybereason's blow-by-blow analysis of the Bumblebee loader: a phishing-delivered ISO/LNK chain that abuses built-in Windows tools ("living off the land"), steals credentials and reaches Active Directory compromise in under two days, usually ahead of ransomware. Steve's conclusion is that one unwitting click can bring down even a well-defended enterprise, and that local privilege escalation bugs are what make such chains so damaging.

# Key points

- Raymond Chen's blog about a "Rhythm Nation" video crashing 2005-era laptop drives got CVE-2022-38392; Steve sees it as a CVE-quality joke, but notes real hard-drive sensitivity to vibration (tracks packed very closely).
- Realtek RTL819x / eCos SDK (CVE-2022-27255, CVSS 9.8), presented at DEF CON by Faraday Security: zero-click remote code execution via the SIP ALG on the WAN side; firmware built before March 2022 is vulnerable; Realtek published no list of affected devices.
- Affected vendors include ASUS, Belkin, Buffalo, D-Link, Edimax, TRENDnet, Zyxel; Steve advises checking vendor firmware, using alternative firmware such as DD-WRT, or a non-consumer border router such as pfSense.
- Steve argues a worm is unlikely today because attackers monetize routers as proxies, miners, botnet nodes or LAN pivots; he assumes states and criminals keep databases of old unpatched edge-device exploits.
- Google Cloud Armor blocked a 46 million rps HTTPS DDoS (76% above Cloudflare's 26M record from June) lasting 69 minutes; 5,256 source IPs in 132 countries, about 22% Tor exit nodes but only 3% of traffic, consistent with the Meris botnet abusing proxies.
- Steve notes HTTP pipelining kept TLS handshakes low for the attackers, and that Google's redacted screenshots used blur, which is not a secure redaction.
- Chrome CVE-2022-2856 (insufficient validation of untrusted input) was exploited in the wild; update to the .102 build; Chromium-based browsers (Edge, Brave, Opera, Vivaldi) follow.
- Apple patched an actively exploited WebKit out-of-bounds bug (CVE-2022-32893) and a kernel out-of-bounds bug (CVE-2022-32894) in iOS, iPadOS and macOS Monterey.
- RubyGems now mandates MFA for maintainers of gems above 180 million downloads (reminders from 165 million), following NPM and PyPI; malicious package attacks on NPM and PyPI rose 289% since 2018 per cited research.
- Listener feedback: domain registrations have separate Owner, Administrative and Technical contacts, which helps a little with the "what if the domain manager disappears" problem; Leo notes it still depends on registrar cooperation and recommends registering domains yourself.
- Bumblebee is a loader seen replacing BazarLoader, Trickbot and IcedID, linked by Symantec to Conti, Quantum and MountLocker ransomware operations; it delivers Cobalt Strike, Meterpreter and Sliver.
- Infection starts with spear phishing delivering an archive or link containing an ISO (which avoids Mark of the Web) with an LNK shortcut that launches the loader DLL through a legitimate Windows binary (a LOLBin).
- Post-infection it injects into legitimate Windows processes, uses a UAC bypass through a trusted binary, performs credential theft (LSASS memory and registry hives), then Active Directory reconnaissance and domain database theft.
- Cybereason's timeline: reconnaissance within 30 minutes, credential theft at about 6 hours, Active Directory database theft around 22 hours, lateral movement over RDP with AnyDesk persistence, and roughly 50 GB exfiltrated with Rclone within about 72 hours.
- Steve's lessons: user clicks cannot be fully prevented, local privilege escalation bugs are the crux, and early-warning tripwires such as Canary tokens can buy time because the intrusion has manual, slow phases.
