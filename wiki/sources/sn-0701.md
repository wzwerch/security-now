# Summary

The episode begins with Apple's iOS 12.1.4 update, which fixed the FaceTime eavesdropping bug plus two memory-corruption zero-days found by Google's Project Zero and exploited in the wild, and a third FaceTime live-photo flaw Apple found itself; macOS 10.14.3 carries the same fixes. Steve then warns about the February 2019 Android bulletin, which fixes three critical PNG-rendering flaws that let a crafted image run code in a privileged process on Android 7 through 9, and he fears a Stagefright-like aftermath given the slow patch ecosystem. Check Point's "reverse RDP" research showed that malicious RDP servers can attack rdesktop and FreeRDP clients (dozens of flaws, many from missing size checks and integer overflows), while Microsoft's own mstsc client was far better, with only clipboard path-traversal and clipboard-sharing exposure that Microsoft declined to service. A LibreOffice (and OpenOffice) path-traversal bug let a crafted document run bundled Python code; LibreOffice fixed it quickly. Microsoft's Matt Miller reported that about 70% of Microsoft's patched vulnerabilities over twelve years were memory-safety bugs, prompting Steve's reflection on C/C++ and the industry's reluctance to change. Other news covers Windows 7 extended-support pricing for enterprises, China's new inspection powers, and Russia's planned test of disconnecting from the global Internet. The main topic is Google's Adiantum, a ChaCha-based length-preserving encryption mode that makes full-disk encryption fast on low-end Android hardware without AES instructions.

# Key points

- iOS 12.1.4 and macOS 10.14.3: fix the FaceTime group-call eavesdropping bug and two actively exploited kernel-level memory-corruption zero-days from Project Zero; update promptly even if no prompt appears.
- Android February 2019 bulletin: three critical PNG decoding flaws (heap overflow, SkPngCodec) affecting Android 7.0 to 9.0; no known exploitation yet; many devices will remain unpatched for long.
- Check Point's RDP research: rdesktop 1.8.3 (19 flaws, 11 major) and FreeRDP 2.0.0-rc3 (6 flaws, 5 major) were audited by hand rather than fuzzed; shared integer overflow in bitmap-update size calculation (CVE-2018-8795 for rdesktop); both projects patched fast.
- Microsoft's mstsc client held up much better; remaining issues are clipboard path traversal and clipboard contents leaking to the server. Mitigation: disable clipboard sharing when the server is untrusted.
- Steve notes open source is only secure if someone audits it, and that parsers of server-supplied data must not trust the server.
- LibreOffice/OpenOffice: CVE-2018-16858 directory traversal lets a crafted ODT trigger bundled pydoc.py through a hover event; LibreOffice patched, OpenOffice confirmed the traversal but not the same exploit. Researcher found the reporting path unclear.
- Microsoft (BlueHat Israel): roughly 70% of its security patches fix memory-safety bugs, unchanged for 12 years; use-after-free and heap corruption remain favourites. Steve doubts the industry will pay for provably safe software.
- Windows 7 Extended Security Updates for enterprises: $25 per seat in year one for Enterprise, doubling yearly ($50 Pro first year); not offered to consumers.
- China's cybersecurity law (in force November 2018) lets the Ministry of Public Security inspect company networks, copy data and run penetration tests remotely; Steve links it to Japan's IoT test and expects other countries to follow.
- Russia plans a trial disconnection from the global Internet before April 1 as part of a "Runet" sovereignty law, with traffic routed through Roskomnadzor-managed exchange points and an in-country DNS backup; Steve notes TLS inspection would require state root certificates.
- Firefox 65 rollout resumed after AV vendors (Avast, AVG and others) stopped scanning Firefox traffic.
- Adiantum: wide-block, length-preserving mode built on ChaCha12, Poly1305 and NH hashing in a Feistel-like layout plus one AES-256 call; about 10.6 cycles per byte on ARM Cortex-A7, roughly 5x faster than AES-256-XTS; designed so entry-level Android devices without AES hardware can enable storage encryption. Security proof relies on ChaCha12 and AES-256 being secure; the name refers to a fern genus. ChaCha is by Daniel J. Bernstein.

# Other segments

- Picture of the week: Oscar Vermeulen's PDP-11/70 front-panel kit driven by a Raspberry Pi.
- SQRL anecdotes: users report easy forum login with Android, iOS and desktop clients; Steve is updating five-year-old documentation before the official release; fingerprint unlocking on iOS to be relaxed.
- pfSense follow-up: Netgate SG-1100 (three ports, about $150) recommended for home isolation; support contracts are costly but community documentation is plentiful, and firmware is freely downloadable.
