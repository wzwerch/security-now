# Summary

The TeslaCrypt ransomware operation wound down and, when an ESET analyst asked in its support chat, the authors published their master decryption key, enabling decryption tools from ESET and a community developer; its former distributors had moved to CryptXXX. Google announced that from late 2016 Chrome will make HTML5 the default by not advertising Flash to pages, with per-site prompts and a whitelist of top sites. A hacker offered 117 million old LinkedIn email and unsalted SHA-1 password pairs from the 2012 breach for a small bitcoin price, and most were cracked quickly. Google's new Allo messenger offers end-to-end encryption (Signal protocol) only in an opt-in mode because its smart features need to read messages. Steve relays Cory Doctorow's warning that the W3C's Encrypted Media Extensions, backed by DMCA anti-circumvention law, could freeze out new browsers and chill security research. Steve and Leo spend a long segment on Microsoft's Get Windows 10 change in which closing the dialog now accepts the upgrade, and on Never10's surging downloads. The Q&A covers whether IoT radio flaws matter versus kicking in a door, what Never10 does and does not do, baby monitor risks (teased for next week), why HTTPS works through a proxy, which secure messenger to use, Windows Update slowness, browsing in a VM and flaky cable modems.

# Key points

- TeslaCrypt: used a server-held key pair so files could not be recovered; the authors released a master key on request; ESET and BleepingComputer community tools can now decrypt affected drives.
- Chrome "HTML5 by Default": Flash stays bundled but is hidden from plugin/MIME enumeration; sites fall back to HTML5; users get a prompt to allow Flash; a top-100 whitelist avoids over-prompting; user settings offer always, ask, prompt or never; Steve calls it a kludge but necessary to kill Flash.
- LinkedIn: 117 million complete credential pairs from the 2012 breach were sold; unsalted SHA-1 hashes are trivially cracked, so users who reused weak passwords should change them everywhere.
- Allo: encryption is per-conversation "incognito" mode using Open Whisper Systems' Signal protocol; the default favours features that require Google to read content; Steve argues for using a separate secure messenger when privacy matters.
- EME/W3C: DRM through Content Decryption Modules plus DMCA section 1201 could let rights holders block new browsers and threaten security researchers; the W3C declined safeguards.
- Windows 10 upgrade dialog: closing with the X now schedules the upgrade; Paul Thurrott and others protested; Never10 reached about 535,000 downloads at 25,000 per day; it sets the documented enterprise policy keys and can remove already-downloaded install files (roughly 6.5 GB) but cannot stop the nag update from arriving.
- Q&A: home automation flaws should be weighed against simple break-ins; the real concern is silent, unobtrusive access.
- Baby monitors: a Rapid7 study of nine Wi-Fi monitors gave eight an F and one a D; details promised next week; Steve advises sticking with an analog monitor for now.
- HTTPS through Squid works because the CONNECT method tunnels the TLS session without breaking it.
- Secure messaging: no interoperable standard; Steve prefers Threema for managed keys and out-of-band authentication; Signal is excellent but needs out-of-band verification and key-change alerts; EFF's scorecard was being revised.
- Windows Update slowness may stem from an anti-malware scan or dependency-tree building at the start of the update.
- Safe browsing in a VM: Steve plans to work out a lean browser VM and share it; Leo mentions Tails and VirtualBox.
- Flaky cable modems and brownouts can force periodic reboots.
