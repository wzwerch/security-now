# Summary

Steve starts with a listener's LG washing machine that uploads about 3.6 GB per day, which he reads as a sign the appliance has joined a botnet, and advises putting IoT gear on a separate guest LAN or not connecting it at all. He then uses the SourceHut outage as a concrete example of DDoS consequences: a sustained attack from 10 January led the upstream carrier Cogent to null-route the target, taking the service offline (with collateral damage to Hacker News) and exposing a lapsed escalation path at the colocation provider. The KyberSlash flaws are timing side channels in some implementations of the Kyber post-quantum key-encapsulation scheme, not in the algorithm itself. StatCounter maps show Chrome now dominating browser use worldwide. After listener questions (the Apple silicon backdoor, entering infosec in your 40s, Proton Drive versus Sync) and an update on SpinRite 6.1's USB handling, the main topic explains Google's Privacy Sandbox, especially the Protected Audience API (formerly FLEDGE, descended from TURTLEDOVE), which moves ad auctions into the browser so advertisers learn nothing about the visitor. Steve calls it a radical but workable replacement for third-party tracking that Google can force on the industry by retiring third-party cookies.

# Key points

- Compromised IoT: a washing machine showing roughly 3.57 GB upstream and 96 MB downstream per day likely took part in DDoS traffic; consumers cannot easily detect or reflash such devices. Mitigation: avoid connecting appliances, or isolate them on a guest network.
- SourceHut DDoS (from 06:30 UTC on 10 January 2024): attack beyond its mitigation capacity; upstream null routing by Cogent made servers unreachable; the colocation provider's ticketing account had been lost in acquisitions, delaying contact by seven hours; Codeberg was hit by a similar attack. Null routing drops all traffic to the target IP at every border router, which stops attack concentration but also blocks legitimate users until lifted.
- KyberSlash: some Kyber implementations perform integer division with secret-dependent operands, leaking via timing; reference code fixes are being rolled out. Signal runs Kyber alongside classical crypto, so it was not at risk. Steve views this as normal shake-out for new algorithms.
- Browser share: in 2012 Internet Explorer led in many regions with scattered Firefox and Opera; by 2022 Chrome dominated nearly every country (Safari the main exception).
- Listener reply on the Apple backdoor: supply-chain explanations are possible but unprovable; the feature first appeared in silicon designed after the 2015 San Bernardino case, which Steve notes without drawing conclusions.
- Career advice: strong demand for infosec professionals; being in your 40s is no barrier given life experience. Proton Drive is a plausible alternative to Sync, which has an iOS Files regression.
- SpinRite 6.1 update: AMI BIOS USB code has a bug that overwrites memory when accessing beyond 137 GB; SpinRite will detect the bug and patch it in place, raising the safe limit to 2.2 TB, and lift the blanket restriction on non-AMI BIOSes. Release is imminent; native USB comes with SpinRite 7.
- Privacy Sandbox components: Topics, Protected Audience, Private State Tokens, Attribution Reporting, Related Website Sets, Shared Storage, CHIPS, Fenced Frames and Federated Credential Management, all live in Chrome since mid-2023.
- Protected Audience API: a site can add the browser to interest groups (named group, owner, bidding configuration); later a page calls navigator.runAdAuction(), buyers' bidding scripts run in isolated worklets in the browser, the seller scores bids, and the winner renders in a fenced frame that cannot communicate out; results are reported through reportResult() and reportWin(). Interest data never leaves the browser, so advertisers cannot profile visitors.
- Steve's argument: pure contextual advertising would roughly halve publisher revenue, so only a workable alternative can make laws outlawing tracking realistic; Google can force adoption by deprecating third-party cookies (1 percent in Q1 2024, fully by mid-year), ad-tech is protesting but testing, and users can opt out or inspect and delete interest groups. Leo notes the browser's growing resource use.
