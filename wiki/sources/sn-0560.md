# Summary

Steve begins by clarifying that he likes Windows but objects to Microsoft's aggressive Windows 10 upgrade prompts, which now lack a clear way to decline, and to the idea that new means more secure. He summarises the Oracle v. Google fight over copyrighting Java APIs, arguing that standards and interoperability depend on APIs not being owned. Other news: a proposed US bill requiring ID to buy prepaid phones, FBI microphones near a San Francisco courthouse, John McAfee's attempt to stage a fake WhatsApp hack with pre-infected phones, Ring doorbell video crossing between users because of a database merge, and a Kickstarter for "DataGateKeeper" encryption making absurd claims about AES. Windows 10 removed Wi-Fi Sense, 7-Zip needed an update, and Microsoft released a Windows 7 convenience rollup. The main topic is a published analysis of the closed Z-Wave protocol: researchers captured traffic with software-defined radio, reverse-engineered firmware and found a protocol mistake that let them unlock an AES-protected door lock remotely without keys. Steve repeats last week's conclusion: wait for an open, multi-vendor standard and avoid relying on today's IoT systems for physical security.

# Key points

- Windows 10 upgrade dialog was refreshed to make declining non-obvious; Steve distinguishes his dislike of Microsoft's motives from the platform and promotes Never10.
- Oracle v. Google: Alsup's 2012 ruling that APIs are not copyrightable was reversed on appeal in 2014; the Supreme Court declined review in 2015; Oracle broadened claims to newer Android versions and claimed Android "destroyed" Java's mobile value; hosts call the precedent dangerous. Leo stresses the Java browser plugin, not Java itself, is the security problem.
- H.R. 4886 would require name, address, birth date and ID verification for prepaid phone and SIM purchases.
- FBI reportedly hid microphones in bus stops and lights near a San Francisco courthouse; legality is unclear because public conversations can still be protected.
- McAfee tried to convince reporters he could read WhatsApp messages using sealed phones pre-loaded with malware; Dan Guido and Moxie Marlinspike confirmed the plan; WhatsApp encryption was not broken.
- Ring Video Doorbell Pro: a few users briefly saw other people's video because call IDs existed in both beta and production databases, not because of weak random numbers; Ring merged the databases; Steve notes IoT devices should self-update.
- DataGateKeeper Kickstarter claimed AES had a backdoor and its own cipher was millions of times stronger; Steve treats it as snake oil.
- Windows 10 preview removed Wi-Fi Sense contact sharing; 7-Zip heap overflows found by Cisco Talos fixed in a new version; Microsoft shipped a Windows 7 convenience rollup to speed fresh installs.
- Z-Wave: single-vendor chips (Sigma Designs), proprietary stack and SDK under NDA; a 32-bit Home ID and 8-bit node IDs are sniffable; researchers' ZForce tool found a flaw in AES-encrypted door locks allowing remote unlocking without keys.
- Steve's advice: ZigBee and Z-Wave are first-round IoT; wait for an open consortium standard, expect frequency-hopping or spread-spectrum, and keep landline-backed alarms; devices must be patchable over the air.

# Other segments

- Anecdote about not discussing one's alarm system; Leo mentions a security expert who will not reveal his operating system.
- SpinRite story: a dying SSD in a 2009 iMac revived by running SpinRite in a DOS VM from an external OS X boot.
- Teaser: Google I/O keynote and home automation next day; Q&A planned next week.
