# Summary

Google is starting a dedicated team to assess sensitive third-party Android apps (such as contact-tracing and election apps) that fall below the 100 million user bar of its Play bounty program, and is also funding Fuzzilli research grants of up to 5,000 dollars in Google Compute Engine credits for fuzzing the V8, SpiderMonkey and JavaScriptCore engines. Microsoft released a tool to inject current Defender definitions into offline Windows WIM and VHD images, closing a protection gap for freshly deployed machines. Steve warns that WSL 2, being a Hyper-V virtual machine, bypasses the Windows firewall that filtered WSL 1 traffic. Rapid7 found over 267,000 Internet-facing Exchange servers still unpatched eight months after the February fix. Cloudflare launched a free API Shield that uses client certificates and schema validation as a positive security model. The US Treasury (OFAC) warned that facilitating ransomware payments may violate sanctions. Kaspersky described MosaicRegressor, a UEFI bootkit built on leaked Hacking Team code and used against North Korea-linked targets. The main segment reviews a ZDNet poll about why roughly 10% of visitors still run Windows 7: compatibility is the top reason, followed by simple preference.

# Key points

- Google plans an Android security team for high-sensitivity apps outside the Google Play Security Reward Program, which requires more than 100 million users.
- Fuzzilli Research Grant: one-year pilot (to October 2021), up to 5,000 dollars of Compute Engine credits, bugs go to vendors only, Project Zero's 90-day policy encouraged, new code must be open source, with interim and final reports required.
- Microsoft's Defender image-update tool (a CAB plus a PowerShell script) updates definitions inside offline Windows images so new systems are protected from first boot.
- WSL 2 runs a real Linux kernel in a Hyper-V VM with a virtual network adapter, so traffic skips the Windows firewall; users must configure Linux-side filtering.
- Exchange: a privilege-escalation flaw patched on February 11, 2020 was known to be exploited by APT actors; Rapid7 counted 433,464 Internet-facing servers on September 21, with at least 61% still vulnerable (267,986 servers).
- Cloudflare API Shield: free mutual-TLS client certificates with a hosted PKI, plus schema validation (JSON in closed beta, gRPC planned); Steve notes it would hide APIs from scanners like Shodan and blunt fuzzing.
- OFAC advisory: companies, negotiators and insurers facilitating ransomware payments risk sanctions exposure; licence requests carry a presumption of denial, while reporting and cooperation count as mitigation.
- MosaicRegressor: Kaspersky found malicious UEFI firmware code (based on VectorEDK from the breached Hacking Team) that re-drops a downloader at each boot, found on two machines, targeting diplomatic bodies and NGOs with ties to North Korea; likely installed with physical access. Steve stresses this is rare and not a threat to ordinary users. It follows the earlier LoJax finding.
- ZDNet poll (about 3,200 replies; 2,855 usable): about 42% cited compatibility, 32% did not want to upgrade (preference or dislike of Windows 10), 10% cost, 5% intrusive updates, 3% privacy and telemetry, 3% fear or lack of time, 3% training issues, under 1% moving to Linux. Only 6% paid for extended security updates. Steve notes legacy medical and CNC equipment as examples.

# Other segments

- Picture of the Week: a three-key "SuperCoder 2000" keyboard (0, 1, Done).
- Errata: Dr. John Campbell is a retired nurse with a PhD, not an MD.
- GRC forums passed 2,800 members; Steve added a "what I'm working on" thread and RSS feed; registration still hidden from the public.
- Steve describes his DOS-based SpinRite 6.1 dev setup (VirtualBox VM, SoftICE, FreeDOS test box) and says he still uses Windows 7 on one workstation and Windows 10 on another.
- Steve mentions possibly moving GRC to Cloudflare someday and IoT devices kept on a segregated network.
