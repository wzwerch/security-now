# Summary

Steve reports that listeners running the CAIDA Spoofer test found essentially every NAT router blocks forged source addresses, which explains why IoT botnets do not spoof. He then revisits LessPass: a listener inspected its code and found that the generated passwords follow a rigid vowel/consonant/digit/symbol pattern that wrecks entropy, illustrating the danger of ad hoc cryptographic designs. Steve describes his visit to Yubico to present SQRL. News items include Wired playing a silent audio track to track dwell time, a Spotify bug that hammered SSDs with database VACUUM writes, researchers taking over Philips Hue bulbs over ZigBee from hundreds of metres, the Web of Trust extension selling browsing data, the Adult Friend Finder breach, the Mirai botnet splintering after its source release, a Pixel hacked at PwnFest and patched within a day, a tool that lets you review curl-to-shell scripts, an OpenSSL 1.1.0 patch, and Eugene Kaspersky's complaint against Microsoft. He closes with the WindTalker WiFi channel-state-information keystroke attack and the BlackNurse ICMP denial of service that needs little bandwidth.

# Key points

- Spoof test results: all but one listener router blocked spoofed packets entirely; one Netgear model allowed only adjacent-address spoofing. Steve concludes NAT itself kills spoofing, so IoT botnets send real-source traffic.
- LessPass flaw: instead of mapping a hash uniformly onto the character set (repeated division and remainder), it forced a fixed vowel/consonant/digit/symbol sequence, greatly cutting entropy. Lesson: do not trust ad hoc crypto; "pronounceable password" options similarly reduce strength.
- Yubico visit: Steve gave a roughly 38-slide SQRL presentation, stressing its identity lifecycle management (identity lock and rescue code) as something FIDO/U2F lacks.
- Wired.com reportedly plays a silent audio stream to measure time on page, which also works without JavaScript but costs visitors bandwidth.
- Spotify desktop bug: repeated SQLite VACUUM caused hundreds of gigabytes of needless writes per day, wearing SSDs; fix expected in a later client version.
- Philips Hue: researchers exploited a ZigBee commissioning weakness and extracted a signing key shared across products to push malicious firmware that spreads bulb to bulb across a city; firewalls cannot help because the attack is over radio.
- Web of Trust: a German broadcaster showed the 140-million-user extension collected and sold browsing data that could be de-anonymised; Mozilla pulled it from its add-on site.
- Adult Friend Finder group breach: over 400 million accounts, deleted accounts only renamed, weak or plaintext password storage, 99 percent of passwords recovered.
- Mirai: after source release the single botnet fractured into dozens of smaller competing botnets; the malware lives only in RAM so a reboot clears it, but the device is quickly reinfected. Slogan: the S in IoT stands for security.
- PwnFest and Mobile Pwn2Own: a Qihoo 360 team compromised a Pixel in about a minute, but Google patched within a day; Steve credits the speed and notes Google-controlled Android devices get fixes first.
- A tool named TAP inserts an editor review step between curl and the shell, and also defeats servers that detect piped execution by timing.
- OpenSSL 1.1.0c fixes three flaws including a crash in the ChaCha20-Poly1305 implementation for large payloads.
- Eugene Kaspersky sued Microsoft over Windows 10 steering users to Defender; Steve is sympathetic to AV monoculture risk but notes OS vendors fold in features (firewalls, ScanDisk).
- WindTalker: channel state information exposed by WiFi chips lets a rogue hotspot infer numeric keystrokes on a phone from hand-motion interference; demonstrated against a payment app with roughly 50 percent recognition.
- BlackNurse: floods of ICMP type 3 code 3 (destination/port unreachable) packets force routers off the fast path and onto the CPU, so about 15 to 18 Mbit/s from one host can disrupt major sites; blocking the packets outright would break the network.
- Taps Kickstarter: synthetic fingerprint stickers for gloves that you enroll as an extra fingerprint, with the obvious security downside that anyone with the glove can unlock.
