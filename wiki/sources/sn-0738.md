# Summary

With Jason Howell hosting alongside Steve, the episode covers another security-software collision: Chrome 78 enabled Microsoft's Code Integrity feature and crashed on machines running outdated Symantec Endpoint Protection. Steve highlights Windows Defender's new Offline Scan, which boots into the recovery environment to find rootkits, and Adobe's exposed Creative Cloud database of about 7.5 million users, which raises phishing risk even without passwords. The City of Johannesburg faced data-theft extortion for four bitcoins and refused to pay; the attackers' use of Tutanota prompts a favorable look at that German encrypted email service. Further items: Firefox's tracker-blocking statistics, a remote code execution flaw in Nginx with PHP-FPM, and the planned carrier initiative to replace SMS with RCS. The main topic is an Oregon appeals court ruling that a suspect can be compelled to enter a phone passcode because her knowledge of it is a "foregone conclusion", contrasted with a Florida decision going the other way.

# Key points

- Chrome 78 (37 security fixes, experimental DoH) enabled renderer code integrity; old Symantec Endpoint Protection triggers "Aw, Snap" crashes in Chrome and Chromium-based Edge; fixes are updating SEP or setting a Chrome policy (RendererCodeIntegrityEnabled=0) at one's own risk. Steve sees a structural clash between rootkit-like AV hooks and Windows' anti-rootkit protections, and recommends Windows Defender.
- Windows Defender Application Control is a strict whitelisting system aimed at enterprises.
- Windows Defender Offline Scan (new fourth scan mode) restarts into the Windows Recovery environment so rootkits cannot hide; Steve suggests running it occasionally after updating signatures.
- Adobe: an unsecured prototype-environment database with email, subscription status, product use, country, last login and an employee flag for about 7.5 million Creative Cloud users was found by Bob Diachenko on Oct 19 and pulled quickly; no passwords or payment data, but useful for convincing phishing; Steve recalls Adobe's 2013 breach.
- Johannesburg (second attack that year): attackers claiming to be "Shadow Kill Hackers" demanded four bitcoins to avoid publishing stolen data; the city declined. Their note used a Tutanota address.
- Tutanota: open-source, client-side-encrypted email from Hanover, Germany, with a free tier, no phone number required, apps and desktop clients; Steve recommends it.
- Firefox's enhanced tracking protection blocked 450 billion cross-site tracking requests since July 2 (about 10 billion per day); Lockwise password manager gains a password generator.
- Nginx plus PHP-FPM (CVE-2019-11043): an underflow in path-info handling, triggered by a newline in the URL, enables remote code execution; fixed in PHP 7.3.11 and 7.2.24; the default Nextcloud Nginx configuration was affected; a public proof of concept exists.
- RCS: AT&T, Verizon, T-Mobile and Sprint announce a Cross-Carrier Messaging Initiative for 2020; RCS adds rich features and TLS-protected transport, but not end-to-end encryption, and is still not fully specified.
- Oregon Court of Appeals (Catrice Pittman case): compelling a suspect to enter a known passcode does not violate the Fifth Amendment under the foregone-conclusion doctrine when police already know it is her phone; a Florida appeals court in 2018 required proof of knowledge of the specific evidence. Steve's takeaway remains that a memorized passcode is stronger than biometrics against compulsion, while noting the issue awaits the Supreme Court.
