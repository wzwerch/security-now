# Summary

Steve starts with the lead-up to the March 2017 Patch Tuesday and then walks through Amazon's post-mortem of the S3 outage in the Northern Virginia region, caused by a mistyped input to a maintenance command that removed far more servers than intended and forced slow restarts of the index and placement subsystems. He adds follow-up perspective on Cloudflare's handling of Cloudbleed and the Amazon Echo murder-case warrant, which ended without a ruling because the defendant consented to release. News items include a Fraunhofer-affiliated study of nine Android password managers (26 flaws, mostly fixed), Cisco Talos's "DNSMessenger" fileless backdoor that fetches commands via DNS TXT records, Chrome's macOS Safe Browsing expansion, Firefox Containers moving to Test Pilot, and Cylance's UEFI ransomware demo. Matthew Green's argument that mobile (especially iOS) is safer than desktops for journalists is summarized. After a long digression on Conway's Game of Life, the show closes with Steve's worry about adversarial examples against AI systems and the controversy over Let's Encrypt issuing hundreds of certificates containing "PayPal," which are used to make phishing sites look legitimate.

# Key points

- Amazon S3 outage (February 28): an authorized operator ran a playbook command with a mistyped input, removing a larger set of servers that supported the index and placement subsystems; both needed full restarts that took longer than expected because they had not been restarted at that scale for years. Dependent AWS services in the region were hit. Amazon said it added safeguards so the command can no longer remove too much capacity. Leo noted the problem of monoculture.
- Steve explained why he has no cellular backup for the podcast: a prerecorded show is not mission critical, whereas GRC itself is heavily redundant.
- Cloudflare follow-up: Cloudflare's security lead and CTO said they saw little evidence of exploitation; Steve points to the candid on-air interview as better evidence of Cloudflare accepting responsibility than the written post, which some listeners read as blaming "ancient software." Opportunistic scrapers could have collected leaked data but could not target anyone.
- Amazon Echo case: the defendant agreed to let investigators see his device data, so no court ruling on voice-assistant warrants will come from it.
- Android password managers (TeamSIK): nine apps tested, 26 vulnerabilities including plaintext master passwords, hard-coded keys, clipboard residue and auto-fill abuse. LastPass's PIN option stored the encrypted master key with a hard-coded key and needed physical access or root to abuse. All except Avast were fixed before disclosure, with Avast leaving about half unfixed.
- DNSMessenger (Cisco Talos): a phishing Word document runs a script that launches a PowerShell backdoor, retrieves its commands through DNS TXT queries to attacker servers, and persists via Windows Management Instrumentation without dropping files, evading much antivirus.
- Chrome extended Safe Browsing to macOS for unwanted software and added confirmation when extensions change home page, start page or search engine, with warnings from March 31.
- Firefox Containers (Test Pilot): isolates cookies, local storage, IndexedDB and cache per context by adding a user context ID to the same-origin policy tuple, letting users log into several accounts on one site; Steve connects it to SQRL alternative IDs.
- Cylance showed a UEFI ransomware proof of concept at RSA, bypassing Secure Boot, Virtual Secure Mode and Device Guard on a fully updated Windows 10 Enterprise machine via System Management Mode, with details promised at Black Hat Asia.
- A write-up titled "Gargoyle" demonstrates return-oriented programming against memory scanners on Windows; URLScan.io (beta) summarizes everything a page loads, which Steve recommends.
- Matthew Green: desktop and laptop operating systems give apps broad access to user files and users open risky attachments constantly, while phone OSes sandbox apps; iOS has the best patch and Secure Enclave track record. Even so, a UAE activist was targeted with a costly three-exploit chain; Steve says he opens suspicious links on an iPad rather than his desktop.
- Russian spies reportedly sold virus-loaded thumb drives near NATO headquarters in Kabul, relying on someone plugging one into a secure machine.
- Listener tips: PingPlotter for tracing packet loss; plugging a shorted mic plug into a laptop's jack to disable the built-in mic; Steve explains ShieldsUP only scans about 1056 ports because scanning all 65,536 is costly; a fake "I am not a robot" CAPTCHA triggering a PowerShell payload was reported.
- Adversarial examples: Steve cites an OpenAI post calling them optical illusions for machines and predicts real-world cases of deliberately fooled AI, such as self-driving cars, before episode 999.
- Let's Encrypt and phishing: a Sectigo-reseller (The SSL Store) writer asked Let's Encrypt to stop issuing certificates containing "PayPal" (988 issued, up from 709 in January and 409 in December); Eric Lawrence's "Certified Malice" post noted targets like Bank of America and Apple. Let's Encrypt holds that CAs should not police content and relies on Safe Browsing. Steve agrees domain-validated certificates are being used for spoofing and thinks browsers should de-emphasize them; Leo sees it as a slippery slope.

# Other segments

- Picture of the Week from xkcd about an Echo ordering creamed corn when guests visit.
- Discussion of Vault 7 (CIA tools release) deferred to a later episode; Leo recommended his Triangulation interview with Marc Rogers of Cloudflare.
- A very long digression on Conway's Game of Life and a working digital clock built in it, with Steve's recollection of seeing it in 1970.
- SpinRite testimonial: a nearly dead laptop holding an unfiled tax return recovered by a Level 1 run.
