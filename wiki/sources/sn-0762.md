# Summary

Steve follows up on Zoom, which hid meeting IDs from title bars, centralized its security controls, turned on waiting rooms and mandatory passwords by default, faced a shareholder class action, and recruited Alex Stamos and a CISO council; Steve thinks an independent crypto audit is still needed. Browser news covers Chrome 81 upgrading passive mixed content to HTTPS and adding Web NFC, and Firefox 75 adding a daily default-browser telemetry ping. A study from Ohio State, NYU and CISPA scanned 150,000 Android apps with the INPUTSCOPE tool and found thousands with hidden backdoor or blacklist logic. Sandboxie was released as open source by Sophos, and Steve pays tribute to John Conway, creator of the Game of Life, who died of COVID-19. After a SpinRite progress report (AHCI driver work), the main topic is a detailed explanation of the Apple/Google contact tracing system, which Steve judges technically well designed and privacy preserving, leaving social and abuse problems to health authorities.

# Key points

- Zoom changes: meeting ID removed from desktop title bars; a security icon consolidates controls; waiting rooms and passwords are default for new meetings; hosts can enable waiting rooms mid-meeting.
- A shareholder lawsuit accuses Zoom of misleading statements about security and end-to-end encryption; Alex Stamos agreed to consult and Zoom formed a CISO Council. Some companies (SpaceX, Google) banned Zoom use.
- Chrome 81: mixed content such as images is auto-upgraded from HTTP to HTTPS and blocked if it fails; Web NFC added; 32 security fixes. Chrome 82 is skipped and TLS 1.0/1.1 removal is planned for 83.
- Firefox 75: new Windows scheduled task sends a daily ping about default browser settings, locale and OS version, separate from regular telemetry, honoring opt-outs; about:telemetry shows collected data; Firefox 74.0.1 had fixed the earlier zero-days.
- INPUTSCOPE study: of 150,000 apps (Google Play, Samsung preinstalled, Baidu), 12,706 had backdoor-style secrets and 4,028 contained blacklist logic; preinstalled apps were roughly double the rate (about 16 percent). Examples include a remote-control app master password. Leo cautions that many such hidden behaviors are benign developer features.
- Sandboxie moved from Sophos to open source.
- Tribute to John Horton Conway (Game of Life), who died 11 April 2020; Steve recalls Martin Gardner's column in Scientific American.
- SpinRite: Steve rebuilt a 16-bit development environment, abandoned the Open Watcom remote debugger and is writing native AHCI controller support, which newer hardware requires since legacy mode is disappearing.
- Contact tracing design: each device creates a random 256-bit master tracing key; a daily 128-bit tracing key is derived using an HMAC-based function and the day number; a rolling proximity identifier derived from the daily key and a 10-minute interval is broadcast over Bluetooth Low Energy, rotating in sync with the randomized Bluetooth address (every 10 to 20 minutes). Devices store identifiers they hear for about 21 days.
- If a user tests positive and consents, the device uploads the recent daily keys (now called diagnosis keys); other devices download new diagnosis keys, regenerate the identifiers and check for matches locally, so no identity or location is shared and the master key stays private.
- Steve disputes early objections from Moxie Marlinspike about MAC-address linkability and bandwidth. Open issues are false positives through walls, fake positive reports (needing health-authority control) and range of Bluetooth LE. Apple and Google planned APIs in OS updates within weeks.
