# Summary

Fr. Robert Ballecer again fills in for Leo. Windows 10 version 1803 (April 2018 Update) shipped a day early and brought problems, including the omission of Spectre v2 microcode protection that earlier builds had received via manual KB updates. The UK NHS announced it will move to Windows 10 after WannaCry. Computest researchers showed a remote compromise of a VW Golf's infotainment unit, stopped from reaching driving functions by the CAN gateway. Oracle's WebLogic deserialization patch was bypassed. Check Point showed PDFs can leak Windows NTLM hashes without user interaction, and Adobe declined to change Acrobat. Checkmarx demonstrated an Alexa skill that keeps listening. F-Secure disclosed a decade-long project that produced a master-key attack on Assa Abloy VingCard hotel locks. Steve corrects his Azure Sphere description and ends on Microsoft's Trusted Cyber-Physical Systems (TCPS) white paper.

# Key points

- Windows 10 1803: includes tar and curl, Focus Assist, and about 8 GB reclaimable by the new storage cleanup; problems reported already; Pro/Enterprise can defer feature updates up to 365 days; rollback available for about 10 days.
- Microsoft expanded Intel Spectre v2 microcode KB updates (4/24) to Windows 10 1507, 1607, 1703 and 1709, but 1803 shipped without them, which Steve calls bewildering. Steve argues the mitigation only gives software control over branch prediction, so no further cat-and-mouse is expected unless early-boot code is subverted; he compares the scare to Y2K.
- UK NHS will upgrade to Windows 10 citing SmartScreen and Windows Defender; Bleeping Computer calls Defender "sneakily good".
- Connected car research: the unauthenticated, unencrypted CAN bus, multiple buses joined by gateways; Computest chose a Golf, found services (including an exposed UPnP port) allowing remote code execution over the car's WiFi hotspot, reached the infotainment CAN bus (screen, speakers, microphone) but not safety systems; Volkswagen was notified and responded. Ballecer suggests one-way firewalling between infotainment and vehicle buses.
- Oracle WebLogic: a Java deserialization flaw (port 7001 exposure) was patched but the patch was bypassed within weeks; attackers mostly install coin miners. Steve explains serialization/deserialization as interpreter risk.
- A hand-crafted NTFS image can crash Windows on mount even when the machine is locked; Microsoft treated it as requiring physical access, though the discoverer noted later updates seemed to no longer crash.
- LAN Manager hash weakness (uppercase only, two independent 7-character halves) explained; Check Point showed PDF remote-content features make readers send NTLM credentials to remote servers. Adobe pointed to Microsoft's optional setting to disable NTLM SSO to public resources and will not change Acrobat.
- Checkmarx's malicious Alexa skill kept the microphone open and streamed audio; Amazon responded with store scanning. Steve wants a signed declared-permission model instead.
- F-Secure's VingCard / Vision attack: sniff a facility's cards via RFID and derive a master key that opens every door; Steve speculates about the card encoding scheme and notes offline locks cannot be centrally updated. Ballecer cautions against trusting in-room hotel safes.
- Azure Sphere errata: the Azure Sphere Security Service is not separable from the platform (only data and telemetry can flow to other clouds); Steve sees that as acceptable because it offloads security maintenance. Devices make outbound-only connections, so no inbound exposure.
- Microsoft TCPS: a conceptual paper on extending trust anchors, signed boot and signed commands (a Trusted Execution Environment chain) down to industrial and utility controllers, with secure logging. Steve compares it to his SQRL client verifying a downloaded update's Authenticode signature before swapping itself in.
