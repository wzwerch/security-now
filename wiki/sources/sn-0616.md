# Summary

Steve Gibson and guest host Father Robert Ballecer survey a run of discouraging stories. Malware was found reading comments on a Snapchat post, using a weak hash to pick marked comments and invisible Unicode characters to spell out a short link to its control server. A leaked NSA document describes how Russian operators phished through a fake Google site and relayed the two-factor code in real time, which Steve says only SQRL's domain-bound design with a client-provided session fully prevents. Tavis Ormandy, using his LoadLibrary tool to fuzz Windows DLLs on Linux, found further critical flaws in Microsoft's malware protection engine. Other items include clipboard-swapping bitcoin malware (a victim lost about 13 BTC), 18 unfixed flaws in Foscam and OEM IP cameras, Platinum group malware abusing Intel AMT Serial-over-LAN, a PowerPoint attack triggered merely by hovering, Apple's iCloud key claims, and Azure's switch to DigiCert intermediates.

# Key points

- Padre mentions old Conficker still present on school networks; Steve recalls coining "Internet Background Radiation".
- Steganographic C&C: malware scans social media comments for ones matching a custom non-cryptographic hash value (183), then uses a regex that picks characters following zero-width joiner marks to rebuild a bit.ly link pointing to its control server. No single node to take down.
- Leaked NSA analysis of Russian phishing of a voting-software vendor and DNC staff: fake Google login relays the username, password and SMS or TOTP code to the real service in real time, defeating 2FA.
- SQRL answer: authentication tied to the real domain name, and client-provided session (CPS) where the token goes from the SQRL client to the browser via a localhost redirect, so a man in the middle gets nothing; Steve details extra work to make this mandatory.
- Tavis Ormandy's LoadLibrary lets Windows DLLs run under Linux for fuzzing; he found critical remote bugs in Microsoft's mpengine (the Defender engine) and says it should be sandboxed; Steve ties this to the "interpreter" theme and to why security routers that intercept TLS are poor ideas.
- June Patch Tuesday and Adobe's 21 critical Flash fixes noted.
- Clipboard hijacking malware replaced a pasted bitcoin address, costing a user 13 BTC (about $35,000 then); check pasted addresses.
- F-Secure found 18 flaws (default and hard-coded credentials, command injection, hidden Telnet, writable files, persistent malicious firmware) in Foscam cameras and many OEM brands; advice is to disable UPnP and put IoT devices on isolated network segments (the "three dumb routers" approach); Padre describes dynamic VLAN setups and Cisco's IoT isolation tooling.
- Admin policy ideas: time-limited superuser access with alerts; Steve describes his own e-commerce lockout rule and its bug.
- Microsoft reported the Platinum group abusing Intel AMT Serial-over-LAN (off by default, but a BIOS setting) to hide traffic from firewalls; Defender was updated to flag it.
- PowerPoint hover action can launch PowerShell and a download chain (decoded, remote desktop access, cleanup) without any click; Microsoft treated it as a feature.
- Apple says its next iCloud sync keeps message keys from Apple; commentators question how recovery works and note Apple could still add a key for group messaging.
- Microsoft Azure moves to new intermediate CAs chaining to DigiCert, effective July 27, 2017; certificate pinning users must update; Symantec remains in the doghouse.
- Listener questions: sharing a SQRL identity (sites should allow many-to-one identity mapping) and 1Password Travel Mode being controlled out of band through the website.
