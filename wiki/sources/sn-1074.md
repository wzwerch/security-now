# Summary

Steve devoted the entire show to Anthropic's Claude Mythos Preview, announced the previous week with Project Glasswing. His thesis: the claims are credible, backed by patched, verifiable cases and SHA-hashed commitments to still-secret reports, and the model is the first of a class that other labs (including China) will soon match. He first covered a fresh example: wolfSSL CVE-2026-5194 (missing hash/digest size and OID checks in signature verification, NVD 9.3, Red Hat 10.0), reported by Anthropic's Nicholas Carlini, in a library shipped in about five billion devices, most of which will never be patched. Andrew Ng's remarks on the future of software engineering framed the job-market context. Steve then walked through Anthropic's red-team blog: Glasswing partners (AWS, Apple, Broadcom, Cisco, CrowdStrike, Google, JPMorganChase, Linux Foundation, Microsoft, NVIDIA, Palo Alto Networks, plus about 40 further organizations), up to $100 million in credits and $4 million for open-source security; the simple agentic scaffold used ("find a security vulnerability"); a 27-year-old OpenBSD TCP SACK denial-of-service bug; a 16-year-old FFmpeg H.264 sentinel-collision bug missed by five million fuzzing hits; a FreeBSD NFS remote root exploit (CVE-2026-4747) built via a 20-gadget ROP chain; chained Linux kernel local privilege escalations; browser exploit chains; logic and cryptography-library bugs; and reverse engineering of closed-source binaries. Steve concludes that humans are being removed from the code-writing loop, that security through friction and obscurity is ending, and that a period of mayhem precedes a future with far fewer vulnerabilities.

# Key points

- wolfSSL CVE-2026-5194: forged certificates can be accepted because minimum digest size and OID are not checked for ECDSA, Ed25519, Ed448 and others; wolfSSL claims 5 billion deployments; many embedded devices are abandoned and will stay vulnerable.
- Mythos Preview is a general-purpose model whose offensive capability emerged from general gains in code, reasoning and autonomy rather than explicit training; prior Opus 4.6 had near-0% autonomous exploit success, while Mythos produced working exploits 181 times against Firefox JavaScript-engine bugs where Opus managed 2, and reached full control-flow hijack on 10 fully patched OSS-Fuzz targets.
- Only about 1% of findings are patched; Anthropic reports "thousands" of high/critical bugs, validated by human contractors who matched the model's severity in 89% of 198 reports (98% within one level). Disclosure commitments use SHA3 hashes, with details published after 90 plus 45 days.
- OpenBSD SACK bug (since 1998, patched 26 March): a missing start-of-range check plus signed integer overflow in sequence comparison lets a crafted SACK block trigger a NULL pointer write and remote kernel crash; the successful run cost under $50 of a roughly $20,000 campaign. Steve notes OpenBSD's role in firewalls, DNS servers and VPN endpoints.
- FFmpeg H.264 bug (since 2003/2010): 65,536 slices collide with the 0xFFFF sentinel and cause an out-of-bounds heap write; found with roughly $10,000 of runs, with other codec bugs fixed in FFmpeg 8.1.
- A memory-corruption bug in a production "memory-safe" VMM, via an unsafe block, gives a guest an out-of-bounds host write; unpatched and unnamed.
- FreeBSD CVE-2026-4747: unauthenticated remote root via NFS, found and exploited with no human steering after the initial prompt (Opus 4.6 required guidance); lesson that building exploits helps triage because stack canaries did not stop it.
- Linux kernel: remote bugs could not be exploited thanks to defense in depth, but nearly a dozen local root chains (2-4 bugs, e.g. KASLR bypass plus UAF write plus heap spray) were built. Anthropic warns that friction-only mitigations weaken against tireless models; hard barriers like KASLR still matter.
- Browsers: autonomous JIT heap spray chains, including a cross-origin read and a sandbox-escape plus kernel-write chain, all unpatched; Steve calls the model effectively unreleasable.
- Logic bugs: authentication bypasses, 2FA bypasses and flaws in widely used crypto libraries (TLS, AES-GCM, SSH) are also found; model can infer intended versus implemented behavior.
- Closed source is no refuge: the model reconstructs plausible source from stripped binaries and then hunts bugs, e.g. firmware root of smartphones.
- Microsoft Patch Tuesday that day had a record 167 fixes (2 zero-days, 10 RCE); Steve speculates about link to AI-assisted discovery.
- Leo's list of a heavy 2026 quarter (Stryker, Lockheed, Cisco GitHub clone, Axios npm, a malicious crypto wallet on the Mac App Store costing about $9.5 million).
- Andrew Ng: AI developer conference 28-29 April; software jobs rising; bottleneck shifting to deciding what to build; more bespoke applications and cheaper technical-debt paydown.
