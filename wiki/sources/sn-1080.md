# Summary

The episode argues that the AI-driven flood of vulnerabilities is a one-time "technical debt" repayment rather than a permanent crisis. It starts with Cisco's Mythos experience: a "Shields Up" guidance paper and a Cisco blog calling for the 27-year-old CVE system to be overhauled (grouped vulnerability class reports, machine-readable records, AI-updated scoring, autonomous patching), noting median patch deployment of about 20 days versus exploitation within about 20 hours. Steve highlights patch deployment latency as the unsolved problem. Microsoft issued CVE-2026-45585 for the YellowKey BitLocker bypass with a script mitigation that removes an autofstx.exe BootExecute entry in WinRE, and says TPM+PIN is not exploitable. Other news: five serious Ubiquiti UniFi OS flaws patched, a highly critical Drupal PostgreSQL SQL injection already attacked, Microsoft dropping SMS for MFA and recovery in favor of passkeys, GitHub's roughly 3,800 internal repositories stolen via a malicious VS Code extension (Nx Console) and offered for sale, and Russian enterprises stuck on outdated Western software. Steve explains why a free AI account with memory feels transformative, and a listener shows Gemini identifying a convincing DMCA phishing email sent from a legitimate Google AppSheet address. The main point: Mozilla's "The zero-days are numbered" post says Mythos found 271 bugs in Firefox 150, nothing a human expert could not find, and Steve expects that after a one-time cleanup, discoverable vulnerabilities need never ship again.

# Key points

- Cisco "Shields Up: Guidance for defending in the age of AI-enabled attacks" and a Cisco security blog: Cisco participated in Project Glasswing; CVE counts grew from 321 in 1999 to about 29,000 in 2023 and a forecast median of about 59,000 in 2026 (upper case 100,000); GitHub reported a 224 percent rise in vulnerability reports in three months. Proposals: Vulnerability Class Reports with hierarchical parent/child identifiers, machine-readable-first CVE records, continuous AI-updated risk scoring, use EPSS and CISA KEV instead of CVSS alone, keep an accurate SBOM inventory, and build autonomous patch pipelines with staged rollout and rollback.
- Patch latency: median enterprise patch time about 20 days versus a Langflow flaw exploited within 20 hours of its advisory without public PoC. Steve notes only Microsoft, Apple, browsers and increasingly Linux distros have effective automatic updating; network appliances lag ("if it's not broke, don't fix it").
- YellowKey: Microsoft CVE-2026-45585 acknowledges the BitLocker bypass (physical access), offers a PowerShell script to remove autofstx.exe from WinRE's BootExecute, says it will not hurt availability, that the mitigation persists after the fix, and TPM+PIN is not affected. Steve says it is a design-level flaw that code scanners like Mythos would not find; the next frontier is AI review of design.
- Ubiquiti UniFi OS: three maximum-severity flaws (CVE-2026-34908 improper access control, 34909 path traversal, 34910 command injection) plus critical CVE-2026-33000 and a high-severity info disclosure (34911); found via HackerOne, not exploited in the wild; nearly 100,000 UniFi OS endpoints exposed per Censys. Advice: enable auto-update; Steve likens it to a fuse. Leo mentions HP BIOS updates bricking some ZBook/EliteBook models via Windows Update.
- Drupal: Mandiant-reported SQL injection affecting sites on PostgreSQL, rated 23 of 25 "highly critical"; Drupal pre-announced the patch, exploitation attempts began within days (patch diffing is trivial for open source); Drupal 8 and 9 got best-effort fixes.
- Microsoft is phasing out SMS for MFA and account recovery in personal accounts in favor of passkeys, the first major platform to do so.
- GitHub breach: a Microsoft developer's VS Code installed a rogue extension (Nx Console), exposing GitHub's internal repositories (about 3,800 to 4,000); sellers on a hacking forum asked at least $50K, promising to shred data for a single buyer or leak it; GitHub rotated critical secrets. Leo suspects the likely buyer is GitHub itself.
- Russia: roughly a third of enterprises still use pre-2022 Western software (Microsoft about half of email), so they will not receive the wave of AI-found fixes; Steve stresses enabling auto-updates for Internet-facing devices now.
- AI memory: a free account is enough for the model to accumulate memory about you and become far more useful; Leo describes layered memory systems (short, long, semantic) in his agent.
- Listener tip: phishing emails can come from legitimate infrastructure (noreply address on Google's AppSheet) and read well because of AI; asking Gemini correctly flagged a fake DMCA copyright notice. Steve expects AI agency for cybercrime prevention to be a major upcoming benefit; ClickFix remains the top attack technique.
- Mozilla (Firefox 151 notice, "The zero-days are numbered"): Opus 4.6 found 22 security-sensitive bugs fixed in Firefox 148; an early Mythos Preview found 271 fixed in Firefox 150. Mozilla says it found no vulnerability class that human experts can find but Mythos cannot, found no bug beyond elite human reach, and believes defects are finite and defenders can now win. Firefox 151 also promotes a free built-in VPN with location selection, which Steve thinks may provoke politicians.
- Steve's conclusion: repaying the vulnerability debt is transient; once Mozilla-style cleanup is done and AI checks new code before release, shipping discoverable bugs can stop; he calls regulating AI futile because LLM knowledge is everywhere. Non-bug threats (human error, phishing, hardware flaws like Rowhammer) remain.
