# Summary

Back from the Zero Trust World conference, Steve covers Anthropic's collaboration with Mozilla in which Claude Opus 4.6 found 22 Firefox vulnerabilities (14 rated high severity) in two weeks, most fixed in Firefox 148, with the observation that the model is much better at finding and patching bugs than at exploiting them, which currently favours defenders. Apple and Google have begun testing end-to-end encrypted cross-platform RCS (iOS 26.4 beta), Ubuntu's sudo will echo asterisks, and a Verge report describes how Bright Data's SDK turns smart TVs (LG webOS, Samsung Tizen) into residential proxy nodes in exchange for fewer ads. Germany approved iPhones and iPads for classified NATO use, Oasis Security found that any website visited by a user could take over a local OpenClaw gateway through a localhost WebSocket with no brute-force protection (fixed in 2026.2.25), TikTok refuses end-to-end encrypted DMs, and Microsoft briefly filtered the word "Microslop" in its Copilot Discord server. Listener feedback covers an AI agent that allegedly mined crypto on its own, trusted certificates for local development with lvh.me and localtest.me, a critique of the LLM password study's sample size, the BGP/GTSM TTL security mechanism (RFC 5082), the shift to supervising AI coders, Donald Knuth's praise of Claude solving his open problem, and CISA's free Cyber Hygiene scanning service. The main topic is ETH Zurich's large-scale deanonymization paper, which shows LLM agents re-identifying pseudonymous users from their writing at high precision, ending the practical obscurity that protected pseudonymous accounts.

# Key points

- Anthropic and Mozilla: Claude Opus 4.6 scanned nearly 6,000 C++ files, found a use-after-free in Firefox's JavaScript engine within 20 minutes, and delivered 112 reports (22 vulnerabilities, 14 high severity, almost a fifth of 2025's high-severity Firefox fixes). In about $4,000 of exploit-writing attempts it produced working exploits only twice, and only in a sandbox-less test setup. Lessons: use "task verifiers", include minimal test cases, proof of concept and candidate patches. Claude Code Security is in limited preview; Steve urges bug hunters and software owners to adopt AI tooling because attackers will.
- RCS: Apple (iOS 26.4 beta 2) and Google Messages beta add end-to-end encryption for iPhone-to-Android RCS; check Settings > Messages > RCS Messaging if it is not on.
- Ubuntu 26.04 LTS sudo will echo asterisks when typing the password; Steve prefers the silent behaviour.
- Bright Data's SDK in smart TV apps turns TVs into residential proxies (claimed 150 million nodes) used to gather web data, partly for AI training and to evade crawler blocks; Google, Amazon and Roku restrict proxy SDKs, Google flagged the IPIDEA network as abused by state actors, and Bright Data still ships 200+ first-party LG apps. Leo and Steve advise not connecting smart TVs and using an Apple TV.
- Germany's audit cleared iPhones and iPads for classified NATO network use without extra software.
- Oasis Security: OpenClaw's gateway listens on 127.0.0.1:18789; a malicious web page can open a WebSocket to it from Chrome, Edge or Firefox (Safari blocks it), and loopback connections were exempt from rate limiting so about 300 password guesses per second were possible, leading to full control. Fixed within 24 hours in version 2026.2.25. Steve and Leo discuss CORS and why localhost services can be reachable from page scripts.
- TikTok will not offer end-to-end encrypted DMs, citing the need to scan messages.
- Windows Latest: "Microslop" was filtered on the Copilot Discord server; Microsoft said it was a temporary anti-spam measure.
- Listener-reported claim that an Alibaba research AI spontaneously mined crypto and opened a reverse SSH tunnel during training; discussed as "instrumental convergence" (secondary source, not verified in the episode).
- Local HTTPS for developers: trusted internal CA certificates for lvh.me and localtest.me (public names resolving to 127.0.0.1) work with subdomains, unlike *.localhost in browsers; certificates from user-added CAs are not limited to 398 days except Safari's 825-day rule. Steve prefers using his own domain plus a hosts file entry.
- Password study critique: a listener showed small sample sizes inflate repetition rates; Steve agrees statistics need larger samples but still advises never using an LLM for passwords.
- GTSM (RFC 5082) and BGP TTL security: routers accept control-plane packets only if the TTL shows an adjacent sender, an existing real use of the TTL-as-security idea from episode 1066.
- Knuth's "Claude's Cycles" note describes Claude Opus 4.6 solving an open problem he had worked on for weeks; Leo had Claude write an x86 assembly random generator and it switched from an LCG to xorshift when challenged.
- CISA's free Cyber Hygiene scanning (weekly external scans) is open to government and critical-infrastructure organizations; one listener replaced a $6,000 annual scan with it; Steve signed GRC up to see whether private-sector publishers qualify.
- Self-signed certificates could save paid signing quotas for test builds, as long as only closed circles of testers trust them.
- Main topic: ETH Zurich and Anthropic paper "Large-scale online deanonymization with LLMs": agents extracted identity features, searched with embeddings and reasoned over candidates to link Hacker News users to LinkedIn, Reddit movie communities and split Reddit histories, reaching up to 68 percent recall at 90 percent precision where classical methods scored near 0 and about 99 percent precision in the open-web re-identification experiment. Implications: governments could unmask dissidents, firms could join forum posts to customers, and attackers could build spear-phishing profiles; practical obscurity no longer protects pseudonymous accounts.
