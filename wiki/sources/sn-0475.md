# Summary

Father Robert Ballecer hosts in place of Leo Laporte. After a joke about a worn door keypad that reveals its own code, Steve announces Apple's optional OS X patch for Shellshock and explains why a typical Mac is not very exposed (though a malicious DHCP server could trigger the shell). He criticises Apple for advertising iOS 8 MAC-address randomization as protecting users from tracking when analysis shows it applies only in deep sleep and is lost whenever the phone wakes. They discuss FBI director James Comey's complaint that Apple and Google encryption puts users above the law, noting the Fifth Amendment difference between something you know and something you are (a fingerprint). Mozilla found that serving SHA-256 certificates on mozilla.org cost about five percent of Firefox downloads because Windows XP before SP3 cannot validate them, reinforcing Steve's criticism of Google's accelerated SHA-1 deadline. Kevin Mitnick launched a zero-day exploit exchange with prices from 100,000 dollars, which both hosts view as arms dealing. Steve mentions a magnetic webcam cover and a SpinRite RAID recovery story. The main topic is Shellshock: Bash will execute trailing commands after a function definition placed in an environment variable, and since CGI web servers, DHCP clients, SSH forced commands and many embedded devices pass untrusted data through the environment into Bash, remote attackers can run arbitrary commands, with severity rated 10 out of 10. Steve contrasts it with Heartbleed, notes the speed of open-source patching (with early patches needing repair), and predicts the issue will linger for years in forgotten devices.

# Key points

- Shellshock: when Bash imports an environment variable that begins with a function definition, it also executes any command that follows, so a remote request that sets a variable (for example from an HTTP header in a CGI script) and then invokes Bash gives command execution with the privileges of the service.
- Steve and Father Robert argue it may have started as a deliberate convenience feature from the 1989 era before hostile networks existed, much like the old Windows metafile design.
- It was rated 10/10 for severity, impact and exploitability: remote, low complexity and no authentication. Unlike Heartbleed, where attackers needed luck to capture sensitive data, a scan can find vulnerable servers by making them ping the scanner, and a reverse shell using only Bash's built-in networking is possible.
- Vulnerable surfaces include CGI-based web servers, DHCP clients that invoke the shell, appliances, webcams and other "Internet of Things" gear that rely on Bash scripts; many will never be patched.
- Patching: the first fix was incomplete and further remote code execution variants were found by fuzzing, showing both the weakness (decades unnoticed) and the strength (rapid pile-on fixes) of open source. IDS signatures for the "() {" pattern help but are easy to evade.
- One CDN vendor counted hundreds of thousands of exploit attempts against its protected domains within days.
- Apple released a small optional OS X Shellshock patch without reboot; Steve recommends installing it.
- iOS 8 MAC randomization works only while the device is in deep sleep, so Apple's marketing statement that it prevents persistent tracking is inaccurate, a trust issue for Apple's other privacy claims such as iMessage.
- FBI director Comey criticised default encryption on phones; the hosts note the government's overreach after Snowden eroded trust, and that law can compel biometrics but not remembered passwords.
- Mozilla.org switched to SHA-256 and lost about 145,000 downloads a week (about 5 percent) from XP pre-SP3 users, then reverted to a SHA-1 certificate ending 2015 and noted Firefox ships its own TLS stack. Steve says two more years of notice would be fine but Google's November start is premature.
- Kevin Mitnick's "Absolute Zero-Day Exploit Exchange" sells exploits for at least 100,000 dollars; Steve and Father Robert call it arms supply because buyers want secrecy rather than patching. Dan Geer's proposal that the US government buy and release zero-days is mentioned.
- Software licence terms that disclaim all liability are unusual compared to other industries.
- A small magnetic cover for laptop webcams (a Kickstarter product) is praised as elegant.
- SpinRite helped a listener rebuild a four-disk NAS RAID 5 after several drives failed, though the friend's backup had silently stopped working.

- Plans for Steve to return to SpinRite 6.1 after SQRL.
