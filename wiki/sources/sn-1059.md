# Summary

The first show of 2026 opens with Steve's growing sense of diminishing returns in security measures that inconvenience users. He criticizes the CA/Browser Forum vote (ballot CSC-31, all ten yes votes from certificate issuers) cutting the maximum code-signing certificate lifetime from 39 to 15 months for certificates issued from March 1, 2026, arguing it solves no real problem since keys already live in hardware and that it pushes developers toward pricey cloud-signing subscriptions (DigiCert quoted about $1,104 per year for 1,000 signatures); he plans to buy a 39-month certificate before the deadline and notes the TLS lifetime cut to 200 days on March 15. He covers reports that OpenAI is exploring advertising in ChatGPT, PyPI's year-in-review security improvements (email verification on top of TOTP, huge request volume), Microsoft's announcement of hardware-accelerated BitLocker for NVMe drives that needs new CPUs such as Intel Panther Lake, and New York's mayoral inauguration prohibited-items list naming Raspberry Pi and Flipper Zero. Off-topic segments recommend the British time-travel series "The Lazarus Project" and discuss a Vanderbilt trial linking magnesium to vitamin D regulation. The main story is MongoBleed: since MongoDB 3.6 (2017), the server trusts an attacker-supplied "uncompressed size" in zlib-compressed wire messages, allocates an uninitialized buffer and returns leftover heap data, leaking passwords, keys and tokens pre-authentication. About 87,000 instances were publicly reachable (Censys). Steve's lesson: never expose such services and never rely on remote authentication.

# Key points

- Code signing: nearly all platforms now expect signed software (macOS strictest, Windows Defender and Smart App Control rely on signatures and reputation, Linux least); since June 2023 all code-signing keys must be in hardware; shortening lifetimes benefits CAs and cloud-signing resellers; prices cited: IdenTrust about $270/yr, GlobalSign about $550, DigiCert about $840 (cloud signing $1,104 with 1,000 signature cap). Smart App Control in Windows 11 cannot be turned back on once disabled and offers no per-app exceptions. Steve and Leo see Linux and Wine as the open alternative; a "Let's Encrypt for code signing" is unlikely because signing requires identity vetting.
- TLS: maximum certificate lifetime falls from about 398 to 200 days on March 15, 2026; issuing just before that date defers pain.
- ChatGPT ads: The Information and Tom's Hardware report staff discussing sponsored answers, sidebar ads or shopping-only ads; OpenAI projects $2 per non-paying user in 2026 rising to $15 by 2030 and expects heavy losses; Steve and Leo prefer clearly labelled ads or paying subscriptions and worry about skewed answers.
- PyPI 2025: 3.9 million new files, 130,000 new projects, 1.92 EB served, 2.56 trillion requests (about 81,000 per second); added email-based verification to TOTP logins; over 52% of active users have non-phishable 2FA. TOTP is phishable via relay sites.
- BitLocker hardware acceleration (Windows 11 24H2/25H2): offloads XTS-AES-256 to SoC crypto engines and wraps keys in hardware, because software BitLocker costs roughly four times the CPU cycles per I/O on fast NVMe; first supported on Intel Core Ultra Series 3 vPro; check with manage-bde -status. Steve suggests disabling BitLocker on NVMe drives that do not need it for now; Leo keeps full disk encryption because SSDs cannot be reliably wiped.
- NYC inauguration list banned Flipper Zero and Raspberry Pi by name; Adafruit's critique calls it security theater, Steve sees Flipper Zero as defensible and Raspberry Pi as nonsensical.
- MongoBleed (CVE-2025-14847, CVSS 8.7; unauthenticated memory disclosure): mismatch between claimed and actual decompressed size leaves uninitialized heap content in the response; C/C++ malloc returns non-zeroed memory; public exploit appeared December 25 and is trivial; exploit hunts for credentials and AWS keys; 87,000 (Censys) to over 200,000 (Beaumont) exposed instances on TCP 27017; patch and rotate secrets; MongoDB should never be Internet-facing. Compared with Heartbleed.
- Steve's recurring law: never rely on remote authentication; filter exposure instead.
