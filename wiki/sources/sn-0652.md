# Summary

Intel released production microcode for Kaby Lake, Coffee Lake and more Skylake platforms to OEMs (end users must wait for BIOS updates), while Windows has dormant Intel/AMD microcode-loading DLLs. In cryptojacking, attackers who found an unprotected Kubernetes console at Tesla (cloud keys visible on the page) ran a quiet miner with a private pool endpoint behind Cloudflare, a non-standard port and throttled CPU use; Steve predicts "intrusion pressure" as stealing idle compute becomes profitable. Google's Tavis Ormandy reported a remote-code-execution style weakness in uTorrent (reachable from any web page via DNS rebinding; the auth token was readable from the local web root), BitTorrent's first patch only blocked his demo, and Steve advises not leaving it running. Georgia's Senate passed a bill criminalizing "unauthorized computer access" with no research exemption. Forbes reports Cellebrite can apparently unlock iPhones through iOS 11, but only at its own facility. Apple will move Chinese iCloud data to Guizhou-Cloud and keep keys in China. US Customs and Border Protection has never verified digital signatures on ePassports. Firefox 60 drops the cookie manager UI, Coinbase must give the IRS data on about 13,000 customers, and Android P will mute background microphone and cut camera access. Recorded Future finds clean, validly issued code-signing certificates now sold underground for $300 to $1,600. Cloudflare Workers can flag pwned passwords via Troy Hunt's API, and Pwned Passwords v2 lists 501 million unique passwords. The explainer covers WebAssembly: a compact precompiled bytecode for a stack machine, faster to start than JavaScript, but not the answer for efficient browser mining, which really needs GPU hashing.

# Key points

- Intel's PDF lists per-processor microcode status (production versus beta); Variant 2 remains the hard one.
- Tesla cryptojacking: exposed Kubernetes pod with cloud-storage credentials on the console; attackers hid mining pool traffic. Same pattern: exposed management consoles.
- uTorrent: HTTP RPC servers on localhost ports; any website could read the token and set the download directory; Project Zero's 90-day clock; wait for confirmation of a real fix.
- Georgia SB: crime of accessing a computer "with knowledge" it is unauthorized, no exemption for good-faith research; EFF opposes.
- Cellebrite: unconfirmed but well-sourced claim to extract data from iPhone 5 to X on iOS 5-11, via device shipped to the vendor.
- Apple China: data moves under Chinese law; Reporters Without Borders advises journalists to change region; iCloud data is accessible to Apple (unlike on-device data).
- ePassports: signatures are never checked at US ports of entry despite a 2010 GAO report; Senators Wyden and McCaskill wrote to CBP.
- Code signing: certificates are now fraudulently obtained rather than stolen; signed malware often evades AV heuristics and SmartScreen.
- Cloudflare Worker adds a header when a posted password appears in Pwned Passwords; Troy Hunt's data shows each password appeared about six times across breaches.
- Router detail: some routers (Peplink, and possibly EdgeRouter X) can force clients' DNS; hardware offloading boosts EdgeRouter throughput.
- WebAssembly: C/C++ compiled to a binary format, standardized at W3C by browser vendors, loads quickly and can approach native speed over time.
