# Summary

The episode begins with Chrome 89.0.4389.72, which fixed 47 vulnerabilities including a zero-day reported by Microsoft's browser researchers, and with a light story about a Lay's extension that turns on YouTube captions when it hears chips being eaten. Google is funding two full-time Linux kernel security maintainers, and the Winamp community project WACUP released a large update. A University of Illinois paper ("Lord of the Rings") shows a side channel based on contention on Intel's on-die ring interconnect, which Steve considers real but not alarming. He then follows up on dependency confusion: copycat packages exploded into thousands, many turned malicious, and a researcher reached Microsoft Teams build infrastructure. The main topic is Hafnium, the China-linked group that exploited four Exchange Server zero-days (ProxyLogon). Quiet targeted attacks since early January turned into indiscriminate mass web-shell planting after Microsoft's March 2 patches, with at least 60,000 victims. Steve criticises Microsoft for taking roughly two months after multiple independent reports, advises scanning with the updated MSERT tool, and warns that manually installed patches fail silently unless run as administrator.

# Key points

- Chrome 89 (47 fixes, bounties up to $10,000) patched an in-the-wild zero-day found by Microsoft; Steve notes the bug-hunting field is growing because software keeps being created faster than flaws are fixed.
- Lay's Crispy Subtitles extension (built by an agency with an AI trained on 178 hours of chewing sounds) enables YouTube captions when it hears crunching; verified by BleepingComputer as genuine marketing.
- Google funds Gustavo Silva (eliminating classes of buffer overflows) and Nathan Chancellor (Clang/LLVM bug triage) as full-time Linux kernel security maintainers.
- WACUP, the Winamp Community Update Project, released a preview with a huge list of fixes, extending Winamp 5.66 through plugins; it is freeware.
- "Lord of the Rings" side channel (USENIX Security 2021): contention on Intel's ring interconnect gives a cross-core covert channel of about 4.18 Mbps and leaks key bits from vulnerable EdDSA and RSA code and keystroke timing; Intel was unconcerned; constant-time cryptography defeats it.
- Dependency confusion fallout: Sonatype counted over 700 copycat npm packages, then over 5,000 across PyPI and npm, some exfiltrating shell history and password-hash files; Birsan had deliberately limited his probes to DNS.
- Contrast Security's Matt Austin registered an "optional dependency" name from Microsoft Teams' package list and saw installs from internal Microsoft addresses; he stopped short of shipping code, noting the potential reach of over 100 million machines.
- Hafnium/ProxyLogon timeline: DEVCORE (Orange Tsai) reported a pre-auth remote code execution chain on January 5, 2021; Volexity saw in-the-wild abuse from January 6 and Dubex from January 18; Microsoft patched March 2 and also patched out-of-support Exchange 2010, meaning the bugs were over 10 years old.
- After disclosure, multiple groups mass-exploited unpatched servers to plant ASPX web shells; a honeypot was hit five times in one day. Patching alone does not remove a web shell already installed. Volexity described SSRF-based mailbox theft followed by credential dumping and lateral movement. Exchange Online was not affected.
- Mitigations: update the Microsoft Safety Scanner (MSERT) to detect web shells, run Exchange security updates as administrator (UAC otherwise lets them fail silently), and use Microsoft's script to verify patch installation and indicators of compromise.
