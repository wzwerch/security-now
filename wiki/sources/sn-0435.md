# Summary

Steve opens with a week of NSA news: a critical reaction to a "60 Minutes" report, a federal judge ruling bulk telephone metadata collection unconstitutional, a White House meeting with fifteen tech executives, and a Forbes profile countering the portrayal of Snowden. He then covers an industry report showing bots now generate 61.5 percent of web traffic, and Google's change to proxy and re-encode images in Gmail, which makes loading them by default safer and hides users' IP addresses from senders. The headline technical item is a new academic side-channel attack from Tel Aviv researchers who extracted 4096-bit GnuPG RSA keys from laptops using the sound of the machine (or chassis electric potential) while it decrypted chosen ciphertexts; Steve says this is impractical in noisy real-world conditions but shows the need for side-channel-safe crypto like the elliptic-curve code he is using. He discusses Microsoft joining the FIDO Alliance and compares Google's token-based Universal Second Factor with SQRL, which he considers simpler, stateless, free and able to recover a stolen identity. Listener questions include running SpinRite inside VirtualBox to get faster BIOS transfers, whether a 256-bit collision is merely improbable (it is, but entropy quality is critical), pointers in programming, NoScript's permanent trust option and how NAT routers drop unsolicited packets.

# Key points

- "60 Minutes" NSA piece was criticised as uncritical; the next day a federal judge found bulk phone-metadata collection unconstitutional; lawsuits include IBM shareholders over lost China sales and class actions against carriers.
- Silicon Valley executives met the White House; one participant paraphrased in the press asked how the agency could hack the overseas infrastructure of cooperating US companies. Steve notes the tension that these firms also profile users, but argues consent and state power make the difference.
- Snowden profile: a coworker described him as a gifted engineer who built a backup system and reported unpatched vulnerabilities, was given broad administrator rights as a contractor, and kept a copy of the Constitution on his desk, contradicting depictions of him as a cheater.
- Bot traffic rose from 51 percent in 2012 to 61.5 percent in 2013, of which about half was benign search crawlers, with scrapers, hacking tools and impersonators making up the rest.
- Gmail now fetches remote images through Google servers and transcodes them, blocking IP-address and cookie tracking by senders and neutralising malicious image payloads, though unique image names can still signal that a message was opened.
- Acoustic cryptanalysis: key-dependent computation changes power-supply load and so produces sounds and ground-potential variation; the attack recovered full 4096-bit keys from laptops in about an hour using chosen plaintexts, with a microphone up to four metres away, but only on an otherwise idle target.
- Side-channel-safe cryptographic code (no secret-dependent branches or memory access) will become necessary; Steve had already chosen such curves for SQRL.
- FIDO and Google's U2F need hardware tokens with per-site state, and are not practical for iOS; Steve argues SQRL needs no storage per site, supports key-lifetime management and identity recovery, and could coexist with FIDO.
- SQRL's specification is finalised, with Steve writing the reference code.
- Entropy: duplicate RSA keys found online came from servers generating keys at boot with an empty entropy pool; decentralised identifiers (Bitcoin wallets, BitTorrent Sync keys, SQRL identities) depend entirely on strong randomness, and operating systems should refuse to generate keys until enough entropy exists.
- SpinRite 6 uses the BIOS for I/O; running it in VirtualBox with raw disk access gave one listener a seven-fold speed up because the virtual BIOS supports Ultra DMA; SpinRite 6.1 will bypass the BIOS entirely.
- NAT works as a one-way valve: it records outbound connections and drops unsolicited inbound packets, shielding hosts from Internet background radiation.
- NoScript offers an "always trust" option so a site need not be re-approved each time; Faraday-style pouches can block phone signals.
- GRC's preferred Windows cipher-suite ordering was published for others to reuse.
