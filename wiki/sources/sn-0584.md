# Summary

Steve opens with a Q&A-style episode that is also crowded with news. He first covers research from UC Riverside and SUNY Binghamton showing that the shared branch-prediction table in Intel CPUs can be probed to undo address space layout randomization (ASLR) in a very short time, and that no obvious fix exists for current hardware. He pairs this with the DARPA "Little Bird" drone result for formally verified code, arguing that proofs of correct software are necessary but not sufficient when attacks now abuse hardware design features rather than bugs. A further paper showed that Microsoft's 2015 C compiler runtime inserted a short-circuit in a 64-bit multiply, turning Adam Langley's constant-time Curve25519 code into variable-time code that leaks key information. Steve then discusses Mozilla's push to restrict the Battery Status API because it is mostly used for fingerprinting, new DMCA research exemptions, Matthew Green's court request, MPAA/RIAA pressure on registrars and Cloudflare, and ProtonMail's claim that Google hid it from search results. He explains how to regain control over Windows 10 forced updates and reports Google's seven-day disclosure of an actively exploited Windows kernel privilege escalation. Errata corrects his earlier framing of Dirty COW as a remotely usable flaw. Listener questions cover DNS-outage workarounds, an EdgeRouter X boot-time bug, and local egress filtering, and a compression-before-encryption puzzler is posed for next week.

# Key points

- Branch-predictor ASLR bypass: researchers showed that probing the shared branch-target table lets code locate kernel chunks in about 50 ms on a Haswell machine under Linux; it also applies to virtualised hosts and likely to Windows and macOS. A possible mitigation is separate prediction tables per privilege level, but that needs new hardware.
- DARPA HACMS and formal verification: a red team failed for six weeks to take over the Little Bird helicopter drone whose key software was formally verified. Steve's caveat is that hardware side channels sidestep correct code.
- Compiler undermining constant-time code: the MSVC 2015 runtime's 64-bit multiply skips work when both high words are zero, so curve25519-donna built with it shows key-dependent timing, which researchers used to extract keys remotely. Lesson: verify constant-time behaviour in the final binary.
- Battery Status API: Mozilla's Chris Peterson proposed making it chrome-only after telemetry showed over 200 million calls in one Firefox release and about 6% of pages using it, mainly for tracking and fingerprinting. Edge and WebKit never implemented it.
- DMCA: new exemptions (running two more years) cover jailbreaking, car software, medical-device data access and security-related reverse engineering; the EFF is backing Matthew Green's suit against Section 1201 so he can publish a cryptographic engineering textbook.
- MPAA and RIAA submissions to the US government name registrars and Cloudflare as piracy facilitators; the I2Coalition pushed back, noting registrars generally need a court order to suspend domains.
- ProtonMail reported that Google search hid it for roughly a year for terms like "secure email" until public pressure; Leo cautioned that accidental delisting is also common.
- Windows 10 forced updates: Group Policy "Configure Automatic Updates" set to notify-for-download-and-install (not on Home edition) restores control; Leo adds that marking a connection as metered also stops automatic downloads. Both stress that patching should still happen.
- Windows 7/8.1 monthly quality rollups: the first optional "preview" rollup appeared a week after the October rollup, raising the question of how it interacts with out-of-band fixes.
- Google disclosed, after seven days per its policy, an actively exploited win32k.sys local privilege escalation (usable as a sandbox escape) alongside a Flash zero-day that Adobe had already patched; Chrome's Win32k lockdown on Windows 10 blocks it.
- Errata: Dirty COW is a local privilege escalation, not remotely exploitable by itself, but dangerous when chained with a bug that gives code execution on a web-facing Linux server. Recurring maxim: attacks never get weaker.
- Drammer follow-up: the project lead praised Steve's explanation; LPDDR4 memory is also vulnerable and bit flips were reported on several Android phones.
- DNS outage questions: swapping bookmarks to IP addresses fails because pages reference other hostnames; a prepopulated hosts file would work; a local shim that falls back to last-known IPs is a good idea nobody ships yet.
- EdgeRouter X boot bug: the router briefly acts as a plain switch at boot until its routing rules load; Ubiquiti provides a boot-update script fix distributed from its firmware site.
- Local egress filtering: dropping outbound packets whose source address is not local is easy on a NAT router, but modern IoT botnets send legitimate traffic from real addresses, so it will not stop DDoS.
- Puzzler: when could compressing before encrypting be undesirable? (Answer deferred to next episode.)
