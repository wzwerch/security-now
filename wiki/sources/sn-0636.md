# Summary

The Picture of the Week is a Charter notice of overnight modem upgrades. A University of Maryland study finds that code signing no longer signals trust: a large share of malware carries valid certificates that anyone can buy, while many antivirus products do not verify signatures properly, so a bogus signature can make malware look benign. A researcher shows how a malicious page can learn which major sites a visitor is logged into by loading each site's favicon cross-origin. Press excitement about MINIX inside Intel's Platform Controller Hub is clarified, and the ME Cleaner project plus a hardware-flashing guide to neutralise the Management Engine is described. A lookalike WhatsApp app with over a million Play Store downloads, a Tor browser IP leak on macOS and Linux (TorMoil) and the upcoming Tor v3 onion services are covered, along with a standalone Signal desktop client. Other items are a Google Docs false-positive lockout, an audio driver that installs its own root certificate, an ARM-authored IoT firmware-update draft, listener reactions to Controlled Folder Access, and finally ROCA fallout: Bernstein and Lange found a more efficient attack, and Estonia suspended about 760,000 ID cards.

# Key points

- Signed malware (Univ. of Maryland, SignedMalware.org): of 325 signed malware samples, 189 (58%) had valid signatures; 111 certificates were used, only 27 revoked; about 89% of malware families used a single certificate; at least 34 antivirus products did not properly validate signatures, with some marking malware benign when a copied or expired signature was attached.
- Cross-site login leak (Robin Linus): script requests each site's favicon and observes whether the request succeeds or is redirected to login, revealing logged-in sessions; ads can run such probes, forming a fingerprint.
- Intel ME: runs MINIX 3 on the Platform Controller Hub, not the CPU. ME Cleaner strips most of the ME firmware and sets the NSA-requested disable bit, but applying it needs external flash programming (e.g. a Raspberry Pi clip on the BIOS chip) and risks bricking; Steve sees it for tinkerers or fleets willing to test on one board.
- Fake WhatsApp app used a trailing Unicode space in the developer name to impersonate "WhatsApp, Inc." and reached over a million Play installs; payload was ad bundling.
- TorMoil: Tor Browser on macOS and Linux could leak the user's IP through file:// URLs; reported to the Tor Project on 26 October and fixed in 7.0.8 with a workaround that breaks some file links.
- Tor v3 onion services (Proposal 224, four years in the making, in alpha): SHA-3, ed25519/Curve25519 in place of SHA-1/RSA-1024/DH, less leakage to directory servers, 56-character onion addresses.
- Signal now ships desktop clients for Windows, macOS and Debian-based Linux, deprecating the Chrome app.
- Google Docs briefly flagged and locked some shared documents for terms-of-service violations; Google said automated scans of shared files detect abuse, and Leo notes this applies only to shared items.
- Savitech USB audio driver installers silently add their own root CA to the Windows trust store (a US-CERT advisory).
- ARM engineers drafted an IETF-style standard for IoT firmware updates with signed images, a shadow firmware slot, watchdog-based fallback and confidentiality; Steve hopes it becomes a labelled standard.
- Controlled Folder Access: reviews are mixed (some legacy apps break, others work fine) but Steve recommends trying it.
- ROCA update: Daniel Bernstein and Tanja Lange devised a roughly 25% more efficient attack from the paper alone, prompting the original authors to reveal an attack up to four times more efficient; a 2048-bit key now costs roughly $5,000 and about 2.5 days. Estonia suspended around 760,000 ID cards and is reissuing with elliptic-curve keys. Steve quotes Schneier: attacks only get better.
