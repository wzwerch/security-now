# Summary

Steve first follows up on the stale Windows driver blocklist: Microsoft's October 2022 preview update refreshes it, but its documentation says the list is normally updated only with major Windows releases, and Steve points to a manual method using Windows Defender Application Control policy files (which would block a couple of his own custom-signed drivers). He then notes Microsoft refused to give a CVE to a patched SharePoint server-side request forgery, because Microsoft defines a CVE as a fix with an MSRC write-up. The OpenSSL project pre-announced a critical 3.0.x fix, which was downgraded to "high" when released. Other stories: a patched Windows TCP/IP flaw in IPv6 IPsec fragment reassembly, a Leiden study finding about 10% of GitHub vulnerability proofs of concept are malicious, Trail of Bits' "Stranger Strings" CVE-2022-35737 in SQLite's printf functions present since 2000, PayPal announcing passkey support, and a CrowdStrike tutorial series on Chrome V8 internals. Listener feedback includes a PayPal one-time-code login that bypasses a user's strong password and authenticator, and a SpinRite 6.1 status report including the end-of-life of the real-time OS Steve chose. The main topic is the farewell blog post of Ian Levy, departing Technical Director of the UK NCSC: stop blaming users for bad design (the B-17 landing gear lesson), fix root causes such as memory safety rather than symptoms, learn from past supply chain attacks, align commercial incentives with security, and pay attention to details.

# Key points

- Microsoft's non-security preview for November 2022 contains a corrected kernel vulnerable-driver blocklist (DriverSiPolicy.p7b, KB5020779) so Windows 10 matches Windows 11 22H2; official guidance still says the list updates with major releases, while a manual path uses the WDAC policy refresh tool and downloadable policy files in audit or enforced form, requiring a reboot. Steve finds yearly updates for known malicious drivers hard to justify.
- STAR Labs found an authenticated SSRF in SharePoint Server 2019; Microsoft patched it but gave no CVE. Kevin Beaumont and Will Dormann criticised the redefinition; Steve compares it to Microsoft's own definition of zero-day.
- OpenSSL 3.0.7 fixes CVE-2022-3602 and CVE-2022-3786 (affecting 3.0.x only, not 1.1.1 or LibreSSL); pre-announced as the first critical OpenSSL bug since 2016, it shipped rated high because of mitigating factors.
- Windows TCP/IP RCE patched in September: a Numen Cyber Labs proof of concept exploits IPv6 IPsec fragment reassembly, but conditions are rare; Steve says nation-states keep databases of old exploits for selective use against unpatched targets.
- Leiden University study: 4,893 of 47,313 GitHub proof-of-concept repositories for 2017-2021 CVEs (about 10.3%) showed malicious symptoms such as calls to bad IPs, obfuscated code or trojanized binaries; treat PoCs from GitHub with caution like malicious npm/PyPI packages.
- SQLite CVE-2022-35737: very large strings to the printf-style functions (with `%Q`, `%q`, `%w`, or the `!` flag) cause a crash, hang, or possible code execution on 64-bit builds without stack canaries; introduced in 2000, fixed in 3.39.2 on 21 July 2022. Despite 100% branch coverage, it was missed because the 1 GB internal limit was not enforced at the C API and 32-bit assumptions broke on 64-bit systems. Many apps embed their own SQLite copy and may stay vulnerable, similar to Log4j.
- PayPal announced passkey login, but Steve could not find it yet; Leo gives account-setting hints.
- CrowdStrike's Jack Halon published part one of a Chrome browser exploitation tutorial on V8 internals (Steve only points to it as educational).
- Kathleen Booth, pioneer of early assembly notation, died at 100.
- PayPal's "login with one-time code" sends an SMS code that bypasses password and TOTP, and cannot be disabled, so SIM or SMS interception defeats strong settings; Steve notes telephony (SS7) is insecure.
- Listener comments: Edge vertical tabs; uBlock Origin Lite for Manifest V3; whether new cryptography can fix privacy (no, the problem is data after decryption); Microsoft too entrenched to be pressured by breach liability.
- Ian Levy's lessons: users are blamed for bad design (B-17 landing gear and flap switches next to each other, solved by shape coding); security burden should sit with the party able to carry it; memory safety flaws have been known since a 1972 USAF study and 400 were reported in Q1 2022, so the UK funds a memory-safe processor under Digital Secure by Design; Active Cyber Defence only treats symptoms; Log4j echoes Heartbleed and SolarWinds echoes 2002 Sendmail/OpenSSH distribution compromises; the US Cyber Safety Review Board resembles aviation's NTSB; incentives matter (customers pick free Netflix over network security, hence the Telecoms Security Act, and private equity ownership shaped SolarWinds); and details matter in debates such as child safety versus end-to-end encryption.

# Other segments

- Picture of the week: a tall security gate beside an easily climbed railing, labelled "in scope" and "out of scope".
- USB vape stick that asks a Mac for permission when plugged in; mention of USB data blockers.
- Steve's love of his 35-year-old Northgate OmniKey keyboard; Alt-Tab versus Ctrl-Tab discussion.
- SpinRite 6.1: Steve reengineered bad-sector location after finding ambiguities in the AHCI spec, completed data recovery and event logging, and plans serial-number drive selection; the commercial RTOS (On Time RTOS-32) he planned for SpinRite 7 will leave the market at year-end, so he will buy its source license after testing.
