# Summary

Before Black Hat, Steve and Leo cover a Synology NAS ransomware worm in passing and then HP Fortify's review of ten popular consumer Internet of Things devices: about 250 vulnerabilities in total, eight of ten accepted weak passwords such as 1234, seven did not encrypt traffic, six had cross-site scripting or weak interface security and six did not encrypt update downloads. A 17-year-old Australian researcher showed that adding a particular string to a PayPal URL, as used by the eBay-linked purchase flow, skipped PayPal's second factor. Steve explains Google's detection of child abuse imagery in email, which relies on matching image hashes against an industry database and is mandatory to report once known, and finds the privacy outrage overblown. The BadUSB research by Karsten Nohl and Jakob Lell, to be presented in two days, shows that USB devices contain reprogrammable controller firmware that can be altered to act as other device classes (for example a keyboard) or hide a boot image; Steve says the real fix is for operating systems to ask before accepting new USB device classes and for vendors to lock firmware, and he asks for judgment until details appear. The main topic previews the UC Berkeley paper (to be presented at USENIX Security) on LastPass, RoboForm, My1login, PasswordBox and NeedMyPassword: CSRF and XSS flaws, credential-sharing authorization bugs and especially bookmarklets, which run script inside untrusted pages, fixed within days of notification a year earlier except by the unresponsive NeedMyPassword. Apple's iOS 8 beta 5 has already removed some services highlighted by Zdziarski from wireless access.

# Key points

- Synology NAS devices exposed to the Internet were hit by a CryptoLocker-style worm (reported demand 0.6 bitcoin); Leo took public NAS units offline.
- HP's ten-device IoT study: 250 flaws, weak default or user passwords, unencrypted traffic and updates, XSS in device interfaces, and heavy personal data collection; Steve expects the industry to fix this quickly.
- PayPal two-factor bypass via a crafted URL parameter was reported two months earlier and left unanswered; it still needed the password. Steve cites SQRL's "request no recourse" and "disable non-SQRL login" options as the opposite design.
- Google's hash match against a shared child-abuse hash database is automated, with a human reviewing matches, and Google must report what it knows; Leo and Steve defend it as no worse than ad-targeting scans.
- BadUSB: USB sticks contain updatable microcontrollers that can be taken over, so a drive can masquerade as a keyboard or add a hidden bootable image; IronKey and YubiKey-style devices also have firmware; operating systems could prompt before accepting new device classes; Steve says this is not a USB protocol flaw like FireWire or Thunderbolt DMA.
- Steve notes hard-drive makers now lock firmware, and no one knows how easily USB sticks can be reprogrammed over the port itself.
- Berkeley paper: My1login computes MD5 over even and odd characters of the password separately (weak); NeedMyPassword stores credentials unencrypted before upload and never replied.
- Bookmarklets inject JavaScript into the current page; a hostile page can subvert the injected iframe and capture the password manager login, so log in to the manager in a separate tab first (My1login does this by design). Steve avoids bookmarklets on iOS and copies credentials manually via clipboard order (password first, then username).
- LastPass issue: with a user's one-time password feature enabled and a CSRF, an attacker could fetch the encrypted vault, which also exposed site names; RoboForm allowed CSRF edits or deletions; NeedMyPassword allowed full account takeover via XSS; My1login sharing used incrementing serial numbers that allowed a revoked party to collude.
- The study's authors plan to build their own manager; findings were fixed a year earlier.
- Apple's iOS 8 beta 5 removed some services (such as the always-running packet capture) from wireless exposure.
- SQRL: first pre-completion client released to the GRC newsgroup for testing; identity import and export and protocol not finished.
- SpinRite: Steve recalls telephone calls asking "does it really work" and notes the money-back guarantee.
