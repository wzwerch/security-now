# Summary

Triggered by Chrome 67 removing HTTP Public Key Pinning (HPKP), Steve introduces Certificate Transparency (CT), Google's append-only, publicly auditable certificate logs that make mis-issuance visible. Earlier segments cover Apple's WWDC anti-fingerprinting and tracker-permission changes in Safari, follow-up on VPNFilter scanning of Ukrainian networks, and a clever side-channel attack in which CSS blend-mode compositing time reveals pixels of a cross-origin iframe, such as a victim's Facebook name. Microsoft Research released a post-quantum fork of OpenVPN. Microsoft let a 120-day disclosure window lapse on a JScript use-after-free remote code execution bug, Valve fixed a decade-old Steam UDP overflow, tens of thousands of Redis servers sit exposed, and a patched VBScript IE bug is in the RIG exploit kit.

# Key points

- Apple (WWDC, macOS Mojave, iOS 12): Safari will thwart browser fingerprinting and ask permission before letting social-widget domains such as Facebook track users across sites. Steve and Leo doubt how practical per-site prompts will be.
- VPNFilter after takedown: scanners (JASK, GreyNoise) still probing port 2000 on MikroTik routers in Ukrainian address space, suggesting the campaign continues.
- Cross-origin leak: CSS3 mix-blend-mode compositing in Skia (used by Chrome and Firefox) was not constant time; a malicious page can overlay an iframe, time pixel operations, and infer the iframe's content (a Facebook name in about 20 seconds). Fixed by making the pipeline constant time, which also made it faster.
- Post-quantum: Shor's algorithm threatens RSA and elliptic curve public-key crypto while AES-256 and SHA-2/SHA-3 are considered safe; Microsoft Research's OpenVPN fork supports Frodo (learning with errors), SIKE (supersingular isogeny) and Picnic (signatures).
- Microsoft bought GitHub for 7.5 billion dollars; some developers are moving to GitLab.
- ZDI published a Windows JScript error-object use-after-free RCE zero-day after Microsoft failed to patch within the disclosure window; mitigation was to avoid untrusted content. A previously patched VBScript flaw is exploited via Word documents in the RIG kit.
- Valve patched a Steam client single-packet RCE: the first UDP fragment lacked a length check, present for about a decade; ASLR had been added the previous summer.
- Around 72,000 Redis servers are exposed without authentication; Imperva honeypots show attackers planting SSH keys for persistence.
- Chrome 67 removed HPKP (about 0.04% adoption) because of denial-of-service and hostile-pinning risks; sites should use the Expect-CT header instead.
- Intel Optane persistent memory is shipping; Steve expects it to change computer architecture.
- Certificate Transparency: logs are append-only, protected by Merkle tree hashes and publicly queryable, with monitors and auditors layered on; DigiCert was the first CA to run a log (2015), Let's Encrypt followed. CT augments rather than replaces the chain of trust; Steve thinks it is the future and distinguishes it from a blockchain.

# Other segments

- Listener question on Norton Disk Doctor similarity: Steve recounts refusing to sell SpinRite to Peter Norton and later finding his BIOS probing code copied in a Norton product; he chose not to sue.
- WWDC aside: iOS 12 performance improvements for older iPhones.
