# Summary

Steve opens with Cisco Talos's discovery of several remote-code-execution bugs in Apple's image-handling code (tiled TIFF, OpenEXR, DAE and BMP parsing), fixed in iOS 9.3.3 and OS X 10.11.6; he stresses manual updating and suggests gateways could simply block rarely used legacy file types. Next comes the alleged Russian intrusion into the DNC and staffers' personal accounts, including a consultant who kept ignoring Yahoo's "state-sponsored actors" warnings. Leo and Steve then cover the Second Circuit ruling that Microsoft need not hand over email stored in Ireland, and a Ninth Circuit ruling treating continued access after a cease-and-desist as a CFAA violation (Power Ventures vs Facebook). A Grace Hopper clip showing the physical length of a nanosecond is played. Steve notes a pfSense bug-fix release, criticises the CUJO consumer security appliance for working through deliberate ARP spoofing, and moves his link handling from bit.ly to a GRC "Link Farm" page. Errata, SQRL design notes (alternate identities, a static secret for server-side encryption, why SQRL passwords can be weaker) and twelve listener questions follow, covering contractor access, Firefox's private certificate store, key-size equivalence, cloud versus local storage, and the point that VLAN tags are not a security boundary.

# Key points

- Apple image-parsing bugs (Cisco Talos): five code-execution flaws across TIFF, OpenEXR, DAE and BMP handling in Image I/O and Core Graphics; reachable via iMessage, web pages, MMS or attachments; fixed in iOS 9.3.3, OS X 10.11.6, tvOS and watchOS; some older OS X releases left unpatched.
- Advice from Talos that Steve endorses: block file types at the network gateway if the organization never legitimately sees them (for example TIFF); legacy formats keep biting.
- Russia/DNC: analysts say Russian actors penetrated DNC mail and some staffers' personal accounts; leaks went through WikiLeaks; a consultant reportedly received daily Yahoo state-actor warnings and kept using the account. Steve says she should have moved to a managed account.
- Microsoft v. US (Second Circuit): the Stored Communications Act does not reach data stored outside the US, so investigators must use a mutual legal assistance treaty with Ireland.
- Facebook v. Power Ventures (Ninth Circuit, per Leo): accessing a site after a cease-and-desist can violate the CFAA even if the user requested it; seen as a bad precedent.
- Grace Hopper's wire-length demonstration: a nanosecond is about 11.8 inches of light travel, a microsecond about 984 feet.
- GRC "Link Farm" page replaces bit.ly links after a listener noted links being hijacked.
- pfSense update: roughly 60 bug fixes; Steve praises actively maintained router software versus consumer blue-box routers.
- CUJO appliance: intercepts traffic in gateway mode via ARP spoofing and samples only flow metadata (IPs, ports, volumes); Steve dislikes the design and the monthly fee.
- Errata: Ubiquiti EdgeRouter does support OpenVPN (CLI-configured); in a RAID 6 recovery the last drive to fail is the one that must be recovered.
- Facebook Messenger secret conversations: Facebook holds the key that recovers the local log key, so a court order plus a seized phone could expose the local log; a modified message would fail signature checks rather than leak.
- SQRL: per-site identity is an HMAC of the domain, so an "alt ID" string appended to the domain gives separate identities; a new static-secret feature lets a site store data it cannot decrypt; because the identity never crosses the wire, the local SQRL password can be less demanding than a web password.
- Listener Q&A: outsourced contractor chains leave weak access control; Firefox's own certificate store can sidestep a corporate-installed root but proxies may still block it; iCloud syncs Wi-Fi passwords across Apple devices (disable auto-join); 256-bit AES versus 4096-bit RSA are rule-of-thumb equivalences, not exact; CryptoDrop is not yet available; VLANs are administrative, not isolation, and a plain four-port router switch offers no separation.
- Ubiquiti EdgeRouter X (about $50) praised for multiple physical interfaces, dual-WAN load balancing and per-network DNS policy; Steve himself uses a Soekris box with pfSense.
