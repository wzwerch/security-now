# Summary

Steve opens with Google's new Open Source Software Vulnerability Rewards Program (rewards from $100 up to $31,337), which also covers third-party dependencies of Google's projects. He then examines the claim that TikTok leaked 2.05 billion records; Troy Hunt stayed skeptical, the forum thread was deleted and the claimant banned, so it appears not to have been a real breach. Chrome shipped its sixth in-the-wild zero-day fix of 2022 (CVE-2022-3075, Mojo), and Steve demonstrates concern over a Chromium behavior that lets any page write to the clipboard without user gesture. Checkmarx found that `pip download` can run a package's setup.py when only an sdist (tar.gz) is available, which malware authors exploit. An Oxford physicist's Financial Times piece calling quantum computing a hype bubble prompts Steve to note that post-quantum cryptography is worth doing regardless. Listener feedback covers LastPass code-tampering worries and telco practices of disabling activity LEDs. The main topic is Symantec's research that 1,859 mobile apps (98% iOS) embedded AWS credentials, 77% of them valid, often inherited from shared third-party SDKs, exposing data of banks, intranet platforms and gambling operators.

# Key points

- Google OSS VRP: rewards for bugs in Google open source projects (Golang, Angular, Fuchsia and others) and their dependencies; Google's VRPs have paid over $38 million on 13,000+ submissions; Google cites a 650% year-over-year rise in open source supply chain attacks. Steve sees bug bounties as now mainstream and a viable career path.
- TikTok 2.05 billion-record leak claim (from the BlueHornet/AgainstTheWest group, 790 GB database): TikTok denied; Bob Diachenko first called it real, Troy Hunt called evidence inconclusive; the forum post was removed and the poster banned for lying about breaches. Leo recounts the Brian Krebs/Ubiquiti retraction as a lesson in skepticism.
- Chrome CVE-2022-3075 (insufficient data validation in Mojo IPC) exploited in the wild; fixed within days; sixth Chrome zero-day of 2022. Chromium derivatives need updating too.
- Chromium lets a foregrounded page write text or images to the clipboard with no permission or gesture (reading does require permission); Steve worries about clipboard poisoning, for example swapping a cryptocurrency address; Chromium and Edge engineers agreed to tighten it, and Firefox and Safari require some page interaction.
- Checkmarx: `pip download` executes setup.py for packages published only as source tarballs (no wheel), so merely downloading a malicious PyPI package can run code; nearly a third of packages trigger autorun-style install code.
- Oxford physicist Nikita Gourianov called quantum computing a financial bubble with no practical product; Steve cautions "impossible until it isn't" and notes public-key crypto (RSA, elliptic curve, 25519) would be at risk, so post-quantum migration is sensible and will take very long.
- Symantec (Kevin Watkins): 1,859 apps with hard-coded AWS credentials, 77% with valid tokens, 47% with S3 access to millions of files, 53% sharing tokens with other apps via common third-party SDKs.
- Case studies (anonymized): an intranet-platform SDK exposing data of over 15,000 companies because a key meant for translation service had full access; a digital identity SDK in several banking apps exposing over 300,000 biometric records; a shared gambling-platform library across 16 betting apps exposing root-level AWS access.
- Steve's advice: apps should fetch scoped, short-lived credentials over authenticated channels; S3 buckets being open by default and developers skipping documentation are root causes; Leo suggests competency standards for developers.
- Csurf, the npm CSRF-protection library, was declared vulnerable and deprecated after Fortbridge found a CSRF flaw in it.
- Listener note on LastPass: stolen source code is not the same as modified code, and repositories keep audit trails; if the CEO's statement is trusted there is no added danger.
- A Canadian telco listener said his employer disabled activity LEDs on switches and routers via undocumented commands to frustrate optical observation of traffic, a defense-in-depth trade-off.
- Black Hat 2022 slides were mirrored publicly by a researcher while the conference lagged on publishing.
