# Summary

Steve marks the end of the show's 17th year, then reviews August 2022 Patch Tuesday: 121 CVEs (141 including Edge and Secure Boot), nearly triple the previous August and the second largest release of the year. The notable item is DogWalk (CVE-2022-34713), a path-traversal flaw in the diagnostics tool's .diagcab handling that Microsoft had dismissed as not a vulnerability in 2020 and that was by then exploited. Other items include a wormable-looking SMB flaw in Windows 11, Exchange elevation bugs, an NFS flaw with CVSS 9.8 and an Outlook crash-on-email bug. Facebook began testing default end-to-end encryption in Messenger, and Cyble found over 9,000 completely open VNC servers, some controlling industrial systems. Steve urges people to hold their own domain registrations, recommends the Cyotek WebCopy cloning tool, and answers listener mail on attack surface management and how SpinRite's per-customer signed executables interact with file reputation. The main topic is the UC San Diego and CU Boulder paper "Open to a fault" showing that occasional hardware faults in RSA signature computations during TLS 1.2 and earlier handshakes let a passive observer compute a server's private key.

# Key points

- August 2022 Patch Tuesday: 121 CVEs (17 critical), plus 17 Edge and 3 Secure Boot fixes; two publicly known, one actively exploited.
- DogWalk (CVE-2022-34713, MSDT): a crafted .diagcab file writes an executable into the user's Startup folder; reported December 2019, rejected by Microsoft as by design, fixed August 2022; the diagnostic tool skips Mark of the Web checks and browsers download the file without warning (0patch's comments).
- Windows 11 only SMB server remote code execution bug (potentially wormable if exposed; workaround of disabling SMBv3 compression), three critical Exchange elevation of privilege bugs needing Extended Protection, the fourth consecutive month of an NFS remote code execution fix (CVSS 9.8), and CVE-2022-35742 where a malformed email crashes Outlook on every start until removed via another client.
- Steve's recurring rule: only publicly expose services that must be anonymous (web, email); put everything else behind a VPN, SSH or an overlay network such as Tailscale. He argues Microsoft is drifting toward enterprises and should leave consumers on Windows 10 with only fixes.
- Facebook (Sara Su) began testing default end-to-end encrypted Messenger chats for some users; the timing follows a Nebraska police order for a mother-daughter message exchange, though Facebook denies a link. Steve stresses defaults matter and frames it as a question of the greater good.
- Cyble scan: over 9,000 VNC servers with no authentication (China 1,555, Sweden 1,506, US 835, Spain 555, Brazil 529), including HMI/SCADA consoles such as pump controls; more than six million connection attempts per month on port 5900; many VNC products only support passwords of up to eight characters.
- Domain ownership advice: if a web designer registered your domain under their own account you have essentially no recourse if they disappear or die; register under your own account with auto-renew and current contact data; Steve suggests a "next of kin" field for registrations. Hover is his registrar; a listener-webmaster creates a separate account per client.
- Cyotek WebCopy is Steve's tool for making locally browsable site copies.
- Open source project quote: running a successful project is "Good Will Hunting" in reverse.
- Listener follow-ups: airline Wi-Fi may block image uploads by firewalling the messenger's media endpoint; Windows 11 now has Copy as path in the normal context menu (Ctrl+Shift+C); attack surface management tools (for example Palo Alto Cortex Xpanse, Shodan, BitSight) scan the internet non-invasively, and ShieldsUP! avoids completing connections by sending RST after a SYN/ACK.
- Steve plans uniquely built, individually EV-code-signed SpinRite executables using a DigiCert hardware security module, which means hash-reputation systems will see each file as new.
- "Open to a fault" (UCSD and CU Boulder, USENIX Security 2022): from 5.8 billion observed TLS handshakes (2.7 billion server signatures) they found nearly 2,000 non-validating signatures and derived private keys including three used by Baidu for hundreds of hosts, plus 127 keys from active scans. Cause: faults in the Chinese Remainder Theorem optimization of RSA signing with PKCS#1 v1.5 padding (Lenstra 1996, Weimer 2015 scans); countermeasure is verifying the signature before sending (about 10% cost), which most open source libraries now do but some proprietary stacks do not. Impact is worst without forward secrecy because stored traffic can be decrypted later. TLS 1.3 encrypts the handshake and uses RSA-PSS, but TLS 1.2 stays for years.
