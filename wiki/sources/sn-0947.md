# Summary

Steve starts with Microsoft's Secure Future Initiative, which will move identity signing keys into HSMs, and notes this confirms the earlier stolen Azure signing key had been handled outside an HSM. He then covers Trend Micro ZDI's disclosure of four Exchange Server zero-days (one RCE via deserialization) that Microsoft declined to fix, the Apache ActiveMQ CVE-2023-46604 exploitation (SparkRAT, HelloKitty, TellYouThePass), Mandiant's post-exploitation findings for Citrix Bleed, and his proposal for autonomous patching of enterprise edge appliances. Other news: the release of CVSS 4.0, an attack on Ace Hardware, Google dropping its Web Environment Integrity "web DRM" proposal, Cisco's BadCandy implant report, Bitwarden browser extension passkey support and a dramatic SpinRite 6.1 SSD recovery. The main topic is EU eIDAS 2.0 Article 45, which would force browsers to trust root certificates designated by any EU member state or approved third country, enabling traffic interception; hundreds of experts and organizations including Mozilla and Google objected.

# Key points

- Microsoft's Secure Future Initiative: HSM-backed signing keys, confidential computing and automated key rotation; Steve's lesson is that more security layers are always better.
- ZDI-23-1578 (ChainedSerializationBinder deserialization RCE as SYSTEM) and three URI-validation information disclosures in Exchange; all require authentication, which criminals can obtain.
- Apache ActiveMQ CVE-2023-46604: maximum severity RCE, exploited since October 10 (Arctic Wolf, Huntress), patched October 27; more than 4,770 of 9,200 exposed servers vulnerable.
- Citrix Bleed (Mandiant): zero-day use since late August; post-exploitation with net.exe, SoftPerfect netscan, 7-zip, certutil, LSASS dumping, a Slack-based backdoor (FREEFIRE) and remote tools (Atera, AnyDesk, Splashtop); four clusters tracked; no request logging exists for the vulnerable endpoint.
- Steve's proposal: enable default-on automatic updates and periodic "phone home" check-ins for enterprise appliances, with admin alert contacts.
- Security workforce shortfall of about four million (2023 Cyber Workforce Study: 5.5 million professionals, 14,865 surveyed).
- CVSS v4.0 adds finer metrics, OT/ICS/IoT metrics (Safety, Automatable, Recovery), Provider Urgency and Threat Metrics; scores will not map one-to-one to v3.1.
- Ace Hardware: cyberattack on October 30 affected about 200 servers and 1,000 systems; stores stayed open.
- Google's Web Environment Integrity ("Web DRM") proposal is dead.
- Cisco Talos documented BadCandy, now in version 3; Shadowserver no longer detects infected devices although most remain unpatched.
- Bitwarden browser extension 2023.10.0 supports FIDO2 passkeys; passkey import/export is planned.
- SpinRite 6.1 level 4 run on a failing SSD: 28 hours, 6,199 command timeouts, 183 defective sectors repaired, and read speeds near the drive start went from 2.2 MB/s to 430 MB/s.
- eIDAS Article 45 / QWACs: states and approved third countries could designate trusted keys that cannot be revoked without their consent, and security checks beyond ETSI rules would be forbidden. An open letter had 466 signatories from 36 countries; Mozilla, Cloudflare, ISRG, Linux Foundation and others wrote a second letter. Steve expects providers to threaten withdrawal as they did over encryption backdoors.
- Listener items: IPv6-only testing shows many major sites still unreachable; leaking a TLS private key enables impersonation but needs DNS or traffic redirection; duplicate RSA primes from low-entropy boot-time key generation; Steve uses four-drive RAID 6 arrays.
