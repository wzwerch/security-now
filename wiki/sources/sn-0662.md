# Summary

Leo returns. Steve updates ongoing stories: Russia versus Telegram escalates to blocking 50 VPN and proxy services, and cloud providers move to end domain fronting; Drupalgeddon2 has now compromised 350-plus sites serving a coin miner, including a Lenovo site. A VU Amsterdam team demonstrated GLitch, a WebGL-based Rowhammer attack that compromises an Android phone from a web page. A new SynAck ransomware, Twitter's admission that it logged unmasked passwords, Android P security improvements and the looming GDPR deadline fill the middle. Deliberate JavaScript package backdoors worry Steve about the web's script-inclusion model. The main item is a Heise report of eight new Spectre-class (Spectre-NG) vulnerabilities, one reportedly much worse for cloud virtual machine isolation.

# Key points

- Telegram in Russia: the IP blocks were lifted after collateral damage, but AWS, Google and Microsoft began blocking domain fronting. Amazon told Signal it could not use a third-party domain to disguise traffic. Russia blocked 50 VPN/proxy services; Steve expects governments to win such fights.
- Domain fronting explained: connect (DNS, TLS SNI) to an innocuous provider domain, then request another hidden service inside the encrypted tunnel; both censorship evaders and criminals used it.
- Drupalgeddon2: a public spreadsheet lists 350-plus compromised Drupal sites delivering a JavaScript cryptominer to visitors (including Lenovo and a US labor board). Imperva's "Kitty" campaign added a Monero miner and persistent PHP backdoor. Advice: compromised sites must be rebuilt, not just patched.
- GLitch (Vrije Universiteit): WebGL timing plus GPU memory sharing on Android phones allows Rowhammer bit flips and device compromise in about two minutes via Chrome or Firefox. Mitigations: coarser timers, DRAM refresh changes, and future Rowhammer-aware hardware.
- Firefox 60 brings opt-out sponsored stories via Pocket on new tabs, privacy-preserving and disableable.
- Deliberately backdoored npm packages (a cookies-related package three levels deep) illustrate the risk of pulling third-party JavaScript; Steve says he has no solution and suggests sandboxing.
- SynAck ransomware uses ECIES with secp192r1 and AES-256 per file; the ransom note styles itself as an optional recovery service.
- Twitter asked about 330 million users to change passwords after a bug stored passwords in an internal log before bcrypt hashing; GitHub had a similar incident. Steve notes SQRL would store only public keys and avoid this class of problem.
- Android P: restricts /proc/net visibility to VPN-like apps, blocks cleartext HTTP, uniform fingerprint UI, background camera/microphone blocking, encrypted backups, MAC randomization experiments and DNS over TLS.
- GDPR takes effect May 25; fines up to 20 million euros or 4% of turnover; a "GDPR Shield" service that simply blocks EU visitors via a script was mocked and promptly went offline. Steve keeps no web server logs; Leo wonders about IP-address logging and download counting.
- Over one million Dasan GPON routers attacked via an authentication bypass (appending a path suffix) and command injection, by a botnet controlled from Vietnam.
- Alex Ionescu reported that Windows 10 Meltdown patches before 1803 had a flaw returning the full kernel page table to user space; fixed only in 1803.
- Microsoft published a roughly 950-page Windows command reference; Twitter appears to be preparing encrypted direct messages with elliptic curve keys.
- Spectre-NG: Heise reports eight new CVEs reserved (undisclosed), four rated high by Intel, one enabling VM-to-host or VM-to-VM attacks and affecting SGX; patches planned in two waves (May and August); ARM also affected, AMD unknown. Steve says end users are less at risk than hosting providers.

# Other segments

- Azure Sphere recap: open chip/OS but Azure-tied security service; cost unknown.
- Capital One virtual card numbers question; Steve views them positively.
- SpinRite testimonial about a sister's non-booting computer.
- SQRL: Steve finished the client and started the forum server; plans a TWiT special.
