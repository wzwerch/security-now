# Summary

Intel says it has released production Spectre microcode only for some Skylake platforms, with other families still in beta, and Steve wonders aloud whether some processors may prove unfixable in microcode. Cisco's adaptive security appliance (ASA) flaw, first thought limited to the VPN component, now affects many more models and subsystems, is rated 10 out of 10, and is being exploited against roughly 200,000 exposed devices. Other news: MIT Technology Review on radio-sniffing drones (illustrated by weak wireless-keyboard obfuscation), Winter Olympics hacking activity, Kaspersky suing the US over the federal ban, Apple's iBoot source code leaking via an intern's circle of jailbreak friends and being taken down by DMCA notice, a critical Broadcom Wi-Fi driver update for certain ThinkPads, and the WordPress 4.9.3 release that broke automatic updates (fixed in 4.9.4 but requiring manual action). The closing segment collects cryptocurrency antics: about 4,300 websites (including government and university sites) served a Coinhive Monero miner after the third-party BrowseAloud accessibility script was altered; Salon offering an ad-blocker opt-in to mining; a water-treatment SCADA network found mining Monero; Russian nuclear scientists arrested for mining on a supercomputer; and power-hungry mining operations straining grids in Iceland and Washington state.

# Key points

- Intel Spectre microcode: Skylake production updates released; Broadwell, Haswell, Kaby Lake and Coffee Lake pending; Microsoft's earlier registry opt-out remains what InSpectre toggles. Second-Tuesday patching was preempted because Microsoft shipped the February rollup a week early, plus a Flash fix.
- Cisco ASA: affected models more than doubled and vulnerable subsystems rose from 1 to 11; patches exist; operators should update immediately.
- Radio drones: unsecured wireless mice and keyboards (some using a static XOR mask) can be sniffed from a distance, so distance is not protection.
- Kaspersky's complaint argues the US ban in the 2018 NDAA is an unconstitutional bill of attainder; Steve notes any closed, auto-updating software (including Windows 10) is a similar trust risk.
- iBoot leak: roughly three-year-old iOS 9 boot code posted to GitHub; Apple stresses its security does not rely on secrecy; the root-of-trust code changes slowly so researchers gain leads. Steve sees it as an insider/social-engineering failure, not a cryptographic one.
- Lenovo ThinkPad models using the Broadcom BCM4356 Wi-Fi chip need the updated Windows 10 driver; the flaw is rated 10 out of 10 but needs radio proximity.
- WordPress 4.9.3 fixed 34 bugs but broke auto-update; self-hosted sites must update manually to 4.9.4.
- BrowseAloud compromise: a modified script on the vendor's server injected a Coinhive miner into thousands of public-sector sites, illustrating third-party script supply-chain risk.
- Salon.com asks ad-block users to allow mining; Steve considers consented, efficient browser-side mining a possible micropayment model.
- SCADA at a water plant and a Russian nuclear lab were found mining Monero or bitcoin.
