# Summary

Microsoft announced that Edge will adopt Manifest V3, Google's two-year-old redesign of the browser extension API that replaces the powerful Web Request API with a declarative rule system. Steve explains the security and performance rationale, the ad-blocker backlash, and the compromise that raised the rule limit from 30,000 to 150,000. October Patch Tuesday fixed 87 flaws, among them a wormable-looking Windows TCP/IP flaw dubbed Bad Neighbor (an IPv6 router advertisement bug, CVSS 9.8) for which only a crash proof of concept existed. Zoom began a technical preview of true end-to-end encryption where meeting hosts generate and distribute keys, though Steve criticizes the CEO's comparison to other messengers. Tripwire disclosed a critical pre-authentication flaw in SonicWall NSA firewalls with nearly 800,000 hosts exposed. Two minor out-of-cycle Microsoft patches (HEVC codec and Visual Studio Code) get brief mention. The main segment summarizes The DFIR Report's step-by-step analysis of a Ryuk ransomware attack that went from a phishing click to every machine encrypted in about five hours, using BazarLoader, Cobalt Strike, the legitimate AdFind utility and Zerologon.

# Key points

- Manifest V3 and the Declarative Net Request API: extensions register rules instead of seeing every request; Google said 42% of malicious extensions detected in 2018 abused Web Request. Critics (uBlock Origin, NoScript authors, Brave, Opera, Vivaldi, Mozilla) worried about reduced blocking power and the rule cap. Steve hopes Firefox keeps the old model and admires the uBlock Origin author.
- October 2020 Patch Tuesday: 87 fixes, 11 critical, six publicly known but none exploited at release. CVE-2020-16898 (Bad Neighbor) is in the ICMPv6 Router Advertisement handling; a crash PoC is trivial. Rapid7 advised patching or disabling RDNSS handling and told organizations to expect one to five "patch now" events monthly.
- Zoom E2EE preview: opt-in per meeting at account level, up to 200 participants, available to free and paid users, same GCM encryption but with host-generated keys distributed via public-key crypto; a green shield indicates it. Phase 1 of 4.
- SonicWall NSA (CVE-2020-5135): stack-based buffer overflow in the custom-protocol handler of the HTTP/HTTPS management and SSL VPN service, reachable unauthenticated; Shodan showed 795,357 exposed hosts; Tripwire withheld details. Steve expects many devices never to be patched.
- Out-of-cycle Microsoft fixes: HEVC codec (a Store add-on) and Visual Studio Code malicious package.json handling; both considered minor.
- DFIR Report case: a user opened a lure disguised as a PDF (actually a signed executable with a double extension), loading BazarLoader into memory and phoning home. After a roughly 2.5-hour pause, operators used built-in Windows tools to map domain controllers, exploited Zerologon, spread via SMB and WMI, deployed Cobalt Strike Beacons, used AdFind for reconnaissance, encrypted backup servers first, then other servers and workstations, and finally the domain controller. Ryuk wipes itself afterward.
- BazarLoader uses signed binaries, in-memory backdoors and the EmerDNS blockchain-based .bazar domain for command and control; Cobalt Strike is a commercial red-team tool (cracked or trial copies are abused); AdFind is a legitimate Active Directory query utility.
