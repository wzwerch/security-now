# Summary

Let's Encrypt explained that its cross-signature from IdenTrust's DST Root X3 expires on September 1, 2021; about a third of Android devices (versions before 7.1.1) do not trust the Let's Encrypt root and will lose access to its sites, so site operators can serve an alternate chain via ACME and users can install Firefox, which carries its own root store. Chrome and Apple patched more zero-days, with Google linking three iOS flaws, three Chrome flaws and the Windows kernel bug to one coordinated campaign. Ransomware victims included Mattel, Compal, Capcom and Campari, and the Ryuk gang averages about 20 attacks a week. China's Tianfu Cup saw 11 of 16 targets compromised. Steve reflects on Woody Leonhard's retirement, restates that the encryption dilemma has no solution after a new EU Council draft resolution, notes a Mississippi pilot streaming residents' doorbell video to police, and recounts a stream of WordPress plugin vulnerabilities. The main topic is Samy Kamkar's NAT Slipstreaming, where a visited web page tricks a router's application-level gateway into opening a path to internal machines; browsers are blocking the SIP ports it abuses.

# Key points

- Let's Encrypt: its own ISRG Root X1 is trusted by Android 7.1.1 and later (about 66% of devices in Sept 2020), but the other 34% rely on the cross-signed DST Root X3, which expires September 1, 2021. From January 11, 2021 the default ACME chain leads to ISRG Root X1, with an alternate chain available (Certbot 1.6.0 onward). Another cross-signature is unlikely because a cross-signing CA takes on responsibility for the other's certificates. This connects to Chrome's own root store plans.
- Chrome 86.0.4240.183 fixed a V8 flaw exploited in the wild, and an Android Chrome sandbox escape (heap buffer overflow in a UI component) was also fixed; Google TAG found three Chrome zero-days in two weeks.
- iOS 14.2 closed three zero-days (font parser remote code execution, kernel privilege escalation, kernel memory disclosure) believed to be used as one sophisticated chain, which Steve guesses was targeted nation-state work.
- Ransomware: Mattel (no data stolen), Compal (DoppelPaymer), Capcom (Ragnar Locker, about 1 TB taken), Campari (Ragnar Locker, 15 million dollar demand, with proof-of-theft documents). Ryuk's average payment is about 48 bitcoin and its largest known about 2,200 bitcoin.
- Tianfu Cup: China's Pwn2Own analogue; 15 teams, 11 of 16 targets cracked (Adobe Reader, iPhone 11 Pro, an ASUS router, CentOS, Docker, Chrome, Windows 10, Firefox, Galaxy S20, a TP-Link router, VMware ESXi); Qihoo 360 won about 744,500 dollars.
- Woody Leonhard retired, remarking that Windows went from wobbly infrastructure to a wobbly OS; Steve remains enthusiastic about the work.
- EU Council draft resolution on encryption: Steve says strong encryption cannot be uncreated and any mandated weakening would only affect honest users.
- Jackson, Mississippi pilot let residents' video doorbells stream to police; the EFF warns it captures neighbors, and an FBI analysis noted doorbells can also tip off suspects.
- WordPress plugins: Ultimate Member (three flaws rated 10, 10 and 9.9, over 100,000 sites) plus a run of other plugin flaws; Steve advises sequestering any WordPress instance on its own network segment.
- NAT Slipstreaming: application-level gateways (needed for FTP, SIP, H.323, IRC DCC) watch control traffic and open firewall pinholes; malicious JavaScript in a browser can imitate such traffic so the router maps an external path to an internal port. Vendors responded by blocking browser connections to SIP ports 5060 and 5061. Steve advises disabling unneeded ALG features on routers.
