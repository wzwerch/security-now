# Summary

Tom Merritt replaces Leo Laporte, who is on vacation. Steve starts with a newly exploited Internet Explorer zero-day affecting all versions, for which Microsoft offers a temporary "Fix it" shim, and warns that browsing with IE is risky since ads and user content on respectable sites can carry exploits. They discuss a California school district paying to monitor students' public social media posts, and Trend Micro's observation that attackers reverse-engineer Java 7 patches to exploit Java 6, which Oracle no longer fixes. Steve reads a report in which EFF co-founder John Gilmore says NSA staff shaped the complexity of IPsec and that its role in IPv6 was downgraded from mandatory to recommended, and he endorses Bruce Schneier's "trust the math" while insisting the system around the math can be fixed. SpinRite's first development phase is finished, with native direct-hardware drivers delivering about 93 minutes per terabyte on a Level 2 scan, and Steve will pause to write up his authentication proposal. The listener segment covers why elliptic curve parameters from NIST are now suspect while ECC itself is sound, a worry about whether privacy exists, a Sartre-based argument for privacy, an onion-routing-like layered encryption idea for SMTP metadata, Steve's coffee method, how Touch ID might work, and why mixing entropy sources keeps random number generators safe.

# Key points

- IE zero-day exploited against IE8 and IE9 with a flaw in how objects are freed; Microsoft released a Fix it MSHTML shim before a patch. Steve urges using another browser and per-site script control (NoScript in Firefox, NotScript in Chrome).
- Chrome had become the most used browser by some counts, though Steve finds it memory hungry.
- Glendale Unified paid Geo Listening about 40,500 dollars to categorize public posts by about 13,000 students; Steve and Tom debate it as nanny-state versus teaching that posts are public.
- Trend Micro: about half of Java users still on Java 6 after support ended in February; attackers use Java 7 patches as a roadmap to attack the unpatched older version. Steve suggests Java was a mistake as a browser plug-in and advises using it only as a local runtime.
- Gilmore claimed NSA involvement made IPsec so complex that cryptographers could not analyze it, IPsec in IPv6 was downgraded in December 2011, and phone standards lack end-to-end encryption. Steve says speculation needs evidence but crypto math remains sound; he avoids BitLocker in favor of TrueCrypt.
- Steve's SpinRite 6.1 core work ended: its own extended memory manager and ATA bus-mastering drivers match manufacturer maximum throughput; AHCI support comes after the authentication write-up.
- Elliptic curve cryptography is not weakened by the Dual_EC affair; the issue is NIST's standard curves whose parameters have no known origin, since a curve can be chosen with a hidden trapdoor. Discrete-log systems offer much stronger security per bit than RSA factoring.
- Reader mail shows widespread fatalism and self-censorship; Steve says tools and protocol upgrades will follow, and he searched Wikipedia over HTTPS to avoid leaving a trail on Google.
- A reader's SMTP idea (encrypt to the recipient, then recipient's domain, then sender's domain) is essentially onion routing for email.
- Touch ID: probably extracts fingerprint features rather than storing images, and presumably hashes or unlocks via an intermediate secret; details were unknown at the time.
- Entropy: the Linux kernel mixes Intel's hardware RNG with other event-timing sources in an entropy pool, and mixing in more entropy can never reduce randomness (Steve's "can't unscramble an egg").
