# Summary

The episode opens with Microsoft cutting Windows Update for Windows 7 and 8.1 on seventh-generation Intel, AMD Ryzen/Bristol Ridge and Qualcomm 8996 hardware, which Steve sees as an understandable but real constraint for anyone avoiding Windows 10. Cisco found a Telnet-reachable remote code execution flaw in IOS and IOS XE devices through the leaked Vault 7 documents, and Ubiquiti's airOS products had a command injection bug tied to a 1997-era PHP, disclosed after months of vendor silence. Check Point found WhatsApp and Telegram web-client account-takeover flaws, and the FBI indictment of four people for the 2014 Yahoo breach exposed how attackers stole the user database and minted their own session cookies. Steve also covers eBay retiring its hardware token in favor of SMS codes, a class-action settlement over an app-connected adult toy that logged usage, a claim that antivirus is no longer needed, a US-CERT warning on HTTPS interception, the Pwn2Own results, an absurdly insecure oil-and-gas login page, and a second LastPass extension flaw reported by Project Zero. The closing feature is a publisher's proposal that browsers let sites forbid specific behaviors from ad scripts, which Leo compares to Google AMP.

# Key points

- Microsoft's support policy: Windows 7 and 8.1 get updates only on hardware of their own era; new CPUs (Intel 7th generation Kaby Lake, AMD Ryzen/Bristol Ridge, Qualcomm 8996) show an "unsupported hardware" error. Steve bought Haswell hardware deliberately to keep Windows 7 supported until 2020; Leo argues the back-porting effort for new CPU power management is a real technical cost, not only a push to Windows 10.
- Cisco IOS Cluster Management Protocol flaw found in Vault 7: remote code execution over Telnet on hundreds of IOS and IOS XE switches and routers; mitigation is disabling Telnet or restricting it with an access control list, since TCP handshakes validate source addresses.
- Ubiquiti airOS (not EdgeMAX, UniFi or AmpliFi) had a command injection in a ping-test CGI script, exploitable through a single GET request because the old PHP had no CSRF protection and ran as root. SEC Consult's researcher went public after silence from the vendor, withholding the proof of concept, and patches followed two days later.
- Check Point reported WhatsApp Web and Telegram Web file-upload authentication bypass issues that could take over accounts via a malicious image; both fixed server-side quickly.
- Yahoo breach: an FBI indictment of three Russians and one Canadian describes spearphishing since 2014, access to the Account Management Tool and a November 2014 backup of the user database (over 500 million accounts), forged session cookies that bypassed passwords, targeting of about 6,500 accounts, spam contact harvesting from up to 30 million, and help from Russian intelligence officers. Steve says Yahoo had downplayed security staff warnings.
- eBay announced retiring its hardware token ("football") in favor of SMS PINs, which Steve calls less secure than TOTP; he describes printing the TOTP setup QR codes for backup, while Leo uses Authy. NIST has deprecated SMS verification.
- Standard Innovations agreed to a $3.75 million class-action settlement over its We-Vibe app, which allegedly collected usage data and email addresses without consent.
- Gizmodo's "you don't need antivirus anymore" piece matches Steve's view that third-party AV "shimware" widens attack surface; US-CERT advised that HTTPS interception weakens TLS security.
- SpinRite and USB: drives must be attached at boot for the BIOS to expose them to SpinRite; native USB support is planned after SpinRite 6.1.
- Pwn2Own 2017 (10th anniversary, about $1 million in prizes): 21 successful exploits across Adobe Reader, Safari on macOS, Edge, Ubuntu, Flash, Firefox and VMware Workstation, many chaining use-after-free or type confusion bugs with kernel escalation; Tencent's Team Sniper won a guest-to-host VMware escape for $100,000 and Chinese teams dominated.
- Oil and Gas International offered a login with no HTTPS and password email recovery, complained when Firefox flagged it as not secure, and was told that was intended behavior.
- Tavis Ormandy found a LastPass extension flaw where a trusted subdomain could be used to call extension functions, enabling password theft or code execution; LastPass neutralized it at once by removing the DNS record for that name, and a longer fix followed.
- Listener topics: key material in hibernation files and RAM, buying used PCs and BIOS reflashing, SQRL for electronic voting, and a correction (Bob Metcalfe founded 3Com, not 3M).
- Publisher proposal (Steve Meyers on Medium): let page authors declare via HTML or CSS which behaviors (audio, popups, focus stealing, redirects) scripts in an ad container may not perform, enforced by the browser. Leo notes Google AMP already restricts ads in a similar way.
