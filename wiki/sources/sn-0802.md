# Summary

Google will block third-party Chromium browsers from using Chrome-only sync APIs starting March 15, 2021. DuckDuckGo passed 100 million queries in a day for the first time. Project Zero published a six-part analysis of a sophisticated early-2020 watering-hole campaign with separate Windows and Android exploit servers; four zero-days were involved, and Steve praises the team's root-cause analysis of each. January's Patch Tuesday had 83 fixes, ten critical, including a Microsoft Defender engine zero-day (CVE-2021-1647) exploited in the wild, and the second phase of Zerologon enforcement was scheduled for the February 2021 update. The NSA advised enterprises to use only their designated resolver and block external DNS-over-HTTPS. Researchers at NinjaLab extracted the private key from a Google Titan FIDO U2F key through an electromagnetic side-channel attack requiring physical access and 6,000 signature observations. After listener feedback on SpinRite, Steve spends the closing segment on the WhatsApp backlash: switching to Signal and Threema, Facebook's heavy-handed rollout, and his argument that on-the-wire encryption is a solved problem, so the practical attack target is endpoint plaintext.

# Key points

- Chrome sync and similar Google-only APIs were being used by some Chromium-based browsers; Google will enforce restriction from March 15, 2021, with synced data remaining reachable via Google account pages and Takeout.
- DuckDuckGo: first day over 100 million searches, 2+ billion a month versus Google's roughly 5 billion a day; default in the Tor Browser.
- Project Zero and Google TAG found two exploit servers (Windows: Chrome renderer plus Windows sandbox escapes using zero-days; Android: older n-day exploits), delivered via iframes on compromised sites, with fingerprinting and slow/fast exploitation paths. Steve stresses root-cause analysis of each bug as the way to prevent repeats.
- Patch Tuesday January 2021: 83 vulnerabilities, 10 critical (codecs, GDI+, Edge, five in RPC); Defender zero-day CVE-2021-1647 in mpengine.dll with public proof-of-concept.
- Zerologon: after the February 9, 2021 patch, Domain Controller enforcement mode makes secure Netlogon RPC mandatory for all Windows and non-Windows devices unless explicitly overridden.
- NSA advisory "Adopting Encrypted DNS in Enterprise Environments": use only the enterprise resolver (encrypted if possible) and block other DoH; Steve agrees.
- NinjaLab Titan key attack: EM side-channel on the NXP A700x secure element, trained on a similar open Java Card chip; ECDSA key extracted; attack needs physical access and costly equipment, so keys remain worth using, and a lost key can be deregistered from services. YubiKeys use the same family of chip and were conjectured affected.
- Steve notes asymmetric schemes such as FIDO (and his SQRL) never share secrets with the server, unlike TOTP.
- Listener feedback: a PayPal token revived with a new battery still worked, supporting press-based (event) one-time codes; SpinRite 6.1 drops diskette and OnTrack-style partition support, but older SpinRite versions remain downloadable for owners.
- WhatsApp backlash: Signal and Threema surged (Threema downloads up 10x), Edward Snowden and Elon Musk promoted Signal, WhatsApp postponed enforcement by 90 days.
- Steve's thesis: network encryption is solved ("all you see on the wire is noise"); because endpoints are the weak point, the best messenger is the one your contacts use and whose business model you understand.
